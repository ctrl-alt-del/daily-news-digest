arxiv:2507.03190 arXiv ✓
Discovering Algorithms with Computational Language Processing
用计算语言处理发现算法
algorithm discovery Monte Carlo tree search reinforcement learning quantum computing
The authors present a framework that treats algorithms as sequences of operations represented as tokens chained by a grammar, with an ensemble Monte Carlo tree search guided by reinforcement learning exploring token chains; it rediscovers, improves and generates algorithms that outperform existing methods on strongly NP-hard combinatorial optimization problems and on quantum computing approaches such as Grover's and QAOA.
→ arxiv.org
arxiv:2507.03194 arXiv ✓
Quantifying Cognitive Bias Induction in LLM-Generated Content
量化 LLM 生成内容中的认知偏差诱导
LLM bias hallucination human decision-making evaluation
Across five LLM families, the authors find that models change the context's sentiment in 26.42% of cases (framing bias), hallucinate on 60.33% of post-knowledge-cutoff questions and emphasize earlier prompt context (primacy bias) in 10.12% of cases; humans were 32% more likely to buy the same product after reading an LLM-written review summary rather than the original review.
→ arxiv.org
arxiv:2507.03198 arXiv ✓
AI-driven Web Application for Early Detection of Sudden Death Syndrome (SDS) in Soybean Leaves Using Hyperspectral Images and Genetic Algorithm
用高光谱图像与遗传算法早期检测大豆猝死综合征的 AI Web 应用
precision agriculture hyperspectral imaging CNN plant disease
The study uses a portable hyperspectral imaging system (398–1011 nm) and a genetic algorithm to select five wavelengths, feeding a lightweight CNN and ten classical ML classifiers; ensemble classifiers, linear SVM and a neural net exceeded 98% accuracy, and the models were deployed in a web app for uploading leaf images.
→ arxiv.org
arxiv:2507.03211 arXiv ✓
DistZO2: High-Throughput and Memory-Efficient Zeroth-Order Fine-tuning LLMs with Distributed Parallel Computing
DistZO2：分布式并行的零阶 LLM 微调框架
LLM fine-tuning zeroth-order optimization distributed training GPU
DistZO2 is a distributed zeroth-order fine-tuning framework combining perturbation parallelism, data parallelism adapted to scalar gradients and a unified 2D parallelism design, plus hardware-aware communication over interconnects such as NVLink; it reports a 3x speedup over ZO2 on OPT-175B and has been open-sourced.

Mixture-of-Experts dynamic routing transformer
The authors hypothesize that neural inhibition in neural populations can improve dynamic routing by suppressing commonly shared signals so the model selects a specialized expert path per sample, and report experimental evidence that the algorithm significantly boosts performance on general tasks.

SI-Agent: An Agentic Framework for Feedback-Driven Generation and Tuning of Human-Readable System Instructions for Large Language Models
SI-Agent：自动生成并调优人类可读系统指令的智能体框架
system prompts LLM agents prompt engineering
