DeepSeek arxiv:2507.14393 arXiv ✓
Adaptive Multi-Agent Reasoning via Automated Workflow Generation
通过自动化工作流生成实现自适应多智能体推理
multi-agent systems reasoning workflow generation LLM
The paper introduces Nexus Architect, an enhanced version of the Nexus multi-agent framework that automatically synthesizes tailored reasoning workflows and iteratively refines agent prompts. Using an off-the-shelf non-reasoning model, it reports up to a 66% higher pass rate than Gemini 2.5 Flash Preview, roughly 2.5x gains over Claude Sonnet 4 and DeepSeek-R1, and more than 3x versus Llama 4 Scout.
→ arxiv.org
DeepSeek arxiv:2507.14406 arXiv ✓
Fail Fast, or Ask: Mitigating the Deficiencies of Reasoning LLMs with Human-in-the-Loop Systems Engineering
快速失败，或提问：以人在回路系统工程弥补推理 LLM 的不足
human-in-the-loop reasoning models uncertainty latency
The paper proposes a human-in-the-loop system that defers queries a reasoning model cannot confidently answer to a human expert, using reasoning-trace length as an uncertainty signal; deferring 7.5% of queries cut Qwen3 235B-A22B’s error rate on difficult MATH problems from 3% to under 1%. Fronting a reasoning model with a large non-reasoning model yielded about 40% latency reduction and 50% cost savings for DeepSeek R1, though “latency drag” limited the gains.
→ arxiv.org

arxiv:2507.14397 arXiv ✓
LIMINAL: Exploring The Frontiers of LLM Decode Performance
LIMINAL：探索 LLM 解码性能的前沿
LLM inference HBM DRAM performance modeling
The paper presents LIMINAL, an analytical performance model for LLM auto-regressive decoding that abstracts application requirements and hardware capabilities, reporting a mean absolute error of 7.6% against existing hardware. Its analysis spans HBM3, HBM4 and 3D-stacked DRAM and identifies compute, memory capacity, bandwidth and collective communication as primary barriers to performance.

Incremental Causal Graph Learning for Online Cyberattack Detection in Cyber-Physical Infrastructures
面向信息物理基础设施在线网络攻击检测的增量因果图学习
cyberattack detection causal graphs graph neural networks critical infrastructure
