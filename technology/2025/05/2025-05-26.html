Learning a Pessimistic Reward Model in RLHF
在 RLHF 中学习悲观奖励模型
RLHF reward hacking reward model
The paper proposes PET, a pessimistic reward fine-tuning method for offline RLHF that learns a reward model robust to reward hacking. On the TL;DR summarization dataset it yields a high-quality policy with high KL divergence from the data distribution and no regularization.
→ arxiv.org
arxiv:2505.20561 arXiv ✓
Beyond Markovian: Reflective Exploration via Bayes-Adaptive RL for LLM Reasoning
超越马尔可夫：用贝叶斯自适应强化学习实现 LLM 推理的反思性探索
LLM reasoning Bayesian RL exploration reinforcement learning
The authors recast reflective exploration for LLM reasoning in a Bayesian RL framework and introduce BARL, which instructs a model to stitch and switch strategies based on observed outcomes. Experiments on synthetic and mathematical reasoning tasks show better test-time performance and token efficiency than conventional RL.
→ arxiv.org
arxiv:2505.23803 arXiv ✓
MultiPhishGuard: An Explainable and Adaptive Multi-Agent LLM System for Phishing Email Detection
MultiPhishGuard：用于钓鱼邮件检测的可解释自适应多智能体 LLM 系统
phishing detection multi-agent LLM cybersecurity
MultiPhishGuard is an LLM-based multi-agent framework for phishing email detection with five cooperating agents whose contributions are weighted via PPO, plus an adversarial training loop. On public datasets the authors report 97.89% accuracy with a 2.73% false positive rate.
→ arxiv.org
arxiv:2505.20578 arXiv ✓
Ctrl-DNA: Controllable Cell-Type-Specific Regulatory DNA Design via Constrained RL
Ctrl-DNA：通过约束强化学习设计可控的细胞类型特异性调控 DNA
regulatory DNA reinforcement learning genomics synthetic biology
Ctrl-DNA is a constrained reinforcement learning framework that applies RL to autoregressive genomic language models to design regulatory DNA with cell-type-specific activity while limiting off-target effects. On human promoters and enhancers it outperformed existing generative and RL-based approaches.
→ arxiv.org
arxiv:2505.20579 arXiv ✓
The challenge of hidden gifts in multi-agent reinforcement learning
多智能体强化学习中「隐藏馈赠」的挑战
multi-agent RL credit assignment cooperation
The authors build a simple grid-world MARL task where agents must pass a single key to one another to unlock a collective reward, with nothing signalling that another agent dropped it. Several state-of-the-art MARL algorithms fail the task; adding action history helps decentralized actor-critic agents, and a derived correction term reduces learning variance.
→ arxiv.org

Bi-Level Unsupervised Feature Selection
双层无监督特征选择
feature selection unsupervised learning optimization clustering

The NaijaVoices Dataset: Cultivating Large-Scale, High-Quality, Culturally-Rich Speech Data for African Languages
NaijaVoices 数据集：为非洲语言构建大规模、高质量、文化丰富的语音数据
