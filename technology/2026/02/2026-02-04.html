以对称性感知的泰勒近似实现每 Token 恒定成本的注意力计算

SemPipes -- Optimizable Semantic Data Operators for Tabular Machine Learning Pipelines
SemPipes——面向表格机器学习流水线的可优化语义数据算子
LLM tabular data code synthesis ML pipelines Python
SemPipes is a declarative programming model that adds LLM-powered semantic data operators to tabular ML pipelines, specifying data transformations in natural language. It synthesizes operator implementations from data characteristics, operator instructions and pipeline context, and uses LLM-based code synthesis guided by evolutionary search to optimize pipelines; the authors report better predictive performance and reduced pipeline complexity.
