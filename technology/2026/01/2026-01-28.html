Multi-task Code LLMs: Data Mix or Model Merge?
多任务代码 LLM：数据混合还是模型合并？
code LLM model merging data mixing Qwen benchmark
The paper compares data mixing with model merging for building small multi-task code LLMs across Qwen Coder and DeepSeek Coder at 2B and 7B scales, finding that merging performs best at larger scale while data mixing is preferable at smaller scale. Its best merged Qwen Coder 2.5 7B configuration reached 92.7% Pass@1 on HumanEval versus 90.9% for the task-specific fine-tuned equivalent.
