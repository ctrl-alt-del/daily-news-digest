FlatLands: Generative Floormap Completion From a Single Egocentric View
FlatLands：从单张第一人称视角补全地板图
embodied AI BEV mapping dataset generative models
FlatLands is a dataset and benchmark for completing a bird's-eye-view floor map from a single egocentric image, built from 270,575 observations across 17,656 real indoor scenes, and it compares training-free, deterministic, ensemble and stochastic generative approaches. The work also instantiates the task as an end-to-end monocular RGB-to-floormap pipeline for embodied navigation.
→ arxiv.org

The Importance of Being Smoothly Calibrated
平滑校准的重要性
calibration omniprediction learning theory
The paper generalizes, unifies and extends prior results on smooth calibration as a robust measure of calibration error, and presents a new omniprediction guarantee for smoothly calibrated predictors covering all bounded proper losses. It also gives a new characterization of smooth calibration as the earth mover's distance to the closest perfectly calibrated joint distribution of predictions and labels.
→ arxiv.org
arxiv:2603.15987 arXiv ✓
Determinism in the Undetermined: Deterministic Output in Charge-Conserving Continuous-Time Neuromorphic Systems with Temporal Stochasticity
未定之中的确定性：时间随机性下电荷守恒连续时间神经形态系统的确定性输出
spiking neural networks neuromorphic computing determinism
The authors develop a continuous-time framework for spiking neural networks that couples charge conservation with minimal neuron-level constraints, so the terminal state depends only on aggregate input charge and stays invariant to temporal stochasticity. They prove the mapping is strictly invariant to spike timing in acyclic networks and establish an exact correspondence between these charge-conserving SNNs and quantized artificial neural networks.

W2T: LoRA Weights Already Know What They Can Do
W2T：LoRA 权重早已知道自己能做什么
LoRA weight-space learning Transformer model adaptation
W2T maps each LoRA update to a canonical form through QR decomposition followed by SVD so that equivalent factorizations share one representation, then tokenizes the components and processes them with a Transformer to produce a weight-space embedding. Across language and vision LoRA collections it reports strong results on attribute classification, performance prediction and adapter retrieval without running the base model or accessing training data.

retrieval-augmented generation agent memory knowledge management LLM

RadAnnotate：高效可靠标注放射学报告的大模型框架

RadAnnotate is an LLM-based framework for radiology report annotation that uses retrieval-augmented synthetic reports and confidence-based selective automation for RadGraph entity labeling.
