Spectral Regularization for Diffusion Models
面向扩散模型的频谱正则化
diffusion models spectral regularization Fourier transform audio generation
The authors propose a loss-level spectral regularization framework that adds differentiable Fourier- and wavelet-domain losses to standard diffusion training without modifying the diffusion process, model architecture or sampling. They report consistent sample-quality gains on image and audio generation, with the largest improvements on higher-resolution unconditional datasets.
→ arxiv.org
arxiv:2603.02465 arXiv ✓
Toward Generalizable Deep Learning Based Peatland Fire Detection via Walsh Hadamard Transform and Domain Adaptation
基于 Walsh-Hadamard 变换与域自适应的泥炭地火灾检测
peatland fire ResNet domain adaptation fire detection
The paper proposes a Walsh-Hadamard Transform enhanced ResNet-50 framework for peatland fire detection, structurally reparameterized into an equivalent inference model and paired with wildfire-to-peatland domain adaptation. It reports higher accuracy and F1 than conventional architectures with fewer parameters and a 100% event detection rate across all positive test videos.
→ arxiv.org
arxiv:2603.02473 arXiv ✓
Diagnosing Retrieval vs. Utilization Bottlenecks in LLM Agent Memory
诊断 LLM Agent 记忆中的检索与利用瓶颈
LLM agent memory retrieval benchmark
A 3x3 study crossing three memory write strategies with three retrieval methods on LoCoMo finds retrieval method dominates, with average accuracy spanning 20 points (57.1% to 77.2%) across retrieval methods but only 3-8 points across write strategies. Raw chunked storage, which requires no LLM calls, matched or outperformed costlier lossy alternatives.
→ arxiv.org
arxiv:2603.02451 arXiv ✓
Composable Attestation: A Generalized Framework for Continuous and Incremental Trust in AI-Driven Distributed Systems
可组合证明：AI 驱动分布式系统中持续与增量信任的通用框架
attestation cryptography supply chain Merkle tree
The paper presents composable attestation as a cryptographic framework for continuous and incremental trust in distributed systems such as AI computation and open-source supply chain verification, with Merkle trees central to proof construction. It defines properties including composability, order independence and transitivity, and introduces attestation inclusion so new components can be added without full re-attestation.
→ arxiv.org
arxiv:2603.02452 arXiv ✓
Manifold Aware Denoising Score Matching (MAD)
流形感知去噪分数匹配（MAD）
score matching manifold learning generative models
The authors propose a simple modification to ambient-space denoising score matching that splits the score function into a known base component and a learned remainder, implicitly accounting for the data manifold while keeping computation efficient. They derive closed-form base components for cases including distributions over rotation matrices and discrete distributions.
→ arxiv.org
arxiv:2603.02462 arXiv ✓
Can Computational Reducibility Lead to Transferable Models for Graph Combinatorial Optimization?
计算可归约性能否带来可迁移的图组合优化模型？
graph neural network combinatorial optimization transfer learning pretraining
The authors introduce a GNN encoder that uses a GCON module for expressive message passing together with energy-based unsupervised losses, then draw on computational reducibility to design pretraining and fine-tuning strategies that transfer across tasks such as MVC, MIS and MaxClique. They report that pretraining on all but one task almost always speeds convergence on the remaining task without negative transfer.
