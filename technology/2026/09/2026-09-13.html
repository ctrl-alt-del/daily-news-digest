Accurate Models of AMD Matrix Cores
AMD 矩阵核心的精确建模
matrix cores floating point numerical reproducibility AMD GPUs
The authors characterize the numerical behavior of matrix multipliers across three AMD GPU architectures (CDNA 1, CDNA 2 and CDNA 3), designing test vectors for every supported input format to determine features such as accumulator width, rounding behavior and special-input handling. They develop MATLAB-based software models for each architecture, validate them for bit-level reproducibility against hardware on 10 million randomized input sets, and use them to quantify application-level accuracy differences versus NVIDIA tensor cores.
→ arxiv.org

uncertainty quantification Earth system models risk-sensitive decisions calibration

Route, Don't Fix: Regime-Dependent Decoding Correction and a Trajectory-Gated Router for Reliable Clinical LLM Answer Selection
路由而非修正：面向可靠临床 LLM 答案选择的机制依赖解码修正与轨迹门控路由器
clinical question answering decoding correction routing inference-time methods
The authors observe that a fixed inference-time logit correction that gains about ten percentage points on a truthfulness stress test yields negligible gains on clinical multiple-choice benchmarks, and propose ALTAS, which reads terminal entropy and late-layer linearity from one forward pass to choose per question between greedy decoding and late-layer trajectory correction. Gated per question, it retains gains of 8.3 to 9.5 percentage points on TruthfulQA while keeping MedQA, PubMedQA and MedHallu within a one-percentage-point do-no-harm band, adding 6.5% latency overhead.
