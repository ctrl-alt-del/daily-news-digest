SiliconBench: Speed, Memory, and Fidelity for LLM Serving on Unified-Memory Desktops
SiliconBench：统一内存桌面端 LLM 服务的速度、内存与保真度
LLM serving Apple Silicon benchmarking unified memory
SiliconBench evaluates nine Apple Silicon LLM serving engines on speed, memory and fidelity for chat and agent workloads with Qwen3, Qwen3.5 and Gemma 4, using an NVIDIA reference for quality regressions and DGX Spark as a complementary serving-performance reference. The study reports that explicit memory budgets do not guarantee memory headroom, that newer model architectures have narrower engine support, and that only three stacks satisfy the completion, fidelity and model-coverage gates.

arxiv:2609.14157 arXiv ✓
When Tools Get in the Way: The Effect of Unnecessary Tool Availability on LLM Answering
当工具成为阻碍：不必要的工具可用性对 LLM 回答的影响
tool use LLM evaluation agentic systems system prompting
The authors construct 500 query pairs across 10 knowledge domains, each pairing a tool-requiring query with a closed-domain query that does not need the tool, and evaluate six LLMs with the tool unavailable, available, and available after a prior tool call. The pooled answer rate fell from 98.2% at baseline to 63.5% when an unnecessary tool was available, a drop that occurred even when the tool was rarely called, and a one-sentence scope-aware system instruction recovered most of the lost answers.
