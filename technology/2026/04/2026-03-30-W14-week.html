PolySwarm：面向预测市场交易与延迟套利的多智能体 LLM 框架

Across 192 inference runs on two code archetypes, poisoned identifier names from obfuscated JavaScript persisted into Claude Opus 4.6's reconstructed code even when the model described the correct semantics. Reframing the task from deobfuscation to writing a fresh implementation reduced propagation from 100% to 0–20% on the physics archetype and to 0% on pathfinding, though the authors note the findings cover one model family.
