ClawVM：面向有状态工具型 LLM agent 的 harness 托管虚拟内存

ClawVM is a virtual memory layer for stateful tool-using LLM agents that manages context as typed pages with minimum-fidelity guarantees and validated writeback at lifecycle boundaries. Across synthetic workloads, real-session traces and stress tests, it eliminated all policy-controllable faults when the minimum-fidelity set fit the token budget, adding median overhead below 50 microseconds per turn.
