arxiv:2607.07964 arXiv ✓
KronQ: LLM Quantization via Kronecker-Factored Hessian
KronQ：基于 Kronecker 分解 Hessian 的 LLM 量化
post-training quantization LLM compression Kronecker-factored Hessian mixed-precision inference
KronQ is a post-training quantization framework that adds gradient covariance to activation statistics under a Kronecker-factored Hessian approximation, contributing bidirectional incoherence processing on the output dimension and a new sensitivity metric for inter-layer mixed-precision allocation. In 2-bit weight-only quantization of LLaMA-3-70B the authors report 7.93 perplexity on WikiText-2, where GPTQ and GPTAQ are described as diverging or producing degenerate quantizations.
→ arxiv.org

Right Answer, Wrong Tokens: Tail-Aware Credit Calibration for RLVR
答案正确、词元错误：面向 RLVR 的尾部感知信用校准
reinforcement learning credit assignment LLM reasoning verifiable rewards training stability
The paper identifies a positive-credit contamination failure mode in GRPO-style reinforcement learning, where uniform credit assignment reinforces locally erroneous tail tokens inside successful trajectories, and proposes TACO, which uses a policy-relative tail-risk score to softly reduce positive credit for high-risk tokens while keeping it nonzero. arxiv:2607.07984 arXiv ✓
Agentic Neural Architecture Search
智能体式神经网络架构搜索
neural architecture search LLM-driven design automated machine learning multimodal benchmarks
The paper proposes a division of labor in which an LLM generates a seed architecture and decomposes it into a slotted architecture whose interchangeable module slots define a bounded, task-specific search space for conventional NAS, instantiated as the three-phase AgentNAS pipeline. On 17 tasks from NAS-Bench-360 and Unseen NAS, AgentNAS is reported to set a new state of the art on 11 tasks, with ablations indicating the two search mechanisms are broadly complementary.
