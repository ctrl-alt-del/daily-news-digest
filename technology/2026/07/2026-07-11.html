NanoVSR: Towards Real-Time Video Super-Resolution on Edge Devices
NanoVSR：面向边缘设备的实时视频超分辨率
video super-resolution edge deployment structural reparameterization real-time inference NVIDIA Jetson
NanoVSR is a fully convolutional video super-resolution architecture that uses structural reparameterization to collapse into standard convolutions at inference, avoiding transformers, explicit optical flow and custom operators while learning spatio-temporal alignment implicitly through progressive training. On REDS4, the 644k-parameter variant reports 28.64 dB PSNR at 27.2 FPS on an NVIDIA Jetson Orin NX 16GB at 25W, and a 1.7M variant reaches 29.15 dB at 19.58 FPS.

以可验证物理为依据的强化学习：用连续奖励后训练 LLM
reinforcement learning PDE solver generation code generation scientific computing reward design
RLVP is an RL post-training framework for multi-PDE solver code generation that pairs hard program-validity checks with continuous physics rewards scoring function-space accuracy and PDE-residual consistency.
