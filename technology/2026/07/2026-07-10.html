The Economics of AI Decoding Chips: Rebalancing Compute, Capacity, and Bandwidth for Efficient LLM Inference
AI 解码芯片的经济学：为高效 LLM 推理重新平衡算力、容量与带宽
LLM inference decode accelerator design memory bandwidth roofline model cost per token
The paper argues that mainstream GPUs are built compute-heavy and capacity-light while LLM decoding is memory-bound, and formalizes the inefficiency with two per-chip constants, the roofline ridge point F/B and the compute bundled per GB of memory F/S. A Symbolic Neural CPU for Quantization-Simulated Writeback and Interpretable Program Execution
一种用于量化模拟回写与可解释程序执行的符号神经 CPU
neural program execution interpretability quantization computer architecture RISC-V
The paper introduces a trace-supervised symbolic neural CPU that combines recurrent control, an explicit operation router over a differentiable ALU bank, destination-masked register writeback, full trajectory supervision and matched fixed-point replay, exposing the selected operation, registers and memory signals at each step. On the principal 16-wide benchmark the non-quantized executor reproduces reference execution exactly, and the 8-bit quantization-simulated executor preserves the symbolic operation path through 1,000-instruction programs.

MLPs are Hebbians: Constructing Efficient Fact-Storing MLPs for Transformers
MLP 即 Hebbian：为 Transformer 构建高效事实存储 MLP
mechanistic interpretability MLP fact storage transformer architecture associative memory knowledge editing
The paper gives a closed-form, Transformer-compatible construction of fact-storing MLPs and analyzes their decoding margin, showing information-theoretically optimal storage scaling for isotropic embeddings and the same scaling for arbitrary key and value embeddings up to geometry-dependent penalty factors. arxiv:2607.10044 arXiv ✓
FlashTrie: A GPU-Accelerated Constrained Beam Search for Generative Retrieval
FlashTrie：面向生成式检索的 GPU 加速约束束搜索
constrained decoding generative retrieval GPU acceleration beam search sponsored search
FlashTrie moves constrained beam search for generative retrieval onto GPUs with an integer-aware succinct trie layout that bit-compresses the index into high-bandwidth memory and a cooperative CUDA kernel that performs beam expansion, validation and pruning on-device. On a library of 800M keywords with beam widths up to 1,000, it is reported to reduce trie-search latency below 3 ms with up to 24x speedup over a multithreaded CPU baseline, and an online A/B test reports a 0.71% revenue lift.
