NeuroAbs: A Neuro-Symbolic RTL Abstraction Framework for Property Checking Acceleration
NeuroAbs：加速属性检查的神经符号 RTL 抽象框架
RTL 形式化验证 LLM CEGAR
NeuroAbs is a neuro-symbolic framework for RTL abstraction in hardware property checking: it uses LLM-assisted RTL analysis to identify signals suitable for abstraction, checks each abstraction's soundness with satisfiability-modulo-theories (SMT) solving, and applies counterexample-guided abstraction refinement (CEGAR) when an abstraction is too coarse. Experiments show it significantly improves the efficiency of hardware property checking.
