Quantifying System-Level Harms from AI Adoption in Complex Sociotechnical Systems
量化复杂社会技术系统中 AI 应用带来的系统级危害
system-level AI risk sociotechnical systems STPA hazard analysis LLM adversarial manipulation financial stability
Proposes a framework that links structured hazard analysis, component-level testing, and probabilistic system modelling to trace model behaviour to system-level outcomes. Applied to the UK's Real Time Gross Settlement system, adversarial manipulation of LLM-based trading measurably shifted recommendations and, in a financial contagion model, increased bank failures and lowered the shock threshold for cascading disruption, particularly under widespread or monopolistic AI adoption.

Names Can Hurt: Spotting Slopsquatting Risks Caused by Package Name Hallucinations in Local Coding LLMs
名称亦能伤人：识别本地代码大模型包名幻觉引发的恶意抢注风险
package name hallucination slopsquatting software supply chain security code generation LLM agents
Proposes a two-layer detector that combines a deterministic PyPI existence check with a Random Forest classifier over ten name- and metadata-derived features, embedded in a LangGraph pipeline that retries at escalating temperatures and falls back to a stronger model. Across 300 curated prompts the pipeline produced hallucination-free code on 76% of runs, and the authors report hallucination rates rising from 0–10% on routine coding prompts to 40–73% on slopsquat baits.

Continual Visual Learning under Evolving Semantic Concept Shift
语义概念演化漂移下的持续视觉学习
continual learning semantic concept shift vision foundation models low-rank adaptation benchmark
Formalizes evolving semantic concept shift, in which taxonomies and concept definitions change so that the same visual evidence requires a different interpretation, and proposes SemReWrite, which localizes affected regions and applies input-dependent low-rank rewriting with structured semantic memory and obsolete-decision suppression. It also introduces the EvoShift-Bench suite and new metrics for selective revision, on which SemReWrite is reported to balance learning revised semantics against preserving unaffected knowledge better than prompt replacement, fine-tuning, parameter-efficient adaptation, and continual-learning baselines.

The Loss Floor of Denoising Score Matching: Fisher Geometry from Schrödinger Bridges
去噪分数匹配的损失下限：来自薛定谔桥的 Fisher 几何
denoising score matching diffusion models Fisher information geometry Schrödinger bridge training loss analysis
Shows that the irreducible excess in the denoising score matching loss, which arises because the conditional score stays random at a fixed noisy state, equals the trace of the Fisher–Rao metric of the conditional endpoint family integrated along the diffusion trajectory. Derived from a Schrödinger bridge variational principle, the result yields a closed form for Gaussian corruption and shows that raw losses under different noise ranges or weightings need not rank models consistently because they contain different additive floors.
