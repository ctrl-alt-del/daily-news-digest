Solvable Sokoban Without a Solver via Diffusion
无需求解器：基于扩散模型的可解 Sokoban 生成
Sokoban discrete diffusion puzzle generation solvability
A transformer-based discrete diffusion model trained only on tile completion, without solvers, rewards, or solvability labels, generates Sokoban puzzles that are solvable 77.4% of the time, and removing a single wall makes 94.5% of the remaining failures solvable. Aborted but Not Forgotten: KV-Cache Retention Breaks Rollback Consistency in Language Agents
已中止却未被遗忘：KV 缓存保留破坏语言智能体的回滚一致性
KV cache rollback consistency language agents stateful inference agent safety
Stateful language agents assume an aborted branch can be discarded by clearing it from the transcript, but retained KV-cache state can let the model keep attending to content the application believes it removed. The authors formalize rollback consistency and show across seven open-weight model families that retained KV alone flips a typed protected effect in 25 of 63 audited cells, while rebuilding the cache closes the channel.

对抗式评审：面向有据可依的智能体代码评审的结构化分歧
agentic code review multi-agent systems structured disagreement LLM agents software engineering
