The authors test whether webcam-based gaze tracking (WebGazer.js) can serve as privileged information to constrain mesa-objective formation in hazard detection, using 137,663 frame-level gaze samples across 388 dashcam clips with two calibration protocols and two architectures. The paper shows that mobile agent frameworks relying on Android accessibility trees and screenshots are systematically vulnerable to indirect prompt injection, with adversarial prompts causing goal hijacking, context drift, and unauthorized device actions. arxiv:2608.14697 arXiv ✓
Synchronized Logit Steering: Real-world Steganography
同步 Logit 引导：面向真实场景的隐写术
大模型隐写术 logit 引导 隐蔽通信 信息隐藏
Synchronized Logit Steering is a deterministic LLM steganographic scheme that derives a proxy prompt from the generated output, letting sender and receiver reconstruct the same logit distribution without sharing the original prompt. Across ShareGPT, GSM8K, and SWE-bench Verified, the KL divergence between true and proxy prompt distributions falls below 0.5 nats once the synchronization window reaches 40 tokens, and a periodic-burst variant reaches 0.20 bits per token.
→ arxiv.org

The study compares a 3D point-cloud pipeline that applies topological data analysis and anomaly detection to PointNet-segmented components with a 2D approach that projects point clouds into views processed by vision foundation models.
