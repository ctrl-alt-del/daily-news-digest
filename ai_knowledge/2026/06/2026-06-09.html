ABC-Bench: An Agentic Bio-Capabilities Benchmark for Biosecurity
ABC-Bench：面向生物安全的 Agent 生物能力基准
biosecurity agentic capabilities dual-use research wet-lab automation benchmark
ABC-Bench measures agentic biosecurity-relevant capabilities on both benign and dual-use tasks: writing code for liquid-handling robots, designing DNA fragments for in vitro assembly, and evading DNA synthesis screening. All tested LLM agents outperformed the median expert human baseliner on all three, and in wet-lab validation OpenAI's o4-mini-high produced scripts that assembled DNA with expected sequences on an OpenTrons robot.

EEVEE: Towards Test-time Prompt Learning in the Real World for Self-Improving Agents
EEVEE：面向自改进 Agent 的真实世界测试时提示学习
test-time prompt learning prompt optimization task routing self-improving agents
EEVEE is a multi-dataset test-time prompt learning framework that routes heterogeneous inputs into task clusters and co-evolves the router with prompt configurations. It improves average multi-benchmark scores by 10.38 and 24.32 points over Qwen3-4B-Instruct and DeepSeek-V3.2, and reportedly surpasses SOTA methods GEPA and ACE by up to 37.2% and 48.2%.

arxiv:2606.11447 arXiv ✓
AI Coding Agents Can Reproduce Social Science Findings
AI 编程 Agent 能够复现社会科学研究结果
reproducibility coding agents social science benchmark design
SocSci-Repro-Bench contains 221 tasks across four disciplines and 13 substantive domains, built from studies that are either fully reproducible or demonstrably non-reproducible in order to isolate agents' reproduction capacity. Claude Code and Codex both reproduce a large share of findings, with Claude Code substantially outperforming Codex; the authors report the results are not primarily driven by memorization, and show that subtle prompt framing can nudge agents toward confirmatory specification search.

ProcAgent: An Agentic Framework for Procedural Task Guidance on Edge with Human-in-the-Loop
ProcAgent：边缘端人在回路的过程性任务指导 Agent 框架
edge agents human-in-the-loop symbolic task graph multimodal perception
ProcAgent is a fully on-device procedural assistant on a single NVIDIA Jetson AGX Orin, combining continuous perception, a symbolic task graph, on-demand vision-language verification, and an LLM interaction agent in a propose-and-verify design. It resolves text-only queries in about 2 seconds and visually grounded queries in about 8 seconds, and drew positive ratings for comprehensibility, actionability, and privacy comfort from 10 assembly-study participants.

The Periodic Table of LLM Reasoning: A Structured Survey of Reasoning Paradigms, Methods, and Failure Modes
LLM 推理的周期表：推理范式、方法与失效模式的结构化综述
reasoning paradigms survey retrieval-augmented reasoning agentic workflows failure modes
This survey organizes 300+ recent papers into a "Periodic Table of LLM Reasoning" spanning nine paradigms, from chain-of-thought and multi-hop reasoning to retrieval-augmented, tool-augmented or agentic, and reinforcement-learning-based reasoning. It reviews methods, benchmarks, and recurring failure modes, arguing that reasoning is not one emergent capability but a family of scaffolded behaviors shaped by scale, task structure, external memory, supervision, and evaluation protocols.

arxiv:2606.11520 arXiv ✓
ISE: An Execution-Grounded Recipe for Multi-Turn OS-Agent Trajectories
ISE：面向多轮 OS Agent 轨迹的执行锚定生成方案
OS agents trajectory synthesis execution grounding fine-tuning
ISE is a three-stage Intent-Simulate-Execute pipeline for synthesizing multi-turn OS-agent training data, building about 50,000 structured intents and 23,132 complete trajectories grounded in a live, isolated OS workspace. Fine-tuning Qwen3-8B on the resulting ISETrace raised ClawEval pass@1 from 19.3 to 37.7, outperforming zero-shot GPT-4o and the larger Qwen3-32B base model.

DeepSeek arxiv:2606.11164 arXiv ✓
ReasonAlloc: Hierarchical Decoding-Time KV Cache Budget Allocation for Reasoning Models
ReasonAlloc：面向推理模型的分层解码时 KV 缓存预算分配
KV cache decoding efficiency reasoning models budget allocation
ReasonAlloc is a training-free decoding-time KV-cache compression framework that recasts budget allocation as a two-level problem: an offline layer-wise preallocation capturing an architecture-driven "Reasoning Wave" and an online head-wise reallocation based on real-time utility. On MATH-500 and AIME 2024 with three distilled reasoning models, it reportedly outperforms uniform-budget R-KV and SnapKV baselines.
→ arxiv.org
arxiv:2606.11119 arXiv ✓
TRACE: A Unified Rollout Budget Allocation Framework for Efficient Agentic Reinforcement Learning
TRACE：面向高效 Agent 强化学习的统一 rollout 预算分配框架
agentic reinforcement learning rollout allocation reward contrast tree search
TRACE models each ReAct-style thought-action-observation turn as a semantically distinct node and allocates rollout budget across prompt roots and intermediate prefixes most likely to yield mixed terminal rewards, forming tree-structured rollouts. At equal sampling cost it improves Qwen3-14B Multi-Hop QA average accuracy by 2.8 points over competitive baselines.
