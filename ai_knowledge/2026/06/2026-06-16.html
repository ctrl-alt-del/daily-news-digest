arxiv:2606.18497 arXiv ✓
Ghost Vectors: Soft-Deleted Embeddings Remain Reconstructible in HNSW Vector Databases
Ghost Vectors：软删除的嵌入向量在 HNSW 向量数据库中仍可被重建
vector databases embedding inversion data deletion RAG privacy GDPR compliance
The paper shows that HNSW vector databases typically only mark records as deleted, leaving embeddings physically intact on disk, so raw index files can be read to recover data that is gone at the API level. Using the Vec2Text inversion model without domain fine-tuning, the authors recover 25.5% of exact person names and 46.4% of geographic locations on a Wikipedia biography dataset, 100% of age and gender markers on synthetic clinical records, and up to 99% top-1 identity from facial embeddings; they propose Epoch Key Rotation, which encrypts vectors and discards the key on deletion.
→ arxiv.org
arxiv:2606.18406 arXiv ✓
CoreMem: Riemannian Retrieval and Fisher-Guided Distillation for Long-Term Memory in Dialogue Agents
CoreMem：面向对话智能体长期记忆的黎曼检索与 Fisher 引导蒸馏
agent memory Riemannian retrieval memory compression edge deployment long-term memory
CoreMem is an edge-cloud memory architecture for long-term dialogue agents that replaces cosine matching with a locally adaptive Fisher-Rao metric to penalize hub memories in high-dimensional retrieval, and adds Fisher-guided discrete token distillation for hierarchical sentence-to-token compression. On the LOCOMO and LongMemEval-S benchmarks it reports gains of 4.51 points in open-domain and 4.17 points in temporal reasoning while operating within a strict 8 GB VRAM budget.
→ arxiv.org
arxiv:2606.18356 arXiv ✓
SafeClawBench: Separating Semantic, Audit-Evidence, and Sandbox Harm in Tool-Using LLM Agents
SafeClawBench：区分工具调用型 LLM 智能体的语义、审计证据与沙箱危害
tool-use security memory poisoning prompt injection agent benchmark
SafeClawBench is a staged benchmark of 600 controlled adversarial tasks across six attack families, including direct and indirect prompt injection, tool-return injection, memory poisoning, and memory extraction, that scores semantic attack acceptance, audit-visible harm evidence, and sandbox-observed tool or state harm separately. Across five agent endpoints, semantic failure rates without extra prompt protection ranged from 9.0% to 44.2%, and a 12,000-row matched analysis found that 291 of 347 observed sandbox harms occurred in rows that passed the semantic check.
→ arxiv.org
arxiv:2606.18385 arXiv ✓
CaVe-VLM-CoT: An Interpretable Vision-Language Model Framework
CaVe-VLM-CoT：可解释的视觉语言模型框架
agentic RAG citation grounding vision-language models closed-loop verification hallucination
CaVe-VLM-CoT is a modular reflection-based agentic-RAG framework for vision-language models that runs a five-stage closed loop of Extractor, Retriever, Solver, Citation Injector, and Verifier, with detected ungrounded claims triggering structured feedback for targeted re-retrieval. It proposes 23 component-wise metrics anchored by CaVeScore, and reaches 87.1% accuracy and 56.6% CaVeScore on ScienceQA plus 55.2% accuracy and 35.7% CaVeScore on MMMU without architectural or prompt modifications.
→ arxiv.org

Evaluating Prompting-Based Defenses Against Domain-Camouflaged Injection Attacks
评估基于提示词的防御对领域伪装注入攻击的效果
prompt injection prompt defenses retrieval security attack success rate
In 3,510 trials across three model families and three deployment domains, the study compares five prompting-based defenses against domain-camouflaged injection attacks. Paraphrasing retrieved content before the agent sees it was the most consistently effective approach, cutting attack success by 55–84%, though results varied by model and financial deployments retained the highest residual risk.

arxiv:2606.18235 arXiv ✓
EvolveNav: Proactive Preflection and Self-Evolving Memory for Zero-Shot Object Goal Navigation
EvolveNav：面向零样本物体目标导航的主动预思与自演化记忆
self-evolving memory rule retrieval embodied agents preflection
EvolveNav is a self-evolving framework for zero-shot object-goal navigation that extracts an agentic rule memory from past trajectories, retrieves rules with an upper-confidence-bound strategy balancing semantic relevance and historical success, and forecasts outcomes before acting. It reports a 10.1% improvement in success rate over zero-shot baselines with fewer unnecessary steps.

Guava: Distilling Frontier VLMs into a Compact Agent through a Robotic Manipulation Harness
Guava：通过机器人操作测试框架将前沿 VLM 蒸馏为紧凑智能体
embodied agents agent harness knowledge distillation tool use
Guava is a harness for embodied tool use whose design study identifies iterative perception-reasoning-action loops, semantic action abstractions, and multimodal observations as key ingredients. The authors distill manipulation capability into a 4B open-source model using fewer than 2K trajectories collected entirely in simulation, reporting simulation and real-world performance comparable to frontier proprietary models and generalization to unseen objects, novel instructions, and long-horizon tasks.

When Web Agents Finish but Still Fail: Reproducible Triggers and Trace Diagnostics for Parallel Web Exploration
当网页智能体“完成”却仍然失败：并行网页探索的可复现触发条件与轨迹诊断
web agents agent benchmark trace diagnostics search loops
The authors introduce Parallel WebBench, a benchmark of 1,679 verified records for studying web agents that return well-formed answers yet still fail. The best GRPO model lifts completion over WebExplorer-8B from 50.7% to 96.0%, but binary accuracy remains far lower, and trace analysis identifies context-bound search loops, premature termination, and synthesis collapse.
