Self-Evolving World Models for LLM Agent Planning
面向 LLM 智能体规划的自演化世界模型
world models episodic memory semantic memory agent planning
WorldEvolver is a self-evolving world-model framework that revises its deployment-time context while keeping the downstream agent and all model parameters frozen, combining episodic memory for retrieval-based simulation of real transitions, semantic memory for heuristic rules extracted from prediction-observation mismatches, and selective foresight that filters low-confidence predictions. On ALFWorld and ScienceWorld it achieves the highest prediction accuracy across three backbones and leads world-model baselines on downstream agent success rate.

arxiv:2606.30840 arXiv ✓
Contrastive Reflection for Iterative Prompt Optimization
面向迭代提示优化的对比反思
prompt optimization agentic IR contrastive reflection validation-driven repair
Contrastive Reflection is an iterative prompt-optimization framework for agentic information-retrieval workflows that uses structured retrieval or reasoning traces and dimension-level grading rationales to identify error-anchored behavioral slices, adds nearby successful examples, and asks a Teacher LLM for a targeted edit accepted only when validation improves. On a HotpotQA retrieval-augmented QA setup one tree-selected contrastive repair raises held-out exact match from 51.4% to 60.4%, versus 59.4% for MIPROv2 and 57.0% for GEPA.

Comparing Large Language Models on Scrum Certification-Style Questions: Accuracy, Stability, and Error Patterns
比较大型语言模型在 Scrum 认证式问题上的表现：准确率、稳定性与错误模式
certification QA prompt strategies model comparison domain knowledge
The study evaluates GPT-5 mini, Gemini 3 Flash and DeepSeek Chat 3.2 on 993 Scrum certification-style questions aligned with the PSM I format under zero-shot, chain-of-thought and source-grounded prompting with repeated executions. Gemini 3 Flash achieved the highest accuracy, followed by GPT-5 mini and DeepSeek Chat 3.2, with low intra-model variability; accuracy was highest on single-answer multiple choice and more error-prone on multi-select and true/false items, and more fragile on topics such as Scrum Values and Self-Managing Teams.

The Label Imitation Game: Turing Test Network for Zero-Shot Pseudo-Label Pruning
标签模仿游戏：用于零样本伪标签剪枝的图灵测试网络
pseudo-label pruning data quality vision-language models zero-shot transfer
The Label Imitation Game formalizes pseudo-label pruning as an adversarial interrogation and trains a Turing Test Network, a task-agnostic judge that evaluates candidate pseudo-labels within dataset-wide context. Across four datasets it improves label accuracy for three vision-language models without extra supervision or retraining, yields F1 gains of 28% for the worst baseline categories and 44% with task-specific fine-tuning, and enables zero-shot transfer from classification to object-detection pruning.

AgRefactor: Self-Evolving Agentic Workflow for HLS Compatibility and Performance
AgRefactor：面向 HLS 兼容性与性能的自演化智能体工作流
self-evolving memory multi-agent workflow hardware design knowledge reuse
AgRefactor is an LLM-based multi-agent workflow that refactors software into HLS-compatible programs, with a self-evolving memory system that accumulates and retrieves factual and strategic knowledge across tasks and automated refactoring tools that balance LLM rewrites with tool transformations. On 9 of 11 real-world benchmarks 5–10x longer than prior cases it matches or beats the state-of-the-art automated refactoring tool and a strong LLM baseline, and further optimization yields a 6.51x geometric-mean speedup over a pragma-tuning tool.
