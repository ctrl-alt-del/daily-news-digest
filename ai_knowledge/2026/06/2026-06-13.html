APEX: Adaptive Principle EXtraction A Three-Layer Self-Evolution Framework for Production AI Agents
APEX：面向生产级 AI Agent 的三层自适应原则提取自演化框架
self-evolving agents harness optimization behavioural principles workflow topology production agents
APEX is a three-layer co-evolution framework that simultaneously patches an agent harness from failure modes, distills behavioural principles from success traces, and selects workflow topology by structural fitness. On a production agent managing a 15-node fleet, it reports an APEX Health Score of 0.570, up 90% from a 0.300 baseline, using four LLM calls on a local qwen2.5-coder:32b instance.

arxiv:2606.15441 arXiv ✓
Defending against Adaptive Prompt Injection Attacks via Reasoning-enabled Task Alignment
通过推理赋能的任务对齐防御自适应提示注入攻击
prompt injection defense task alignment multi-objective RL adversarial training
RETA is a training-based defense against adaptive indirect prompt injection that grounds each tool-output decision in the user task through chain-of-thought verification, while a simulated attacker with a dictionary-learning diversity reward generates adversarial training data. Across six black-box adaptive attacks, it keeps every per-attack success rate below 10%, with average rates of 2.92% and 3.75% on the two target models.

Not All Skills Help: Measuring and Repairing Agent Knowledge
并非所有技能都有用：度量与修复 Agent 知识
skill curation causal attribution agent knowledge tool-use agents
ASSAY separates skill generation from skill curation: it measures each skill's causal contribution through randomized masking on a small development set, restructures the library offline, and suppresses skills predicted to hurt on each test task. Across seven base models and two benchmarks, DeepSeek-V3 reaches 69.3% task-goal completion on AppWorld's hardest split, a 47.4% relative improvement, while GPT-4.1 gains 8.7% relative on tau-bench retail.

Let Large Language Models Judge Each Other: Multi-Agent Peer-Reviewed Reasoning for Medical Question Answering
让大语言模型互评：面向医疗问答的多 Agent 同行评审推理
multi-agent debate peer review medical QA chain-of-thought
The study has multiple LLM agents independently generate chain-of-thought reasoning and candidate answers, then peer-review each other's reasoning for factual correctness and logical soundness before selecting the highest-rated chain. Across five models and three medical QA datasets, the best combination reaches 0.820 average accuracy, above the strongest single model at 0.777 and majority voting at up to 0.789.

编码错误：面向多语言语法纠错的情境示例表征检索
demonstration retrieval in-context learning error representations multilingual GEC

arxiv:2606.15474 arXiv ✓
Who Drifted: the System or the Judge? Anytime-Valid Attribution in LLM Evaluation Pipelines
Who Drifted：是系统还是评审？LLM 评估流水线中的随时有效归因
LLM evaluation judge drift change attribution sequential testing
The paper introduces a fixed human-labeled anchor set, a second betting e-process, and a guard-window rule to decide whether an LLM evaluation score moved because the system changed or because the judge did. It reports correct attribution of a silent judge version bump in 60 of 60 runs and of a strict-prompt change in 110 of 120 runs, while a rolling z-test false-alarmed on 75% of drift-free streams.
