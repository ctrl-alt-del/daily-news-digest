arxiv:2606.08340 arXiv ✓
Benchmarking Open-Ended Multi-Agent Coordination in Language Agents
语言 Agent 开放式多智能体协作基准测试
multi-agent coordination benchmark language agents communication zero-shot evaluation
The authors introduce alem, a JAX benchmark built on Craftax-like dynamics to test long-horizon coordination among language agents. Thirteen modern LLMs averaged only about 6% normalized return zero-shot; communication was the largest contributor to coordination, and Gemini-3.1-Pro-High approached MARL agents trained for a billion steps on the hardest setting while GPT-5.4-High showed much lower coordination reward.

arxiv:2606.08251 arXiv ✓
Contemporary AI lacks the imagination to diverge or negate in science
当代 AI 缺乏在科学中发散或否证的想象力
scientific ideation LLM evaluation hypothesis generation human evaluation retrieval augmentation
In what the authors call the largest scientist-in-the-loop evaluation to date, authors of 121,640 recent preprints were invited to judge LLM-generated ideas derived from their own papers; 6,749 scientists returned 25,139 rating sets. Non-reasoning models collapsed into similar ideas while reasoning models explored more, yet no model spontaneously proposed null hypotheses, and automated evaluators agreed only weakly with expert judgment.

arxiv:2606.08245 arXiv ✓
ZAS-SQL: Distilling Rules from Failures for Zero-Shot Text-to-SQL
ZAS-SQL：从失败中蒸馏规则的零样本文本转 SQL 框架
text-to-SQL rule distillation zero-shot schema grounding self-correction
ZAS-SQL distills generation rules from systematic failure cases through a Map-Reduce pipeline and adds knowledge-augmented schema representation, rule-driven structured reasoning, and execution-guided early stopping. On Spider it reaches up to 87.2% and 88.6% execution accuracy on Dev and Test, and 81.3% on the domain-specific UrbanPlan dataset.

AeroSpectra Sentinel: An Auditable LLM Prompt-Chaining Decision-Support Workflow for Acute Asthma Risk Assessment from Respiratory Sounds and Clinical Signals
AeroSpectra Sentinel：基于呼吸音与临床信号的可审计 LLM 提示链哮喘风险评估工作流
prompt chaining clinical decision support guardrails auditability FHIR reporting
AeroSpectra Sentinel combines respiratory-sound analysis, lightweight ML screening, clinical feature fusion, and a five-stage LLM prompt chain with guardrails and FHIR-ready reporting. In a 40-vignette audit, the guardrail-plus-schema variant gave the strongest simulated safety and documentation consistency; the authors describe it as a research prototype, not a diagnostic medical device.

arxiv:2606.08270 arXiv ✓
An AI Security Agent for University ACMIS: Multi-Vector Threat Detection and Automated Response
面向高校 ACMIS 的 AI 安全 Agent：多向量威胁检测与自动响应
security agents anomaly detection threat detection automated response
The paper presents an AI security agent for university academic management systems that combines supervised anomaly detection, behavioral analytics, and a natural-language password-recovery chatbot across five operational layers. On a simulated log of 147,922 sessions it reports a 0.966 macro-average F1 versus 0.156 for a rule-based baseline, with critical-tier response latency under 1 ms on a single-node prototype.

arxiv:2606.08146 arXiv ✓
SAGE: An LLM-driven Self Reflective Agentic Framework for Fraud Detection
SAGE：LLM 驱动的自反思多 Agent 欺诈检测框架
fraud detection multi-agent systems self-reflection reward optimization
SAGE coordinates three dedicated agents over a six-layer Data Diagnostic Tree and a Markov decision process guided by natural-language gradients to optimize fraud models under a fraud-specific reward. Across five fraud datasets and five LLM backbones it wins 96% of method-dataset comparisons and improves F1 by an average of 40.86% over baselines.

arxiv:2606.08256 arXiv ✓
Traxia: A Framework for Verifiable, Agent-Native Scientific Publishing
Traxia：可验证、Agent 原生的科学出版框架
scientific publishing knowledge graph provenance agent identity peer review
Traxia proposes an agent-native publishing framework in which AI research agents publish verifiable papers with reasoning traces and claims carrying confidence intervals, hold signed identities, peer-review one another, and log contributions immutably. It specifies five components, including a knowledge graph with contradiction detection; the paper reports architecture and formal specifications only and no empirical results yet.

arxiv:2606.08348 arXiv ✓
Bayesian-Agent: Posterior-Guided Skill Evolution Across LLM Agent Harnesses
Bayesian-Agent：跨 Agent 框架的后验引导技能演化
agent skills Bayesian updating skill evolution cross-harness
Bayesian-Agent treats reusable agent skills as Bayesian evidence objects, maintaining posterior beliefs over their reliability and failure modes to guide updates and model-facing guardrails. In incremental mode its repair lifted SOP-Bench from 80% to 95%, Lifelong AgentBench from 90% to 100%, and RealFin-Bench from 45% to 65%, running across its native harness, MiniSWEAgent, and Claude Code.
