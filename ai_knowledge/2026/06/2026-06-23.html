EvoClawBench：智能体能否从自身运行中学习可复用技能？
skill learning agent memory benchmark self-improvement agent runtimes

arxiv:2606.25115 arXiv ✓
Forget to Improve: On-Device LLM-Agent Continual Learning via Budget-Curated Memory
以遗忘求改进：端侧LLM智能体基于预算策展记忆的持续学习
agent memory memory curation forgetting memory poisoning on-device agents
Proposes a single net-value-per-byte score that governs an on-device agent's experience-memory lifecycle, deciding what to keep under RAM and energy budgets, what to share over a thin uplink, and what to trust by provenance; on task-drift benchmarks and a Jetson testbed it cuts memory 2.7x and uplink 2.4x, drives injection success from 0.75 to zero, and improves accuracy on cases corrupted by poison or stale memory.

RAVEN：面向长程推理与导航的视觉-时空记忆

Agents Don't Paginate: First-Chunk Selection for LLM Tool Responses
智能体不翻页：LLM工具响应的首块选择
tool responses context budget SWE-bench coding agents retrieval precision
Observes that coding agents never request a second chunk of oversized tool responses, then treats first-chunk selection as a 0/1 knapsack over 500 SWE-bench Verified tasks; raising precision-at-1 does not systematically raise downstream accuracy, with per-model deltas under three points, because agents recover the gold item from anywhere in the chunk.

SHERLOC：面向代码修复智能体的结构化诊断定位

SoK：AI安全代码生成——进展、陷阱与前路

Systematizes AI secure code generation with a three-level framework covering natural-language understanding of secure-coding principles, code-level actuation, and the knowledge-actuation gap; across models and coding agents, principle understanding strongly predicts functional and security outcomes, yet models often recognize principles without translating them into secure, functional code.
