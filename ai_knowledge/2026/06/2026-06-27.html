LAMP: Lean-based Agentic framework with MCP and Proof Repair
LAMP：基于 Lean、MCP 与证明修复的智能体框架
Lean 4 multi-agent framework domain ontology MCP proof verification
LAMP is a multi-agent framework that synthesizes kernel-verified Lean 4 proofs by supplying structured domain knowledge at inference time through an ontology rather than fine-tuning the prover, coordinating Planner, Builder and Verifier agents with MCP-based access to a Combinatorics on Words ontology. The authors also formalize CoW in Lean 4 with eight modules and 93 declarations and report verified proofs for 96.7% of 90 CoW theorems; ablations show that removing tool grounding or Planner/Builder separation each costs roughly 12 percentage points.

Set-Valued Routing for Language-Model Agent Systems: A WildChat Benchmark and Cost-Aware Evaluation
面向语言模型智能体系统的集合值路由：WildChat 基准与成本感知评估
agent routing set-valued retrieval cost-aware evaluation WildChat
The paper formulates fixed-catalog routing for agent systems as set-valued language understanding and builds a benchmark of 3,000 WildChat prompts over 12 capability-defined agents. A fine-tuned text encoder reaches 89.59 F1 versus 71.79 for a linear SVM and 41.51 for GPT-4o, and the authors introduce Weighted Agent Routing, a deterministic post-scoring rule that shifts the quality-cost operating point without retraining.

The Contagion Tensor: A Framework for Measuring Output-Distribution Coupling in Multi-Agent LLM Systems -- and Auditing the Claims It Enables
传染张量：衡量多智能体 LLM 系统输出分布耦合的框架
output coupling multi-agent systems measurement framework ablation protocol
The Contagion Tensor is a measurement framework for quantifying how LLM output distributions couple across modalities, agents and time steps, yielding the Coupling Amplification Factor with bootstrap confidence intervals. In a 2x2x2 simulation plus real-API tests on DeepSeek-Chat and GPT-4o-mini, diverse personas drove convergence (CAF 0.88) while GPT-4o-mini with real vision showed a super-linear CAF of 1.72; five of 11 conditions were tested on real APIs and six remain unverified.

Customized Generative AI Agent for Transportation Engineering Practice: A Development and Continued Pre-training Guideline
面向交通工程实践的定制生成式 AI 智能体：开发与持续预训练指南
continued pretraining LoRA transportation engineering domain corpus
The study continued-pretrained six state-of-the-art LLMs through a unified LoRA framework on a curated corpus of U.S. transportation manuals, design guidelines and regulatory documents, monitoring training for convergence and stability. Evaluated with BLEU-4 and ROUGE, Qwen2.5-7B and LLaMA-3.1-8B showed the highest domain alignment and response quality, supporting a reproducible development framework for domain-specialized agents.

From Tool Connection to Execution Control: Benchmarking Security Invariants in MCP-Style Agent Runtimes
从工具连接到执行控制：MCP 风格智能体运行时安全不变量基准
MCP security execution invariants tool use AgentDojo
The paper formulates eight execution-layer invariants covering structured authority, resource resolution, principal binding, handle lifecycle and approval state, then compares an in-memory runtime (HCP) with an independent gateway ACL enforcing the same contract. Both block 18 modeled violations and complete 25 workflows, but live AgentDojo tests show strict grants also deny 40 non-attacker calls, and per-call grants cannot stop a secret passed as an ordinary argument to an authorized sink.

arxiv:2606.28896 arXiv ✓
A Task-Driven and Quality-Assured Agent Framework for SAR Data Generation
面向 SAR 数据生成的任务驱动与质量保障智能体框架
agent framework schema grounding data augmentation quality evaluation
SAGA is a schema-grounded, benefit-aware agent framework for task-oriented synthetic aperture radar data generation and augmentation that extracts dataset facts, validates executable schemas, plans with validator constraints and compiles an auditable workflow. Generated data pass quality, distribution, SAR-artifact, duplicate, leakage and optional downstream-task evaluators, and experiments show gains in schema grounding, skill planning, invalid-sample rejection and downstream utility over rule-based, LLM-only, ReAct-style and fixed-augmentation baselines.

arxiv:2606.29090 arXiv ✓
AB-RAG: Adaptive Budgeted Retrieval-Augmented Generation for Reliable Question Answering
AB-RAG：面向可靠问答的自适应预算检索增强生成
adaptive retrieval confidence estimation retrieval budget question answering
AB-RAG is a training-free, backbone-agnostic framework that generates an answer, estimates confidence from model certainty, answer-evidence agreement and retrieval-score variance, then decides whether to stop or retrieve more within a fixed budget. Across three backbones and two datasets the confidence estimate separated correct from incorrect answers on every backbone, reaching 57.6% versus 0% exact match between high- and low-confidence answers on a factoid dataset, with the adaptive policy improving accuracy on capable backbones.

Beyond the Mean: Three-Axis Fidelity for Aligning LLM-Based Survey Simulators from Small Pilot Data
超越均值：基于小样本试点数据对齐 LLM 调查模拟器的三轴保真度
survey simulation alignment fidelity fine-tuning synthetic respondents
Using a COVID-19 misinformation survey as a case study, the authors decompose recovery of human survey statistics into structural, marginal and individual fidelity and benchmark prompting, rectification and fine-tuning approaches. Fine-tuning on small pilot samples offers a balanced route to multiple fidelity types, but fidelity varies across subsamples in ways that may threaten pluralistic alignment.
