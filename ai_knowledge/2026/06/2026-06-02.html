Language Models Need Sleep: Learning to Self-Modify and Consolidate Memories
语言模型需要睡眠：学习自我修改与巩固记忆
memory consolidation continual learning knowledge seeding dreaming self-improvement
The authors propose a Sleep paradigm in which models continually learn, distill short-term fragile memories into stable long-term knowledge through a Knowledge Seeding stage combining on-policy distillation with RL-based imitation learning, then use reinforcement learning to generate a synthetic curriculum in a Dreaming phase. Experiments on long-horizon continual learning, knowledge incorporation and few-shot generalization tasks support the importance of the sleep stage.

arxiv:2606.04120 arXiv ✓
SaliMory: Orchestrating Cognitive Memory for Conversational Agents
SaliMory：为对话 Agent 编排认知记忆
conversational memory memory consolidation personalization reinforcement learning reward decomposition
SaliMory learns to manage a cognitively structured memory spanning user facts, preferences and working memory, using stage-wise process rewards and reward-decomposed contrastive refinement to supervise selective filtering, consolidation and cue-driven recall end to end. Across four datasets it reports the highest personalization rate (39.8%) and QA accuracy (72.9%) while keeping memory vagueness under 20% and factuality above 89%.

MM-BizRAG: Rethinking Multimodal Retrieval-Augmented Generation for General Purpose Enterprise Q&A
MM-BizRAG：重新思考企业问答的多模态检索增强生成
multimodal RAG document structure page embeddings enterprise QA RAG evaluation
MM-BizRAG extracts document structure and routes documents through orientation-specific ingestion pipelines, applying layout-aware parsing to vertically structured reports and holistic page-level images to slide decks, with placeholder-based alignment preserving reading order. It outperforms vision-centric baselines by up to 32 points on a heterogeneous enterprise dataset, SlideVQA and FinRAGBench-V, and introduces FastRAGEval, a single-call LLM-judge metric for generative recall.

arxiv:2606.04261 arXiv ✓
Can Generalist Agents Automate Data Curation?
通用 Agent 能自动完成数据策展吗？
data curation agent benchmark method adaptation data selection
Curation-Bench fixes the model, training recipe and evaluation suite while giving agents command-line access to inspect data, implement policies and revise them against fixed benchmark feedback. Out-of-the-box agents match strong published data-selection baselines within ten iterations but mostly tune local variants; a scaffold requiring each iteration to cite and adapt a prior method produced a policy that beats strong baselines at one-tenth the data budget.

Discourse-Role Labels as Presentation-Time Variables for Context Use in Language Models
话语角色标签作为语言模型上下文使用的呈现时变量
discourse labels RAG context context utilization prompt framing context benchmark
A paired fixed-content probe over 500 MMLU-Pro items gives the same misleading answer-bearing assertion different discourse-role labels and measures whether models adopt the injected wrong option. Across GPT-5.5, DeepSeek V4 Pro, Llama-3-8B-Instruct and Qwen2.5-7B-Instruct, misleading adoption shifts by 56-84 percentage points, with Instruction: and Reference: raising adoption and Example: consistently suppressing it.

Adaptive Retrieval Strategies for Biomedical Question Answering
面向生物医学问答的自适应检索策略
adaptive retrieval biomedical QA knowledge graph reranking BioASQ
The framework selects retrieval and evidence-aggregation strategies according to question type, combining query understanding, biomedical document retrieval, reranking, knowledge graph augmentation and document clustering. On the BioASQ benchmark it reports improved evidence relevance and answer quality across yes/no, factoid, list and summary questions.

arxiv:2606.09873 arXiv ✓
Rotate2Think: Geometric Priming via Orthogonal Rotation to Improve Language Model Reasoning
Rotate2Think：通过正交旋转进行几何启动以提升语言模型推理
reasoning traces embedding geometry orthogonal Procrustes training-free
The authors show that input embeddings and thinking embeddings are highly conical around distinct mean directions, and cast the input-to-thinking transition as a rotation solvable in closed form via orthogonal Procrustes analysis. Rotate2Think estimates this rotation from a small set of correctly solved examples and injects a synthetic thinking vector at inference, improving accuracy in 30 of 32 model-benchmark configurations and generalizing zero-shot to multimodal reasoning on MATH-Vision.
