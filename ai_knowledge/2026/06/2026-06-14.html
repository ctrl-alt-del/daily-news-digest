DeepRoot: A KG-Coordinated Multi-Agent System for Therapeutic Reasoning over Historical Medical Texts
DeepRoot：面向历史医学文本治疗推理的知识图谱协同多 Agent 系统
knowledge graphs multi-agent systems therapeutic reasoning evidence grounding
DeepRoot is a multi-agent LLM system that jointly builds and uses a verified knowledge graph to reason over historical medical texts, treating grounding and reasoning as separable axes. Applied to the Shen Nong Ben Cao Jing, it recovers 10 of 21 held-out compound-disease treatment pairs at R@20, versus 4.8% for a raw-corpus LLM, while tool-using LLMs hallucinate evidence on 87% of claims versus 7-10% for DeepRoot.

Intelligent Multimodal Retrieval and Reasoning for Geospatial Knowledge Discovery on the I-GUIDE Platform
I-GUIDE 平台上面向地理空间知识发现的多模态检索与推理
geospatial RAG knowledge graph retrieval routing production deployment
I-GUIDE Smart Search is a production multimodal geospatial RAG system that combines OpenSearch keyword, vector, and spatial indexes with a Neo4j knowledge graph and an iterative retrieval pipeline for routing, relevance grading, grounded generation, and hallucination checks. On a single A100 it supports about 100 concurrent simulated users at 4.4 requests per second and improves evidence coverage and judged answer quality over non-retrieval and naive-RAG baselines.

arxiv:2606.15971 arXiv ✓
SAG: SQL-Retrieval Augmented Generation with Query-Time Dynamic Hyperedges
SAG：带查询时动态超边的 SQL 检索增强生成
structured retrieval hyperedges multi-hop QA SQL
SAG is a structured retrieval architecture that indexes each chunk as a semantically complete event plus its entities, forming a latent hyperedge without building a global knowledge graph; shared entities act as join keys to assemble a query-scoped neighborhood at retrieval time. It achieves the best retrieval and end-to-end QA results on HotpotQA, 2WikiMultiHopQA, and MuSiQue, reaching 80.36% Recall@5 on MuSiQue, 11.52 points above the strongest baseline.

BALTO: Balanced Token-Level Policy Optimization for Hallucination Mitigation
BALTO：面向幻觉缓解的平衡 token 级策略优化
hallucination mitigation token-level credit faithfulness RAG
BALTO extracts checkable factual claims, verifies them against the reference context, and projects claim-level judgments onto token-level labels with a balanced credit-assignment mechanism. It reports the highest faithfulness across all six model-benchmark settings on ConFiQA, RAGTruth, and FinLLM-Eval, with better faithfulness-informativeness trade-offs than existing post-training baselines.

Beyond NL2Code: A Structured Survey of Multimodal Code Intelligence
超越 NL2Code：多模态代码智能的结构化综述
multimodal code code agents evaluation visual grounding
This survey reviews multimodal code intelligence, covering systems that generate, edit, refine, or reason with code under visually grounded inputs and outputs. It organizes the field by code's role as rendered artifact, editable structure, intermediate reasoning trace, or executable tool interface, and across GUI, scientific visualization, structured graphics, and frontier tasks, arguing for verification beyond visual fidelity.

CAMI: Cost-Aware Agent-Guided Multi-Indexing for Semantic Retrieval
CAMI：面向语义检索的成本感知 Agent 引导多索引构建
multi-index retrieval semantic enrichment cost-aware optimization agentic discovery
CAMI frames multi-index construction for RAG as a budgeted, multi-objective portfolio selection problem, with an agentic discovery phase, atomic-unit search over enrichment-model pairs, and confidence-aware promotion that prunes weak configurations early. It isolates high-recall portfolios under strict budgets, improving recall@10 by up to 9.4% over content-only baselines while using up to 5x less budget than random search.

Formalize Once, Edit the Rest: Efficient Lean-Based Answer Selection for Math Reasoning
一次形式化，编辑其余：面向数学推理的高效 Lean 答案选择
Lean verification answer selection autoformalization test-time scaling
BASE formalizes one base candidate per math problem in Lean and derives the remaining candidate statements by editing the answer expression in place, using a trained LEANSCRIBE rewriter to localize the answer and generate a reusable edit function. It improves answer-selection accuracy while cutting autoformalizer calls by about 5x at K=8 across 12 dataset-solver configurations.

From Argument Components to Graphs: A Multi-Agent Debate with Confidence Gating for Argument Relations
从论辩成分到关系图：带置信度门控的多 Agent 辩论
multi-agent debate argument mining confidence gating selective computation
The authors apply a Proponent-Opponent-Judge multi-agent debate to argument relation identification and add confidence gating so that only uncertain cases are debated.
