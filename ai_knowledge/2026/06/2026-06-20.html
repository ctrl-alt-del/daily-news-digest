When Does Belief-Based Agent Memory Help? Reliability-Conditional Updating and Provenance-Capped Poisoning Defense
基于信念的智能体记忆何时有用？可靠性条件更新与来源封顶的投毒防御
agent memory belief updating memory poisoning provenance evaluation reliability
Nous represents each entity-attribute pair as a categorical probability distribution updated by closed-form Bayesian inference, with information-theoretic surprise driving belief revision and entropy-based forgetting. A controlled LoCoMo ablation finds Bayesian updating alone barely beats last-write-wins, but reliability-conditioned updating substantially outperforms last-write-wins and raw-memory retrieval when observations differ in trustworthiness, and provenance-capped updating resists volumetric memory poisoning; the paper also reports a 27.5-point discrepancy between strict token-F1 and LLM-as-judge evaluation on identical outputs.

Novelty-Aware Agentic Retrieval: Comparing Research Contributions Through Structured Multi-Step Reasoning
新颖性感知的智能体检索：通过结构化多步推理比较研究贡献
agentic retrieval literature comparison structured reasoning contribution extraction
The Novelty-Aware Research Agent layers six typed-contract components, including query analysis, a ReAct-style retrieval loop, schema-guided contribution extraction, and a three-pass comparison agent, on a RAG pipeline to produce per-paper contribution records, paper-level overlaps, and a problem-by-method gap matrix. On a 100-paper corpus it supports five structured comparison capabilities that a standard RAG baseline supports none of, with mean Precision@5 of 1.000 and nDCG@5 of 0.752 on the main queries.

arxiv:2606.22180 arXiv ✓
FeLoG: Scalable and Efficient Distributed Graph Embedding with Feedback Loop Mechanism
FeLoG：带反馈环机制的可扩展高效分布式图嵌入
graph embedding GraphRAG distributed training sampling efficiency
FeLoG is a distributed graph-embedding system that couples sampling with real-time embedding-quality feedback to prioritize undertrained nodes, adds activity-aware communication compression, and overlaps next-round sampling with current-round training. Against six state-of-the-art baselines on large-scale graphs it reports an average 27.9x speedup, more than 53.1% lower communication cost, and over 80% CPU-GPU utilization, with graph-based retrieval-augmented generation among its target applications.

arxiv:2606.22082 arXiv ✓
CodeTeam: An LLM-Powered Multi-Agent Framework for Repository-Level Code Generation
CodeTeam：面向仓库级代码生成的 LLM 多智能体框架
multi-agent code generation repository-level generation design contracts dependency scheduling
CodeTeam separates natural-language-to-repository generation into planning, decision making, and implementation: multiple Architect agents draft competing design sketches, a CTO agent selects and normalizes one into a machine-checkable contract, and Developer agents build code under a dependency-aware scheduler with Git-based coordination while a QA agent drives repairs. On the SketchEval benchmark across 19 repositories under a retrieval-free protocol, its prompt-engineering variant improves the mean structural score by 3.84 points over CodeS (53.88 versus 50.04).

Lexical Consensus: Grounded Word Learning and Shared Meaning in Artificial Agents
词汇共识：人工智能体中有依据的词语学习与共享意义
grounded word learning perceptual embeddings memory fidelity concept acquisition
Lexical Consensus studies grounded word learning over frozen DINOv2 visual embeddings with Carroll-style nonce words, testing whether agents acquire artificial labels for visual concepts, generalize them bidirectionally, and stabilize them across controlled settings. It finds a perceptual-coherence gradient governed by perceptual rather than semantic distance, and shows naming and retrieval are distinct, with exemplar-based mechanisms outperforming centroid prototypes in label-to-image retrieval.

SamatNext v0.2-B: An Exploratory Study of RMS-Normalized Hybrid Decoders for Curriculum Retention in Small Code Models
SamatNext v0.2-B：面向小型代码模型课程保持的 RMS 归一化混合解码器探索性研究
catastrophic forgetting curriculum retention hybrid decoders small code models
SamatNext v0.2-B is an experimental 356M-parameter hybrid decoder that alternates differential-attention-style layers with DeltaNet-inspired linear-state mixers under RMS normalization, evaluated on a staged Python code curriculum against a parameter-matched Transformer. It reaches a 100.0% pass rate on the Stage 5 holdout while retaining 98.8% of adjacent Stage 3 behavior, versus 97.6% and 6.0% for the Transformer baseline, though both remain weak on long-horizon early-stage retention.

Revelio: Cost-Efficient Agentic Memory Safety Vulnerability Detection For Repository-Scale Codebases
Revelio：面向仓库级代码库的低成本智能体内存安全漏洞检测
agentic security vulnerability detection static analysis proof-of-vulnerability
Revelio combines inexpensive LLMs with lightweight static analysis to generate and rank vulnerability hypotheses, then confirms them with an executable proof-of-vulnerability checked by a sanitizer. Across seven long-fuzzed projects and 100 Arvo projects it found 19 previously unknown memory-safety bugs for about $300 and roughly one hour per project.

L20-Edu-135M: An Auditable Single-GPU Study of Data-Efficient Small Language Modeling
L20-Edu-135M：单 GPU 数据高效小语言建模的可审计研究
small language models data efficiency RLVR training data curation
L20-Edu-135M is a 134.5M-parameter language model trained end-to-end on a single NVIDIA L20 GPU on roughly 13B tokens, with documented data gates, near-deduplication, benchmark-overlap removal, supervised fine-tuning with weight interpolation, and RLVR on GSM8K. It trails SmolLM-135M on a self-run six-task harness (mean 0.4150 versus 0.4767) while using 2.17% of its nominal token count, and direct GRPO-style RLVR decreased GSM8K exact-match accuracy in the reported single runs.
