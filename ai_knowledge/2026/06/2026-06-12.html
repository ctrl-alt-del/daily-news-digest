Nemotron 3 Ultra: Open, Efficient Mixture-of-Experts Hybrid Mamba-Transformer Model for Agentic Reasoning
Nemotron 3 Ultra：面向 Agent 推理的开源高效 MoE 混合 Mamba-Transformer 模型
mixture-of-experts hybrid Mamba-Transformer long-context models open-weight models agentic reasoning
Nemotron 3 Ultra is a 550-billion-total, 55-billion-active Mixture-of-Experts hybrid Mamba-Attention model pre-trained on 20 trillion text tokens and extended to a 1M-token context. Alibaba arxiv:2606.14697 arXiv ✓
ClinHallu: A Benchmark for Diagnosing Stage-Wise Hallucinations in Medical MLLM Reasoning
ClinHallu：诊断医疗多模态 LLM 推理中分阶段幻觉的基准
hallucination diagnosis medical MLLM knowledge recall reasoning traces
ClinHallu is a benchmark of 7,031 validated instances for diagnosing stage-wise hallucinations in medical multimodal LLM reasoning, with each instance annotated with a trace split into visual recognition, knowledge recall, and reasoning integration. Stage-replacement interventions measure how correcting specific stages changes answers, and trace-supervised fine-tuning is shown to reduce stage-wise hallucinations.
→ arxiv.org
arxiv:2606.14958 arXiv ✓
MVEB: Massive Video Embedding Benchmark
MVEB：大规模视频嵌入基准
video embeddings embedding benchmarks multimodal retrieval MTEB
MVEB is a 23-task benchmark for video embeddings covering classification, clustering, pair classification, retrieval, and video-centric question answering, evaluated across 33 models. No single model dominates: MLLM-based embeddings lead several task types, multimodal binding leads retrieval and zero-shot classification, and audio's contribution depends on whether dataset labels were produced from both modalities.
→ arxiv.org
arxiv:2606.14948 arXiv ✓
Beyond Correctness: Enhancing Architectural Reasoning in Code LLMs via Scalable Labeling with Agentic Judgment
超越正确性：通过 Agent 评判的可扩展标注增强代码 LLM 的架构推理
architectural reasoning agentic judging code LLMs fine-tuning
The paper introduces an agentic judging pipeline with an Architecture Complexity Judge and an Architecture Quality Judge that uses source-grounded rubrics to score how well code patches follow repository conventions. Fine-tuning Qwen3-8B/14B/32B on 3,360 curated instances reaches up to 27.2% on SWE-bench Verified, which the authors report as up to 540% over the base model.

arxiv:2606.14885 arXiv ✓
Dr-DCI: Scaling Direct Corpus Interaction via Dynamic Workspace Expansion
Dr-DCI：通过动态工作区扩展规模化直接语料交互
agentic search direct corpus interaction workspace expansion retrieval scaling
DR-DCI is a retriever-steered direct-corpus-interaction framework in which an agent pulls relevant documents into a growing local workspace and runs shell-style search, filtering, comparison, and verification there. It reaches 71.2% on Browsecomp-Plus, rising to 73.3% with workspace-preserving context reset, and remains effective from 100K to 10M documents.
→ arxiv.org
DeepSeek arxiv:2606.15008 arXiv ✓
Security Engineering of OpenClaw: Analyzing Attack Surface Expansion and Trust-Boundary Violations
OpenClaw 的安全工程：攻击面扩张与信任边界违规分析
multi-agent security attack surface trust boundaries policy gating
A security analysis of OpenClaw, a self-hosted multi-agent system whose LLM outputs can execute commands and call tools, finds compromise probability rising from 0.24 with one agent to 0.86 with seven when any single agent can trigger an action. Policy gating and execution filtering reduced compromise probability by 0.10, though the system remained sensitive.
→ arxiv.org
arxiv:2606.15017 arXiv ✓
Are Online Skill and Memory Modules Always Worth Their Tokens? A Budget-Constrained Study of Web Agents
在线技能与记忆模块真的值这些 token 吗？一项预算受限的 Web Agent 研究
agent memory skill modules token budget evaluation variance
The authors compare three online augmentation methods for Web agents against a token-matched vanilla baseline across four WebArena domains and three models, finding the baseline matches or surpasses all three in aggregate success rate while often using fewer tokens. They report a similar trend on WorkArena-L1 and argue that run-to-run variance should be a core evaluation criterion.
