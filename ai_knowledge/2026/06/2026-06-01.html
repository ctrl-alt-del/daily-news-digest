PIXELRAG: Web Screenshots Beat Text for Retrieval-Augmented Generation
PIXELRAG：网页截图在检索增强生成中胜过文本
visual RAG pixel retrieval visual embeddings screenshot datastore multimodal QA
PixelRAG represents websites in their native visual form and performs retrieval and reading entirely in pixel space, scaling to a 30-million-screenshot Wikipedia datastore built on a fine-tuned Qwen3-VL-Embedding. It outperforms text-based RAG baselines by up to 18.1% on text-centric, multimodal and agentic benchmarks, and image compression cuts token cost by up to 3x at lower resolutions while maintaining accuracy.

Traj-Evolve: A Self-Evolving Multi-Agent System for Patient Trajectory Modeling in Lung Cancer Early Detection
Traj-Evolve：用于肺癌早期检测患者轨迹建模的自进化多智能体系统
experience pool self-evolving agents patient trajectories EHR reasoning lung cancer prediction
Traj-Evolve pairs a non-parametric Experience Pool, which indexes rejection-sampled reasoning traces so similar patients can be retrieved as few-shot context, with multi-agent reinforcement learning that optimizes inter-agent and agent-memory collaboration. On lung cancer prediction from up to five years of multimodal electronic health records it beats nine baselines, with the experience pool improving specificity and MARL improving sensitivity.

Forgetting is Not Erasure: Recovering Latent Knowledge via Transport Keys
遗忘并非抹除：通过传输键恢复潜在知识
catastrophic forgetting latent knowledge transport keys continual learning model stitching
The paper argues that much apparent catastrophic forgetting reflects interface drift between internal stages rather than permanent erasure, tested with a stitched evaluation protocol that joins early computation from a post-update network with late computation from its predecessor. Compact task-specific transport keys recover most original Task A performance after sequential training on split CIFAR-100, suggesting continual learning needs better indexing of latent computations rather than only methods that prevent weight change.

Attention Calibration for Position-Fair Dense Retrieval
面向位置公平稠密检索的注意力校准
dense retrieval position bias attention calibration sentence transformers
The authors introduce a strength coefficient that interpolates between uncalibrated and fully equalized attention for dense retrieval, plus an implementation that cuts peak calibration memory from 5-7 GiB to under 1 MiB. A configuration selected on English FineWeb-PosQ and transferred without tuning reduced position sensitivity in all 16 evaluated settings by up to 43% relative while improving nDCG@10 by up to 4.8%, and the code is released.

Acceptance-Test-Driven Evaluation Protocols for Business-Centric LLM Systems
面向业务型 LLM 系统的验收测试驱动评估协议
acceptance testing LLM governance release gates behavioral contracts
The paper proposes an evaluation-protocol extension for operational LLM systems that turns stakeholder goals into executable behavioral contracts, release gates, monitoring signals and evidence artifacts before prompt, model, retrieval or agent changes are accepted. It adapts test-driven development into a red-train-green lifecycle and describes a governance-oriented metric stack and reference architecture for comparing acceptance-test-driven development with prompt-first and benchmark-after workflows.

Designing for Doubt: The Case for Informed Abstention in Autonomous Agents
为怀疑而设计：自主 Agent 需要“知情弃权”
informed abstention agent safety compliance bias runtime enforcement
The authors argue that agent evaluation rewards task completion even when inputs or authorization are missing, a pattern they call compliance bias, and propose an Informed Abstention Framework. In a 144-scenario test across seven model families, runtime enforcement blocked 87.5-91% of hazardous actions at 75-92% usability.

LLM-Assisted Reranking to Operationalize Nuanced Objectives in Recommender Systems
LLM 辅助重排序：在推荐系统中落实细微目标
LLM reranking recommender systems prompt constraints content exposure
Using real YouTube trajectories, the authors rerank sidebar candidates by zero-shot prompting across three models and an embedding baseline, measuring relevance, ideological alignment and exposure to conspiratorial or extremist content. Pure personalization instructions improved relevance but narrowed ideological exposure and, for two of three models, promoted problematic content for users with such histories, while lightweight prompt-level constraints substantially reduced that exposure and the constrained rerankers still ranked above the platform baseline on relevance.
