SkillOpt: Agent skills as trainable parameters
SkillOpt：将智能体技能作为可训练参数
self-evolving skills skill optimization validation gating agentic workflows prompt drift
Microsoft Research's SkillOpt treats an agent's natural-language skill file as a trainable parameter outside a frozen model, running a forward–backward–update loop with a textual learning rate and validation gating to prevent prompt drift. Across six benchmarks, seven models and three execution modes it was best or tied-best in all 52 cells, raising GPT-5.5's six-benchmark average from 58.8 to 82.3 without updating any model weights; code is on GitHub.
→ www.microsoft.com
Microsoft arxiv:2602.03315 Microsoft Research ✓
Memora: A Harmonic Memory Representation Balancing Abstraction and Specificity
Memora：一种平衡抽象与具体的谐波记忆表示
agent memory memory consolidation cue anchors multi-hop retrieval LongMemEval
Microsoft Research introduced Memora, an agentic memory framework that decouples what is stored (rich memory values) from how it is retrieved (short primary abstractions and cue anchors), plus a policy-guided retriever for multi-hop recall. It reports state-of-the-art results on LoCoMo (86.3% LLM-judge) and LongMemEval (87.4%), beating Mem0, RAG, Zep and full-context inference while using up to 98% fewer context tokens; the paper appears at ICML 2026 with code on GitHub.
→ www.microsoft.com

Google DeepMind, with Schmidt Sciences, the Cooperative AI Foundation, ARIA and Google.org, announced a technical research funding call of up to $10M focused on the safety of large-scale multi-agent systems where millions of independently built agents interact. Google DeepMind Google DeepMind ✓
Securing the future of AI agents
保障 AI 智能体的未来安全
AI control agent safety agent trajectory monitoring chain-of-thought oversight
Google DeepMind detailed its AI Control Roadmap, a defense-in-depth framework that treats internal agents as potential insider threats and layers system-level security on top of model alignment, using trusted AI 'supervisors' to monitor an agent's reasoning and actions. The team says it has already analyzed a million coding-agent trajectories, noting most flagged events stem from agent misinterpretation or overeagerness rather than adversarial intent, and published a companion policy paper, 'Three Layers of Agent Security.'
