MLEvolve: A Self-Evolving Framework for Automated Machine Learning Algorithm Discovery
MLEvolve：自动机器学习算法发现的自进化框架
self-evolving agents experience memory MLE-Bench tree search algorithm discovery
MLEvolve extends tree search to Progressive MCGS so information flows across branches through graph-based reference edges, and adds Retrospective Memory combining a cold-start domain knowledge base with dynamic global memory for task-specific experience reuse. On MLE-Bench it reports state-of-the-art average medal rate and valid submission rate under a 12-hour budget, and also outperforms specialized methods including AlphaEvolve on mathematical algorithm optimization tasks.

OpenSkill: Open-World Self-Evolution for LLM Agents
OpenSkill：LLM Agent 的开放世界自我进化
self-evolution skill acquisition self-built verifier open-world learning
OpenSkill targets open-world self-evolution, where an agent receives only a task prompt and must build both skills and verification signals from documentation, repositories and the web with no target-task supervision. It synthesizes grounded knowledge into transferable skills and refines them against self-built virtual tasks, attaining the best automated pass rate across three benchmarks and two target agents while satisfying the no-supervision constraint.

Code2LoRA: Hypernetwork-Generated Adapters for Code Language Models under Software Evolution
Code2LoRA：软件演化下代码语言模型的超网络生成适配器
repository knowledge LoRA adapters hypernetwork code models RepoPeftBench
Code2LoRA uses a hypernetwork to generate repository-specific LoRA adapters, injecting repository knowledge with zero inference-time token overhead; a static variant converts one snapshot while an evolution variant maintains an adapter backed by a GRU hidden state updated per code diff. On the new RepoPeftBench of 604 Python repositories the static variant matches per-repository LoRA at 63.8% cross-repo exact match, and the evolving variant gains 5.2 points over a single shared LoRA.

Will the Agent Recuse, and Will It Stop? Measuring LLM-Agent Compliance with In-Band Governance Signals at the Access Door and Mid-Flight
Agent 会回避、会停下吗？衡量 LLM Agent 对带内治理信号的遵从
agent governance recuse signal cooperative control compliance measurement
The paper proposes an in-band Recuse Signal that servers emit over existing channels such as an SSH banner, PostgreSQL notice or Kubernetes warning to ask a connecting or running agent to withdraw, defining an open mini-standard and three live adapters. Across five agents, access-door recusal ranged from 100% to 55-75% among agents that received it, mid-flight halts were weaker and model-dependent, and a harness-level interceptor stopped the loop 120/120 across six models.

Diagnosing Evidence Utilization in Long-Context and Retrieval-Augmented Language Models under Matched Evidence Conditions
在证据匹配条件下诊断长上下文与检索增强语言模型的证据利用
evidence utilization long context ONCU metric multi-hop QA
The paper introduces a four-condition diagnostic protocol and the ONCU metric to measure how much answer advantage long-context and retrieval-augmented models actually recover from supplied evidence. Across 18,000 predictions from five open-weight Qwen, Gemma, Llama and Mistral models, results were task-dependent, with full context outperforming tested retrieval on realistic multi-hop tasks.

MADRAG: Multi-Agent Debate with Retrieval-Augmented Generation for Training-Free Analytic Essay Scoring
MADRAG：面向免训练分析性作文评分的多 Agent 辩论与检索增强生成
multi-agent debate retrieval augmentation LLM-as-judge essay scoring
MADRAG decomposes analytic essay scoring into an Advocate that identifies strengths, a Skeptic that critiques weaknesses and a Judge that aggregates their arguments, with the Judge augmented by rubric-aligned exemplar retrieval for calibration. It significantly outperforms prompt-based baselines and approaches supervised systems without task-specific training, with ablations attributing calibration gains to retrieval and higher-level reasoning gains to debate.

RECAP: Regression Evaluation for Continual Adaptation of Prompts
RECAP：面向提示持续适配的回归评估
prompt adaptation continual learning regression evaluation production agents
RECAP measures forgetting, regression and forward transfer at the constraint level under a proactive adapt-then-test protocol, where prompt optimization methods receive only a constraint specification and must generalize before seeing any test data. Evaluating six methods across five LLMs and three schedules with evolving constraints, the authors find no significant performance improvement despite higher latency.

Goedel-Architect: Streamlining Formal Theorem Proving with Blueprint Generation and Refinement
Goedel-Architect：通过蓝图生成与细化简化形式化定理证明
formal theorem proving blueprint graph Lean 4 MiniF2F
Goedel-Architect generates a blueprint dependency graph of definitions and lemmas for Lean 4, then closes each open lemma node in parallel with a tool-equipped prover while failed lemmas drive refinement of the global blueprint. Using DeepSeek-V4-Flash as backbone it reaches 99.2% pass@1 on MiniF2F-test and 75.6% on PutnamBench, rising to 100% and 88.8% when the initial blueprint is seeded with a natural-language proof.

Evidence Graph Consistency in Retrieval-Augmented Generation: A Model-Dependent Analysis of Hallucination Detection
检索增强生成中的证据图一致性：幻觉检测的模型依赖性分析
hallucination detection evidence graph structural consistency RAGTruth
