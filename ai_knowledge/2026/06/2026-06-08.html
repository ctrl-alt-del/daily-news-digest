$τ$-Rec: A Verifiable Benchmark for Agentic Recommender Systems
τ-Rec：面向 Agent 推荐系统的可验证基准
agentic recommendation verifiable rewards pass^k reliability multi-turn dialogue
$\tau$-Rec replaces subjective LLM-as-a-judge evaluation for agentic recommenders with verifiable rewards and a reveal-tagged elicitation mechanism that controls when task constraints surface during dialogue. Across nine configurations from five model families, even the best model reaches only about 57% at pass^1 and 35% at pass^4, revealing a steep reliability cliff.

Regimes: An Auditable, Held-Out-Gated Improvement Loop Demonstrated on LongMemEval with ActiveGraph
Regimes：在 LongMemEval 与 ActiveGraph 上演示的可审计、留出集门控改进循环
agent memory self-improvement held-out validation event sourcing LongMemEval
Regimes is an auditable improvement loop on the event-sourced ActiveGraph runtime that diagnoses failed evaluations, proposes repairs at typed pipeline seams, and promotes them only after static checks, sandbox execution, in-sample evaluation, and held-out validation. On LongMemEval-S it finds the dominant failure is reconciliation rather than retrieval, with reader-prompt repairs improving held-out accuracy by +0.05 to +0.10 in four of five seeded splits.

A Source Domain is All You Need: Source-Only Cross-OS Transfer Learning for APT Anomaly Detection via Semantic Alignment and Optimal Transport
仅需源域：通过语义对齐与最优传输实现跨 OS APT 异常检测
APT detection embeddings optimal transport zero target supervision
The paper studies source-only cross-OS APT detection from system-level provenance traces, abstracting process behavior into structured natural-language descriptions and embedding them for comparison against a source-normal reference. It combines semantic, structural (graph-autoencoder), and optimal-transport deviations into a barycentric anomaly score, requiring no target-domain labels.

Bittensor Agent Arenas as a Trajectory Primitive: Distilling a Shopping Agent from ShoppingBench Subnet Traces
Bittensor Agent 竞技场作为轨迹原语：从 ShoppingBench 子网轨迹蒸馏购物 Agent
agent trajectories post-training data Bittensor benchmark contamination
The paper argues that incentive-aligned agent arenas can manufacture the multi-turn traces needed for small-model agentic post-training, demonstrating this on Bittensor ORO Subnet 15, a deployment of the ShoppingBench agentic-commerce benchmark. Its race mechanism, LLM reasoning judge, and rotating leak-cluster-guarded problem suite reportedly yield incentive-aligned diversity, per-trajectory judging, and anti-memorized held-out evaluation, with a structural-quality filter separating agentic from sub-task trajectories.

ReasonRec: A Reasoning-Augmented Multimodal Agent for Unified Recommendation
ReasonRec：面向统一推荐的理由增强多模态 Agent
multimodal recommendation chain-of-thought uncertainty estimation instruction tuning
ReasonRec is a reasoning-augmented multimodal recommendation agent built around a three-stage explicit reasoning pipeline, with reasoning-aware visual instruction tuning that turns recommendation tasks into unified chain-of-thought prompts and uncertainty-guided delegation of compute. Across four recommendation tasks and five real-world datasets it reports over 30% relative improvement and better cold-start and long-tail handling.

Robust Active Learning for Few-Shot Example Selection in Text-to-SQL
面向文本转 SQL 少样本示例选择的鲁棒主动学习
text-to-SQL active learning query embeddings few-shot retrieval
The paper treats which queries to annotate for few-shot text-to-SQL as constrained experimental design on a low-dimensional query-embedding manifold, with query-dependent annotation noise and a partition-matroid spread constraint. It proposes a stratified greedy algorithm with a 1/2-approximation guarantee and a retrieval model that bounds few-shot accuracy by fill distance, demonstration noise, and domain coverage.

当设计规则失效：基准组成决定标签信息量能否预测 GNN 聚合器选择
