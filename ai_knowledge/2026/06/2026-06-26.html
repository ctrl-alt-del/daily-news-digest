SkillOpt: Agent Skills as Trainable Parameters — Microsoft Research Achieves +23.5 Point Average Improvement Across 52 Evaluation Cells
SkillOpt：将Agent技能参数化为可训练参数 — 微软研究院在52个评估单元中平均提升23.5分
SkillOpt agent skills prompt optimization training loop open-source
Microsoft Research proposes SkillOpt (Jun 30), treating agent skill files as trainable parameters outside a frozen model, with a full training loop: forward pass (batch execution), backward pass (trajectory reflection), bounded text edits, validation gating, rejected-edit feedback, and epoch-wise slow/meta updates. Evaluated across 6 benchmarks, 7 models (from GPT-5.5 to Qwen3.5-4B), and 3 execution modes (direct chat, Codex, Claude Code), SkillOpt was best or tied-for-best in all 52 evaluation cells. Average six-benchmark score rose from 58.8 to 82.3 (+23.5). Skills transfer across model scales and harnesses: a spreadsheet skill trained in Codex lifted Claude Code from 22.1 to 81.8. Only 1-4 accepted edits yield compact ~920-token skill files. Open-source at github.com/microsoft/SkillOpt.

Project Fetch Phase Two: Claude Opus 4.7 Operates Robodog Autonomously, 20x Faster Than Human Teams
Project Fetch第二阶段：Claude Opus 4.7自主操控机器狗，比人类团队快20倍
physical agents robotics Claude Opus 4.7 autonomous
Anthropic revisited Project Fetch: Claude Opus 4.7 operated a robotic quadruped without human assistance and was ~20x faster than the fastest human team from Phase One on all completed tasks. The model was ~37x faster than the team without Claude. However, Claude still struggled with precise physical manipulation (beach ball retrieval). The trajectory mirrors coding agents: 'models helpful to humans → humans helpful to models → models do it themselves,' suggesting the early era of physical agentic AI.

Paving the Way for AI Agents in Biology: Deterministic Retrieval Layers Make Scientific Agents Reliable (VirBench + gget virus)
为生物学AI Agent铺路：确定性检索层让科学Agent可靠（VirBench基准 + gget virus工具）
scientific agents deterministic retrieval VirBench gget virus biology
Anthropic studied how AI agents perform on viral sequence retrieval from NCBI Virus. Even frontier models (Claude, GPT-5.5, Biomni) achieved only 16-91% accuracy on VirBench due to brittle biological data infrastructure. Adding gget virus, a deterministic retrieval layer, raised accuracy to near 100% and eliminated run-to-run variability. Quantified real-world impact: inconsistent NCBI Virus retrievals shifted inferred Ebola outbreak TMRCA from 2014 to 1922. Preprint, benchmark, and tool are public.
→ www.anthropic.com

Coding Agents in the Social Sciences: 1,260-Researcher Survey Finds 20% Adoption, Sharp Disparities
社会科学中的编程Agent：1260名研究者调查发现20%采用率，存在显著差异
coding agents adoption survey Claude Code 社会科学
Anthropic surveyed 1,260 quantitative social scientists (Feb-Mar 2026). 81% have tried AI chatbots, but only 20% adopted coding agents (Claude Code 86% dominant). Adoption gap: economists 39% vs public health 6%; men 2x women; top-university researchers 40% more likely. Coding agent users post more working papers and grants but not yet more journal submissions. Most common uses: coding (97% of agent users), editing prose, methods advice.
