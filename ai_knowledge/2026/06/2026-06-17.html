Diffusion-Proof: Recipe for Formal Theorem Proving Beyond Auto-Regressive Generation
Diffusion-Proof：超越自回归生成的形式定理证明配方
formal theorem proving diffusion LLM proof correction Lean
Diffusion-Proof is described as the first framework to train and apply diffusion LLMs to formal theorem proving, pairing a 7B whole-proof writer with a 7B large-block diffusion corrector that repairs proofs locally using bidirectional context. It reports absolute gains of 1.61% on ProofNet-Test and 6.14% on MiniF2F-Test over an autoregressive baseline trained on the same data, and resolves one IMO problem that the more advanced thinking model DeepSeek-Prover-V2-7B reportedly could not solve.

arxiv:2606.19605 arXiv ✓
FAPO: Fully Automated Prompt Optimization of Multi-Step LLM Pipelines
FAPO：多步 LLM 流水线的全自动提示优化
prompt optimization LLM pipelines failure attribution pipeline evaluation
FAPO lets Claude Code optimize a multi-step LLM pipeline inside a standardized codebase by evaluating it, inspecting intermediate steps, diagnosing failures, and proposing scoped changes, starting with prompt edits and altering chain structure only when attribution identifies a structural bottleneck. It beats GEPA in 15 of 18 model-benchmark comparisons with a mean gain of 14.1 percentage points, and wins all six cases where prompt-first search escalated to structural changes, by 33.8 points on average.

arxiv:2606.19625 arXiv ✓
Capability Provenance in Language Models: A Case Study in Social Reasoning
语言模型中的能力溯源：社会推理案例研究
training-data attribution capability provenance machine unlearning social reasoning
Using gradient-based training-data attribution over the Dolma3 mix, the authors map which corpus regions support social versus STEM reasoning in OLMo3-7B and find that the two draw on qualitatively distinct regions, with the contrast sharper at the reasoning level than at the knowledge level. Targeted unlearning of high-attribution topics degrades the aligned benchmark more than within-topic random baselines, and the code and aggregate artifacts are released.
→ arxiv.org
DeepSeek arxiv:2606.19559 arXiv ✓
Uncertainty Decomposition for Clarification Seeking in LLM Agents
面向 LLM 智能体澄清提问的不确定性分解
clarification seeking uncertainty estimation prompt-based estimation underspecified tasks
The paper proposes a prompt-based decomposition that separates action confidence from request uncertainty, letting an agent ask for clarification when a task specification is ambiguous, using only signals available under black-box API and latency constraints. On two clarification-augmented benchmarks where half the tasks are deliberately underspecified, it improves clarification F1 on ALFWorld-Clarification by 73% over ReAct+UE and by 36% over Uncertainty-Aware Memory averaged across five backbones.

SAGE-OPD: Selective Agent-Guided Intervention for Multi-Turn On-Policy Distillation
SAGE-OPD：面向多轮在线策略蒸馏的选择性智能体引导干预
agent distillation on-policy distillation teacher confidence ALFWorld
SAGE-OPD is a verifier-free selective-intervention framework for multi-turn on-policy distillation that uses environment feedback and teacher judgment to decide when to intervene and weights token-level distillation by teacher confidence. It reports up to a 13.3% relative gain in ALFWorld unseen-task success over standard on-policy distillation.

IHBench: Evaluating Post-Interruption Recovery in Voice Agents with Structured Workflows
IHBench：评估结构化工作流中语音智能体被中断后的恢复能力
voice agents interruption recovery agent benchmark workflow state
IHBench evaluates how voice agents recover after interruptions while executing state-machine-driven workflows across 10 enterprise domains, scoring task fulfillment and recovery quality for six interruption types injected mid-utterance. Across 27 audio-language model configurations, closed-weight models were consistently more robust, degraded roughly 3.3x more slowly as conversations grew longer, and showed no audio-versus-text modality gap, while open-weight models lost ground on all three.

Deontic Policies for Runtime Governance of Agentic AI Systems
面向智能体 AI 系统运行时治理的道义政策
agent governance deontic policy ontology reasoning runtime policy
The paper proposes AgenticRei, which expresses deontic policies covering obligations, dispensations, conflict resolution, and permit or prohibit rules in OWL on top of the Rei framework and evaluates them at runtime with a logic engine outside the LLM. The same pipeline governs tool invocations and agent-to-agent messages, addressing governance constraints the authors say production engines such as XACML, Rego, and Cedar cannot express.

arxiv:2608.28596 arXiv ✓
Paper Pilot: A Human-in-the-Loop Expert System for Evidence-Traceable Scientific Manuscript Generation in Applied Sciences
Paper Pilot：面向应用科学、证据可追溯的人机协同手稿生成专家系统
evidence traceability human-in-the-loop citation grounding manuscript generation
Paper Pilot adapts the Collaborative Agent Reasoning Engineering methodology to scientific manuscript development with eight approval gates, claim classification, audit logging, and evidence-locked revision control that keeps reported numbers and interpretations traceable to approved evidence. In a mechanically scored citation-grounding benchmark, ungated drafters fabricated up to 25% of their citations and never flagged an evidence gap, while the same models under Paper Pilot's rules produced zero fabricated citations and surfaced planted gaps as explicit placeholders.

arxiv:2606.21089 arXiv ✓
Repeated post-training is not Self-improving: Diagnosing Scientific Amnesia in Continual DPO Pipelines
重复后训练并不等于自我改进：诊断持续 DPO 流水线中的“科学失忆”
scientific amnesia continual learning DPO meta-scientific memory
The paper names scientific amnesia as a failure mode in which repeated DPO campaigns preserve previously learned behaviors but fail to accumulate reusable methodological knowledge about how to run the next campaign, and contributes a diagnostic suite plus a 30-campaign HumanEval subdomain benchmark. Across a five-condition, three-step real-model chain, four of five strategy proposers degraded in step-level peak pass@1, including the meta-scientific memory candidate MSCL, while only a deliberately conservative rule-based schedule improved; follow-up pilots qualified rather than overturned that finding.
