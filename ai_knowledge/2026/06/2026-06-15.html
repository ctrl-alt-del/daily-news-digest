Trust-Aware Multi-Agent Traceability: Confidence-Calibrated Knowledge Graphs for Consistent Software Artifact Management
可信多 Agent 可追溯性：面向一致软件制品管理的置信度校准知识图谱
shared knowledge graph confidence calibration multi-agent coordination semantic memory traceability
The paper proposes a trust-aware coordination framework in which a shared knowledge graph serves as both centralized semantic memory and a coordination surface for multi-agent software pipelines, with calibrated confidence scores. It combines embedding-based retrieval with LLM multi-criteria analysis for traceability links and adds confidence-threshold gating, divergence detection, and conflict resolution, evaluated on an automotive case study.

Verified Detection and Prevention of Concurrency Anomalies in Multi-Agent Large Language Model Systems
多 Agent 大语言模型系统中并发异常的验证检测与预防
multi-agent concurrency shared memory formal verification vector indices
The paper models shared state in multi-agent LLM systems, including memory stores, vector indices, and tool registries, as long-running read-generate-write operations and formalizes four concurrency anomalies in TLA+. It machine-checks a consistency hierarchy, proves detectors sound and complete with 274 Verus obligations, and reproduces a silent lost update in ByteDance's deer-flow and tool-effect reordering in LangGraph's ToolNode.

DeepSeek arxiv:2606.16999 arXiv ✓
Selection Without Signal, Recovery Through Expression: A Measurement Study of Post-Hoc Falsification Operators for Frozen Small Code Models
无信号的选择，通过表达式恢复：冻结小型代码模型事后证伪算子的测量研究
post-hoc selection code models test-time compute negative result
The study evaluates 26 semantic post-hoc operators for frozen small code models against Best-of-N under a deterministic execution oracle and a leakage-free, matched-compute protocol, and finds none improves held-out accuracy on the tested cells. The one accuracy gain comes from an expression-layer recovery that preserves correct programs the standard extractor discards, lifting DeepSeek-Coder-1.3B by 12 tasks on HumanEval+.

arxiv:2606.17220 arXiv ✓
When Rules Learn: A Self-Evolving Agent for Legal Case Retrieval
当规则学会学习：面向法律案例检索的自演化 Agent
query rewriting self-evolving agents legal retrieval rule learning
The paper presents a self-evolving framework for rule-driven query rewriting that improves BM25 without parameter training: an LLM agent creates rewriting rules, plans validation experiments over rule combinations, and eliminates ineffective rules from historical feedback. On the Chinese legal retrieval benchmark LeCaRD-v2, it outperforms human-designed rules and greedy rule selection, particularly with a high-capacity core LLM.

arxiv:2606.16987 arXiv ✓
Consensus-based Agentic Large Language Model Framework for Harmonized Tariff Schedule Code Classification
面向协调关税表编码分类的共识式 Agentic LLM 框架
multi-agent retrieval tariff classification consensus validation human-in-the-loop
The paper proposes an agentic LLM framework for Canadian 10-digit Harmonized Tariff Schedule classification that combines multi-agent information retrieval, semantic retrieval over official tariff documents, evidence-grounded reasoning, consensus validation, element-wise voting, confidence estimation, and human-in-the-loop escalation. On 3,300 expert-labeled product records, exact 10-digit classification remains difficult even for advanced LLMs, with performance degrading from chapter-level to fine-grained suffixes.
→ arxiv.org
arxiv:2606.17246 arXiv ✓
GeoDisaster: Benchmarking Orchestrated Agents for Operational Disaster Geo-Intelligence
GeoDisaster：面向业务化灾害地理智能的编排 Agent 基准
agent benchmark tool-grounded reasoning geospatial evidence multi-agent orchestration
GeoDisaster is a benchmark of 2,921 verified instances across 43 question types and five disaster-reasoning task families, integrating optical and SAR imagery, raster masks, vector geometries, road networks, and exposure layers with ground truth from executable geospatial workflows. The authors also propose an orchestrated multi-agent framework with 18 tools and a Role-Contract Expectation Alignment training scheme.
