EpiEvolve: Self-Evolving Agents for Streaming Pandemic Forecasting under Regime Shifts
EpiEvolve：机制切换下流式疫情预测的自进化智能体
episodic memory self-evolving agents regime shifts regime-aware retrieval forecasting
EpiEvolve wraps a fixed-weight LLM forecaster with hierarchical episodic memory, reflection on delayed labels and regime-aware retrieval for streaming weekly COVID-19 hospitalization forecasts. It reports 0.629 average accuracy versus 0.561 for the static backbone and cuts recovery lag after regime shifts from five weeks to two.

Trust, but Don't Verify: Epistemic Blind Spots in LLM Source Evaluation
信任但不验证：LLM 信息源评估中的认知盲区
source evaluation epistemic alignment multi-source synthesis numeric validity mechanistic analysis
The paper shows models can detect fabricated statistics in isolation but do not recruit that capability during multi-source synthesis, producing similar numeric estimates whether statistics are fabricated or valid. Source influence follows a methodology-register gate rather than numeric validity, a dissociation that replicates across six models from four families and three professional domains; prompting mitigations, even an oracle checklist, produce blanket skepticism rather than selective discernment.

Agentic Monte Carlo: Simulating Reinforcement Learning for Black-Box Agents
Agentic Monte Carlo：为黑盒 Agent 模拟强化学习
black-box agents sequential Monte Carlo test-time compute value function AgentGym
Agentic Monte Carlo exploits the equivalence between reinforcement learning and Bayesian inference to sample from an optimal policy for black-box LLM agents, using Sequential Monte Carlo with a learned value function to steer the agent while leaving the underlying model unchanged. On three AgentGym environments it beats prompting baselines and outperforms GRPO as test-time compute scales, with code released.

schema contracts knowledge graph multi-source retrieval agent routing provenance

ReasoningFlow: Discourse Structures for Understanding LLM Reasoning Traces
ReasoningFlow：理解 LLM 推理轨迹的话语结构
reasoning traces discourse structure DAG annotation monitorability
ReasoningFlow captures the discourse structure of reasoning traces as fine-grained directed acyclic graphs, validated on 31 manually annotated traces and scaled to 1,260 traces (247.7k steps) across three tasks and five models. The analysis finds structurally similar traces across models, surfaces fine-grained behaviors useful for monitoring, and reports that most erroneous steps are not used to derive final answers while causal dependencies do not mirror language-level discourse.

ANN indexing vector search hyperparameter optimization LLM agent

arxiv:2606.05315 arXiv ✓
LoRi: Low-Rank Distillation for Implicit Reasoning
LoRi：面向隐式推理的低秩蒸馏
implicit chain-of-thought distillation low-rank structure mathematical reasoning
Observing that hidden-state reasoning trajectories exhibit low-rank structure, the authors propose a low-rank distillation framework that aligns teacher and student trajectories in a shared low-rank tensor subspace using first- and second-order statistics. Across LLaMA and Qwen models at different scales it improves mathematical reasoning, approaching explicit chain-of-thought accuracy and outperforming prior implicit-CoT distillation methods.

Localizing Prompt Ambiguity in Large Language Models with Probe-Targeted Attribution
利用探针靶向归因定位大语言模型中的提示歧义
prompt ambiguity attribution linear probe interpretability
PRIG is a gradient attribution method that trains a linear probe to separate clear from ambiguous prompts and attributes the probe score to token positions. It reaches 0.840 AUROC on a synthetic benchmark and 0.891 on a human-written gold set while outperforming GPT-5.4 on sentence-level ambiguity identification.
