EvoEmbedding: Evolvable Representations for Long-Context Retrieval and Agentic Memory
EvoEmbedding：面向长上下文检索与智能体记忆的可演化表示
evolvable embeddings agentic memory long-context retrieval latent memory
EvoEmbedding maintains a continuously updated latent memory as it processes input sequentially and uses it alongside the raw content to produce embeddings that adapt to evolving context, trained on a new 180K dataset with a memory queue to prevent representation collapse during recurrent encoding. It reports outperforming larger specialists such as Qwen3-Embedding-8B and KaLM-Embedding-Gemma3-12B on long-context retrieval, generalizing to contexts 10x longer than its training window, and letting a naive RAG pipeline surpass dedicated agentic memory systems.

arxiv:2606.28379 arXiv ✓
LEDGER: Scaling Agentic Document Editing with Dependency-aware Graph Retrieval
LEDGER：用依赖感知图检索扩展智能体文档编辑
dependency graph document editing graph-guided retrieval context engineering
LEDGER builds a lightweight dependency graph over long structured documents, covering hierarchical organization, explicit references, implicit dependencies, and semantic relationships, and retrieves only the context each edit needs. On a 1.9k-case benchmark spanning six models it raises consistency from 56% to 76% while reducing token usage, and LEDGER at low reasoning effort matches baseline high-effort performance.

arxiv:2606.21553 arXiv ✓
Dissecting Agentic RAG: A Component Ablation for Multi-Hop QA with a Local 7B Model
解构 Agentic RAG：本地 7B 模型多跳问答的组件消融
agentic RAG component ablation hybrid retrieval query decomposition
The study ablates a full agentic RAG pipeline on 5,000 HotpotQA distractor questions with a local Qwen2.5-7B-Instruct, where the full pipeline reaches EM 53.2% and F1 61.6% versus 43.1% and 54.0% for single-pass dense retrieval. Fixed hybrid retrieval with reciprocal rank fusion beats rule-based adaptive routing, and two retrieval iterations over decomposed sub-questions capture 95% of the gains of five.

arxiv:2606.21627 arXiv ✓
Counsel: A Meta-Evaluation Dataset for Agentic Tasks
Counsel：面向智能体任务的元评估数据集
agent evaluation LLM-as-judge process critiques meta-evaluation
Counsel is described as the first public dataset of meta-evaluations for agentic tasks, containing process-level critiques from open-weight LLM judges on tau-bench and DA-Code plus human labels of whether each critique was spot on, correct in location but poor in reasoning, or should not have been flagged. Annotator agreement reached Krippendorff's alpha of 0.78, and the strongest judge reached about 88% agreement on error location and 65% on reasoning.

CRAwLeR -- Cross-Reference Aware Legal Retrieval
CRAwLeR：交叉引用感知的法律检索
cross-reference retrieval legal retrieval context-aware chunking benchmark validity
CRAwLeR targets cross-reference-aware context utilization for chunk retrieval in legal documents, with a pipeline that detects legal cross-references, identifies query candidates, generates context-demanding queries with an LLM, and filters them against an adversarial non-contextual baseline. It releases Danish and Polish datasets, reports that about 80% of sampled queries genuinely target the labelled chunk and require context, and shows the benchmarks remain unsolved, with best Recall@10 of 55% on CRAwLeR-DK and 59% on CRAwLeR-PL.

CalVerT: Augmenting Agents with Calibrated Verifier Telemetry Improves Action and Learning in Knowledge-Intensive Tasks
CalVerT：用校准验证器遥测增强知识密集型任务中的智能体
verifier calibration adaptive retrieval agent state knowledge grounding
CalVerT adds a calibrated self-confidence score and a grounding verifier score to an LLM agent's state, so the agent retrieves when parametric knowledge is over-trusted and skips redundant retrieval when context already suffices. The authors report higher F1 with the telemetry and say the approach works with or without training.

Error-Aware TF-IDF Retrieval-Augmented Generation for ASR Error Correction
面向 ASR 纠错的错误感知 TF-IDF 检索增强生成
ASR correction lexical retrieval TF-IDF word error rate
The paper proposes a purely lexical retrieval-augmented correction framework for ASR that combines symmetric text normalization with an error-aware TF-IDF that penalizes documents unlikely to contain observed phonetic misrecognitions. On the Persian FLEURS subset it raises the error-aware hit rate from 53.7% to 90.9% and lowers end-to-end word error rate from 23.06% to 18.83% with near-zero inference latency.
