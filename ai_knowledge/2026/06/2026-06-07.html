PerspectiveGap: A Benchmark for Multi-Agent Orchestration Prompting
PerspectiveGap：多 Agent 编排提示词基准
orchestration prompting benchmark multi-agent topologies prompt composition
PerspectiveGap benchmarks 110 scenarios across 10 topologies to test how well LLMs compose orchestration prompts, using role-fragment assignment and free-form prompt writing. Testing 33 commercial models from 10 companies, it finds GPT-5.5 clearly ahead, Opus 4.8 weak at orchestration prompting despite strong coding, and an average combined pass rate of just 17.2%.

From Player to Master: Enhancing Test-Time Learning of LLM Agents via Reinforcement Learning over Memory
从玩家到大师：通过记忆强化学习提升 LLM Agent 的测试时学习
agent memory test-time learning reinforcement learning GRPO
MemoPilot trains the memory-update process of a frozen LLM as a multi-turn decision problem using multi-turn GRPO, with turn-wise rewards and context-independent turn-level advantage estimation. On multi-round Rock-Paper-Scissors and Limit Texas Hold'em it ranks first in Elo (1590 and 1762 respectively), outperforming baseline memory methods and proprietary models including DeepSeek-V3.2.

在亿级用户规模上构建客服 AI Agent：评估驱动框架
customer support agents context engineering LLM-as-judge production deployment

mathematical reasoning neuro-symbolic systems theorem proving survey benchmark evaluation

Sample-Efficient LLM-Based Detection of Malicious Web Server Logs with Forensically Explainable Reasoning
CEF-Log：样本高效且可法证解释的恶意 Web 服务器日志 LLM 检测
forensic log analysis chain-of-thought few-shot prompting explainability
CEF-Log is a context-enhanced few-shot chain-of-thought prompting strategy that embeds a structured five-step investigative template so LLMs learn how to analyze logs rather than what patterns to memorize. It reports an F1 of 0.99 on CSIC 2010 with only four examples, a 10x sample-efficiency improvement, and introduces the ForenWebLog dataset with real-world multi-step attacks.

Activation Steering Induces Emergent Misalignment: Steering Vector Construction and Comprehensive Evaluation
激活引导诱发涌现性失配：引导向量构建与综合评估
activation steering emergent misalignment AI safety interpretability
The study shows that steering vectors derived from a narrow task can induce emergent misalignment across unrelated domains, with activation-steering-induced misalignment reportedly producing more actionable harmful responses than finetuning-induced misalignment. It characterizes dependence on steering magnitude, steering-subspace rank, and construction epochs, and tests sensitivity across model families, scales, tasks, and intervention layers.

arxiv:2606.08696 arXiv ✓
Agentic Search for Counterfactual Recourse under Fixed LLM Budgets
固定 LLM 预算下的反事实救济 Agent 搜索
counterfactual recourse agentic search Monte Carlo tree search LLM budget
ReCo-MCTS frames counterfactual recourse generation as a fixed-budget search problem and combines LLM multi-candidate generation, constraint checking, black-box oracle evaluation, and UCT-guided tree search. On four real-world tabular datasets it returns more oracle-validated counterfactuals than the evaluated baselines under the specified resource limits, with trade-offs in the extent of the required changes.

Intrinsic Selection and Particle Resampling for Inference-Time Scaling Beyond Domain Verifiability
超越领域可验证性的推理时扩展：内在选择与粒子重采样
inference-time scaling entropy-based selection self-consistency compute allocation
The authors use length-adjusted tail entropy from parallel sample sets as a ground-truth-free signal of solution quality and as a gate for allocating compute. Intrinsic selection matches consensus methods across three domains and improves engineering-design selection by 20% over pass@1; particle filtering adds 6.1 points of pass@1 on hard math, and distillation yields up to 26.5% gains on complex clinical responses.

PaperMentor：面向 Overleaf 上 AI 研究论文的以人为本多 Agent 写作导师
multi-agent writing agent skills human-in-the-loop open-source
