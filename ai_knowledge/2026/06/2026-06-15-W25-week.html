arxiv:2606.28379 arXiv ✓
LEDGER: Scaling Agentic Document Editing with Dependency-aware Graph Retrieval
LEDGER：用依赖感知图检索扩展智能体文档编辑
dependency graph document editing graph-guided retrieval context engineering
LEDGER builds a lightweight dependency graph over long structured documents, covering hierarchical organization, explicit references, implicit dependencies, and semantic relationships, and retrieves only the context each edit needs. arxiv:2606.18356 arXiv ✓
SafeClawBench: Separating Semantic, Audit-Evidence, and Sandbox Harm in Tool-Using LLM Agents
SafeClawBench：区分工具调用型 LLM 智能体的语义、审计证据与沙箱危害
tool-use security memory poisoning prompt injection agent benchmark
SafeClawBench is a staged benchmark of 600 controlled adversarial tasks across six attack families, including direct and indirect prompt injection, tool-return injection, memory poisoning, and memory extraction, that scores semantic attack acceptance, audit-visible harm evidence, and sandbox-observed tool or state harm separately. Across five agent endpoints, semantic failure rates without extra prompt protection ranged from 9.0% to 44.2%, and a 12,000-row matched analysis found that 291 of 347 observed sandbox harms occurred in rows that passed the semantic check.
→ arxiv.org
arxiv:2606.20954 arXiv ✓
Learning What Not to Forget: Long-Horizon Agent Memory from a Few Kilobytes of Learning
学会不该忘记什么：仅需几千字节学习的长期智能体记忆
agent memory memory eviction long-horizon agents context management
LRE is a kilobyte-scale, CPU-only, language-model-free scorer that learns which units of interaction history are task-critical and keeps them by verbatim extraction rather than compression. Under a matched-budget comparison it recovers 93% of the accuracy of retaining full history (41.1 versus 44.0), cuts the worst-case peak prompt by 52%, and outranks dense and token-pruning encoders on conversational memory at zero neural cost while being 295–1569x smaller.
