Recursive Agent Harnesses
递归 Agent Harness：以完整 Agent 框架为递归单元
recursive agent harnesses subagent orchestration long-context reasoning harness recursion context management
Recursive Agent Harnesses (RAH) extends recursion over model calls to recursion over full agent harnesses: a parent agent runs a script that spawns subagent harnesses with filesystem tools, code execution, and planning. With GPT-5 held fixed, RAH raises a Codex coding-agent baseline from 71.75% to 81.36% on Oolong-Synthetic, and reaches 89.77% with Claude Sonnet 4.5.

Agents-K1: Towards Agent-native Knowledge Orchestration
Agents-K1：迈向 Agent 原生的知识编排
scientific knowledge graphs knowledge orchestration multimodal parsing graph retrieval GRPO
Agents-K1 is an end-to-end pipeline that converts raw scientific documents into agent-native knowledge graphs, using a five-module multimodal parser, a 4B GRPO-trained extraction backbone, and a tri-source CLI for web search, graph retrieval, and cross-document traversal. The authors process 2.46 million papers across six subjects into Scholar-KG and release a one-million-paper subset.

Learning to Reason by Analogy via Retrieval-Augmented Reinforcement Fine-Tuning
通过检索增强强化微调学习类比推理
retrieval-augmented fine-tuning analogical reasoning reasoning-aware retrieval reinforcement learning
Retrieval-Augmented Reinforcement Fine-Tuning (RA-RFT) trains a retriever to rank contexts by expected reasoning benefit rather than semantic similarity, then fine-tunes the policy with retrieved analogous demonstrations under verifiable outcome rewards. It improves AIME 2025 average@32 accuracy over GRPO by 7.1 and 2.8 points for Qwen3-1.7B and Qwen3-4B.

Hallucination as a Feature, not a Defect: Evaluating a multi-agent architecture to transform speculative language-model outputs into testable scientific hypotheses

multi-agent orchestration speculative generation web grounding hypothesis evaluation
The paper proposes a Rust-based multi-agent orchestration that pairs a high-entropy generating agent with a web-grounded evaluating agent through a low-entropy semantic bottleneck, aiming to turn speculative model outputs into viability-rated scientific hypotheses. arxiv:2606.13649 arXiv ✓
Operadic consistency: a label-free signal for compositional reasoning failures in LLMs
Operadic 一致性：LLM 组合推理失败的无标签信号
compositional reasoning reasoning failure detection multi-hop QA selective prediction
Operadic consistency (OC) compares a model's direct answer to a compositional query with the answer obtained by composing a stated decomposition of the same query, yielding a label-free per-question diagnostic. Across twelve LLMs on four multi-hop QA datasets, OC correlates strongly with accuracy (Pearson r 0.86-0.94) and adds selective-prediction gains beyond chain-of-thought self-consistency.
→ arxiv.org
arxiv:2606.13945 arXiv ✓
LatentDx: Latent Multi-Agent Communication for Cross-Hospital Rare-Disease Diagnosis
LatentDx：面向跨医院罕见病诊断的潜空间多 Agent 通信
multi-agent communication latent KV privacy-preserving rare-disease diagnosis
LatentDx lets hospital agents keep clinical records and retrieved cases local while sending compact latent KV blocks to a host agent for rare-disease diagnosis, using latent KV distillation for same-backbone agents and cross-family latent alignment otherwise. On its CrossRare-Bench it improves diagnostic performance while leaving less clinical content reconstructable than raw-latent baselines.

Can Post-Training Turn LLMs into Good Medical Coders? An Empirical Study of Generative ICD Coding
后训练能让 LLM 成为合格的医疗编码员吗？生成式 ICD 编码的实证研究
post-training ICD coding GRPO retrieval-augmented
A controlled study compares prompting, supervised fine-tuning, and reinforcement learning for generative ICD coding under a common protocol, finding that prompting-only evaluation substantially underestimates LLM potential. SFT provides the main capability jump, GRPO improves code-set prediction further, and a diagnostic curriculum called PHI adds targeted macro-level gains.
