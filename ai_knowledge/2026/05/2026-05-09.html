GRC: Unifying Reasoning-Driven Generation, Retrieval and Compression
GRC：统一推理驱动的生成、检索与压缩
context compression text embeddings latent memory RAG unified model
GRC unifies reasoning-driven generation, reasoning-enhanced text representation and context compression in a single forward pass using meta latent tokens and a joint generative, representative and compressive tuning approach. It introduces self-reason-latent embeddings and latent memory-augmented generation backed by an O(1)-length internalized KV cache, and reports gains on reasoning-intensive retrieval, generation, document compression and RAG settings.

arxiv:2605.09033 arXiv ✓
ShadowMerge: A Novel Poisoning Attack on Graph-Based Agent Memory via Relation-Channel Conflicts
ShadowMerge：通过关系通道冲突对图式智能体记忆发起的新型投毒攻击
graph memory poisoning knowledge graph agent security defense evaluation
ShadowMerge poisons graph-based agent memory by crafting a malicious relation that shares the query-activated anchor and canonicalized relation channel of benign evidence while carrying a conflicting value. Across Mem0 and the PubMedQA, WebShop and ToolEmu datasets it reports 93.8% average attack success, 50.3 points above the best baseline, and representative input-side defenses were insufficient.
→ arxiv.org
arxiv:2605.09184 arXiv ✓
Open Ontologies: Tool-Augmented Ontology Engineering with Stable Matching Alignment
开放本体：基于稳定匹配对齐的工具增强本体工程
ontology engineering ontology alignment MCP tools OWL reasoning
Open Ontologies is an open-source Rust system that combines LLM-driven ontology construction with formal OWL reasoning and alignment over the Model Context Protocol. Stable 1-to-1 matching reached F1 0.832 on the OAEI Anatomy track, and structured MCP tool access (F1 0.717) far outperformed an LLM reading a raw OWL file (0.323).

arxiv:2605.16363 arXiv ✓
ORACLE: Anticipating Scams from Partial Trajectories in Streaming App Usage
ORACLE：从流式应用使用中的部分轨迹预判诈骗
streaming trajectories context management self-distillation scam detection
ORACLE is an agentic framework for anticipating scams from streaming app-usage trajectories, using a self-evolving context manager to consolidate entity-centric interactions and on-policy self-distillation from a teacher conditioned on anti-scam reflections and clues. It is evaluated on a long-horizon benchmark covering 12 scam types, 95 apps and trajectories averaging 15 days.

arxiv:2605.09218 arXiv ✓
Flame3D: Zero-shot Compositional Reasoning of 3D Scenes with Agentic Language Models
Flame3D：用智能体语言模型对 3D 场景进行零样本组合推理
3D scene memory compositional reasoning tool use training-free
Flame3D is a training-free framework that represents 3D scenes as editable visual-textual memories exposed to an off-the-shelf MLLM through composable spatial tools, and lets the agent synthesize custom spatial programs at inference time. It reports competitive results with finetuned 3D-LMM methods on ScanQA and studies multi-hop compositional reasoning on a curated Compose3D benchmark.

Agentic MIP Research: Accelerated Constraint Handler Generation
智能体式混合整数规划研究：加速约束处理器生成
agentic research constraint programming tool use solver automation
The framework embeds LLM agents in a solver-aware harness to generate, verify and evaluate SCIP constraint handlers, recovering global constraint structures from constraint programming on MIPLIB 2017. It also supports in-context tuning and debugging of generated handlers, and novel propagation methods solved five additional instances.

检测、定位与解释：LLM 增强的交互式分层日志异常分析
log abstraction LLM reasoning human-in-the-loop anomaly detection
