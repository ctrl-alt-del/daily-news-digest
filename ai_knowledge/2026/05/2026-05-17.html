Episodic-Semantic Memory Architecture for Long-Horizon Scientific Agents
面向长程科学智能体的情景—语义记忆架构
agent memory long-horizon agents memory consolidation episodic memory long-context limits
A Dual Process Memory Architecture separates a fixed 10-message episodic window from consolidated long-term knowledge that grows at about three tokens per message, tested over 15,000 messages with six LLMs and 1,440 queries. It maintained 70-85% accuracy using 62% fewer tokens, while full-context models failed at 10,000 messages.

Evaluating Deep Research Agents on Expert Consulting Work: A Benchmark with Verifiers, Rubrics, and Cognitive Traps
评估深度研究智能体在专家咨询工作中的表现：带验证器、评分标准与认知陷阱的基准
deep research agents benchmark evaluation rubric scoring cognitive traps
The benchmark comprises 70 SME-authored management consulting prompts with embedded cognitive traps, scored by deterministic binary verifiers and a five-criterion rubric. o3-deep-research led the continuous Verifier-Rubric Score at 61.4, but no agent exceeded a 15.7% acceptance rate under the joint threshold.

Firefly: Illuminating Large-Scale Verified Tool-Call Data Generation from Real APIs
Firefly：从真实 API 生成大规模可验证工具调用数据
tool calling MCP servers verified data generation DAG exploration GRPO
FireFly inverts tool-call data synthesis by having a strong LLM explore real MCP servers along graph-guided DAGs and then generating tasks backward from observed outcomes, yielding 5,144 verified tasks across 240 servers and 993 tools. A 4B model trained with GRPO on this data matched Claude Sonnet 4.6 on the held-out test set.

arxiv:2605.17617 arXiv ✓
GraphMind: From Operational Traces to Self-Evolving Workflow Automation
GraphMind：从运维轨迹到自进化工作流自动化
workflow graphs self-evolving systems multi-agent traversal graph-guided retrieval incident investigation
GraphMind extracts action-centric workflow graphs from human resolution traces, executes them with a multi-agent traversal engine, and reinforces successful paths through Adaptive Traversal Reinforcement. Deployed across four production cloud database services, it required 8x less retrieval context than an Agentic Summary-RAG baseline, and its Adaptive Traversal Reinforcement layer reduced hallucination rate by 26%.
