arxiv:2605.06997 arXiv ✓
Echo: KV-Cache-Free Associative Recall with Spectral Koopman Operators
Echo：基于谱 Koopman 算子的无 KV 缓存联想召回
associative recall KV cache state-space models long-context retrieval
Echo replaces attention-layer KV caching with Spectral Koopman Attention, which fits a spectral linear system to key-value history via kernel ridge regression and retrieves through a learned power-iterated filter in constant memory. At 50M parameters, SKA-augmented models reach 100% retrieval accuracy on multi-query associative recall with distractor gaps of 4,096 tokens and 32 KV pairs, where pure Mamba-2 stays near chance.
→ arxiv.org
arxiv:2605.07022 arXiv ✓
Self-Driving Datasets: From 20 Million Papers to Nuanced Biomedical Knowledge at Scale
自驱动数据集：从两千万篇论文到规模化细粒度生物医学知识
biomedical knowledge entity tagging multi-agent research hybrid retrieval dataset construction
The work tags 4.5 billion entities across 19 categories in a 22.5-million-paper PubMed corpus using nine biomedical ontologies, adds hybrid sparse-dense retrieval, and introduces Starling, a multi-agent deep-research system that designs its own filters and extraction schemas. Across six tasks Starling produces about 6.3 million records, with frontier-model rejection of 0.6-7.7%, below measured error rates on curated counterparts.
→ arxiv.org

Beyond the Black Box: Interpretability of Agentic AI Tool Use
超越黑箱：智能体 AI 工具调用的可解释性
mechanistic interpretability tool use sparse autoencoders agent observability
The work builds a mechanistic-interpretability toolkit of sparse autoencoders and linear probes that reads model states before each action to infer whether a tool is needed and how risky the next call is. It is applied to GPT-OSS 20B and Gemma 3 27B using multi-step traces from NVIDIA's Nemotron function-calling dataset.

arxiv:2605.06978 arXiv ✓
Group of Skills: Group-Structured Skill Retrieval for Agent Skill Libraries
技能组：面向智能体技能库的分组结构化技能检索
skill retrieval skill libraries agent context execution contracts
GoSkills changes the agent-facing retrieval object from a flat skill list to role-labeled execution groups built from a typed skill graph, rendering Start, Support, Check and Avoid fields without changing the downstream agent. Across SkillsBench, ALFWorld and Terminal-Bench 2 with six backbones it reports the highest mean reward or accuracy in every benchmark-backbone setting.
→ arxiv.org
arxiv:2607.14109 arXiv ✓
ReasonLab: A Controlled and Auditable Evaluation of Prompting Techniques for Multiple-Choice QA
ReasonLab：对多项选择问答提示技术的受控可审计评估
prompting techniques multiple-choice QA reproducible evaluation reasoning budget
ReasonLab makes prompting technique a first-class experimental variable and retains every generation, covering eight techniques, 10 MCQA datasets, 27 model configurations and 480,927 evaluations at temperature zero. It finds prompting technique is a minor determinant of accuracy, while enabling model reasoning is worth up to 12.74 points.
→ arxiv.org

Delulu: A Verified Multi-Lingual Benchmark for Code Hallucination Detection in Fill-in-the-Middle Tasks
Delulu：面向填充中间任务代码幻觉检测的已验证多语言基准

Research on Security Enhancement Methods for Adversarial Robust Large Language Model Intelligent Agents for Medical Decision-Making Tasks
面向医疗决策任务的对抗鲁棒大语言模型智能体安全增强方法研究
medical agents adversarial robustness evidence grounding knowledge consistency
ARSM-Agent is a full-link security framework for medical decision agents spanning input risk perception, medical evidence constraint, knowledge-consistency verification, confidence reweighting and adversarial feedback. Under semantic perturbation, prompt injection, drug-name confusion and false-evidence attacks it reports an 8.7% overall attack success rate and a 0.91 knowledge-consistency score.
