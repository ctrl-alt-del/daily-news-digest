PEAM: Parametric Embodied Agent Memory through Contrastive Internalization of Experience in Minecraft
PEAM：在 Minecraft 中通过对经验的对比内化构建参数化具身智能体记忆
parametric memory embodied agents Mixture-of-Experts continual learning catastrophic forgetting
PEAM moves Minecraft agent memory from inference-time retrieval into model parameters, pairing a slow deliberative LLM with a Mixture-of-Experts LoRA module of isolated adapters that internalizes failure-correction pairs. The design is reported to consolidate skills without catastrophic forgetting.

MemTrace: Tracing and Attributing Errors in Large Language Model Memory Systems
MemTrace：追踪并归因大语言模型记忆系统中的错误
memory attribution failure diagnosis RAG pipelines evaluation benchmark
MemTrace turns LLM memory pipelines into executable evolution graphs and builds MemTraceBench from Long-Context, RAG, Mem0 and EverMemOS systems. Its attribution method is reported to pinpoint failure root causes and lift end-task performance by up to 7.62%.

面向多模态智能体推理的智能体探索式策略优化
multimodal agents policy optimization tool calling reinforcement learning
NVIDIA's AXPO targets the Thinking-Acting Gap in multimodal agents by fixing thinking prefixes and resampling failed tool calls. On Qwen3-VL-Thinking it is reported to beat GRPO by about 1.8 points, and an 8B model surpasses the 32B base on Pass@4.

Evaluating using Mock Tool Calls to Quarantine Untrusted Prompt Inputs
用模拟工具调用隔离不可信提示输入的效果评估
prompt injection instruction hierarchy untrusted input red teaming
The study tests whether wrapping untrusted content in a mock tool call acts as a quarantine, using an automated red-teaming search over static attack strings across seven models and three LLM-as-a-Judge tasks. Counter to the hypothesis, tool-wrapping did not broadly improve robustness, and on GSM8K grading it typically increased attack success rates.

arxiv:2605.30589 arXiv ✓
ImmigrationQA: A Source-Grounded Dataset and Small-Model Adaptation for U.S. Immigration Law
ImmigrationQA：面向美国移民法的来源可溯数据集与小模型适配
domain QA source grounding small language models LoRA fine-tuning LLM-as-judge
ImmigrationQA is a source-grounded question-answering dataset of 17,058 pairs across 13 immigration subdomains, assembled from 11 primary and secondary sources including the USCIS Policy Manual and 8 CFR. A Llama 3.2 3B Instruct model fine-tuned with LoRA scored a mean of 1.08/3.0 versus 0.85/3.0 for the Llama 3 8B base, against a zero-shot Claude Sonnet baseline of 1.52/3.0.

arxiv:2605.30514 arXiv ✓
MAAT: Multi-phase Adapter-Aware Targeted Unlearning
MAAT：多阶段适配器感知的定向知识遗忘
machine unlearning causal knowledge LoRA adapters benchmark balance
The authors introduce 5WBENCH, a balanced 5,000-sample unlearning benchmark with 1,000 examples per 5W category, showing that Why-type causal questions make up less than 0.06% of CounterFact, 0.6% of ZSRE and under 1.3% of TOFU, MUSE and WMDP-Cyber. Their MAAT method operates on LoRA adapter weights in three phases and is reported as the first to achieve both high forgetting and high retention on Why-type causal knowledge.
→ arxiv.org
arxiv:2606.00135 arXiv ✓
On Effectiveness and Efficiency of Agentic Tool-calling and RL Training
论智能体工具调用的有效性与效率及强化学习训练
tool calling evaluation reproducibility reinforcement learning multi-turn agents
The paper analyzes tool-calling evaluation pipelines and finds reported performance can be highly sensitive to implementation choices such as random seed, system prompt, multi-turn template construction and how prior interaction history is carried forward. For training, it identifies wasted computation in rollouts without learning signal and in policy updates, then introduces two techniques reported to accelerate RL-based tool-calling training without degrading performance.
→ arxiv.org
arxiv:2605.30646 arXiv ✓
Same Patient, Different Words, Different Diagnosis? Evaluating Semantic Stability in Clinical LLMs
同一位患者，不同的措辞，不同的诊断？评估临床 LLM 的语义稳定性
semantic stability prompt variation clinical LLMs NLI verification
The paper proposes an NLI-based semantic verification framework, refined by an LLM-as-a-judge and audited by a clinical expert, to filter meaning-preserving prompt variations, plus three metrics for model sensitivity. Evaluating 16 open-source general-purpose and medical LLMs, it finds robustness differences between domain-specific models are mixed and highly model-dependent.
