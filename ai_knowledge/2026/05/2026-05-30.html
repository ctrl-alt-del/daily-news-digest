Not All Flips Are Conformity: Decomposing Stance Convergence in Multi-Agent LLM Debate
并非所有立场翻转都是从众：拆解多智能体 LLM 辩论中的立场趋同
multi-agent debate stance convergence peer influence evaluation methodology
The study separates genuine peer influence from self-reflection in multi-agent LLM debate using matched self-reflection, stance-only and full-reasoning conditions with five GPT-4o agents on MMLU-Pro disagreement questions. It finds 37% of agent-question pairs change without peer information, and among pairs stable under that control 29.3% adopt a peer answer, with adoptions including corrections, new errors and changes between wrong answers.

Alibaba arxiv:2606.00831 arXiv ✓
Subliminal Learning is a LoRA Artifact
潜意识学习是 LoRA 的产物
subliminal learning LoRA fine-tuning context behavioral transmission
The paper shows that subliminal learning, in which a teacher model transmits a behavioral trait through seemingly innocuous data, is a LoRA artifact: transmission has an inverted U-shaped relationship with LoRA rank and disappears with full fine-tuning. It further finds the effect depends on the fine-tuning and evaluation context, appearing only at tokens seen in both, such as the default system prompt and chat-template tokens.

arxiv:2606.00765 arXiv ✓
FALAT: Tracing Failures in LLM Agent Trajectories via Dependency-Guided Search
FALAT：通过依赖引导搜索追踪 LLM 智能体轨迹中的失败
failure attribution agent trajectories dependency tracing benchmark
FALAT frames failure attribution in LLM agent trajectories as dependency-guided search: it constructs an expectation of how a task should be solved, traces dependencies among decisions, tool outputs and agent messages, and tests whether correcting a candidate step would recover the expected outcome. On the Who&When benchmark it reaches 46.0% step-level accuracy on algorithm-generated trajectories and 29.1% on hand-crafted ones, outperforming specialized baselines and direct prompting.

arxiv:2606.00825 arXiv ✓
SuperMemory-VQA: An Egocentric Visual Question-Answering Benchmark for Long-Horizon Memory
SuperMemory-VQA：面向长程记忆的自我中心视觉问答基准
long-horizon memory egocentric video visual question answering hallucination robustness
SuperMemory-VQA is an egocentric VQA dataset built from 52.9 hours of everyday activities recorded with AI glasses, including synchronized RGB video, audio transcription, eye gaze, IMU and SLAM trajectories, with 4,853 human-verified question-answer pairs. Questions include an explicit unanswerable option to test hallucination robustness, and benchmarking leading agentic frameworks and LLM backbones shows existing systems remain far from reliable on real-world memory tasks.

arxiv:2606.00925 arXiv ✓
Benchmarking Security Risk Detection and Verification in Open Agentic Skill Ecosystems
开放智能体技能生态中安全风险检测与验证的基准评测
agent skills supply-chain security runtime verification sandboxing
SkillVetBench is a two-stage security vetting benchmark for open agentic skill ecosystems: semantic vetting over each skill's natural-language specification, then sandboxed execution of flagged skills to collect auditable runtime evidence. Built from confirmed malicious skills in the live OpenClaw ecosystem, it finds semantic-only and signature-based baselines miss up to 89% of malicious skills, with runtime attacks concentrated in high-permission primitives such as exec, write_file, install_skill and spawn.

Dynamic Coordination Strategy Selection for Enterprise Multi-Agent Systems
企业多智能体系统的动态协调策略选择
multi-agent coordination dynamic routing enterprise agents evaluation
The paper evaluates whether coordination strategy in enterprise multi-agent systems should be selected dynamically by problem class rather than fixed globally, running 30 tasks across six industries, five problem classes and four model arms with 1,440 judged outputs. The pre-registered exact-winner criterion was not supported, but a weaker near-best routing claim held in every arm and problem class, with the predicted strategy within 0.10 quality-score points of the best observed condition.

CV-Arena: An Open Benchmark for Instructional Computer Vision Problem Solving with Human-AI Collaborative Preferences
CV-Arena：面向指令式计算机视觉问题求解的开放基准与人机协作偏好
visual benchmark human-AI evaluation agentic curation instruction following
CV-Arena is an open benchmark with 12K high-resolution real-image instruction pairs spanning 16 instruction-based visual task types, built with a dual-track retrieval-and-curation pipeline called CogRetriever. It also proposes Active Elo, a human-AI collaborative preference protocol using a logic-gated VLM evaluator, and evaluates 21 systems, finding persistent gaps in instruction adherence and physical reasoning.

Task diversity produces systematic transfer but inhibits continual reinforcement learning
任务多样性带来系统性迁移，却抑制持续强化学习
continual learning task diversity transfer learning reinforcement learning
The authors introduce Banyan, a GPU-accelerated continual RL domain in which map layouts, objects and sub-goal dependency structures can be varied independently. They find increasing diversity along each axis induces systematic transfer, but too much diversity inhibits continued adaptation: learners plateau on new tasks while still improving on old ones.
