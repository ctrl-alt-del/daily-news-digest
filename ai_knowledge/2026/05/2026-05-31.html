Med-HEAL: Analyzing and Mitigating Hallucinations in Medical LLMs with Hallucination-Aware In-Context Learning
Med-HEAL：利用幻觉感知上下文学习分析与缓解医疗 LLM 幻觉
medical hallucination self-critique in-context learning clinical QA
Med-HEAL builds a hallucination dataset by evaluating BioMistral-7B on open-ended clinical question answering from EHRNoteQA, with outputs labeled by a GPT-4o LLM-as-a-judge pipeline plus human auditing by medical student reviewers. Across five open-source LLMs, a self-critique pipeline improved accuracy for three of five models without parameter updates.

NVIDIA arxiv:2606.01494 arXiv ✓
ClawHub Security Signals: When VirusTotal, Static Analysis, and SkillSpector Disagree
ClawHub 安全信号：当 VirusTotal、静态分析与 SkillSpector 判断不一致
agent skills scanner disagreement supply-chain security skill vetting
ClawHub Security Signals is a sanitized dataset of 67,453 latest public OpenClaw skill versions pairing redacted SKILL.md content with registry verdicts and evidence from VirusTotal, static heuristic analysis and NVIDIA SkillSpector. Rather than estimating prevalence, it studies scanner disagreement: any pair of scanners overlaps on at most 10.4% of combined positives, only 0.69% of skills are flagged by all three, and 81.9% of flagged skills are identified by a single scanner.

Reliable Post-Retrieval Assembly for Agent Memory: Separating Evidence Extraction from Policy Execution
面向智能体记忆的可靠检索后组装：将证据抽取与策略执行分离
post-retrieval assembly agent memory evidence extraction conflict resolution benchmark
The paper studies post-retrieval assembly failures, where a memory system retrieves relevant evidence but answer generation entangles semantic filtering, conflict resolution, prior suppression and output generation. On MemoryAgentBench FactConsolidation at 262K tokens, separating evidence extraction from policy execution reaches 82%/93% single-hop and 27%/41% multi-hop with gpt-4o-mini/gpt-4o, versus a best reported 54% single-hop in the benchmark comparison and at most 7% multi-hop across the 22 reported systems.

Bridging Requirements and Architecture: Multi-Agent Orchestration with External Knowledge and Hierarchical Memory
连接需求与架构：融合外部知识与分层记忆的多智能体编排
multi-agent orchestration hierarchical memory RAG software architecture
MAAD is a knowledge-driven framework that orchestrates Analyst, Modeler, Designer and Evaluator agents to transform requirements specifications into multi-view architectural blueprints with quality attribute assessments. It injects architectural standards and patterns via RAG, uses a hierarchical memory of design history for iterative refinement, and is reported to produce more complete, modular and traceable architectures than MetaGPT across 10 case studies.

arxiv:2606.01336 arXiv ✓
LongAttnComp: Cross-Family Context Compression for Long-Context Reasoning
LongAttnComp：面向长上下文推理的跨模型族上下文压缩
context compression long-context reasoning cross-attention benchmark transfer
LongAttnComp adapts AttnComp by fine-tuning a lightweight cross-attention scoring layer and adding token-level chunking, a token-budget top-p algorithm, positional reordering and a format-agnostic query parser. With a two-stage fine-tuning recipe, it matches or exceeds full-context accuracy on InfiniteBench Code-Debug and transfers across four target models from three families.
