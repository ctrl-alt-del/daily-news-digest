FlexSQL：灵活探索与执行让文本到 SQL 智能体更出色
text-to-SQL database exploration plan repair benchmark
FlexSQL lets a text-to-SQL agent explore schema structure, inspect data values and run verification queries at any point, generating diverse execution plans and repairing at both code and plan levels. Web2BigTable: A Bi-Level Multi-Agent LLM System for Internet-Scale Information Search and Extraction
Web2BigTable：面向互联网级信息搜索与抽取的双层多智能体 LLM 系统

NVIDIA arxiv:2605.03213 arXiv ✓
When Agents Handle Secrets: A Survey of Confidential Computing for Agentic AI
当智能体处理机密：面向智能体 AI 的机密计算综述
agent security confidential computing trusted execution threat modeling
The survey maps confidential computing for agentic AI, covering six TEE platforms, an agent-centric threat model across perception, planning, memory, action and coordination, and a comparison of hardware-rooted defenses. It concludes that several trust primitives appear mature enough for targeted deployments, but no broadly established end-to-end framework yet binds them into a coherent security substrate.
→ arxiv.org
DeepSeek arxiv:2605.03129 arXiv ✓
PIIGuard: Mitigating PII Harvesting under Adversarial Sanitization
PIIGuard：缓解对抗性清洗下的 PII 抓取
prompt injection PII protection web agents defense evaluation
PIIGuard is a webpage-level defense that embeds optimized hidden HTML fragments to steer browsing LLM assistants away from disclosing contact PII, using rule-based leakage scoring, evolutionary mutation and judge-based recoverability assessment. It reports at least 97% defense success on three target models while preserving benign same-page QA, though robustness varies across browsing interfaces and sanitizer prompts.
→ arxiv.org

Reinforcement Learning for LLM-based Multi-Agent Systems through Orchestration Traces
通过编排轨迹为基于 LLM 的多智能体系统做强化学习
multi-agent systems orchestration traces reward design credit assignment
The paper frames multi-agent RL through orchestration traces, temporal interaction graphs covering spawning, delegation, communication, tool use, aggregation and stopping, and organizes reward design, credit assignment and five orchestration sub-decisions. It reports no explicit RL training method for the stopping decision in its curated pool as of May 4, 2026, and releases an 84-entry tagged paper pool.

arxiv:2605.03227 arXiv ✓
Evaluating Prompting and Execution-Based Methods for Deterministic Computation in LLMs
评估 LLM 确定性计算中的提示与执行方法
prompting strategies deterministic computation tool use evaluation
The study compares chain-of-thought, least-to-most, program-of-thought and self-consistency prompting on exact computation tasks such as binary counting, longest substring detection and arithmetic. Program-of-thought reached perfect accuracy by delegating to an interpreter, while a small CodeT5 model trained to generate programs also achieved perfect accuracy on held-out synthetic data.

从技能文本到技能结构：Agent Skills 的调度-结构-逻辑表示
