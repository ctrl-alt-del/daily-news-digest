Trojan Hippo Bench: A Dynamic Benchmark for Persistent Memory Attacks and Defenses in LLM Agents
Trojan Hippo Bench：LLM 智能体持久记忆攻击与防御的动态基准
agent memory memory poisoning red-teaming security-utility tradeoff
Trojan Hippo Bench is a dynamic framework for persistent memory attacks and memory-layer defenses, combining an OpenEvolve-based adaptive red-teaming benchmark with capability-aware security-utility analysis. On an email assistant across four memory backends, the undefended attack reached 85-100% success against frontier OpenAI and Google models, while four defenses cut success to 0-5% at widely varying utility costs.

Beyond Semantic Similarity: Rethinking Retrieval for Agentic Search via Direct Corpus Interaction
超越语义相似度：通过直接语料交互重新思考智能体搜索中的检索
agentic search direct corpus interaction tool use embedding-free retrieval
The paper studies direct corpus interaction, where an agent searches a raw corpus with general-purpose terminal tools such as grep, file reads and shell commands instead of an embedding index or retrieval API. It reports substantial gains over sparse, dense and reranking baselines on several BRIGHT and BEIR datasets and strong accuracy on BrowseComp-Plus and multi-hop QA.

12 Angry AI Agents: Evaluating Multi-Agent LLM Decision-Making Through Cinematic Jury Deliberation
十二怒 AI：通过电影式陪审团审议评估多智能体 LLM 决策
multi-agent debate deliberation RLHF agent benchmark
The study instantiates twelve persona-conditioned LLM agents debating the murder case from 12 Angry Men, testing GPT-4o and Llama-4-Scout across three conditions with 18 total runs. Seventeen of eighteen runs ended in a hung jury, and the models differed sharply in vote changes, which the author links to RLHF intensity rather than model capability.

Enhancing Judgment Document Generation via Agentic Legal Information Collection and Rubric-Guided Optimization
Judge-R1：通过智能体法律信息收集与评分标准引导优化增强判决书生成
agentic retrieval legal reasoning GRPO rubric optimization
Judge-R1 combines an agentic legal information collection stage, which uses a dynamic planning agent to retrieve precise statutes and precedents from multiple sources, with rubric-guided reinforcement learning using GRPO and a legal reward function. On the JuDGE benchmark it is reported to outperform state-of-the-art baselines in legal accuracy and generation quality.

Retrieval with Multiple Query Vectors through Anomalous Pattern Detection
通过异常模式检测实现多查询向量检索
multi-query retrieval vector search anomaly detection query fusion
The method takes a set of query vectors, identifies the dimensions that stand out as anomalous, and retrieves database vectors that are also anomalous along those dimensions. Across image, text and tabular datasets, larger query sets generally improved retrieval, with the largest gains when moving from one to eight queries.
