AgentOdyssey: Open-Ended Long-Horizon Text Game Generation for Test-Time Continual Learning Agents
AgentOdyssey：面向测试时持续学习智能体的开放式长程文本游戏生成
continual learning episodic memory long-horizon agents benchmark generation catastrophic forgetting
AgentOdyssey procedurally generates open-ended text games with rich entities, world dynamics and long-horizon tasks to evaluate test-time continual learning agents, interleaving learning and inference throughout deployment. Across six generated games, even the top agent remained far below human performance, and supervised fine-tuning agents still suffered catastrophic forgetting despite short-term memory benefits.

arxiv:2606.00328 arXiv ✓
KG-Guard: Graph-Based Hallucination Detection for Knowledge Base Question Answering
KG-Guard：面向知识库问答的基于图的幻觉检测
hallucination detection knowledge base QA graph neural networks answer verification
KG-Guard formulates hallucination detection in knowledge base question answering as answer-node classification and treats the answering LLM as a black box, representing each instance as an augmented graph with a virtual question node. It reports F1 of 82.0, 87.4 and 84.3 on WebQSP, ComplexWebQuestions and PUGG with roughly 305x fewer parameters than LLM-based baselines, and feeding flagged answers back improves downstream KBQA F1 by 13.0-14.5 points.

Masking Stale Observations Helps Search Agents -- Until It Doesn't: A Regime Map and Its Mechanism
屏蔽过期观测对搜索智能体有帮助——直到不再有帮助：机制与状态图
context management search agents observation masking retrieval benchmark sweep
The authors sweep agent backbones from 4B to 284B parameters and three retrievers on offline and live-web agentic search benchmarks to study masking stale observations from context. They find accuracy gains follow an asymmetric inverted-U shape relative to the model's unmasked accuracy, reflecting the interaction between retriever recall and the model's implicit filtering capacity.

CRMA: A Spectrally-Bounded Backbone for Modular Continual Fine-Tuning of LLMs
CRMA：面向 LLM 模块化持续微调的光谱有界骨干
continual fine-tuning catastrophic forgetting LoRA adapters spectral normalization
CRMA is a residual adapter whose internal mixing matrix is doubly stochastic at every forward pass via Sinkhorn normalization, giving a structural spectral bound rather than a penalty. On Mistral-7B across five sequential domains, modular per-task LoRA on a CRMA backbone reportedly reduces loss-relative drift from +42.96% to -0.17% and improves prior-task holdout loss over a frozen-substrate baseline.

The Deterministic Horizon: When Extended Reasoning Fails and Tool Delegation Becomes Necessary
确定性视界：何时扩展推理失效、工具委派成为必要
reasoning limits tool delegation state tracking chain-of-thought
The paper presents an attention bottleneck analysis arguing that total state-tracking capacity in bits is bounded by head count, head dimension and context length, and defines a Deterministic Horizon of 19-31 marking the depth where unaided accuracy crosses 50%. Across twelve models and eight task domains, tool-integrated reasoning reaches 76-94% accuracy versus 17-42% for neural chain-of-thought on PermutationProbe.

arxiv:2606.00305 arXiv ✓
Bridging Reasoning Trajectories in On-Policy Distillation via Near-Future Guidance
通过近未来引导弥合同策略蒸馏中的推理轨迹
on-policy distillation reasoning trajectories token-level supervision model training
The paper shows that on-policy distillation's token-level learning signal cannot reliably bridge student trajectories toward teacher trajectories, since about 30% of high-loss tokens are surface-form mismatches rather than real reasoning forks. Its Trajectory-aware OPD uses near-future trajectory information to identify divergent states and distribute guidance, improving average accuracy to 52.2% from 47.8% for standard OPD.

Skill0.5: Joint Skill Internalization and Utilization for Out-of-Distribution Generalization in Agentic Reinforcement Learning
Skill0.5：智能体强化学习中的技能内化与调用联合优化
skill internalization agent RL skill routing out-of-distribution generalization
An East China Normal University framework internalizes general skills through privileged distillation while keeping task-specific skills external, routed by a difficulty-aware router that penalizes shortcuts on easy tasks. It is reported to outperform memory- and skill-based RL baselines on ALFWorld and WebShop.

CONF-KV: Confidence-Aware KV Cache Eviction with Mixed-Precision Storage for Long-Horizon LLM
CONF-KV：面向长程 LLM 的置信度感知 KV 缓存淘汰与混合精度存储
KV cache eviction long-context retrieval confidence-aware budgeting needle-in-a-haystack
CONF-KV is a KV-cache manager from Carnegie Mellon that sets the per-step cache budget from the model's next-token confidence, combined with blockwise online-softmax attention and mixed FP16/INT8 storage. It reaches 91.4% Needle-in-a-Haystack retrieval at 32K tokens, versus 53.8% for sliding windows.
