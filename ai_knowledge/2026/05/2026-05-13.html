Mini-JEPA 基础模型集群赋能智能体水文智能
geospatial embeddings JEPA routing agent dual retrieval

PolitNuggets: Benchmarking Agentic Discovery of Long-Tail Political Facts
PolitNuggets：评测智能体对长尾政治事实的发现能力
agentic information synthesis long-tail facts benchmark multilingual retrieval
PolitNuggets is a multilingual benchmark for agentic information synthesis built from political biographies of 400 global elites covering more than 10,000 facts. Derivation Prompting: A Logic-Based Method for Improving Retrieval-Augmented Generation
推导式提示：改进检索增强生成的逻辑方法
retrieval-augmented generation derivation tree prompting hallucination reduction
Derivation Prompting is a generation-step technique for retrieval-augmented generation that derives conclusions from initial hypotheses through systematic application of predefined rules, building an interpretable derivation tree. In a case study it significantly reduced unacceptable answers compared with traditional RAG and long-context methods.

从描述到规范：揭示 LLM 智能体的社会价值对齐
GraphRAG value alignment instruction retrieval dilemma benchmark
The authors propose a value-based framework that uses GraphRAG to convert principles into value-based instructions and retrieve suitable instructions for a given conversation context. arxiv:2605.15229 arXiv ✓
PBT-Bench: Benchmarking AI Agents on Property-Based Testing
PBT-Bench：评测 AI 智能体的属性测试能力
agent benchmark property-based testing semantic reasoning documentation grounding
PBT-Bench contains 100 curated property-based testing problems across 40 Python libraries, with 365 injected semantic bugs designed so default random inputs rarely trigger them. Under a PBT-guided prompt bug recall ranges from 42.1% to 83.4% across eight LLMs, and the hardest bugs prove model-specific.
