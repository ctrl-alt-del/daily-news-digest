FORGE: Self-Evolving Agent Memory With No Weight Updates via Population Broadcast
FORGE：无需权重更新、通过种群广播自进化的智能体记忆
agent memory self-evolving memory Reflexion failure reflection population broadcast
FORGE is a staged, population-based protocol that evolves prompt-injected natural-language memory for hierarchical ReAct agents without gradient updates, converting failed trajectories into reusable rules, examples or both. On the stochastic CybORG CAGE-2 network-defense task it improved average return by 1.7-7.7x over zero-shot and by 29-72% over Reflexion across all 12 model-representation conditions.

Enhancing Metacognitive AI: Knowledge-Graph Population with Graph-Theoretic LLM Enrichment
增强元认知 AI：用图论 LLM 增强进行知识图谱填充
knowledge graph population GraphRAG metacognition targeted retrieval Neo4j
MetaKGEnrich builds a knowledge graph from a seed query, detects sparse regions using seven graph metrics and has GPT-4o generate targeted questions whose web-retrieved answers are ingested into Neo4j. On 30 queries from each of three datasets it improved GraphRAG answer quality for 80% of HotpotQA, 87% of Natural Questions and 83% of MS MARCO questions.

arxiv:2605.16598 arXiv ✓
GRASP: Graph Agentic Search over Propositions for Multi-hop Question Answering
GRASP：面向多跳问答的命题图智能体搜索
graph agentic search multi-hop QA knowledge graph token efficiency sub-agents
GRASP decomposes multi-hop questions into dependency-aware plans and resolves each single-hop sub-query over a three-layer graph of entities, propositions and passages, scaling the number of sub-agents to problem complexity. It reports the highest QA accuracy in open retrieval on MuSiQue and 2Wiki while using 40-50% fewer tokens than IRCoT+HippoRAG2.
→ arxiv.org

SKG-Eval: Stateful Evaluation of Multi-Turn Dialogue via Incremental Semantic Knowledge Graphs
SKG-Eval：通过增量语义知识图谱对多轮对话进行有状态评测
semantic knowledge graph dialogue evaluation contradiction detection state tracking
SKG-Eval models multi-turn dialogue as an incrementally updated semantic knowledge graph of entities, relations and commitments, then scores local relevance, historical consistency and logical coherence. Across multiple benchmarks it reports higher correlation with human judgments and better detection of long-range inconsistencies, with deterministic scores and explicit contradiction certificates.
