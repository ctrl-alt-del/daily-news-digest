arxiv:2605.08538 arXiv ✓
Human-Inspired Memory Architecture for LLM Agents
面向 LLM 智能体的类人记忆架构
agent memory memory consolidation forgetting knowledge graph long-term memory
The architecture combines six cognitive mechanisms - sleep-phase consolidation, interference-based forgetting, engram maturation, reconsolidation upon retrieval, entity knowledge graphs and hybrid multi-cue retrieval - with thresholds calibrated without benchmark exposure. On a 13K-issue VSCode dataset, deduplication-based consolidation reached 97.2% retention precision with 58% store reduction, and on LongMemEval it matched raw retrieval accuracy (70.1% vs. 71.2%) at a 200K-token context budget.

arxiv:2605.08442 arXiv ✓
Injection-Execution Dissociation: A Mechanistic Evaluation of Persistent Memory Attacks and Defenses in Stateful LLM Agents
注入-执行分离：有状态 LLM 智能体持久记忆攻击与防御的机制评估
persistent memory prompt injection agent security memory sandbox attack evaluation
The study separates whether a stateful agent stores an injected instruction from whether it later acts on it, evaluating 29 frontier endpoints with a malicious document in the retrieval corpus. Execution was common, and models that never exfiltrated in draft-only runs sometimes did when a follow-up supplied content and asked for a send; only removing the recall tool blocked the attack, and even that was bypassed when models rebuilt the instruction from the corpus.
→ arxiv.org
arxiv:2605.08399 arXiv ✓
CoCoDA: Co-evolving Compositional DAG for Tool-Augmented Agents
CoCoDA：面向工具增强智能体的协同进化组合 DAG
tool library skill composition typed retrieval planner evolution
CoCoDA co-evolves a planner and tool library around a compositional code DAG whose nodes store typed signatures, descriptions, pre- and post-conditions and worked examples, with typed retrieval pruning candidates before context materialization. Successful trajectories are folded into validated composite tools, and an 8B student matches or exceeds a 32B teacher on GSM8K and MATH.

planning horizon tool calling token efficiency multi-hop QA
A controlled study isolates planning horizon, comparing full-horizon plans with single-step interleaving across knowledge-base QA and multi-hop QA. Full-horizon planning with lazy replanning matches single-step accuracy across depths, breadths and robustness levels while using two to three times fewer tokens.

基准是否低估了 LLM 性能？用 LLM 优先、人工裁决的评估检验幻觉检测
hallucination detection human adjudication RAG evaluation annotation quality
The study re-adjudicates conflicts between original human annotations and reason- and span-based judgments from Gemini 2.5 Flash and GPT-5 Mini on QAGS-C and SummEval. Triple agreement rose 6.38% and 7.62%, with adjudicators often siding with models when they gave explicit reasoning, and overall human adjudicator agreement ranged from 83% to 87%.

When Independent Sampling Outperforms Agentic Reasoning
当独立采样优于智能体推理
inference-time compute independent sampling agentic reasoning competitive programming
Evaluating 216 Codeforces problems across Divisions 1-3, the authors compare agent-based reasoning with repeated independent k-shot sampling under fixed budgets. K-shot consistently gives better accuracy-cost and accuracy-query tradeoffs, even with prompt caching in agent frameworks.

StraTA: Incentivizing Agentic Reinforcement Learning with Strategic Trajectory Abstraction
StraTA：用策略轨迹抽象激励智能体强化学习
agentic reinforcement learning strategy abstraction hierarchical GRPO long-horizon tasks
