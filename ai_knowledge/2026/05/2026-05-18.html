FAGER: Factually Grounded Evaluation and Refinement of Text-to-Image Models
FAGER：文生图模型的事实基础评估与改进
factual grounding text-to-image evaluation visual fact verification agentic evaluation
FAGER builds a structured factual rubric by combining LLM-based fact proposals with reference-guided visual fact extraction and verification, then converts the rubric into question-answer pairs for VLM evaluation. Across five datasets it outperformed prior metrics on a Factual A/B test and refined text-to-image outputs in a training-free manner.

arxiv:2605.19093 arXiv ✓
Embedding by Elicitation: Dynamic Representations for Bayesian Optimization of System Prompts
通过启发式嵌入为系统提示的贝叶斯优化提供动态表示
system prompt optimization prompt embeddings Bayesian optimization black-box optimization
ReElicit uses an LLM to elicit an interpretable feature space for prompts, runs Gaussian-process Bayesian optimization over it, and has the LLM realize selected feature vectors as deployable system prompts, re-eliciting the space as evaluations arrive. Across ten prompt-optimization tasks with a 30-evaluation budget it achieved the strongest aggregate profile among aggregate-only baselines.
→ arxiv.org

用极简形式化证明压力测试大语言模型的推理能力
reasoning benchmark formal proofs machine-checkable evaluation
ProofGrid is a 15-task benchmark suite that scores LLM reasoning through machine-checkable proofs written in NDL, a compact natural-deduction language, rather than final answers. Solvita：通过智能体进化增强大语言模型的竞赛编程能力
agentic evolution knowledge network competitive programming continuous learning
