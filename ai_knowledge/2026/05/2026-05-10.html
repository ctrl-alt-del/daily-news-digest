Oracle Poisoning: Corrupting Knowledge Graphs to Weaponise AI Agent Reasoning
Oracle Poisoning：破坏知识图谱以武器化 AI 智能体推理
knowledge graph poisoning agent tool use data integrity trust evaluation agent security
Oracle Poisoning corrupts a structured knowledge graph that agents query at runtime, so they reach incorrect conclusions through correct reasoning; the authors demonstrate six scenarios against a production 42-million-node code knowledge graph. Across nine models from three providers, every model trusted poisoned data at 100% under directed queries at moderate attacker sophistication, while inline evaluation produced false negatives relative to real tool use.

arxiv:2605.09806 arXiv ✓
LEAD: Length-Efficient Adaptive and Dynamic Reasoning for Large Language Models
LEAD：面向大语言模型的长度高效自适应动态推理
chain-of-thought length efficiency reinforcement learning reasoning budget
LEAD replaces static length penalties in reasoning RL with online self-adaptive mechanisms: potential-scaled instability calibrates the correctness-efficiency tradeoff, and an adaptive per-problem target length applies a symmetric reward that penalizes both overthinking and over-compression. Across five math reasoning benchmarks it reports the highest accuracy and accuracy-efficiency score among compared RL-trained efficient-reasoning methods while producing shorter outputs.
→ arxiv.org
arxiv:2605.09661 arXiv ✓
MedMeta: A Benchmark for LLMs in Synthesizing Meta-Analysis Conclusion from Medical Studies
MedMeta：评测 LLM 从医学研究中综合元分析结论的基准
evidence synthesis medical benchmark retrieval grounding negation
MedMeta is a benchmark of 81 PubMed meta-analyses that tests whether LLMs can synthesize conclusions from cited study abstracts under golden-RAG and parametric-only workflows. Golden-RAG consistently outperformed parametric-only, domain fine-tuning added little once external material was provided, all models failed to reject negated evidence, and even under ideal RAG conditions models averaged only about 2.7 out of 5.

FreeMOCA: Memory-Free Continual Learning for Malicious Code Analysis
FreeMOCA：面向恶意代码分析的无记忆持续学习
continual learning catastrophic forgetting malware analysis parameter interpolation
FreeMOCA is a memory- and compute-efficient continual-learning framework for malicious code analysis that preserves prior knowledge through adaptive layer-wise interpolation between consecutive task updates. On EMBER and AZ benchmarks it outperforms 11 baselines in class-incremental settings, reduces forgetting and improves accuracy by up to 42% and 37%.

学习用于数据选择的多指标权重：带高效代理的联合任务-模型适配框架
