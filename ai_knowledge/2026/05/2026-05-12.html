arxiv:2605.12729 arXiv ✓
Large Language Models for Agentic NetOps and AIOps: Architectures, Evaluation, and Safety
面向智能体 NetOps 与 AIOps 的大语言模型：架构、评估与安全
agentic operations assurance contract tool scope AIOps governance
This survey reviews agentic LLM systems for network and IT operations and introduces an operational assurance contract that ties each autonomy level to permitted tools, required evidence, independent gates, execution budgets and audit requirements. It identifies a capability-assurance gap as systems move from read-oriented assistance toward configuration change and closed-loop operation.
→ arxiv.org
arxiv:2607.01243 arXiv ✓
STRUCTSURVEY: Structured Agentic Retrieval for Automated Survey Paper Generation
STRUCTSURVEY：面向自动综述论文生成的结构化智能体检索
agentic retrieval graph representation survey generation long-form summarization
STRUCTSURVEY is a hierarchical multi-agent framework that moves structural reasoning from generation to retrieval by dynamically building graph-based representations of entities, relations and topical taxonomies. On a new reference-grounded benchmark of ACL survey papers it improves ROUGE-1 recall by 2.9 points over embedding-only retrieval without reducing precision.
→ arxiv.org

TMAS: Scaling Test-Time Compute via Multi-Agent Synergy
TMAS：以多智能体协同扩展测试时算力
multi-agent collaboration hierarchical memory test-time scaling experience bank
TMAS organizes inference as collaboration among specialized agents with hierarchical memories, an experience bank of reliable intermediate conclusions, a guideline bank of explored strategies and a hybrid reward RL scheme. It reports stronger iterative test-time scaling than prior structured methods.

arxiv:2605.18833 arXiv ✓
Automated Big Data Quality Assessment using Knowledge Graph Embeddings
利用知识图谱嵌入进行自动化大数据质量评估
knowledge graph embeddings data quality link prediction context representation
The paper uses knowledge graph embeddings to predict missing edges between a dataset's context representation and relevant quality rules and dimensions, producing a context-specific data quality assessment plan. It evaluates the approach with AmpliGraph on a real-world radiation sensor dataset from the Lebanese Atomic Energy Commission.

Dynamic Skill Lifecycle Management for Agentic Reinforcement Learning
SLIM：面向智能体强化学习的动态技能生命周期管理
skill lifecycle agent skills reinforcement learning skill validation
SLIM treats an agent's active external skill set as a dynamic optimization variable jointly updated with policy learning, using leave-one-skill-out validation to retain, retire or expand skills. It beats the best baselines by an average of 7.1 points across ALFWorld and SearchQA.

EleutherAI arxiv:2605.09063 HuggingFace Papers
Soohak: A Mathematician-Curated Benchmark for Evaluating Research-level Math Capabilities of LLMs
Soohak：由数学家策划的研究级数学能力评测基准
math benchmark research-level reasoning LLM evaluation ill-posed problems
EleutherAI introduced Soohak, a 439-problem benchmark written from scratch by 64 mathematicians to test research-level math capabilities. On its Challenge subset Gemini-3-Pro reaches 30.4%, GPT-5 26.4% and Claude-Opus-4.5 10.4%, and no model clears 50% at identifying ill-posed problems.

Microsoft Research arxiv:2605.10781 HuggingFace Papers
Rebellious Student: Reversing Teacher Signals for Reasoning Exploration with Self-Distilled RLVR
Rebellious Student：反转教师信号，用自蒸馏 RLVR 探索推理
self-distillation reinforcement learning reasoning exploration GRPO
Microsoft Research proposes RLRT, which reverses the self-distillation signal to reinforce tokens where a successful student diverges from its teacher, augmenting GRPO. Synthesizing the Expert: A Validated Multimodal Dataset for Trustworthy AI-Assisted Swimming Coaching
合成专家：面向可信 AI 辅助游泳训练的多模态数据集
retrieval-augmented generation synthetic dataset multimodal knowledge base sports coaching
The authors build a multimodal knowledge base spanning physiological data, literature, kinematic sensor data and unstructured expertise, then use a multi-agent LLM architecture to synthesize 1,864 validated question-context-answer triplets for swimming coaching.
