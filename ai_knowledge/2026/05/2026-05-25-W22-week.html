Why LLMs Fail at Causal Discovery and How Interventional Agents Escape
LLM 为何在因果发现中失败，以及干预式智能体如何突围
causal discovery interventional agents Bayesian optimization theoretical limits
The authors prove a kernel obstruction theorem showing that supervised fine-tuning, direct preference optimization and in-context learning produce predictors that cannot distinguish causal graphs generating similar observational data. They propose Agentic Causal Bayesian Optimization, where a frozen LLM acts as an interventional oracle inside an external Bayesian loop; it matches fine-tuned baselines on Corr2Cause without training and outperforms fine-tuning and preference optimization on the new 24-variable Extended Corr2Cause benchmark.

arxiv:2606.00765 arXiv ✓
FALAT: Tracing Failures in LLM Agent Trajectories via Dependency-Guided Search
FALAT：通过依赖引导搜索追踪 LLM 智能体轨迹中的失败
failure attribution agent trajectories dependency tracing benchmark
FALAT frames failure attribution in LLM agent trajectories as dependency-guided search: it constructs an expectation of how a task should be solved, traces dependencies among decisions, tool outputs and agent messages, and tests whether correcting a candidate step would recover the expected outcome. On the Who&When benchmark it reaches 46.0% step-level accuracy on algorithm-generated trajectories and 29.1% on hand-crafted ones, outperforming specialized baselines and direct prompting.
→ arxiv.org
arxiv:2605.26252 arXiv ✓
Is Agent Memory a Database? Rethinking Data Foundations for Long-Term AI Agent Memory
智能体记忆是数据库吗？重新思考长期智能体记忆的数据基础
agent memory memory governance state trajectory property graph
The authors argue that long-term agent memory is a new data-management workload whose correctness is a property of the state trajectory rather than individual records, and identify four failure modes: unregulated growth, missing semantic revision, capacity-driven forgetting and read-only retrieval. They formalize Governed Evolving Memory with ingestion, revision, forgetting and retrieval operators, argue that no record-level system can satisfy six correctness conditions, and prototype MemState on a property-graph backend.
→ arxiv.org

Reliable Post-Retrieval Assembly for Agent Memory: Separating Evidence Extraction from Policy Execution
面向智能体记忆的可靠检索后组装：将证据抽取与策略执行分离
post-retrieval assembly agent memory evidence extraction conflict resolution benchmark
The paper studies post-retrieval assembly failures, where a memory system retrieves relevant evidence but answer generation entangles semantic filtering, conflict resolution, prior suppression and output generation. On MemoryAgentBench FactConsolidation at 262K tokens, separating evidence extraction from policy execution reaches 82%/93% single-hop and 27%/41% multi-hop with gpt-4o-mini/gpt-4o, versus a best reported 54% single-hop in the benchmark comparison and at most 7% multi-hop across the 22 reported systems.

RICE-PO: Turning Retrieval Interactions into Credit Signals for Reasoning Agents
RICE-PO：将检索交互转化为推理智能体的信用信号

RICE-PO is a critic-free policy optimization framework that selects high-uncertainty executable retrieval actions as anchors, evaluates local counterfactual branches with retrieval metrics, and propagates credit to latent reasoning steps only when reasoning-to-action influence is strong. On BRIGHT and BEIR it consistently outperforms prompt-based agents and group-based RL baselines under the same retriever.
