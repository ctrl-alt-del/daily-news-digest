一个分数就够了吗？重新思考顺序演化 LLM 记忆的评测
LLM memory memory evaluation forgetting negative transfer
SeqMem-Eval is a diagnostic framework for sequentially evolving LLM memory that measures online utility, hold-out generalization, backward transfer and forgetting rather than only final or cumulative accuracy. arxiv:2605.15343 arXiv ✓
Belief Engine: Configurable and Inspectable Stance Dynamics in Multi-Agent LLM Deliberation
信念引擎：多智能体 LLM 审议中可配置、可检查的立场动态
belief updating structured memory multi-agent deliberation stance dynamics
The Belief Engine is an auditable belief-update layer that represents belief as an evidential state over a proposition and exposes it as a scalar stance, extracting arguments into structured memory and updating stance with a log-odds rule. Parameter sweeps across base LLMs show evidence uptake and prior anchoring reliably shape stance dynamics while preserving an update trail.

arxiv:2607.20453 arXiv ✓
A Knowledge-Injection Framework for Zero-Shot Adaptation of LLMs to Delirium Prediction
面向 LLM 零样本谵妄预测的知识注入框架
knowledge injection clinical prediction inference-time adaptation zero-shot
The authors augment a deterministic natural-language summary of structured EHR data with an external clinical knowledge report at inference time, without fine-tuning or retrieval, and evaluate LLaMA 3.1 8B and 3.3 70B on 3,160 ICU admissions. Adding the report improved AUROC by 8.57 points for the 8B model and 1.99 points for the 70B model, while random control reports did not help.

From Feedback Loops to Policy Updates: Reinforcement Fine-Tuning for LLM-Based Alpha Factor Discovery
从反馈循环到策略更新：面向 LLM Alpha 因子发现的强化微调
self-evolving agents reinforcement fine-tuning context explosion alpha factor discovery
QuantEvolver replaces prompt-level generation-evaluation-feedback loops with reinforcement fine-tuning, converting executable quantitative evaluation into policy updates so a Miner LLM internalizes historical optimization experience. It accumulates high-quality factors in a mined factor database and improves the primary metric over LLM-based alpha-factor baselines on three market benchmarks.

arxiv:2605.15474 arXiv ✓
Jobs' AI Exposure Should Be Measured from Evidence, Not Model Priors
AI 对职业的暴露度应基于证据而非模型先验来衡量
retrieval-augmented measurement AI exposure evidence grounding labor policy
This position paper argues that AI job-exposure labels should be grounded in evidence rather than zero-shot LLM priors, and proposes a retrieval-augmented framework that assigns labels to all 18,796 occupation-task pairs in O*NET 30.2 using retrieved news and paper abstracts. The grounded condition was preferred in over 72% of disagreement cases under automatic and human evaluation.
