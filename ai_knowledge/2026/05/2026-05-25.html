Memory Architectures for Multi-Turn Text-to-SQL: A Benchmark and Empirical Study
多轮 Text-to-SQL 的记忆架构：基准与实证研究
agent memory multi-turn Text-to-SQL working memory benchmark
The authors introduce EnterpriseMem-Bench, 300 sessions and 1,400 turns across BIRD financial, SEC EDGAR and Northwind, with per-turn memory-critical annotation and a three-way ablation of working memory, episodic retrieval and semantic augmentation. They report that stateless multi-turn Text-to-SQL falls to zero execution accuracy by turn 3 across five frontier models, that working memory dominates, and that Claude Sonnet 4.6 underperforms Sonnet 4.5 by 17-33 points on SEC EDGAR.

arxiv:2605.26252 arXiv ✓
Is Agent Memory a Database? Rethinking Data Foundations for Long-Term AI Agent Memory
智能体记忆是数据库吗？重新思考长期智能体记忆的数据基础
agent memory memory governance state trajectory property graph
The authors argue that long-term agent memory is a new data-management workload whose correctness is a property of the state trajectory rather than individual records, and identify four failure modes: unregulated growth, missing semantic revision, capacity-driven forgetting and read-only retrieval. They formalize Governed Evolving Memory with ingestion, revision, forgetting and retrieval operators, argue that no record-level system can satisfy six correctness conditions, and prototype MemState on a property-graph backend.

基于 LLM 实体解析的混合格式居住数据家庭迁移检测

The paper combines prompt-based LLM named entity recognition, semantic text embeddings and graph-based reasoning to detect indirect household-movement links in unstandardized name-address records. Personalizing Embodied Multimodal Large Language Model Agents over Long-term User Interactions
通过长期用户交互实现具身多模态大模型智能体的个性化
multimodal memory knowledge graph embodied agents personalization
POLAR is a multimodal memory-augmented framework that organizes prior interactions into a knowledge graph with semantic memory for personalized context and visual concepts plus episodic memory for embodied trajectories. Across multiple MLLM backbones, the memory mechanism consistently improves performance, especially for multi-interaction reasoning, multi-hop inference and tracking user-specific context over time.

RICE-PO: Turning Retrieval Interactions into Credit Signals for Reasoning Agents
RICE-PO：将检索交互转化为推理智能体的信用信号
retrieval agents credit assignment reinforcement learning interactive retrieval
RICE-PO is a critic-free policy optimization framework that selects high-uncertainty executable retrieval actions as anchors, evaluates local counterfactual branches with retrieval metrics, and propagates credit to latent reasoning steps only when reasoning-to-action influence is strong. On BRIGHT and BEIR it consistently outperforms prompt-based agents and group-based RL baselines under the same retriever.

The Bridge-Garden Dilemma in LLM Distillation: Why Mixing Hard and Soft Labels Works
LLM 蒸馏中的桥-花园困境：为何混合硬标签与软标签有效
knowledge distillation exposure bias hybrid supervision model compression
The authors show that mixing hard and soft labels in knowledge distillation consistently beats either alone, and trace the gain to reduced exposure bias rather than closer teacher matching. Their Bridge-Garden decomposition separates steps where the next token must be exact from steps where it can be flexible; hybrid supervision beats divergence-based and on-policy baselines across seven teacher-student pairs while cutting training cost 9.7x.

VeriTrace: Evolving Mental Models for Deep Research Agents
VeriTrace：为深度研究智能体演化心智模型
deep research agents mental models cognitive graph feedback loops
VeriTrace is a cognitive-graph framework that explicitly implements three regulatory loops for deep research agents: interpretive update, deviation feedback and schema revision. With matched Qwen3.5-27B backbones it improves over the strongest matched baseline by 4.82 points on DeepResearch Bench Insight and 5.9 points overall win rate on DeepConsult, and with Config-DeepSeek it reports the strongest reproducible open-source DRB result.

从模型扩展走向系统扩展：扩展智能体 AI 的执行框架
