Comment and Control: Hijacking Agentic Workflows via Context-Grounded Evolution
评论与控制：借助上下文锚定演化劫持智能体工作流
prompt injection agentic workflows prompt provenance LLM security GitHub Actions
JAW is a detection and exploitation framework that hijacks agentic workflows on automation platforms by evolving crafted inputs under contexts derived from static path-feasibility, dynamic prompt-provenance and capability analysis. arxiv:2605.11336 arXiv ✓
Much of Geospatial Web Search Is Beyond Traditional GIS
大量地理空间网络搜索已超出传统 GIS 范畴
geospatial search sentence embeddings query taxonomy hybrid retrieval
Applying dense sentence embeddings, a SetFit classifier and density-based clustering to 1.01 million MS MARCO queries, the authors identify 181,827 geospatial queries (18.0%), nearly three times the 6.17% labelled as Location. They release an 88-category taxonomy and argue that cost, opening-hours and travel lookups fall outside traditional GIS and knowledge-graph coverage.

HyperEyes：面向并行多模态搜索智能体的双粒度效率感知强化学习

arxiv:2605.11235 arXiv ✓
Internalizing Curriculum Judgment for LLM Reinforcement Fine-Tuning
METIS：为 LLM 强化微调内化课程判断
curriculum learning metacognition reinforcement fine-tuning reward variance
METIS internalizes curriculum judgment in LLM reinforcement fine-tuning by predicting within-prompt reward variance from recent training outcomes and jointly optimizing that self-judgment with standard RFT rewards. The authors report up to 2.1x training speedup across mathematical reasoning, code generation and agentic function-calling benchmarks.
→ arxiv.org
arxiv:2605.11188 arXiv ✓
Adversarial SQL Injection Generation with LLM-Based Architectures
基于 LLM 架构的对抗性 SQL 注入生成
retrieval-augmented generation adversarial testing SQL injection chain-of-thought
The paper introduces RADAGAS, a retrieval-augmented generation system for adversarial SQL injection generation, and RefleXQLi, a reflective chain-of-thought variant, comparing them against ten web application firewalls. RADAGAS-GPT4o achieved a 22.73% bypass rate overall, while the variants were far more successful on AI/ML-based firewalls than on rule-based ones.
→ arxiv.org

Strategic Coercion Within Alliances: The Greenland Sovereignty Game as an AI Stress Test
联盟内的战略胁迫：以格陵兰主权博弈作为 AI 压力测试
multi-agent simulation LLM behavior benchmark inverse game theory geopolitical reasoning
Using 3,604 multi-agent games in which eight frontier LLMs play six geopolitical roles, the authors recover structural utility parameters via inverse game theory and find four-action escalation rises from 10.7% to 28.6% under coercion framing. Peaceful US acquisition emerges in only 1.9% of clean games.
