Combating Catastrophic Forgetting in Continual Domain Adaptation via Knowledge Recasting
通过知识重铸缓解持续域适应中的灾难性遗忘
catastrophic forgetting continual learning skill schemas domain adaptation procedural reuse
Skill Schema Transport recasts new-domain examples as instances of reusable procedures in the model's existing skill space rather than pulling updates back toward old outputs. Across two 3B instruction-tuned backbones it improves streamed-domain performance by 2.53 to 5.75 points and cuts maximum forgetting from 42.41 to 7.10 points on the Qwen-3B MATH stream.

Combining Long-Term Memory and LLMs Comes at a High Cost: From Prompt Injection to Persistent Compromise
长期记忆与 LLM 结合代价高昂：从提示注入到持久化攻陷
memory injection prompt injection persistent memory MCP resources AI security
The authors present a general threat model for memory injection in LLM-as-a-service platforms and report that all NIST attack goals are collectively achievable across ChatGPT Instant 5.3, Claude Sonnet 4.6 and Gemini 3 Flash. Injections can spread through personal memories, projects, skills, organization instructions and MCP-connected resources, and nearly half of the proposed mitigations remain unimplemented.

DiffResearch: Accelerating Deep Research with Diffusion Language Models
DiffResearch：用扩散语言模型加速深度研究
deep research diffusion language models multi-agent systems inference latency open source
DiffResearch is an open multi-agent deep research framework that places a diffusion language model at the core of every stage; with the scaffold held fixed, the diffusion backbone is roughly 6 times faster end-to-end across 100 Deep Research Bench tasks. Its dFast decomposition mode adds a 1.99x median speedup without loss of report quality, and the framework is released under Apache-2.0.

Attention-based Classification for Indirect Prompt Injection
面向间接提示注入的基于注意力的分类方法
indirect prompt injection attention tracking agent security AgentDojo
The authors show that Attention Tracker's dataset-agnostic detection claim does not hold in agentic settings on AgentDojo, and propose AttnDA, which replaces its scalar threshold with a Fisher linear discriminant classifier over per-head focus scores. AttnDA improves detection across agentic and tool-integrated benchmarks, though transfer to AgentDojo remains difficult.

Scan or Index? large Evidence Coverage, Answer Quality, and Cost in Long-Document RAG
扫描还是索引？长文档 RAG 中的证据覆盖、答案质量与成本
long-document RAG evidence coverage hybrid retrieval retrieval cost
Comparing 11 retrieval configurations on 396 QASPER questions and 80 questions from eight textbooks, the study finds Hybrid + Jev reaches the highest observed book evidence coverage (94.1%), while Hybrid + Decisions achieves the best book answer accuracy (0.892) despite recovering less reference evidence. Full scanning incurs substantially higher latency, and reusable dense retrieval has lower projected API cost as queries accumulate.

Speedrunning Relational Foundation Model Pretraining
极速关系型基础模型预训练
relational foundation models structured data pretraining speedrun leaderboard trilinear attention
The authors introduce modded-nanoRT, the first speedrun leaderboard for Relational Transformers, fixing the held-out database by calibration and pairing typed trilinear attention with Muon and SIGReg. The recipe reaches its quality target in 305.63 seconds on one NVIDIA H200, 8.11x faster than the reference implementation.

arxiv:2610.28811 arXiv ✓
A Mechanistic Study of Automated Failure Attribution in LLM-based Agentic Systems
LLM 多智能体系统自动化故障归因的机制研究
failure attribution linear probes multi-agent systems latent knowledge agent evaluation
Using linear probes on internal activations, the study uncovers a 'knows-but-won't-say' gap: models encode enough information to attribute a failure correctly but fail to explicitly output the responsible step. A simple grafting intervention that exploits this latent knowledge improves automated failure attribution over direct prompting across multiple LLMs and benchmarks.

通过强化学习对多智能体系统进行黑盒红队测试
red-teaming multi-agent systems reinforcement learning system prompt extraction
ReMAS is described as the first reinforcement-learning-based red-teaming framework for multi-agent systems, fine-tuning attacker LLMs through a rewrite stage and a template-generation stage to extract system prompts. arxiv:2610.28982 arXiv ✓
Behavior Beyond Text: Evaluating Refusal Transfer Failure in LLM Agents
超越文本的行为：评估 LLM 智能体中的拒答迁移失效
refusal behavior tool use activation steering agent safety safety benchmark
Across a benchmark of 2,304 prompts in four domains and five models, the authors find that 10-52% of harmful requests refused in chat still led to unsafe tool calls under standard tool-enabled prompting. A refusal-associated activation direction decreased in tool contexts and predicted unsafe calls, but restoring it only partially prevented them.
