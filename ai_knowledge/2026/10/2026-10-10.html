Trace Evolution Bench: Measuring Whether Agents Improve from Their Own Environment Traces
轨迹演化基准：衡量智能体能否从自身环境轨迹中改进
self-evolving agents agent evaluation environment traces benchmark protocol
Trace Evolution Bench separates genuine context or weight updates from frozen rescoring when measuring whether self-evolving agents improve on held-out tasks. On a coding pack of 40 tasks, DeepSeek v4 Pro under no_evolve moved 7.5, 5.0 and 12.5 percentage points across three seeds, and seven of nine text-update cells exceeded their seed's band, though no method stayed above its band on every seed across three models.

arxiv:2610.33025 arXiv ✓
Can Language Models Learn While They Think? Testing Gradient Adaptation Across Architectures
语言模型能在思考时学习吗？跨架构的梯度适应测试
dynamic evaluation test-time learning long context gradient adaptation
Dynamic evaluation with one SGD step per 128-token chunk cuts next-token loss by 5-8% on softmax-attention models and outperforms a frozen model given the full 32k-token context, while hybrid Gated-DeltaNet models gain under 1%. On long-context benchmarks the weight updates recover none of the accuracy lost to truncation, indicating the adaptation captures style and vocabulary rather than retrievable facts.

neuro-symbolic reasoning argumentation graphs retrieval-augmented reasoning persuasion detection
NARS combines retrieval-augmented iterative LLM reasoning, which extracts bipolar argument structures from online discussions, with symbolic gradual argumentation semantics that propagate argumentative influence. On the CMV2BAS dataset built from Webis-CMV-20, it reaches F1 0.57 and AUC 0.56 in its best configuration, outperforming zero-shot Qwen3.6:27B and GPT-oss:20B.

Scoring Explanations Without Reading Them: Structural Shortcuts in Automated-Interpretability Evaluation Data
不读解释也能评分：自动可解释性评估数据中的结构性捷径
interpretability evaluation sparse autoencoders evaluation shortcuts benchmark validity
The paper shows that standard automated-interpretability evaluation data can be scored without reading the explanation: on 500 GPT-2 small features from Neuronpedia, a rule keying on the centre token reaches 0.979 balanced accuracy versus 0.838 for stored LLM scorers. It recommends reporting scores alongside the best explanation-free rule on the same items.

arxiv:2610.15084 arXiv ✓
Self-Evolving Visual Agent via Margin Reward
通过边际奖励实现自进化的视觉智能体
self-evolution tool invocation margin reward reinforcement learning
Marvo is a self-evolution approach in which a challenger agent generates question-answer pairs from unlabeled images and a solver learns tool invocation through reinforcement learning. A margin reward, defined as the solver's performance difference with and without tools, drives an adaptive curriculum and improves average accuracy by up to 7.1% across agentic reasoning, visual search, math and real-world reasoning benchmarks.
→ arxiv.org
arxiv:2610.15046 arXiv ✓
Belief Embedding Tree Search
信念嵌入树搜索
belief representation distribution embeddings POMDP planning Monte Carlo tree search
BETS is a Monte Carlo planner that represents each search node's belief with a generative distribution embedding updated through POMDP dynamics, training the belief model alongside policy and value networks. Across six configurations of RockSample, LightDark and PocMan it is competitive or leading against BetaZero and three planners without learned components.

HarnessNet: Feedback-driven Hierarchical Joint Harness Evolution for Multi-agent Systems
HarnessNet：多智能体系统的反馈驱动分层联合 harness 演化
multi-agent systems harness evolution agent optimization model transfer
HarnessNet decomposes joint harness evolution in multi-agent systems into layered Agentron units whose local optimizers see only their own harness. On AgentBench it matches a single global optimizer with fewer tokens and less time, and the evolved harnesses transfer when foundation models are swapped.
