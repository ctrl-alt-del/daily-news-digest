Evaluating Context Compaction on the Questions That Come Later
评估上下文压缩对后续问题的表现
context compaction later-question evaluation evidence retention token budget
The study evaluates context compaction against later questions using four corpora that annotate evidence for several questions per text and recorded agent trajectories, comparing every method with random deletion at the same budget. Selecting sentences for the current question raised MultiRC accuracy by 11.4 points at 25% of tokens but did not detectably help later questions, while question-ignoring LLMLingua-2 beat random sentence deletion by 12.5 points on later MultiRC questions.

记忆越多，智能体越差：LLM 智能体的错误复现与反持久化
agent memory error propagation retrieval memory design
The paper describes error reproduction, in which faulty stored abstractions propagate through retrieval, execution and re-abstraction and extend the life of errors in LLM agents. Diagnostic Analysis for Large Language Model Reasoning
大语言模型推理的诊断性分析
reasoning graphs uncertainty estimation multi-hop QA diagnostic evaluation
The paper proposes a two-stage diagnostic evaluation of reasoning structures in open-ended multi-hop QA, first testing the capabilities needed to build reasoning graphs and then using uncertainty estimation as a downstream test. Graph reliability varied with topology, prompt design and model family; generated-edge graphs were sensitive to upstream errors, and gold graphs provided little benefit as prompt context but improved confidence-based separation and node-level diagnostics.

arxiv:2610.27190 arXiv ✓
On the Fragility of Tasks under Composition: Implicit Budgeting in Language Models
任务组合下的脆弱性：语言模型中的隐式预算
task composition implicit thinking budget model robustness token efficiency
The paper finds that language models make substantially more errors when tasks are composed, even when each constituent task is solved reliably in isolation, and that this is not fully explained by independent error accumulation. Evidence across open-weight models and Claude Opus 5 points to an implicit thinking budget: composed prompts receive fewer tokens per task, and grouping tasks by fragility cut token usage by 43% while preserving accuracy.
→ arxiv.org

Exposing Vulnerability Monoculture Through Systemic Adversarial Robustness
以系统性对抗鲁棒性揭示漏洞单一化
adversarial robustness model distillation shared vulnerabilities
The paper introduces Systemic Adversarial Robustness (SAR), a measure of shared vulnerability in a model pool based on the attack diversity needed to compromise it, formulated as a partial set-cover problem with approximation guarantees. Model pools distilled from DeepSeek-R1 and Claude Opus 4.6 showed lower estimated systemic robustness than their parent pools, indicating a potential systemic cost of frontier-model distillation.
