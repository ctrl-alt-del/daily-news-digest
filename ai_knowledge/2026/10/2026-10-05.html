The Right Memory in the Wrong Context: Verifying Retrieval Admissibility in Long-Term Agent Memory
错位上下文中的正确记忆：验证长期智能体记忆的检索可采性
agent memory retrieval admissibility prompt exposure memory benchmarks
The paper introduces a retrieval-admissibility verification framework that assigns each long-term memory–query pair a status of admissible, inadmissible or unresolved, and tracks memory IDs through prompt exposure. A post-hoc top-20 reanalysis of 3,767 queries from the RHELM and MemOps benchmarks reports anchor recall rising from 0.432 to 0.533 and 80% recall feasibility rising from 0.237 to 0.311.

知道是谁写的还不够：检测是谁贡献了洞见
knowledge provenance authorship attribution LLM-assisted review shortcut learning
The paper introduces Insight Provenance, the task of identifying whether a review insight originates from a human, an LLM or a hybrid contribution, with InsightProv-v0 built from 4,057 scientific papers and 12,660 human reviews. It finds that AI insights predominantly remain close to generic or paper-provided information, whereas human insights more often introduce external knowledge and independent judgment.

Understanding and Enhancing Backdoor Persistency in LLM Agent Post-Training
理解并增强 LLM 智能体后训练中的后门持久性
agent security backdoor attacks post-training model supply chain
The paper shows that backdoors in third-party models can survive benign supervised fine-tuning and subsequent task-level reinforcement learning when developers build software-engineering agents. Its PersistBD method raises attack success on Qwen2.5-Coder-7B from 20% to 74% after SFT and to 76% after SFT-RL.

What pass@k Cannot Measure: Evaluating Diversity and Capability Retention after Post-Training
pass@k 无法衡量什么：评估后训练后的多样性与能力保持
pass@k output diversity RL post-training capability retention
The paper shows that pass@k depends only on a problem's probability of a correct sample and has no term for how correctness is distributed across outputs. Training Qwen2.5-1.5B-Instruct with GRPO and RFT moves three diversity measures in opposite directions, yet pass@8 and pass@32 show no consistent winner on GSM8K, so the protocol misses a property it is often used to certify.
→ arxiv.org
arxiv:2610.07473 arXiv ✓
From Dialogue to Diagnostic Hypotheses: Evaluating LLM Agents for Psychiatric Assessment
从对话到诊断假设：评估用于精神科评估的 LLM 智能体
clinical agents diagnostic reasoning simulated patients tool use
The study evaluates LLM agents conducting free-form psychiatric interviews, introducing PsyCPG for structured simulated patients and PsyCIDRA, a dual-agent interviewer and diagnostic framework with notepad, expert-written skill and ICD-11 tools. On 81 held-out simulated cases PsyCIDRA reaches 60.5% exact-code rank-1 accuracy versus 51.9% for direct prompting, and in 101 human interviews it agrees with experts on whether to issue a hypothesis in 79.6% of cases versus 65.4%.

arxiv:2610.07269 arXiv ✓
What Words Keep of a Place: Zero-Shot Language Reasoning for Cross-View Geo-Localization
文字为地点保留了什么：跨视角地理定位的零样本语言推理
cross-view retrieval vision-language models zero-shot reasoning geo-localization
The study prompts a multimodal LLM to describe ground panoramas and satellite tiles as structured text and localizes by comparing the descriptions, with no component trained. On 9,826 VIGOR pairs from four U.S. cities, full-pool description ranking almost never returns the correct tile (0.39% Recall@1), but within ten neighbouring tiles an MLLM judge doubles random ranking and states which description fields agree or conflict.
→ arxiv.org

On Open-Ended Information Seeking for Information Elicitation Agents
面向信息引导智能体的开放式信息搜寻研究
information seeking information value elicitation agents interaction history
The study compares how 11 LLMs judge information value in open-ended elicitation and uses a controlled simulation to isolate how those judgments shape breadth-versus-depth information seeking. It also examines how interaction history changes the evaluation and selection of prospective information.
