CompSkill: Compiling Execution Experience for Skill Retrieval
CompSkill：为技能检索编译执行经验
skill retrieval execution experience skill documents experience hypergraph agent benchmark
CompSkill indexes skill documents with learned 512-d keys and compiles matched same-task comparisons into skill offsets and capped key residuals, so execution experience changes which document an executor receives without altering its text. Compact keys raise SkillRet NDCG@10 from 64.0 to 70.9 at one-eighth the dimension, and with one document it completes 256 and 260 of 332 ToolQA tasks with GPT-5.6-luna and DeepSeek-V4.1-Flash, more than every baseline.

Auriga Technical Report: A Task-Agnostic Agent Harness for Zero-Shot Embodied Manipulation
Auriga 技术报告：面向零样本具身操作的任务无关智能体 Harness
agent harness embodied agents zero-shot manipulation execution verification task belief
Auriga is a task-agnostic agent harness in which a vision-language model makes task decisions over an explicit task belief and acts through tool calls or synthesized Python programs, while the harness supplies calibrated 3D measurements, dual-arm control and a single admission gateway to the robot. It closes 68.3% of RoboDojo's planning-execution gap zero-shot, ranks first on that leaderboard at 57.7% success, and reaches 73.2% on RoboCasa365 with the same frozen harness.

CogRSI: Evolving and Auditing Cognitive Reasoning Strategies
CogRSI：进化与审计认知推理策略
reasoning strategies theory of mind self-improvement rule auditing counterfactual tests
CogRSI studies whether a model can improve how it reasons about other minds by writing its own guiding principle, keeping an update only when accuracy rises by a calibrated margin and sometimes requiring counterfactual test pairs. Learned principles transfer to 800 unseen BigToM pairs and beat the expert-written principle, but translating each rule into code shows that most give a wrong answer in at least one situation they claim to cover, so accuracy alone does not reveal which rules are wrong.

Do GEO Gains Survive the Live Web? Evaluating In-the-Wild Visibility Gains of Generative Engine Optimization via LIVE-GEO
GEO 增益能否在真实网络中存活？用 LIVE-GEO 评估生成引擎优化的真实可见度提升
generative engine optimization LLM search visibility retrieval evaluation live web benchmark content optimization
LIVE-GEO publishes GEO-rewritten product content as live webpages and tests five optimization strategies across 80 fictional brands and 18 product families on three generative engines plus several direct-text evaluators. With frozen prices, CORE reaches the highest Top-1 rate on most evaluators, at 66.3–76.3% on the generative engines, yet those engines select the same top product for only 48.8–66.3% of brands, and ChatGPT's ranking shifts with candidate URL order.

MAPLE: A Multimodal Mobile Agent with Playbook-Learned Experience
MAPLE：具备剧本学习经验的多模态移动智能体
mobile agents experience sharing prompt evolution multi-agent framework GUI automation
MAPLE is a gradient-free multi-agent framework for mobile GUI agents that shares runtime insights step by step and evolves prompts during execution, instead of relying on post-hoc self-reflection or costly trial-and-error trajectory exploration. It reports state-of-the-art performance on complex long-horizon tasks in AndroidWorld and MobileWorld while adapting across novel environments.

Compile as Hypothesis: A Headroom Typology for Prompt Optimization on Real Reasoning Models
编译即假设：真实推理模型上提示优化的余量类型学
prompt optimization reasoning models evaluation fidelity knowledge limits automated prompt search
The authors run paired same-day evaluations of four prompt-optimizer families across eight tasks and find no statistically significant accuracy gains on strong reasoning models, while a discrete structural genome prevents catastrophic bimodal seed collapse. A three-dimensional headroom typology shows prompt optimization cannot compensate for missing knowledge or physical token truncation but does fix protocol and formatting errors, and the paper also reports silent backend-mixing in commercial APIs during outages.

MedAstra: ASR-less Speech Retrieval with Diagnostic Grounding for Medical QA
MedAstra：面向医疗问答的免 ASR 语音检索与诊断依据
speech retrieval cross-modal embeddings medical QA dense retrieval retrieval evaluation
MedAstra maps frozen WavLM speech representations through a lightweight adapter into a frozen E5 text embedding space, enabling dense retrieval from a waveform without an ASR transcript, with retrieved passages and speech-linked metadata supporting answer generation. It reports 87.6 Recall@10 for the speech-only retriever and 90.4 for the hybrid configuration, versus 81.0 for transcript-first dense retrieval, while noting limits in acoustic uncertainty modeling and clinical generalization.
