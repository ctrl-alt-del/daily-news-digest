Routed Continual Learning
路由式持续学习
continual learning memory routing experience retention context memory
Routed Continual Learning clusters past trajectories, gives each cluster its own memory system from a fixed library, and uses an LLM router to reuse or create a cluster before each run based on the problem statement and cluster summaries. On a stream interleaving 301 instances from six CL-Bench tasks with 97 banking instances from τ³-Bench, it raised normalized reward over a single global ICL history by 15–30% of the maximum attainable reward and cut estimated API cost by 65–72%.

Context Compaction for World Models
世界模型的上下文压缩
context compaction world models context retrieval agent harness
The paper frames consistent world-model revisits as a context-retrieval problem, builds a benchmark that generates new worlds for every episode, and adds an agent harness that compacts context. Context compaction let the tested world models retrieve rooms up to four times beyond their context window without retraining, though models with sliding-window attention lost most of that retrieval when dreaming.

arxiv:2610.38719 arXiv ✓
Learning Scientific Trajectories to Predict Future Biomedical Discoveries
学习科学轨迹以预测未来生物医学发现
scientific discovery conclusion embeddings temporal trajectories hypothesis generation
ForeSCITE clusters published biomedical conclusions, estimates a temporal direction within each cluster and projects conclusion embeddings along it, then decodes the projected coordinates into natural-language hypotheses with an embedding language model. Across 407 clusters from about three million pre-cutoff conclusions, it increased semantic coverage, entity-pair novelty and post-cutoff pair re-observation over five baselines, and experts rated 37 prioritized CAR-T hypotheses as novel and biologically plausible.
→ arxiv.org
arxiv:2610.38851 arXiv ✓
Learning to Reason from Reference Samples Alone: Reinforced Adversarial Learning for Modern LLM Post-Training
仅凭参考样本学习推理：面向现代 LLM 后训练的强化对抗学习
reinforcement learning LLM judges reference answers scientific writing
Reinforced Adversarial Learning (RAL) uses a co-trained LLM judge to turn reference answers alone into the sole reward for on-policy post-training, avoiding explicit verifiable rewards. It matched direct RLVR on three verifiable tasks given sufficiently capable judges and enough training, and in scientific abstract generation its outputs were harder for human scientists and an LLM judge ensemble to distinguish from real abstracts than frontier-LLM baselines.
→ arxiv.org
arxiv:2610.38683 arXiv ✓
Quantum-Inspired Pairwise Ranking Aggregation via Active LLM Feedback
通过主动 LLM 反馈进行量子启发的成对排序聚合
LLM reranking ranking aggregation pairwise feedback retrieval evaluation
LLM-IRA extends quantum-inspired interactive ranking aggregation to document reranking, using an LLM only for pairwise judgments on high-disagreement pairs and producing a fast pointwise linear fusion of retriever scores. On BEIR and TREC Deep Learning benchmarks it matched or exceeded strong static fusion baselines on five of six benchmarks, reached significance over the best unsupervised aggregator on four, and required no training data or fine-tuning.
→ arxiv.org
