Context as Infrastructure: Knowledge Compilation for Retrieval in Agentic Systems with Harnesses
上下文即基础设施：智能体系统中面向检索的知识编译与 Harness
knowledge compilation agentic retrieval context engineering navigation hierarchy RAGFlow
The paper argues that agentic retrieval harnesses have largely solved accuracy and that the missing layer is knowledge compilation, an ingestion pipeline in which LLMs enrich documents with navigation hierarchies, entity graphs, timelines, wikis and memory. It reports that a navigation tree of claim-evidence leaves cuts query tokens by 91% when evidence is sufficient and by 38% on average, and it describes RAGFlow's open-source pipeline.

MEMENTO: Learning Context Management for Long Context Processing Agents
MEMENTO：面向长上下文处理智能体的上下文管理学习
context compaction long-context agents reinforcement learning note-taking confidence calibration
MEMENTO builds on Qwen3-8B, bootstrapping note-taking from synthetic trajectories annotated with hindsight notes and then reinforcing it with a reward that combines answer correctness, note-quality heuristics and confidence calibration. On book-level QA over inputs of up to 2.5M tokens it raises Qwen3-8B's accuracy from 36.9% to 67.8% while never holding more than 20K tokens, beating a GPT-5.5 agent in the same harness and nearly matching a roughly 100x larger GLM-5.3 agent at one-ninth the cost.

Subquadratic Attention with a Hierarchical Tree-Structured Indexer
采用分层树状索引器的次二次注意力
sparse attention hierarchical index long context KV cache subquadratic scaling
Zyphra Hierarchical Attention builds a tree of recursively compressed key summaries over the KV cache that queries traverse from the top down to retrieve a sparse subset of keys, making total cost including routing grow sublinearly in sequence length. It can be applied to pretrained models with a short KL-distillation stage of a billion tokens while preserving long-context retrieval, reasoning, math and agentic coding performance, and it scales far better than competing methods beyond one million tokens.

arxiv:2610.42128 arXiv ✓
DecisionRank: On-Policy Distillation for Decision-Model Rerankers
DecisionRank：面向决策模型重排器的同策略蒸馏
retrieval reranking on-policy distillation decision models ranking retrieval benchmark
DecisionRank transfers a generative LLM's ranking knowledge to a faster decision model through item-space on-policy distillation, sorting the student's document scores into a ranked list that the teacher uses to give conditional feedback on those scores. It reaches state-of-the-art results on TREC DL, BEIR and BRIGHT, and at 1.7B parameters surpasses its 27B generative teacher on TREC DL19–23, while the 8B model runs 24.5x faster than its listwise counterpart on TREC DL.

Agent Stack for ML Training Lifecycle: Generation, Validation, and Optimization
面向机器学习训练生命周期的智能体栈：生成、验证与优化
agent stack ML lifecycle automated validation model migration experiment orchestration

Latent Sparse Attention: Towards Subquadratic Ultra-Long Context Attention
Latent Sparse Attention：面向次二次超长上下文注意力
sparse attention latent clustering ultra-long context attention efficiency distillation
Latent Sparse Attention hierarchically clusters keys in a learned latent space so that queries score clusters rather than every key, with a distilled variant for pretrained models and a variant trained natively on next-token loss. On GLM-5.3-FLASH at 10M tokens the distilled variant speeds up one attention layer by 22.7x in prefill and 4.6x in decode over the original sparse attention while keeping similar accuracy across tasks.
→ arxiv.org

Exo: An Architecture for Self-Improving Systems at Runtime
Exo：运行时自我改进系统的架构
self-improving systems agent harness runtime learning policy activation continual learning
Exo is an agent runtime that collapses the optimization loop into task execution so agents can revise both their harness policies and their strategies while work continues, with a protected mechanism layer that preserves execution history and governs policy activation through inspectable code changes. On long-running game objectives it cuts model cost 12–53% versus Codex and Pi in standalone runs while matching task completion, and on AppWorld and SREGym it reduces held-out model cost 35–61% with comparable correctness.
