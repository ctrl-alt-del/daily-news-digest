OpenMobile-2: Building Versatile Mobile Agents with Scalable Environments and App-Native Tools
OpenMobile-2：以可扩展环境和应用原生工具构建通用移动智能体
mobile agents open training data GUI agents tool use agent benchmark
OpenMobile-2 is a near-frontier mobile agent released with fully open training environments and recipes, including MobileGym++ with 35 commercial-style apps and over 110 apps in total, nearly 12K supervised interaction trajectories and more than 2K verifiable RL tasks with automatic rewards. It also explores hybrid GUI and app-native tool use with over 300 tools across 50+ apps, scoring 79.9 on AndroidWorld and 50.4 on MobileWorld and nearly doubling SPA-Bench from 31.9 to 59.6.

arxiv:2610.13889 arXiv ✓
RATED: Reliability-Aware AI Agent Tool Retrieval via Execution Dynamics
RATED：通过执行动态进行可靠性感知的智能体工具检索
tool retrieval contextual bandit execution feedback semantic matching retrieval benchmark
RATED combines a frozen dual-encoder with contrastive fine-tuning for semantic tool matching and a lightweight contextual bandit that re-ranks candidates from real-time execution feedback, adapting to runtime tool failures without retraining. On the EcoAgent benchmark of 5,172 tools and over 210,000 query-tool pairs it improves relative MRR by 52.2% over the ToolLLM API retriever and cuts fault selection from 86.2% to 2.9% under a 30% API failure rate.
→ arxiv.org
arxiv:2610.14393 arXiv ✓
SciCurateBench: Curating Experimental Data from Heterogeneous Scientific Literature with Verbal-Action Agents
SciCurateBench：用语言-行动 agent 整理异构科学文献中的实验数据
scientific literature data curation verbal-action agents benchmark design
SciCurateBench is a benchmark of 200 expert-annotated life-science papers that asks systems to verify conjunctive experimental criteria from raw literature, and plain LLMs plus reasoning, tool-using and feedback-based agents all struggle with it. The authors' LangPoli system, in which a policy agent writes action guidelines that actor agents turn into tools, reaches 83.16% F1 on paper classification against 58.22% for its base LLM.

DeepSeek arxiv:2610.13948 arXiv ✓
Can Language Models Play the Wikipedia Game?
语言模型能玩维基百科游戏吗？
information retrieval graph navigation sentence embeddings human baseline
The study uses the Wikipedia Game—reaching a target article using only article links—as an information-retrieval test for sentence-embedding models and LLMs across five Wikipedia languages and five academic-literature datasets, building local Wikipedia and OpenAlex citation graphs. No model significantly outperformed humans, though GPT-o3 mini, GPT-4o, QwQ:32B and DeepSeek-R1:70B achieved comparable success, and rankings varied across languages and topics.
→ arxiv.org
arxiv:2610.14402 arXiv ✓
SAT-RL: Training Language Models for Logical Reasoning with Symbolic Solvers
SAT-RL：用符号求解器训练语言模型进行逻辑推理
symbolic solvers tool use reinforcement learning logical reasoning
SAT-RL is a reinforcement-learning framework that teaches LLMs to use symbolic solvers such as Z3 through multi-turn tool use, combining synthetic data with verifiable solutions, supervised warm-up on solver-augmented traces and solver-grounded RL. The authors report gains on both in-domain and out-of-domain logic tasks.

arxiv:2610.14381 arXiv ✓
ACED-Bench: Evaluating How LLM Agents Acquire and Act on Causal Evidence
ACED-Bench：评估 LLM agent 如何获取并依据因果证据行动
causal reasoning evidence gathering neuro-symbolic benchmark design
ACED-Bench is a neuro-symbolic benchmark in which LLMs generate natural-language scientific scenarios while hidden probabilistic graphical models hold the causal graph, intervention semantics and oracle answers. Across seven contemporary LLMs and two earlier models on its 180-task ACED-CORE leaderboard, agents tested the wrong intervention, lost relevant evidence or continued after enough evidence had appeared.

arxiv:2610.14258 arXiv ✓
Do Artificial Neural Networks Need Dendritic Nanotubes? Two Reasons for Shrinking Importance Estimates in Continual Learning
人工神经网络需要树突纳米管吗？持续学习中重要性估计收缩的两个原因
continual learning importance estimation catastrophic forgetting elastic weight consolidation
The paper traces a biologically inspired continual-learning mechanism—transient lateral links that diffuse importance tags between hidden units—to linear shrinkage of importance toward the layer mean, finding that random links with lifetimes of 25 or 200 steps raised final accuracy on 20-task Permuted MNIST by 1.5 to 2.6 points while activity-dependent rules did worse. It further separates variance and bias effects in EWC and MAS importance estimates as the number of samples grows.
