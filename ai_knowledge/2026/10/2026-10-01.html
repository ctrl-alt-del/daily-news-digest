APDMem: Agent-Controlled Progressive Disclosure for Query-Adaptive Long-Term Memory
APDMem：面向查询自适应长期记忆的智能体控制渐进披露
agent memory progressive disclosure long-term memory LongMemEval
APDMem represents conversation history as four progressively detailed layers and uses a controller that reads high-level summaries first, drilling into finer evidence only when a query needs it. On LongMemEval it reports strong long-context memory reasoning while accessing only 8% of the total conversations.

arxiv:2610.02542 arXiv ✓
How To Train Your World Model: Fine-tuning vs RAG for LM-based World Modeling
如何训练你的世界模型：基于语言模型的世界建模中微调与 RAG 的对比
retrieval-augmented generation world models parametric knowledge hybrid memory agent planning
A systematic comparison across five text environments finds that fine-tuned world models let agents obtain higher rewards in 15 of 20 settings, while retrieval-based world models are more data-efficient. The authors propose a hybrid system that captures core environment dynamics parametrically and relies on retrieval from an actively maintained memory store.

Counterexample Generation via Per-Theorem Symbolic Verifiers: When Imitation Hurts and Reinforcement Repairs
通过逐定理符号验证器生成反例：模仿有害而强化学习可修复
counterexample generation symbolic verification RLVR theorem proving training environments
The authors release SymCE, a corpus of 4,707 false undergraduate-algebra and real-analysis conjectures each paired with an executable per-theorem Python verifier that also serves as a reward function. arxiv:2610.02438 arXiv ✓
Are you Synthesizing or Recalling? Evaluating LLMs on Algorithmic Code Retrieval
你是在综合还是回忆？评估 LLM 的算法代码检索能力
parametric knowledge code retrieval benchmark prompt augmentation
AlgoREval is a 599-problem benchmark spanning 77 classical algorithms, 14 domains, 7 programming languages and 4 graph-input representations, designed to measure code generation as parametric retrieval of known algorithms. Testing 15 models zero-shot reveals substantial variation in retrieval accuracy across languages and input representations, even for widely documented algorithms, and shows that retrieved code snippets or structured hints help on complex algorithms.

arxiv:2610.02516 arXiv ✓
Student-Guided Teacher Distillation for Efficient LLM Task Routing: Positioning Against Jev-Style System-1 Classifiers
面向高效 LLM 任务路由的学生引导教师蒸馏
task routing knowledge distillation embeddings evaluation
A compact ModernBERT student predicts a full distribution over 60 task categories in one forward pass and retrieves a small top-k set for a larger zero-shot NLI teacher to rerank, cutting the cost of scoring every request against every label. The best student checkpoint reaches 77.5% teacher agreement, with preliminary Coverage@16 measurements of 91-100%.

arxiv:2610.02413 arXiv ✓
Prompted to Discriminate: Generalizing Malicious-Input Probes in the Wild
被提示去判别：在真实环境中泛化恶意输入探针
activation probes runtime monitoring prompt suffixes out-of-distribution detection
Across 13 safety benchmarks and three open-weight model families under leave-one-dataset-out evaluation, appending a short classification suffix to the user turn improves out-of-distribution detection for activation probes by up to about 4 AUC points. The gain appears to come from the classification format rather than the named criterion, and which suffix helps depends on the model and readout.
→ arxiv.org
arxiv:2610.02405 arXiv ✓
When Terminal-Agent Training Stalls: Demystifying Data Generation and Verification Challenge
当终端智能体训练停滞：揭开数据生成与验证挑战
terminal agents verifier design training data GRPO
The authors build a pipeline that generates containerized terminal tasks and executable verifiers, then separate structural validity, verifier faithfulness, policy solvability and infrastructure reliability as distinct requirements that are often conflated. In a GRPO run, Qwen3.5-9B overfits a relatively easy dataset within 20 steps, while adding hard tasks lowers mean rollout pass@2 from 81.3% to 20.6% and restores informative failures.
→ arxiv.org
