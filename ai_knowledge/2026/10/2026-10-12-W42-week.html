MemDerive: A Diagnostic Benchmark for Agent Memory over Evolving Data
MemDerive：面向演化数据的智能体记忆诊断基准
agent memory derivation DAG diagnostic benchmark evolving data
MemDerive is a diagnostic benchmark for agent memory over evolving data with 10 scenarios, 4,692 events and 1,503 queries, deriving exact gold answers with Datalog and recording each gold derivation DAG and supporting events. Evaluating four memory systems, it found every system fell behind simple BM25 on derived state, most failures were ungathered intermediate states, and systems rarely propagated implicit changes.
