History Replays Itself: Unleashing Long-Context Capability in Linear Attention
历史自我重演：释放线性注意力的长上下文能力
episodic memory long-context retrieval linear attention training-free memory RULER
NoteBank is a training-free, plug-and-play sparse episodic memory that archives selected text before future queries are known and reads retrieved evidence through the backbone's native forward computation via replay. At one million tokens it raises Gated DeltaNet's mean accuracy on six RULER retrieval tasks from 1.7% to 70.3%, adds at most 0.025% to analytical FLOPs, and uses about 1/2,600 of a Transformer's full KV cache at matched settings.

A Decade in a Day: Synthesizing Agent-Native Interfaces from Human-Oriented Software Evolution
一日十年：从面向人类的软件演化中合成智能体原生界面
agent-native interfaces desktop automation interface design agent benchmark
DeskIF-Bench holds the task, agent and verifier fixed while varying software releases across 255 artifact-verified tasks and six desktop applications, finding the newest interface consistently outperforms the oldest. Guided by discoverability, granularity and observability, the authors build ANIS to synthesize agent-native interfaces; atomic interfaces beat native SDK use by 3.8 and 3.5 points with DeepSeek V4 Flash and Claude Haiku 4.5 while cutting online token use by about 73%.

LLM Value Functions for Credit Assignment in Agentic RL
用于智能体强化学习信用分配的 LLM 价值函数
credit assignment value functions agentic RL step-level rewards
LVRL uses a pretrained LLM's in-context learning to estimate policy-aware state values without finetuning a separate critic, conditioning on group context and calibrating against known values at the initial and terminal states to assign step-level credit. It outperforms GRPO and PPO across 4B-32B policy scales, with absolute gains up to 13.6 points on AppWorld and 8.6 on SWE-bench Verified, and lifts BabyAI from total failure to 75.0% success.

SkillMarker: A KGW-Based Watermarking Method for Agent Skill Ownership Verification
SkillMarker：基于 KGW 的智能体技能所有权验证水印方法
agent skills watermarking ownership verification knowledge assets
SkillMarker is a KGW-based watermarking method for agent skills that combines quality-constrained rewriting, which separates essential knowledge from flexible expression, with signal-oriented candidate search to strengthen the watermark. Across four datasets it negligibly affects downstream task performance, and window-based detection identifies copied passages as short as 1,536 consecutive tokens, retaining 72.2-77.8% detection after merging with background skills.

PopGen: Generating Semantically Diverse Populations for Zero-Shot Coordination
PopGen：为零样本协作生成语义多样的智能体种群
multi-agent systems zero-shot coordination behavior generation LLM-generated code
PopGen uses LLMs to generate textual descriptions of distinct agent behaviors and translates each into an executable code policy, producing semantically diverse populations for multi-agent reinforcement learning. Cooperators trained against these populations achieve robust zero-shot cooperation with unseen partners across four collaborative environments, and semantic diversity scales with population size.

Revocation Is Not Complete at Receipt: An Executable Outcome Contract for Distributed Agent-Tool Gateways
撤销在回执时并未完成：面向分布式智能体-工具网关的可执行结果契约
agent-tool gateways revocation distributed agents security contracts
The paper defines C0-C5, a bounded outcome contract for revocation in distributed agent-tool gateways, and implements it as a persistent monitor over a frozen gateway set. In an experiment with Keycloak 26.7, eight agent-tool gateways and 16 AWS hosts, receiver-selective non-delivery still admitted 112 of 225 calls and all 112 effects committed, which the authors cite as evidence that transport success is not proof of revocation completion.

Large language model-generated patterns for epidemiological modeling: a multi-benchmark evaluation framework
LLM 生成的模式用于流行病学建模：多基准评估框架
knowledge validation epidemiological modeling LLM-generated data multi-benchmark evaluation
The study evaluates LLM-generated behavioral outputs for hepatitis C-related behaviors among people who inject drugs against literature, agent-based model and survey benchmarks. Across three LLMs, unconditional directional recovery was 46-68% for 28 literature-informed associations, versus 82-93% when the models were asked directly to classify them, indicating only partial alignment.

AutoSec-RAN: Specification-Grounded LLM Fine-Tuning for Automated Security Analysis of O-RAN
AutoSec-RAN：基于规范的 LLM 微调，用于 O-RAN 自动化安全分析
retrieval-augmented generation domain fine-tuning standards documents telecom security
AutoSec-RAN fine-tunes Mistral-7B-Instruct through two LoRA stages on 69 O-RAN, 3GPP and adjacent standards documents, then selectively adds RAG retrieval over the same index for security triage without raw packet access. On a 5G/O-RAN testbed with labeled fronthaul DDoS replay scenarios, it scored a mean of 0.713 across 313 items on a Gemma-4-31B judge, with weaker performance on the held-out attack-direction class.
