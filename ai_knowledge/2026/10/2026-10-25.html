CTXAgent - Self-Controlled Context Management of LLM Agents
CTXAgent：LLM 智能体的自控上下文管理
context management agent harness context compaction token cost
CTXAgent lets the model manage its own context, deciding when to compact, what to keep and what hand-off to write with two tools and one paragraph of guidance, and evaluates seven frontier models on mixed sessions of 35–212 turns. Most strong models compact and curate regularly without significant benchmark-score loss, and with Claude Opus 5.5 the self-managed harness matches Claude Code on task success at 34% lower cost than its 200k-window configuration and 49% lower than its default.

EvolveMAS: A Unified Self-Evolution Framework for Decentralized Multi-Agent Systems
EvolveMAS：去中心化多智能体系统的统一自我进化框架
agent memory knowledge evolution multi-agent systems test-time adaptation
EvolveMAS pairs each main agent with a dedicated MemoryAgent that governs structured memory outside the reasoning context, supporting within-episode online adaptation and cross-episode knowledge evolution across cooperative, mixed-motive and adversarial settings. Across five benchmarks and six evaluation configurations it achieves the highest normalized average score of 77.2, and ablations show that both test-time memory governance and cross-episode reuse improve performance without updating model parameters.

DynaFlow: Learning Free-Form Multi-Agent Orchestration
DynaFlow：学习自由形式的多智能体编排
multi-agent orchestration workflow synthesis supervised fine-tuning information flow
DynaFlow integrates free-form executable workflow synthesis into the main agent's action space, letting it decide when to collaborate and generate task-specific programs that coordinate fixed sub-agents sequentially or in parallel with verification. Trained only on distilled trajectories and refined on filtered examples, it reaches 88.08% overall accuracy in Forced mode across six benchmarks, 10.90 points above the strongest evaluated baseline with the same Qwen3.5-27B backbone.

AgentProofBench: Benchmarking Reusable Verifiers for Web Agents
AgentProofBench：评测 Web 智能体可复用验证器的基准
web agents reusable verifiers test replay execution validation
AgentProofBench connects paired tests of a frozen acceptance rule to execution from identical saved openings across 97 tasks, 79 families and four web services. Across 48 families, complete-panel and decision-replay tests retain 82/96 Flash and 79/96 Pro source programs, and deployment-state panel correctness separates assignments with both saved openings delivered correctly (32/33) from those with panel errors (1/11).

AndroidFlux: Evaluating and Reward Modeling Failure Recovery Capabilities in Mobile Use Multimodal Agents
AndroidFlux：移动多模态智能体故障恢复能力的评测与奖励建模
mobile agents failure recovery reward modeling agent benchmark
AndroidFlux restores recorded mobile-agent trajectories to controlled checkpoints before, at and after the first recoverable error so different agents continue from the same device state and history, paired with a reward-modeling benchmark using downstream rollout outcomes. Its evaluations show that recovery performance only partially correlates with clean-start success, and that explicit reasoning helps only models trained with GUI-domain-specific reinforcement learning.

Improving the Chain-of-Thought Compressibility of Pruned Reasoning Models via Long--Short Contrastive Pruning
通过长短对比剪枝提升剪枝推理模型的思维链可压缩性
chain-of-thought model pruning preference optimization reasoning efficiency
The paper proposes Contrastive Set-Difference, which identifies neurons enriched in redundant reasoning by contrasting activations on long and short correct solutions to the same problem, and extends preference pairs to problems a pruned model always or never solves. Pruning 20% of DeepSeek-R1-Distill-Qwen-7B this way uses 8–22% fewer thinking tokens on four math benchmarks than reasoning-aware calibration followed by the same compression, with accuracy within 0.5 points.

Large Language Models: A Plain-Language Overview for Engineers
大语言模型：面向工程师的通俗综述
LLM fundamentals retrieval-augmented generation evaluation claims context-prompting
This plain-language overview walks engineers through the transformer, pretraining, fine-tuning with reinforcement learning from human feedback, retrieval-augmented generation, chain-of-thought prompting and tool-using agents, plus efficiency techniques such as FlashAttention and QLoRA. It closes with a checklist for judging LLM evaluation claims that flags data contamination, LLM-as-a-judge grading, long context and hallucination.
