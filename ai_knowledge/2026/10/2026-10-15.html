From Relevant Memories to Sufficient Evidence: Rethinking Memory Utilization in LLM Agents
从相关记忆到充分证据：重新思考 LLM 智能体中的记忆利用
agent memory evidence sufficiency memory retrieval LoCoMo
QEMem reframes agent memory use as building query-specific evidence sets instead of retrieving individually relevant memories, combining query-guided discovery, structured ViewCards and sufficiency-guided refinement. It reaches 91.43% LLM-judge accuracy on LoCoMo with Claude Opus 4.5, 7.6 points above MemR³ and 10.7 points above NEMORI on a shared memory store.

Graph Serializations for Reasoning LLMs: A Study Across Knowledge Extraction and Structural Reasoning
面向推理 LLM 的图序列化：跨知识抽取与结构推理的研究
knowledge graph serialization graph reasoning LLM orchestration benchmark study
A study evaluates 15 knowledge-graph serialization formats across nine frontier LLM configurations on ontology-based knowledge extraction and structural graph reasoning tasks. It finds extraction is relatively insensitive to format while structural reasoning accuracy varies significantly, and proposes treating serialization as a dynamic orchestration decision.

HeRE: A Novel Benchmark for Hebrew Relation Extraction via LLM-Guided Denoising of Knowledge Graph Alignments
HeRE：通过 LLM 引导的知识图谱对齐去噪构建希伯来语关系抽取基准
relation extraction low-resource languages dataset construction natural language inference Hebrew NLP
The authors propose a language-agnostic pipeline that builds relation-extraction data by denoising noisy knowledge-base and text alignments, validated through natural language inference. Applying it produces HeRE, a 1.5-million-instance silver dataset for Hebrew, where the best open-weights model reaches F1 0.915 versus 0.921 for the best API model.

NoveltyScope: A Multi-Agent Research Assistant for Evidence-Grounded Novelty Assessment of Scientific Papers
NoveltyScope：面向科学论文证据驱动新颖性评估的多智能体研究助手
multi-agent systems novelty assessment hybrid retrieval evidence grounding scientific literature
NoveltyScope compares a paper with retrieved prior work using BM25 and dense retrieval with reciprocal rank fusion, then has Prosecutor, Defender, Judge and Critic roles produce an evidence-grounded five-level novelty score. On 50 balanced RINoBench samples, multi-agent scoring had lower mean absolute error than single-LLM scoring with both Gemini and Qwen3.

Predicting Privileged Information Effectiveness for On-Policy Self-Distillation
预测在线策略自蒸馏中特权信息的有效性
self-distillation privileged information agentic training KL metrics
A systematic study of 16 privileged-information configurations across three multi-turn agentic benchmarks and three student models finds that information-dense trajectories and PI from stronger generators generally yield larger gains, while thinking models benefit less consistently. KL-based metrics tracked post-training performance more reliably than PI utility.

Repair, Retry, and the Cost of Hindsight: Verifier Feedback in Formal Theorem Proving
修复、重试与事后回顾的代价：形式定理证明中的验证器反馈
verifier feedback self-repair theorem proving test-time compute
Controlled Lean theorem-proving experiments with Qwen3.6-27B and DeepSeek-Prover-V2-7B find that showing a model its failed proof reduces success and increases copying, while correct compiler diagnostics can recover part of the loss.
