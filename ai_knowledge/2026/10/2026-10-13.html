Plant Memory: Technical Language Processing and a Verified Maintenance Ontology for Agent-Accessible Failure Knowledge from SAP PM Work Orders
Plant Memory：面向智能体可访问故障知识的技术语言处理与经验证维护本体
maintenance ontology verified knowledge MCP server human-in-the-loop industrial knowledge
Plant Memory applies technical language processing to SAP Plant Maintenance work orders and builds an ISO 14224-aligned maintenance ontology in which each extracted fact carries a confidence score, its source evidence, and a verification state. The graph is served to people through a web app and to agents through an MCP server; on a synthetic 400-work-order export, ontology-ranked root causes were top-1 correct in 82.1% of 28 diagnostic questions versus 53.6% for the raw SAP root-cause column.

CLASHarness: Benchmarking Multi-Agent Conflict in Computer Use via a Controllable and Verifiable Generation Pipeline
CLASHarness：通过可控可验证生成流水线评测计算机使用中的多智能体冲突
multi-agent systems conflict resolution computer-use agents benchmark generation visual grounding
CLASHarness is a controllable generation framework and 600-task benchmark for evaluating how vision-language agents resolve conflicting information in multi-agent computer-use workflows. Across 15 frontier models, weaker models blindly follow misleading sub-agent outputs while stronger ones inspect visual evidence, and even frontier models fail more than 58% of closing actions.

TRACER: Trace-Regularized Training Against Indirect Prompt Injection
TRACER：针对间接提示注入的轨迹正则化训练
indirect prompt injection retrieval security adversarial training attack success rate
TRACER is a channel-aware adversarial training method that defends LLMs against indirect prompt injection arriving through retrieved content, tool outputs, and agent messages. On GSM8K with Qwen2.5-3B-Instruct, it reduces RAG-framed attack success from 65.5% to 6.1% while preserving 78-82% clean accuracy.

Verifier-Grounded Agentic RL for Provably Correct Code
基于验证器的 Agentic RL：训练可证明正确的代码
agentic RL verifier feedback formal verification reward design
The authors build an agentic reinforcement-learning environment that rewards code candidates by the weighted share of proof obligations they discharge from verifier diagnostics, adding an integrity audit against specification tampering. Across Qwen3 models from 1.7B to 14B and a 35B Qwen3.6 mixture-of-experts model, held-out verification reportedly rises from 66.1% to 93.5% on DafnyBench and from 56.3% to 100% on SWE-Proof.

Revisiting Generative vs. Dense Retrieval: A Static Value Prior Reverses the Gap
重新审视生成式检索与稠密检索：静态价值先验逆转差距
generative retrieval dense retrieval reranking offline evaluation
The authors compare generative retrieval with dense retrieval on two Amazon Toys datasets and an industrial e-commerce dataset, finding that popularity contributes most to generative retrieval's measured value lead. Adding the same static item value to dense retrieval in one reranking step reverses that lead, and a 14B SID-LLM still underperforms a 47x smaller dense encoder on LLM-judged relevance.

arxiv:2610.19302 arXiv ✓
DTDD: Divergence-Triggered Dynamic Distillation for Reliable On-Policy Supervision
DTDD：面向可靠在线策略监督的发散触发动态蒸馏
on-policy distillation teacher takeover long-horizon reasoning agent training
DTDD is an adaptive on-policy distillation framework that triggers teacher takeover when segment-level student-teacher divergence grows, then trains the student on the teacher's recovery suffix through behavior cloning. It reduces the post-warmup peak gradient norm by 8.6x and improves best-observed ALFWorld performance by 4.8 points with LoRA.

Learning from Self-Generated Responses: Reliability--Uncertainty Self-Distillation for Reasoning
从自生成回答中学习：面向推理的可靠性—不确定性自蒸馏
self-distillation reasoning uncertainty estimation benchmark evaluation
The paper proposes Reliability-Uncertainty Self-Distillation, in which one model serves as both teacher and student and weights each self-generated attempt by judged reliability and predictive uncertainty. Across eleven reasoning benchmarks it reports 70.47% average accuracy on Qwen3-4B and 76.69% on Qwen3-8B, outperforming five baselines.

Pre-Trained Language Models as Zero-Shot Tools for Social Science Research
预训练语言模型作为社会科学研究的零样本工具
embeddings record linkage zero-shot inference demographic inference
The paper shows pre-trained language models can perform record linkage and demographic inference from names without task-specific training. EnsembleLink combines pre-trained embeddings with string-based scorers to retrieve candidate matches, while LLMs reach up to 83.8% ethnicity-inference accuracy on U.S. voter files versus 78.0% for name-supplemented BISG.

LLM 真的回答了问题吗？用于越狱评估的语义重建游戏
jailbreak evaluation LLM-as-judge semantic reconstruction evaluation reliability
