DREAM: Dynamic Resolution Assignment For Multimodal Multi-agent Debate
DREAM：面向多模态多智能体辩论的动态分辨率分配
multimodal debate adaptive image resolution groupthink multi-agent evaluation
DREAM assigns each agent in a multimodal multi-agent debate an empirically optimal image resolution through a zero-shot probe round, and counteracts groupthink with uncertainty-guided rollback. On six multimodal datasets it improves the accuracy-token trade-off by 1.5–3.2% without dataset-specific tuning.

Expanding LLM Reasoning
扩展 LLM 推理
reasoning chains inference compute self-consistency restart position
A study measures expansion utility — the change in correctness from restarting a reasoning chain at a stored step — at every eligible step for nine models on six benchmarks. It finds restart position matters; a fixed rule that restarts from the last eligible steps is a strong baseline, and the authors' learned router beats uniform placement but shows no detected gain over it.

Have I Scene This Before? Spatially Grounded Conversational Memory for Complex Queries in Egocentric Assistants
我是否见过这一幕？面向自我中心助手中复杂查询的空间锚定对话记忆
conversational memory spatial grounding egocentric assistants multimodal retrieval
SpaC-MEM is an object-centric working memory that uses 3D reconstruction and segmentation to ground conversational information in persistent physical objects, compressing multimodal histories while preserving spatial evidence. The authors also introduce Ego-SpaCR, a benchmark of 620 ScanNet video sessions, 95 task-oriented conversations and 3,100 evaluation queries; SpaC-MEM reports the highest overall answer accuracy among evaluated methods with substantially fewer reference input tokens than native-video baselines.

CASE: Cost-Aware Stopping for Efficient Long-Video Agents
CASE：面向高效长视频智能体的成本感知停止
agent stopping evidence gathering long-video agents token efficiency
CASE is a plug-in termination framework that frames when a long-video agent has seen enough as policy-conditioned sequential stopping. On Video-MME it changes end-to-end accuracy by +0.67 percentage points on average while reducing model-token use by 53.63%, and transfers zero-shot to LongVideoBench and MLVU with token savings of 58.78% and 51.28%.

arxiv:2610.05387 arXiv ✓
GNN-CB: A Graph Neural Network Competition Benchmark for Human and LLM Evaluation
GNN-CB：面向人类与 LLM 评估的图神经网络竞赛基准
graph neural networks coding benchmark zero-shot prompting agent evaluation
GNN-CB is presented as the first competition-based benchmark for evaluating humans and LLMs on end-to-end graph neural network coding tasks, with 18 curated competitions, hidden test sets and a unified automated scoring pipeline. Under a frozen zero-shot plan-then-code protocol, LLMs rarely match human top performance, no single model dominates, and humans hold the top score on most tasks.

arxiv:2610.05630 arXiv ✓
Atomic Visual Entailment: Enhancing Zero-Shot Vision-Language Reasoning through Atomic Fact Decomposition and Learned Selection
原子视觉蕴含：通过原子事实分解与学习式选择增强零样本视觉语言推理
fact decomposition visual entailment zero-shot reasoning SNLI-VE
AVE decomposes a visual-entailment hypothesis into atomic facts, produces candidate predictions from both the full hypothesis and its facts with frozen vision-language models, and learns which candidates to trust. It reaches 0.803 test accuracy on SNLI-VE without fine-tuning any vision-language model, and finds decomposition helps only when hypothesis context is preserved.

Measuring and Reducing Cross-Vendor Mismatch in Language Models
测量并减少语言模型的跨厂商不一致
cross-vendor mismatch model reproducibility knowledge distillation mixture-of-experts
The study analyzes logit, top-K and task-accuracy differences when the same dense or mixture-of-experts models run on GPUs from different vendors, tracing part of the mismatch to accumulation order in matrix instructions. FP32 upcasting reduces the dense model's logit error by 43% at three times the runtime, and the mismatch also propagates into distillation: a student distilled from a teacher on AMD answers 431 MMLU questions differently from one distilled on NVIDIA.
→ arxiv.org

More Than Words: Compositional Tokenization for Efficient Language Models
不止于词：面向高效语言模型的组合式分词
tokenization compositional embeddings language model pretraining compute efficiency
CoBPE represents short phrases as a lexical base token plus reusable surface modifiers that are composed in embedding space and predicted jointly. In pretraining from scratch at 780M and 1.3B scales it shortened sequences by 30% and improved average downstream performance by 1.2 points over standard BPE at matched compute.
