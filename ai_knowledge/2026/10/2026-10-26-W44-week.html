Auriga Technical Report: A Task-Agnostic Agent Harness for Zero-Shot Embodied Manipulation
Auriga 技术报告：面向零样本具身操作的任务无关智能体 Harness
agent harness embodied agents zero-shot manipulation execution verification task belief
Auriga is a task-agnostic agent harness in which a vision-language model makes task decisions over an explicit task belief and acts through tool calls or synthesized Python programs, while the harness supplies calibrated 3D measurements, dual-arm control and a single admission gateway to the robot. Context Is a Pipeline, Not a Window: Information Attrition in LLM Agent Harnesses
上下文是一条流水线，而非一个窗口：LLM 智能体框架中的信息损耗
context management tool output truncation agent harness information attrition
Measuring a Linux-trace debugging agent over 720 runs, the authors found the largest prompt used only 5.75% of the context window while 3,827 of 11,189 tool results were cut into broken JSON before reaching the model. ReplayRCA: Measuring Post-hoc Diagnosis and Live Oversight of Agent Failures by Counterfactual Replay
ReplayRCA：通过反事实重放衡量智能体故障的事后诊断与实时监督
agent failure diagnosis counterfactual replay live oversight causal repair agent benchmark
ReplayRCA scores an agent-failure diagnosis by intervention rather than annotation agreement: the environment is restored to the state before the chosen step, the proposed action replaces the agent's own, and the same agent continues, with a paired placebo subtracted. On 62 calibrated systematic failures the best of 13 frontier models reaches a causal repair of +51.3 points, five items are repaired by no model, and a top post-hoc diagnoser is the weakest live supervisor on 87 runs.
→ arxiv.org

TSSDA：自主构建时间序列 Text-to-SQL 基准的智能体
text-to-SQL benchmark generation data agent temporal-aware memory synthetic data
TSSDA is an autonomous data agent that models time-series SQL syntax and semantics to build the TERN text-to-SQL benchmark, using a planning and decision module, a query-generation module and temporal-aware memory for reuse across heterogeneous schemas. The authors report that it improves coverage, diversity and complexity over existing generation methods, and that evaluations on TERN expose limitations of current Text-to-TSSQL approaches.
