When Retrieval Is Not Enough: Obsolete Facts in Agent Memory
检索还不够：智能体记忆中的过时事实
agent memory stale knowledge retrieval-augmented generation memory benchmark
On MemoryAgentBench's FactConsolidation task, a retrieved obsolete statement was far more damaging than an unrelated one: replacing one unrelated statement with a stale competing statement cut accuracy from 100% to 44.6% for Qwen2.5-7B and to 87.8% for Qwen3-14B. The authors argue that retrieving the correct fact is not enough when outdated versions compete with it.

kw-bench: Breaking Frontier Harnesses on Real-World Tasks
kw-bench：在真实任务上击穿前沿智能体框架
agent harness long-horizon tasks deterministic benchmark knowledge work
kw-bench is a deterministic benchmark built from real audit-style engagements, starting with a five-year VAT reconstruction across three generations of SAP, and it uses no LLM judge. Running four harnesses on DeepSeek v4.1 Flash for two hours, the two model-agnostic harnesses scored 0.542 and 0.528 while the two lab harnesses scored 0.00; Claude Code and micro-cc on Claude Opus 5.5 reached 1.000 and 0.9986.

arxiv:2610.36114 arXiv ✓
Context Is a Pipeline, Not a Window: Information Attrition in LLM Agent Harnesses
上下文是一条流水线，而非一个窗口：LLM 智能体框架中的信息损耗
context management tool output truncation agent harness information attrition
Measuring a Linux-trace debugging agent over 720 runs, the authors found the largest prompt used only 5.75% of the context window while 3,827 of 11,189 tool results were cut into broken JSON before reaching the model. Controlled experiments showed the cut first costs extra work—43% more tool calls and yield falling from 0.61 to 0.31—though whether it causes the accuracy drop remains an open question.

arxiv:2610.36335 arXiv ✓
OA-RAG: Ontology-based Agentic RAG for Faithful LLM Reasoning
OA-RAG：基于本体的智能体 RAG，实现忠实的 LLM 推理
ontology reasoning agentic RAG answer grounding medical QA
OA-RAG combines formal ontology reasoning with LLM reasoning, reporting the ontology observations used as evidence and a model-assessed grounding level—entailed, supported, related or unrelated—for each answer. Across benchmarks from three large ontologies and six real-world medical question-answering tasks, it achieved the best overall performance among evaluated ontology-tuned and popular RAG methods, especially on reasoning-intensive tasks.
→ arxiv.org
arxiv:2610.36325 arXiv ✓
Ontology-guided multi-agent reasoning for explainable differential diagnosis
本体引导的多智能体推理，用于可解释的鉴别诊断
medical ontology multi-agent reasoning explainable diagnosis clinical knowledge
The framework grounds differential-diagnosis inference in an expert-curated medical ontology and decomposes it into explicit, auditable steps across multiple agents, then identifies the most discriminative missing symptoms and asks targeted follow-up questions. The authors report improved reliability, explainability and diagnostic accuracy, with source code publicly available.
→ arxiv.org
arxiv:2610.36389 arXiv ✓
MAREval: A Multi-Agent Framework for Evaluating Natural Language Recommendation Explanations
MAREval：评估自然语言推荐解释的多智能体框架
multi-agent evaluation LLM judges recommendation explanations human alignment
MAREval orchestrates a planner using Chain of Debate prompting, a moderator that limits prompt drift, an arbitrator that aggregates evaluation rounds and Monte Carlo sampling to score recommendation explanations. It improved alignment with human judgments over single- and multi-agent baselines, showed lower variability across repeated trials and passed a production-quality human-annotation gate.
→ arxiv.org

multi-agent pipeline memory-guided search narrative planning bilingual benchmark

Dual Exam：多模态智能体与世界模型的受控评测

Cross-Day Compatibility of Daily Item Embeddings: An Empirical Study of Alignment, Scale Management, and CTR Adaptation
每日物品嵌入的跨天兼容性：对齐、尺度管理与 CTR 适配的实证研究
embedding drift cross-day alignment norm rescaling industrial recommendation
The study compares Word2Vec and an item-graph XSimGCL adaptation across 48 configurations for daily item embeddings paired with next-day behavior, reporting relative changes from the Word2Vec baseline while withholding raw values and exact dataset sizes. ID-init and orthogonal alignment raised cosine similarity by 51.2% and 93.4% and GAUC by 2.2% and 2.6%, while daily global rescaling limited eight-day norm growth to 8.2% and gave the highest observed GAUC gain of 4.0%.
