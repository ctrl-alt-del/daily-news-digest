Multi-Head Latent Control: A Unified Interface for LLM Agent Decision Making
多头潜在控制：LLM 智能体决策的统一接口
latent control model routing tool use inference efficiency decision making
Multi-Head Latent Control is a lightweight layer that reads hidden-state trajectories from a frozen LLM or VLM to produce deployment-time control signals, with a Capability Head for deferral to a stronger model and a Resolution Head for clarification, tool use, abstention or direct answering. In routed small-plus-large execution it reduces large-model usage by up to 90.7% on AndroidWorld and 27-53% on average across benchmarks while retaining most large-model performance.

Do Agent Optimizers Compound? A Continual-Learning Evaluation on Terminal-Bench 2.0
智能体优化器会复利吗？Terminal-Bench 2.0 上的持续学习评估
continual learning agent optimization regression control Terminal-Bench lifelong learning
The paper runs a two-phase continual-learning evaluation on hard Terminal-Bench 2.0 tasks comparing GEPA, Meta Harness and RELAI-VCL under identical optimization budgets. All three beat the baseline in the static single-phase setting, but only RELAI-VCL both transferred positively to new tasks and kept improving after those tasks were added, reaching a lifelong average pass rate of 76.4% versus 66.0% for GEPA, 64.6% for Meta Harness and 58.7% for the baseline.

NeuroGRIP: Retrieval-Augmented Graph Refinement for Knowledge-Grounded EEG Seizure Diagnosis
NeuroGRIP：面向知识驱动的 EEG 癫痫诊断的检索增强图精炼
knowledge graph retrieval-augmented generation graph refinement clinical diagnosis
NeuroGRIP builds a large domain-specific knowledge base from authoritative clinical guidelines and uses an LLM to extract structured biomedical entities and relations into a textual knowledge graph. It projects EEG node embeddings into the knowledge graph's semantic space and runs FAISS-based similarity search over triplets to score and prune medically implausible edges, improving seizure detection accuracy and interpretability on TUSZ and CHB-MIT.

Assessing AI in Introductory Physics Problem Solving
评估 AI 在入门物理问题求解中的表现
reasoning evaluation multimodal reasoning physics problems model accuracy
The study evaluates OpenAI's o4-mini on traditional end-of-chapter problems from Halliday and Resnick's Fundamentals of Physics and reports about 90% overall accuracy. Accuracy was 96% on text-only problems versus 79% when text and images had to be interpreted together, and it declined significantly as problem difficulty increased.

Automatic Hard Example Synthesis with Multi-Level Agentic Data Curation
自动困难样本合成：多层级智能体数据策管
agentic data curation multi-agent system test-time retrieval red teaming in-context learning
The paper proposes an automated agentic red-teaming framework that synthesizes difficult multimodal safety examples with an iterative strategy that proposes novel hypotheses and mutates past attempts, using an Architect agent, an image generator and a multi-level verification committee of LLM raters. Using the synthesized examples as in-context demonstrations via test-time retrieval reduced the false negative rate from 41.2% to 24.5% on a public image safety benchmark without human labeling.

Inference-Time Concept Suppression and Video-Centric Evaluation for Text-to-Video Models
SIRUS：文本到视频模型的推理时概念抑制与视频中心评估
concept erasure machine unlearning text-to-video evaluation framework
SIRUS is a training-free inference-time framework for concept-level text-to-video unlearning that localizes target-related prompt evidence and suppresses target expression during sampling without updating the text encoder or denoising network. Across five safety, object and style concepts on CogVideoX it reaches 70.4% average forgetting success and 25.7% average frame hit, versus 44.4% and 47.2% for VideoEraser, while reducing the average VBench quality drop from -0.043 to -0.016.
