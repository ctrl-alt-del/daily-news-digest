An Explicit World Model Based on Data-First Ontology: DaoQL Multimodal Storage Validation and Counterfactual Reasoning Evaluation
基于数据优先本体的显式世界模型：DaoQL 多模态存储验证与反事实推理评估
explicit world model ontology multimodal database counterfactual reasoning hybrid query
The paper proposes a data-first ontology in which LLMs act as reasoning and language engines while deterministic knowledge is moved into an explicit multimodal database, DaoQL, integrating graph, column, vector and full-text engines within one process. On an embedded setup it reports graph BFS at 1.20 ms, HNSW at 83.1 microseconds and a Fluent hybrid query at 105.8 microseconds, and in a five-domain counterfactual experiment DaoQL with GPT-4o reaches 94% composable counterfactual decomposability, 49 percentage points above GPT-4o alone.

arxiv:2607.17291 arXiv ✓
DRNOISE: Benchmarking Deep Research Agents in Misleading Evidence Environments
DRNOISE：评估深度研究智能体在误导性证据环境中的表现
deep research agents misleading evidence evidence verification benchmark
DRNOISE is a 100-task benchmark for answer recovery under misleading evidence, where each task has a gold answer supported by two corroborating indirect record chains and a paired noisy condition adds one plausible document stating a conflicting answer. Among models with strong clean-task performance, this single intervention causes 66-88 percentage-point accuracy drops, and trace analyses reveal a pattern of verification inertia in which agents retrieve truthful records yet defer to the answer-like document.

Debate-on-Graph: Reliable and Adaptive Reasoning of Large Language Model on Uncertain Knowledge Graph
Debate-on-Graph：不确定知识图谱上可靠且自适应的 LLM 推理
uncertain knowledge graph multi-agent debate knowledge graph QA reasoning reliability
Debate-on-Graph combines a heuristic search algorithm that extracts reliable, question-relevant subgraphs from uncertain knowledge graphs with a multi-agent debate mechanism that produces answers through adaptive adversarial debate. Experiments on four benchmark QA datasets are reported to achieve state-of-the-art performance over existing LLM reasoning methods and knowledge-graph-based baselines.

面向智能体能力检索的嵌入模型适配
agent capability retrieval embeddings agent marketplace transfer evaluation
The study fine-tunes three open retrieval backbones, BGE-base, KaLM-v1.5 and EasyRec, on AgentSelect, which represents marketplace-visible agents, tool bundles and reusable skill packages as capability profiles derived from public metadata. arxiv:2607.17250 arXiv ✓
EvolvingWorld: An Open-Schema Framework for Co-Evolving Role-Play Agents and World Model in Interactive Literary World
EvolvingWorld：交互式文学世界中角色智能体与世界模型协同演化的开放模式框架
role-play agents world model persistent state LLM-as-judge
EvolvingWorld is an open-schema framework and benchmark that models interactive literary simulation as a long-horizon process, with a Character Agent for multi-character role-play and persistent profile evolution and an LLM-based World Model for global and location/entity-level state maintenance. Built from 57 books into 138,596 supervised training samples and 222 test snapshots, it reports improved long-horizon coherence under a 10-dimension, 20-metric LLM-as-judge protocol.

Poor Man's Agentic Modeling: Simulating Large LLM-Agent Societies on a Laptop
Poor Man's Agentic Modeling：在笔记本电脑上模拟大规模 LLM 智能体社会
agent society simulation surrogate modeling scaling memory taxonomy
The paper replaces each LLM agent in a large society simulation with a low-parameter surrogate fitted from a few hundred to a few thousand cheap queries, then runs the society at any agent count on a laptop. An interaction-order by memory taxonomy predicts how surrogate error scales with the number of agents, and the predictions are validated on a reimplementation of the EconAgent macroeconomy and seven further named LLM simulations, with two refuted predictions also matched quantitatively.

arxiv:2607.17288 arXiv ✓
SAGA: Synthetic Agentic Graph Architecture for Temporal Benchmark Generation
SAGA：面向时序基准生成的合成智能体图架构
temporal graph synthetic benchmark LLM agents RAG rule base
SAGA generates large-scale, semantically rich temporal graphs through a four-phase skeleton-first, semantics-second pipeline in which LLM agents inject domain semantics using RAG-based rule bases and a state alignment engine resolves conflicts via temporal replay, yielding anomaly labels as a byproduct. On a single H100 GPU with vLLM batching it generates 500,000 temporal edges with controlled anomalies in under 90 minutes, scaling to 100,000 nodes while maintaining clustering coefficients above 0.99.

Multi-Agent Scheduling with LLM-Assisted Contract Net Negotiation for Stream Processing in Mobile Edge Computing
移动边缘计算流处理中基于 LLM 辅助合同网协商的多智能体调度
multi-agent negotiation contract net protocol negotiation memory edge computing context disclosure
MAS-DecStream extends the Contract Net Protocol with semantic call-for-proposal formulation, progressive context disclosure, multi-round proposal revision, negotiation memory and deterministic validation for stream-processing scheduling across mobile edge-cloud infrastructure. In experiments derived from the Alibaba ASI Trace it reduces latency violations to 3%, eliminates resource overcommitment, reaches a 0.91 conflict-resolution rate with 20 agents and improves utility by up to 22% over a multi-round rule-based baseline.
