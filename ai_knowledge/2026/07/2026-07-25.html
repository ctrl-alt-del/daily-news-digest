RareLens: Towards End-to-End Rare Disease Care via Aligning Divergent Large Language Model Reasoning
RareLens：通过对齐发散的大模型推理实现端到端罕见病诊疗
multi-model reasoning clinical decision support reasoning diversity rare disease benchmark
RareLens reconciles divergent reasoning trajectories from multiple heterogeneous LLMs into decisions across risk screening, diagnosis, treatment planning and prognosis prediction, built on RarelensBench with 157,525 real-world cases spanning 33 Orphanet categories. It outperformed GPT-5, DeepSeek-R1, Claude-3.7-Sonnet and Gemini-2.5-Pro across all stages, reaching 0.917 AUC for screening and top-1 accuracies of 65.5% and 89.8% for diagnosis and treatment, and in an external evaluation of 1,287 cases with 23 physicians both autonomous and assisted RareLens outperformed unaided physicians.

Co-Evolving Graph and Text Memory for Training-Free Multi-Hop Question Answering
协同演化的图与文本记忆：面向免训练多跳问答
graph memory agent memory multi-hop QA training-free memory consolidation
Co-E is a training-free system built on synchronized bidirectional graph-text working memory: a synchronization cycle consolidates textual memory, extracts relational triples into graph memory and injects graph facts back into the generation context, so both memories shape subsequent retrieval and generation. On six multi-hop QA benchmarks it improves over comparable training-free open-backbone baselines and is competitive with larger or trained systems.

arxiv:2607.23124 arXiv ✓
AgentOmnia: Scaling Agentic Models for Full-Scenario Applications
AgentOmnia：面向全场景应用的智能体模型扩展
agentic scaling data synthesis agentic reinforcement learning benchmark self-evolution
AgentOmnia is a full-scenario agentic scaling framework that coordinates a Domain x Capability x Atomic Difficulty taxonomy with environment-task synthesis, post-training, evaluation and PRD-guided improvement, constructing 5,018 stateful environments, 255,375 tools and 52,361 tasks. Starting from Qwen3-30B-A3B-Thinking-2507, it raises the OmniaBench challenging-subset pass rate from 9.16% to 37.11% and the four-benchmark macro-average from 22.86% to 41.69%, surpassing Qwen3-235B-A22B-Thinking-2507 on all four benchmarks.

False Prophets: On the Security of World Models in Agentic Systems
假先知：论智能体系统中世界模型的安全性
world models agent security adversarial attacks terminal agents
The paper identifies security vulnerabilities specific to learned world models used by LLM agents, showing that attackers can induce mispredictions in terminal-based agent pipelines with up to 95% success, potentially causing unintended command execution, denial of service, wallet drainage and private-information extraction. It introduces a security benchmark dataset for text-based world models and offers practical recommendations for hardening agentic systems.

An Ontology for Machine Learning Interatomic Potentials
面向机器学习原子间势的本体
ontology knowledge graph materials science data provenance OWL reasoning
The paper presents the MLIPs ontology, an OWL 2 DL ontology organized into Method, Training Data and Benchmark modules that describes machine-learning interatomic potential methods, their hyperparameters, DFT-provenance training datasets and published benchmarks. It connects materials-science and machine-learning ontologies, declares 27 formal axioms enforcing data completeness and consistency, and is evaluated through competency questions over a 20-paper seeded knowledge graph and OWL reasoning.

超越全球规范：无需重训练即可个性化语言模型的毒性敏感度
personalization toxicity alignment inference-time intervention decoding evaluation

On the Impossibility of Unbiased and Length-Invariant Policy Optimization with Outcome Rewards
结果奖励下无偏且长度不变策略优化的不可能性
GRPO policy optimization length bias reasoning training
The paper proves an impossibility theorem showing that, under standard outcome-reward GRPO, no length-based weighting scheme can simultaneously be gradient-unbiased and length-invariant. It characterizes the trade-off with the family f_alpha(L) = L^(alpha-1), where alpha = 0 recovers GRPO and alpha = 1 recovers Dr. GRPO, and shows that Dr. GRPO's length bias can let longer trajectories dominate gradient updates by a factor proportional to the length ratio.

自信地犯错：前沿大模型规则评估中的异常链崩塌
neuro-symbolic reasoning rule evaluation legal reasoning SMT benchmark
The paper documents exception chain collapse, a failure in eligibility evaluation under nested conditional rules, and notes that some failure cells silently closed under the same model alias between March and April 2026. It presents the Aethis Eligibility Module, a neuro-symbolic architecture in which LLMs author rules and an SMT-based layer executes them deterministically, reporting higher accuracy than frontier models on LegalBench tasks.
