arxiv:2607.12058 arXiv ✓
AutoTrace: From Patches to Triggers via Agentic Interprocedural Exploration
AutoTrace：通过智能体跨过程探索从补丁定位触发点
agentic reasoning code property graph vulnerability localization grounded evidence security benchmark
AutoTrace is an agentic pipeline that localizes vulnerability triggers by exploring a code property graph layer by layer, with LLM agents deciding where to look next and deterministic admissibility gates requiring explicit evidence before a trigger is reported. It reaches 75.0% VulnHit and 80.8% FuncHit on the full InterPVD benchmark, and the authors also release SinkTrace-Bench with 1,542 verifier-confirmed, balanced vulnerable/safe samples.
→ arxiv.org

面向联邦多模态大模型微调的弹性正则化与合成回放持续学习
continual learning catastrophic forgetting federated learning generative replay gradient aggregation
The paper proposes FedCMM, a federated continual multimodal learning framework that combines modality-aware elastic weight consolidation, local generative replay at the embedding level without raw-data sharing, and task-similarity-aware gradient aggregation. Malaika: Understanding Malware through Tri-Grounded Agentic Reasoning
Malaika：通过三重锚定智能体推理理解恶意软件
multi-agent grounding malware analysis threat attribution
Malaika is a multi-agent framework for malware analysis that combines domain grounding for behavior hypotheses, semantics grounding for evidence localization, and knowledge grounding for threat attribution. It is reported to improve analysis quality over prior LLM-based malware-analysis frameworks for Android malware.

An Empirical Analysis of Continual Learning for Heterogeneous Medical Visual Question Answering
异构医学视觉问答持续学习的实证分析
continual learning catastrophic forgetting medical VQA LoRA empirical evaluation
The paper systematically evaluates continual learning for medical visual question answering across classification, multi-label classification, detection, cell counting, and report generation. It finds that existing methods struggle to maintain a stability-plasticity balance when tasks with different objectives and supervision formats are interleaved, and analyzes task-order sensitivity and LoRA weight drift.

arxiv:2607.26075 arXiv ✓
IDP AutoOpt: Agent-Driven Optimization of Document Processing Pipeline Configurations
IDP AutoOpt：智能体驱动的文档处理流水线配置优化
document processing agent optimization domain skills configuration search
IDP AutoOpt is an autonomous LLM agent that tunes prompts, models, OCR settings, and schemas for intelligent document processing by scoring configurations, diagnosing field-level errors, and generating targeted edits in a closed loop. It reports matching or exceeding human-expert accuracy at equal or lower cost, with one extraction benchmark at 90.2% versus 81.6% and 4.6x lower per-page cost, while cutting configuration time from weeks to under two hours.
→ arxiv.org
arxiv:2607.11736 arXiv ✓
MET: Theory-Grounded and Culture-Aware Multilingual Moral Reasoning
MET：理论锚定且文化感知的多语言道德推理
multilingual reasoning moral reasoning theory-grounded prompting self-distillation
The paper introduces MCLASH, a multilingual moral decision-making benchmark, and MET, a two-step prompting method that first selects situation- and culture-specific theory-based grounds and then reasons over them in the user's native language. MET-D self-distillation improves macro-F1 by an average of 3.71 points on MCLASH and 4.23 on MMoralExceptQA across three models, with a peak MCLASH gain of 12.94 points for Malay on Qwen3-8B.
→ arxiv.org
arxiv:2607.12216 arXiv ✓
RCWT: Measuring Task-Budget Displacement from Coordination Content in LLM Calls
RCWT：测量 LLM 调用中协调内容挤占任务预算的程度
context budget multi-agent coordination long context controlled benchmark
The paper introduces the Roundtable Context Window Test (RCWT), a controlled protocol for measuring how coordination content such as shared state, prior discussion, tool outputs, summaries, and role instructions displaces task instructions and evidence under a fixed context budget. In a 4,096-token context-dependent recall task, three commercial models degrade sharply once residual reference evidence falls to a few hundred tokens, while an intact-task ablation keeps answers correct up to a 95% coordination ratio.
