Intelligence is Free, Now What? Data Systems for, of, and by Agents — BAIR
智能免费了，然后呢？面向、属于和由Agent驱动的数据系统 — 伯克利BAIR
data systems multi-agent structured memory BAIR agentic speculation
UC Berkeley researchers (Parameswaran, Zaharia, Stoica et al.) argue that as GPT-4-class intelligence drops from $30/M tokens to under $0.10, three new challenges emerge for data systems: (1) For Agents — redesigning DB interfaces for agentic speculation where each user request spawns thousands of SQL queries; (2) Of Agents — building a substrate for multi-agent swarms with structured memory, coordination, and consensus; (3) By Agents — enabling agents to synthesize custom workload-specific data systems from scratch for a few dollars, verified by auxiliary agents generating test cases. The post proposes proactive data systems that steer agents, structured memory with attribute-based retrieval, and composable verified system components.
→ bair.berkeley.edu
Rowboat Labs Hacker News (Show HN) ✓
Rowboat: Open-Source Local-First Alternative to Claude Desktop with Knowledge Graph and Work Surfaces
Rowboat：开源本地优先的Claude Desktop替代品，内置知识图谱和工作台
knowledge graph Claude Code open-source local-first agent desktop
Rowboat is an Apache-2.0 licensed local-first desktop app designed as a full work environment for AI agents, not just a chat interface. It includes: an email client with style-learning drafts, a Granola-style meeting notetaker that feeds into a knowledge graph, an isolated browser for agent navigation, parallel Claude Code/Codex instances with ACP orchestration, and an Obsidian-style local note system. Users can build custom work surfaces as web apps. Data is stored as plain Markdown files. Scored 97 points on Hacker News.

LlamaIndex LlamaIndex Blog ✓
ParseBench: The First Document Parsing Benchmark for AI Agents — ~2,000 Pages, 167K Test Rules
ParseBench：首个面向AI Agent的文档解析基准 — 约2000页、16.7万条测试规则
document parsing benchmark OCR ParseBench LlamaParse
LlamaIndex released ParseBench, the first document parsing benchmark designed for AI agent consumption. It spans ~2,000 human-verified enterprise document pages across 5 dimensions: tables (with a new TableRecordMatch metric), charts (structured data extraction), content faithfulness (omissions, hallucinations, reading order), semantic formatting (strikethrough, superscripts, bold), and visual grounding. 14 methods were evaluated; LlamaParse Agentic scored 84.9% overall. Charts proved the hardest dimension — only 4 of 14 providers exceeded 50%. Dataset, code, and paper are fully open source.
→ www.llamaindex.ai
