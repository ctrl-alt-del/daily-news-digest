ZenGen: Social Mind for LLMs
ZenGen：面向大语言模型的社会心智
social intelligence benchmark design agent harness retrieval-augmented generation mental-state modeling
ZenGen is an integrated framework for measuring, internalizing and grounding social intelligence in LLMs. It introduces SoMBench, a 3,481-instance psychology-grounded benchmark on which the best of 20 evaluated models reaches only 72.08%, and pairs a diagnosis-driven training recipe with Actio, a harness that routes procedural guidance, mental-state representations, reusable experience and gated RAG into inference.

arxiv:2607.23809 arXiv ✓
ACM: Agentic Context Management for Long Horizon Tasks
ACM：面向长程任务的智能体上下文管理
context management external memory context offloading agentic search
ACM is a framework that gives agents purpose-built context-editing tools so they can decide when to compress their context, offload discarded content to an external memory system and query it later on demand. The authors also build a post-training pipeline from demonstrations of context management and report gains on agentic search and coding tasks, with code and checkpoints released.
→ arxiv.org
arxiv:2607.23806 arXiv ✓
A Frozen 12B Beats Frontier Models on Verified Work: 100% Accuracy, 0 Tokens, Bit-Exact, Forever
冻结的12B模型在已验证任务上胜过前沿模型：100%准确、零Token、位精确且永久一致
verified memory exact retrieval persistent memory long context benchmark claims
The report describes a frozen 12B model paired with a persistent memory of verified solutions, claiming 180/180 correct answers at zero generation tokens across nine problem families and four model architectures. It reports that exact addressing makes zero errors where approximate similarity retrieval selects the wrong item 94.3% of the time, and that the store supports a 6,000,000-token movable window on a single 46 GB GPU.

Teaching LLMs to Update Beliefs for Efficient Long-Horizon Interaction
教LLM更新信念，实现高效长程交互
belief state context compaction long-horizon interaction recursive summarization
BAIR researchers introduce ABBEL, a framework that replaces an agent's full interaction history with supervised natural-language belief states. It aims to keep long-horizon contexts concise and interpretable without the performance cost of recursive summarization, which the post says is especially severe in human-assistance domains such as collaborative code generation.

E-Bench: Benchmarking Multi-Step Tool-Use Agents in Real-World Product Scenarios
E-Bench：面向真实产品场景的多步工具使用智能体基准
tool-use agents multi-step reasoning agent benchmark stateful environments
E-Bench is a fully synthetic benchmark of 323 state-changing tasks across three product domains, built to test multi-step tool use in stateful environments. Across 11 LLMs, Pass^3 stays below 60% for the strongest models and below 70% even with code execution in the E-Bench-Code extension.
→ arxiv.org
arxiv:2607.23784 arXiv ✓
A Few Words Go a Long Way: Language Guided Robot Policy Synthesis
寥寥数语，成效显著：语言引导的机器人策略合成
program synthesis skill library long-term in-context learning human corrections
ARCHITECT treats robot policy acquisition as interactive program synthesis, using LLM coding agents to build modular programs from perception and control tools. Human natural-language corrections are grounded in execution traces and distilled into a persistent skill library, and the system outperforms VLA and program-synthesis baselines on long-horizon Franka Panda tasks.
→ arxiv.org
arxiv:2607.23837 arXiv ✓
Latent-LoRA: Compact Latent-Space Adapters with Gradient-Free Routing for Continual Learning
Latent-LoRA：面向持续学习的紧凑潜空间适配器与无梯度路由
continual learning catastrophic forgetting adapter routing latent subspace
Latent-LoRA selects per-task low-rank adapters using a Gaussian mixture model fitted on pooled embeddings from a frozen LLM, avoiding a trained gating module. It constrains adapters to the principal subspace of pretrained weights, and experiments across five model scales and two continual-learning benchmarks report state-of-the-art performance with near-zero forgetting.
→ arxiv.org
arxiv:2607.23718 arXiv ✓
Melo: A Production LLM-Powered Music Recommendation Agent
Melo：生产环境中的LLM驱动音乐推荐智能体
production agents entity grounding reflective retry online A/B testing
Melo is an LLM-powered music recommendation agent deployed on NetEase Cloud Music as a deterministic five-node state graph over heterogeneous tools. It adds inference-time entity grounding and reflective retry to handle entity hallucination and long-tail degradation; a one-month A/B test reports an over 2 pp lift in a primary playlist retention metric.
→ arxiv.org
