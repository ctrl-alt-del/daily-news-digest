Chronofy: A Temporal-Logical Decay Architecture for Information Validity in Time-Aware Retrieval-Augmented Generation
Chronofy：面向时间感知 RAG 信息有效性的时序逻辑衰减架构
temporal decay temporal knowledge graph Matryoshka embeddings signal temporal logic temporal QA
Chronofy is a three-layer neuro-symbolic framework that embeds temporal validity into the representation, retrieval and reasoning layers of RAG, reserving a temporal subspace in Matryoshka embeddings, adding learnable exponential decay to graph retrieval, and using Signal Temporal Logic robustness to bound confidence by the most decayed evidence. Evaluated on temporal knowledge graph forecasting and the TimE temporal QA benchmark, it is reported to improve retrieval precision and reduce temporal hallucination.

arxiv:2607.16387 arXiv ✓
Fantastic Adaptive Taxonomies and How to Use Them
出色的自适应失败分类法及其应用
agent failure taxonomy execution traces agent evaluation SWE-bench runtime feedback
AdaMAST induces a compact, evidence-grounded taxonomy of agent failure codes from execution traces along system, role and domain axes, then uses it as a shared feedback interface. Taxonomy feedback is reported to raise SWE-agent's SWE-bench Verified Mini resolution from 60% to 70% and Claude Code from 64.0% to 70.7%, while AdaMAST-Judge improves best-of-5 accuracy on Terminal-Bench 2.0 by 8-15 points.

arxiv:2607.16448 arXiv ✓
Retrieval is Enough: Training-Free Interpretability with a Tool-Using Agent
检索足矣：基于工具智能体的免训练可解释性方法
activation vectors tool-using agent retrieval interpretability linear probes
HARP gives an LLM agent a vector database of neural activations paired with textual contexts plus tools for projecting out directions and computing activation differences and averages, so it can form and test hypotheses through retrieval and linear probes without training. It is reported to outperform activation oracles and SAE-based agents on concept discovery, concept detection, model steering and secret elicitation, while being cheaper and able to index new datasets on demand.

PANOPTICON: A PII-Based Assemblage of Naturalistic Output Tokens for Investigating Privacy Leakage Within LLM Context Window
PANOPTICON：用于研究 LLM 上下文窗口隐私泄露的 PII 自然输出令牌数据集
context window PII leakage privacy benchmark prompt inversion
PANOPTICON is a pipeline and dataset of 67,718 prompts containing PII spans derived from 9,674 publicly available synthetic user profiles and generated with Meta's Llama-3.1-8B-Instruct, intended for studying privacy leakage in the LLM context window. arxiv:2607.28657 arXiv ✓
TAPR: Enhancing LLM Performance with a Task-Aware Prompt Rewriter
TAPR：面向任务的提示重写器，提升 LLM 下游表现
prompt rewriting reinforcement learning GRPO LLM-as-judge instruction tuning
TAPR is a model trained with Group Relative Policy Optimization to rewrite user prompts into task-optimized prompts, using LLM-as-judge rewards on both the rewritten prompt and the task output. Fine-tuning Phi-4-mini-instruct is reported to produce clearer, more instructive prompts and higher accuracy on Natural Questions and GSM8K across question answering, summarization and arithmetic reasoning.

Auditing Retrieval-Augmented LLM Hypotheses for Longitudinal Cell Painting Morphology
审计面向纵向 Cell Painting 形态学的检索增强 LLM 假设
retrieval-augmented generation provenance evidence auditing scientific hypothesis generation
The paper presents an evaluation-first, retrieval-augmented framework that combines week-matched Cell Painting morphology deltas with retrieved perturbation neighbors, pathway context and literature evidence through stable evidence identifiers, producing provenance-preserving biological hypotheses. Two auditing tests check citation validity and morphology compatibility on a 9-week RPE-1 time course; no invalid evidence references were detected, and compatibility increased with perturbation strength.

基于反例补全草图的智能体代码合成
