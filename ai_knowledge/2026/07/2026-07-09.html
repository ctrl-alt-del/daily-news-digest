Autonomous disproofs of the sum-product conjecture over $\mathbb R$ with GPT-5.5 Pro
用 GPT-5.5 Pro 自主证明实数域上的和积猜想不成立
autonomous proof generation mathematical reasoning prompting pipeline GPT-5.5 Pro reproducibility
A simple agent built on GPT-5.5 Pro used a problem-agnostic three-stage pipeline — proof-plan proposal, proof construction and review — to generate correct disproofs of the Erdős–Szemerédi sum-product conjecture over R in 7 of 8 independent trials. The remaining trial exposed an unresolved gap, and the code, intermediate outputs and proofs are released as a reproducible case study.

Long-Horizon-Terminal-Bench: Testing the Limits of Agents on Long-Horizon Terminal Tasks with Dense Reward-Based Grading
Long-Horizon-Terminal-Bench：用密集奖励评分测试智能体在长时程终端任务上的极限
terminal benchmark long-horizon planning dense reward context management agent evaluation
The benchmark contains 46 long-horizon terminal tasks across nine categories, each decomposed into graded subtasks to provide dense intermediate rewards and partial credit. Evaluating 15 frontier models, it finds agents consume 9.9M tokens and about 85 minutes per task on average, with the strongest model reaching 15.2% pass@1 at a 0.95 partial-reward threshold and 10.9% at a perfect-reward threshold.

arxiv:2610.00010 arXiv ✓
Heavy-Tailed Memory Traces in Long-Horizon Language Agents
长时程语言智能体中的重尾记忆痕迹
agent memory heavy-tailed distribution memory controller retrieval policy LongMemEval
The authors show that repeated retrieval in long-horizon language agents can produce heavy-tailed memory usage, where a few states are accessed often while many others are rarely retrieved and more prone to prediction errors, with the pattern depending strongly on the retrieval policy and graph structure. Their rank-based Core-Tail Memory Controller reduces prompt tokens by 24.48% on LongMemEval while maintaining aggregate accuracy.
→ arxiv.org
DeepSeek arxiv:2607.08652 arXiv ✓
Formal Mechanisms for Market Stability in Self-Interested Agent Societies: A Marketplace Simulation Study
自利智能体社会中的市场稳定形式化机制：一项市场模拟研究
multi-agent simulation mechanism design adversarial robustness prompt optimization
The paper simulates a marketplace of 18 DeepSeek-V3 agents with complementary production specialties trading over 200 rounds, comparing eight conditions under progressive troll injection and finding mediation the strongest mechanism. Iteratively prompt-optimised trolls reduced honest-agent utility by 13.3% at most but could not collapse the market, suggesting mediation is robust though bendable.

arxiv:2607.09806 arXiv ✓
An Autonomous Scientific Knowledge Generation Framework for AI-Driven Scientific Discovery
面向 AI 驱动科学发现的自主动科学知识生成框架
scientific knowledge base knowledge extraction ontology provenance literature mining
The framework chains ontology-guided literature acquisition, hybrid knowledge extraction, semantic harmonisation, knowledge fusion and validation to turn publications into a provenance-preserving, AI-ready scientific knowledge base. In an electro-optic materials proof of concept it retrieved about 1,000 publications and converted eight through the full workflow into 29 structured records harmonised into 7 canonical records.

arxiv:2607.08960 arXiv ✓
Eluna: An Agentic LLM System for Automating Warehouse Operations with Reasoning and Task Execution
Eluna：面向仓储运营自动化的推理与任务执行智能体系统
SOP execution multi-agent episodic memory distillation production deployment
Eluna is a production-deployed, graph-guided multi-agent system that encodes standard operating procedures as directed acyclic graphs with progressive disclosure and delegates independent tasks to parallel sub-agents with code execution and live data access. Asymmetric episodic distillation transfers a teacher's error-memory-corrected trajectories into a smaller student, which matches or exceeds the teacher and reaches 94% expert agreement on ticket processing.
