GuideSkill: Evolving Executable LLM Agent Skills for Guideline-Grounded Clinical Reasoning
GuideSkill：演化可执行LLM智能体技能，实现基于临床指南的推理
agent skills clinical reasoning guideline grounding skill evolution clinical benchmark
GuideSkill compiles clinical-practice-guideline criteria into executable functions that return ordinal diagnostic-support scores, which an LLM grounds and fuses with its differential diagnosis. It reports a 13.45% average macro-accuracy gain over guideline RAG for GuideSkill-Zero and, for GuideSkill-Evo, a relative 18.49% gain over direct inference and gold-label skill coverage rising from 56.5% to 99.5%.

Detecting Knowledge Inconsistencies Across Text, Tables, and Knowledge Graphs
检测文本、表格与知识图谱之间的知识不一致
knowledge inconsistency knowledge graph auditing Text-to-SPARQL cross-modal reasoning Table-QA
Kontrast is an automatic framework that uses Text-to-SPARQL and LLM reasoning to compare table-based answers with knowledge-graph evidence and categorize cross-modal inconsistencies. Experiments on Table-QA datasets find such inconsistencies are common and informative, revealing true conflicts as well as missing KG structure and temporal mismatches, while the approach is limited by Text-to-SPARQL errors and noise.

Is It Still Worth Training a Classical Model in the Era of LLMs? A Crossover Benchmark on Tabular Data
LLM时代还值得训练经典模型吗？面向表格数据的交叉点基准
tabular data LLM prompting learning curves few-shot learning
The paper measures the labeled-data crossover at which a trained classical model overtakes a frozen LLM on tabular prediction, aggregating 126 evaluations across 18 datasets. It finds that training wins with no more labeled data than is already on hand in 86% of cases, with a median crossover at about 6% of the training set, and that few-shot examples do not behave like training.

MemLens: A Value-Aware Memory Management System with Interactive Analytics for LLM-based Agents
MemLens：面向LLM智能体的价值感知记忆管理系统与交互式分析
agent memory memory valuation Shapley value memory analytics
MemLens is a value-aware memory management system that treats heterogeneous memory records as first-class objects across evaluation, storage and response. It combines Shapley-style memory evaluation with an interactive dashboard and a study-copilot application for inspecting memory values, visualizing hierarchical structures and comparing strategies on quality, latency and token consumption.

StealthBench: Measuring Operational Stealth in Autonomous Offensive-Security Agents
StealthBench：衡量自主进攻性安全智能体的作战隐蔽性
agent security OPSEC offensive-security agents safety benchmark
StealthBench measures operational stealth in autonomous offensive-security agents across six OPSEC dimensions, using 11 hand-verified incidents expanded into 14 dockerized task scenarios. With a three-model LLM judge panel, no model exceeds a 54% safe success rate, indicating that OPSEC failures are systematic across model families.
