Oracle Agent Memory as an Enterprise Memory Substrate for Long-Horizon AI Agents
Oracle Agent Memory：面向长周期 AI 智能体的企业级记忆底座
agent memory memory lifecycle long-horizon agents LongMemEval enterprise memory
This report studies Oracle Agent Memory as a database-native memory substrate built on Oracle Database for long-horizon agents, organized around a memory lifecycle of ingestion, extraction, consolidation, retrieval, summarization and revision or removal. It reports 93.8% accuracy on LongMemEval and about 10.7x fewer tokens than flat-history baselines, with a layered architecture separating an active memory core from a passive store interface.

arxiv:2607.13311 arXiv ✓
Finding the Right Tables and Columns: A Benchmark and Corpus-Adaptive Embeddings for SQL Schema Retrieval
找对表和列：SQL Schema 检索基准与语料自适应嵌入
schema retrieval embeddings corpus-adaptive fine-tuning retrieval benchmark text-to-SQL
The paper recasts five text-to-SQL datasets (Spider, BIRD, BEAVER and two LiveSQLBench variants) as table- and column-level schema retrieval tasks and shows that off-the-shelf text and code embedders transfer poorly. Corpus-adaptive fine-tuning with synthesized queries and mined hard negatives raises a 305M-parameter embedder's average recall@10 from 60.4 to 75.6 and nDCG@10 from 51.9 to 68.0, making it competitive with 4-8B embedders.

RAGthoven at SemEval-2026 Task 1: A Multi-Stage Pipeline Walks Into a Benchmark and Barely Clears the Bar
RAGthoven 出战 SemEval-2026 任务 1：多阶段流水线勉强过关
retrieval-augmented generation multi-stage pipeline agentic orchestration constrained generation benchmark evaluation
RAGthoven is a multi-stage LLM pipeline with Planner, Best-of-N Writer, Reflector and LLM-as-a-judge stages, augmented with retrieval-augmented generation from a curated joke corpus for multilingual constrained humor generation. It shared Rank 1 with the Gemini 2.5 Flash baseline in English, Spanish and Chinese, and neither agentic variant was judged superior to the non-agentic pipeline despite substantially higher tool-call budgets.

arxiv:2607.12886 arXiv ✓
A Multi-Agent System for Autonomous, Fine-Tuning-Free Clinical Symptom Detection: Development and Validation Study
Pythia：无需微调的自主多智能体临床症状检测系统
multi-agent system prompt optimization clinical knowledge extraction sensitivity and specificity
Pythia is a multi-agent system running on a locally hosted open-weights model that autonomously writes and optimizes extraction prompts for clinical concepts without manual prompt engineering or fine-tuning. Across 72 signs and symptoms from 400 clinical notes, it reached mean sensitivity of 0.76 and specificity of 0.95, matching or exceeding a curated lexicon on both metrics for 20 of 62 directly comparable concepts.

arxiv:2607.13034 arXiv ✓
Do AI Agents Know When a Task Is Simple? Toward Complexity-Aware Reasoning and Execution
AI 智能体知道任务有多简单吗？迈向复杂度感知的推理与执行
execution-scope estimation agent efficiency context management agent benchmark
The paper argues that agents lack task-aware execution-scope estimation and formalizes minimum-sufficient execution plus an Agent Cognitive Redundancy Ratio, proposing E3 (Estimate, Execute, Expand) to expand scope only when verification fails. On MSE-Bench, E3 matched the strongest baseline's 100% success while cutting cost by 85%, tokens by 91% and inspected files by 92%, and a companion harness on a live gpt-4o agent found the over-reading milder but real.

arxiv:2607.13248 arXiv ✓
GSM-Plus-BN: A Perturbation-Based Benchmark for Bangla Mathematical Reasoning in Large Language Models
GSM-Plus-BN：面向大模型孟加拉语数学推理的扰动基准
multilingual benchmark mathematical reasoning chain-of-thought low-resource languages
GSM-Plus-BN is a perturbed Bengali mathematical reasoning dataset derived from the English GSM-Plus benchmark and verified by human translators; six open-source LLMs were evaluated on 9,000 samples under standard and chain-of-thought prompting. GPT-OSS-20B achieved the highest seed-question accuracy at 96.08%, larger models were more robust across perturbation types, and a performance gap relative to English benchmarks persisted.
