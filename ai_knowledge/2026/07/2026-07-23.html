Agentic Context Management: Solving Agent Memory and Cost by Treating Them as Lifecycle and Architecture Problems
智能体上下文管理：将智能体记忆与成本视为生命周期与架构问题
agentic context management context compaction agent memory token cost long-term memory benchmark
The paper argues that production agent failures stem more from mismanaging reasoning context than from weak reasoning, and proposes Agentic Context Management (ACM) with five primitives: architecting, ingesting, scoping, anticipating, and compacting and consolidation. A reference implementation, Maximem Synap, reports 92% on LongMemEval and 93.2% on LoCoMo under the configuration detailed in the paper, while the authors show that naive context accumulation grows token cost quadratically and that validated compaction keeps it linear.

Beyond Static RAG: An Adaptive, Tri-Metric Routing Framework for Efficient Long-Context Inference on Commodity GPUs
超越静态 RAG：面向商用 GPU 高效长上下文推理的自适应三指标路由框架
retrieval-augmented generation prompt compression KV cache adaptive routing
The paper identifies a compression paradox when RAG is served on 16 GB T4 GPUs, where neural prompt compression can add KV-cache contention and latency while skipping compression risks out-of-memory failures on long contexts. Its training-free Tri-Metric Router selects among raw, LLMLingua-2 and BM25 pipelines using length, key-token density and type-token ratio, reporting 0% OOM failures, 88.5% oracle alignment and 49.3% combined F1 on out-of-distribution holdouts, 5.2 points above always-on lexical compression.

Benchmarking LLMs for Verilog Design Flows
面向 Verilog 设计流程的大语言模型基准评测
Verilog generation LLM benchmark hardware design iterative refinement
The paper presents a reproducible benchmarking platform that evaluates open-source LLMs on 50 Verilog RTL generation tasks using constrained prompting, AST-based repair, formal equivalence verification, Verilator compilation and Icarus Verilog simulation. Across 1,610 runs on Llama-3-8B, StarCoder2-7B and TinyLlama-1.1B, the pipeline raised average syntax validity from 0% to 70.43% and simulation pass rate to 51.8%, with TinyLlama reaching 80.0% syntax validity.

Compact Latent Coordination for Autonomous Vehicles at Unsignalized Intersections
无信号交叉口自动驾驶车辆的紧凑潜空间协调
multi-agent coordination hierarchical reinforcement learning latent embeddings autonomous driving
MAPS is a hierarchical deep reinforcement learning architecture in which a centralized Master agent generates a compact continuous proto-plan embedding that decentralized Worker agents combine with local observations. Tested across 72 intersection configurations in HighwayEnv, it achieved collision-free navigation while reducing average travel time, and a system trained with three agents reached a 94% success rate when deployed zero-shot to five-agent scenarios.

arxiv:2607.21781 arXiv ✓
MosaicJoin: Compact Semantic Sketches for Value-Level Join Discovery
MosaicJoin：面向值级连接发现的紧凑语义草图
semantic join discovery embeddings data discovery sketching
MosaicJoin is a value-level semantic join discovery method that uses compact sketches to approximate whether two columns are joinable without comparing every value, plus query subsampling with provable accuracy guarantees. It requires no training, handles query columns of up to 57K values and data-lake columns of up to 1M values, and runs up to 66 times faster than other value-level methods across the benchmarks tested.

arxiv:2607.21447 arXiv ✓
RUMBA: Russian User Memory Benchmark
RUMBA：俄语用户长期记忆基准
long-term memory memory benchmark temporal reasoning multilingual evaluation
RUMBA is a long-term conversational memory benchmark built from timestamped user-assistant dialogues, with a fine-grained taxonomy covering semantic type, session scope, temporal reasoning and explicitness of temporal expressions. It is designed for Russian with an aligned English subset, and is used to diagnose memory systems and long-context models across benchmark slices and identify their strengths and failure modes.

Same Dangerous Objective, Opposite Advice: Direct Exposure versus Multi-Agent Mediation
同样危险的目标，相反的忠告：直接暴露与多智能体中介
multi-agent safety compositional safety prompt mediation LLM evaluation
Using 25 pre-specified mirrored trade-off profiles with OpenAI's gpt-5.6-sol model alias, the study finds that direct exposure to a dangerous objective produced advice net opposed to its target, while relaying the same objective through Id and Censor agents led the user-facing Superego to produce advice net aligned with it. The author describes this as a compositional safety gap in multi-stage agent workflows and does not identify the internal mechanism behind the behavioral shift.

arxiv:2607.21835 arXiv ✓
ToolGuardian: Declarative Security for AI Agent-Tool Interactions
ToolGuardian：面向 AI 智能体-工具交互的声明式安全
agent security tool use MCP declarative policy runtime authorization
ToolGuardian is a policy-driven framework that vets third-party agent tools before admission and authorizes them at runtime using progressive characterization from descriptions, system-call traces, mock execution and source analysis. An Answer Set Programming policy layer reached 0.86 deny-class F1 and 88% accuracy on 16 MCP-style tools, including 8 malicious variants, and fully specified runtime realizations classified all 20 scenarios correctly.
