Deep Agentic Search for Repository-Level Code Question Answering: An Empirical Study
面向仓库级代码问答的深度智能体搜索：一项实证研究
semantic search context pollution subagent delegation code question answering failure taxonomy
The authors compare semantic search with deep agentic search — a planner delegating exploration to a subagent in an isolated context window — on the SWE-QA repository-level code QA benchmark. Semantic search answered 65.2% of questions correctly versus 46.2% at less than half the cost, and 41.8% of deep agentic search's failures occurred at the planner-to-subagent hand-off, usually ending in a fluent and confident but wrong answer.

DiffusionGemma Technical Report
DiffusionGemma 技术报告
diffusion LLM open-weight model parallel decoding inference throughput
DiffusionGemma is an experimental open-weight model that fine-tunes a 25.2B-parameter mixture-of-experts Gemma 4 model with discrete diffusion, refining blocks of 256 tokens in parallel instead of decoding one token at a time. It generates roughly 1,500 output tokens per second on a single NVIDIA H100 at around 20 tokens per forward pass, while retaining thinking mode, multimodal inputs and long contexts.

The paper proves that the recall of any fixed-invariant finite-automaton runtime monitor is bounded by the concentration of the attack distribution, so dispersed attack patterns cannot be covered by a tractable invariant set. Across eight frontier LLM architectures, GPT-class and DeepSeek backends produced concentrated attacks (H ≈ 0.24 bits) with 68–75% coverage, Gemini variants produced high-entropy attacks (H ≈ 2.81 bits) with 6–13% coverage, and entropy explained 76% of coverage variance.

在线持续学习中生长型与弹性神经网络的塑性
