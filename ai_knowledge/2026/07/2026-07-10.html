Index SLM Technical Report
Index SLM 技术报告：Bilibili 开源 19 亿参数小模型系列
small language models open-weight models retrieval-augmented generation model release
Index-1.9B is a family of four open small language models from Bilibili, including a base model pre-trained on 2.8 trillion predominantly Chinese and English tokens, an instruction-filtered Pure variant, a Chat model aligned with SFT and DPO, and a Character model that adds retrieval-augmented generation for few-shot role-playing. arxiv:2607.10044 arXiv ✓
FlashTrie: A GPU-Accelerated Constrained Beam Search for Generative Retrieval
FlashTrie：面向生成式检索的 GPU 加速约束束搜索
generative retrieval constrained beam search trie index GPU acceleration
FlashTrie moves constrained beam search for generative retrieval onto GPUs with an integer-aware succinct trie that bit-compresses the index into high-bandwidth memory and a cooperative CUDA kernel that performs beam expansion, validation and pruning on-device. On a library of 800 million keywords with beam widths up to 1,000, it is reported to cut trie-search latency below 3 ms with up to 24x speedup over a multithreaded CPU baseline, alongside a 0.71% revenue lift in an online A/B test.

arxiv:2607.09876 arXiv ✓
Prompting-MammAlps: Fine-Grained Text-to-Video Retrieval for Camera-Trap Data
Prompting-MammAlps：面向相机陷阱数据的细粒度文本到视频检索
text-to-video retrieval camera-trap data LLM coding agent retrieval benchmark
The paper introduces Prompting-MammAlps, described as the first camera-trap text-to-video retrieval benchmark, and a fine-grained method that converts spatiotemporal action-localization output into structured text that an LLM coding agent parses to retrieve videos. The approach reaches a set-based F1 of 34% on 135 ecological queries and 775 candidate videos, versus 18% for the best zero-shot VLM, while remaining interpretable.

arxiv:2607.09521 arXiv ✓
SAGEAgent: A Self-Evolving Agent for Cost-Aware Modality Acquisition in Multimodal Survival Prediction
SAGEAgent：面向多模态生存预测成本感知模态获取的自进化智能体
self-evolving agent episodic memory semantic memory clinical decision support sequential decision making
SAGEAgent is a self-evolving LLM clinical agent that treats diagnostic modality acquisition as a sequential decision problem, using tools that translate predictions into text plus episodic and semantic memories to decide which diagnostic modalities are worth acquiring. On a glioma cohort with four modalities it achieves competitive survival prediction accuracy while reducing average acquisition burden by 55%.

arxiv:2607.09623 arXiv ✓
Task-Specific Multimodal Question Answering Agents via Confidence Calibration and Incremental Reasoning for QANTA 2026
面向 QANTA 2026 的多模态问答智能体：置信度校准与增量推理
confidence calibration multimodal QA multi-agent quizbowl benchmark
The paper describes a two-agent system for the QANTA 2026 multimodal quizbowl challenge: a Tossup agent with confidence-calibrated answering and a domain-specific numeric reasoning policy, and a Bonus agent using leadin-aware and structured relational reasoning with multimodal evidence. It reports the highest overall leaderboard score of 0.402, with a Tossup score of 0.238 and a Bonus Effect score of 0.164, without a retrieval pipeline or model ensembles.
→ arxiv.org
arxiv:2607.09954 arXiv ✓
A Knowledge-Based Multi-Agent Framework for Security Control Recommendation
面向安全控制推荐的知识型多智能体框架
decision support multi-agent influence diagram no-regret learning expert knowledge
The paper proposes a security decision support system that recommends security control sub-families from minimal coverage requirements, modeled as a non-zero-sum simultaneous game grounded in a Multi-Agent Influence Diagram over seven security dimensions and solved with no-regret online learning. It reports 99% satisfaction coverage using about 65% of software-implementable controls and 73%–77% coverage using about 29%, running in roughly 0.8 to 35.7 seconds.
→ arxiv.org
