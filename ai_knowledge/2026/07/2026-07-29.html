Disentangling Algorithmic Bias from Archival Artifacts: A Controlled Audit of Vision-Language Model Valuation in Metropolitan Museum Archives
将算法偏见与档案伪影分离：大都会博物馆档案中视觉语言模型估值的受控审计

They caution that macro-level score equivalence does not rule out localized visual biases, and that excluding unattributed holdings introduces survival bias.

LayerRAG-Bench: A Cross-Layer Reliability Benchmark for Agentic Retrieval-Augmented Generation
LayerRAG-Bench：面向智能体检索增强生成的跨层可靠性基准
agentic RAG reliability benchmark fault scenarios session state tool contracts
LayerRAG-Bench tests agentic RAG across 8 enterprise domains, 240 tasks, 9 fault scenarios and nine models, and finds schema normalization fixes schema drift (0.000 to 0.913) but not stale evidence, missing tool output, denied permissions or wrong-session context. Its authors argue that a reliability fix should be credited only for repairing its target layer.

AgentMap: Joint Equivalence and Subsumption Discovery for Ontology Matching
AgentMap：本体匹配中的等价与包含关系联合发现
ontology matching multi-agent reasoning semantic retrieval knowledge alignment
AgentMap is an LLM-based multi-agent framework for hybrid ontology matching that combines semantic retrieval, hierarchical search and collaborative reasoning to find either an equivalent concept or the most fine-grained subsumer. It outperforms equivalence-only and subsumption-only baselines on the authors' extended ontology-matching benchmark.

arxiv:2607.28680 arXiv ✓
TELLER: Dual-Path Iterative Preference Optimization for Table Entity Linking
TELLER：面向表格实体链接的双路径迭代偏好优化
entity linking preference optimization table understanding Wikidata
TELLER links ambiguous table cells to Wikidata entities through a direct-answer path with iteratively refreshed preference data and a reasoning path trained on compressed chain-of-thought. The direct path raises accuracy from 94.35% to 94.50% on TableInstruct and from 87.59% to 88.20% on MammoTab V2, while the reasoning path lifts MammoTab V2 from 79.09% to 81.85%.

面向可扩展金融 RAG 系统的分层重排序
financial RAG reranking long-context management table retrieval
The paper proposes a financial RAG pipeline combining pre-retrieval query normalization and table transformation, a two-stage hierarchical reranker and adaptive long-context partitioning. It reports an NDCG@20 of 0.7918 across FinQA, FinanceBench and ConvFinQA and placed second in the ACM-ICAIF '24 FinanceRAG Challenge.

Leveraging Trajectory Graphs for Pre-Execution Error Diagnosis in Agentic LLM Systems
利用轨迹图在智能体 LLM 系统执行前诊断错误
agent trajectories graph neural network error diagnosis self-correction
Trajectory Graph Copilot models historical agent trajectories as a probabilistic graph and uses a graph neural network to flag action patterns that often lead to failure before the actions are executed. Across four benchmarks and three LLM agents, it improves the average pass ratio by 14.69% without fine-tuning.

arxiv:2607.27201 arXiv ✓
Mental World Modeling
心理世界建模
world models theory of mind agent simulation decision prediction
The authors formulate Mental World Modeling, which keeps beliefs, desires, intentions and social expectations as core state alongside the physical scene, and instantiate it in MENTIS, a training-free and inspectable baseline. Across situated decision scenarios in text, image and sounding-video stories, experiments with eight LLM-based world models find that explicitly modeling mental state is essential for predicting human decisions.
