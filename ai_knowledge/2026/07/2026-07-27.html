Kimi K3: Open Frontier Intelligence
Kimi K3：开放前沿智能
mixture-of-experts long context open weights agentic reinforcement learning scaling efficiency
Kimi K3 is a 2.8T-parameter mixture-of-experts model with 104B activated parameters, native vision and a 1-million-token context window, built on Kimi Delta Attention, Attention Residuals and Stable LatentMoE. The team reports roughly 2.5x better scaling efficiency than Kimi K2 and frontier-level results that still trail Claude Fable 5 and GPT-5.6 Sol, and releases the full weights.

arxiv:2607.25066 arXiv ✓
Addressable Recall Compaction for Long Context-Window Control in AI Agents
面向AI智能体长上下文窗口控制的可寻址召回压缩
context compaction addressable memory long-context agents needle-in-a-haystack
ARC separates archival storage from active context: it keeps tool observations in an append-only, ID-addressable log and replaces older observations with compact citations that the agent can use to request stored content. With Qwen3-8B and Qwen3-32B, it reports 99.40% average exact-answer accuracy on Needle-in-a-Haystack versus 88.12% for the best baseline, and 29.97% versus 28.25% on LongBench-v2 Hard.

arxiv:2607.24663 arXiv ✓
A corrective agentic hybrid RAG and an operations-grounded evaluation for a scientific facility
面向科学设施的纠正式智能体混合RAG与基于运营的评估
agentic RAG hybrid retrieval knowledge graph evaluation harness
APS-RAG is a deployed retrieval platform for the Advanced Photon Source that fuses dense, sparse and knowledge-graph channels with query-type-adaptive reciprocal-rank fusion, a corrective agentic loop and a ReAct executor over MCP tools. On the 50-question APS-Bench, the full corrective Agentic GraphRAG reaches 70.3% strict vital-nugget recall versus 63.8% for BM25, and removing the cross-encoder reranker cuts strict recall by 32.8%.

Authoring Agent Skills: A Software-Engineering Approach
编写Agent Skills：一种软件工程方法
agent skills software engineering behavioral evaluation staged context loading
This note argues that Agent Skills are software artefacts whose construction should follow software-engineering principles such as single responsibility, separation of interface from implementation and low coupling, with behavioural evaluation instead of deterministic testing. Using Claude Code as a reference, it describes staged skill loading and compares skills with project memory files, slash commands, subagents, tool connections and hooks.

arxiv:2607.24984 arXiv ✓
Automatic Knowledge Graph Construction and Query for Earthquake Catalogs
面向地震目录的自动知识图谱构建与查询
GraphRAG knowledge graph construction scientific knowledge prompt engineering
The paper applies GraphRAG directly to raw tabular records from three earthquake catalogs, building queryable knowledge graphs without manual data structuring. It reports that four seismology-informed prompt fixes eliminate all targeted fabrications, and that a vector RAG baseline shows the graph layers' value in catalog-wide summarization and temporal stage comparison.

Eviction as Estimation: A Fixed-Lag Smoothing View of Test-Time Memory, and When Measuring Beats Accumulating
将驱逐视为估计：测试时记忆的固定滞后平滑视角，以及测量何时优于累积
test-time memory KV cache eviction fixed-lag smoothing negative result
The paper recasts which items a bounded memory should keep as a fixed-lag smoothing problem and introduces RMM, a training-free policy that generalizes H2O. In controlled settings demonstrated utility identifies reused memory better than accumulated attention, but on third-party benchmarks in NVIDIA's KVPress harness the advantage mostly disappears, with RMM on par with H2O for single-turn QA and behind H2O and SnapKV in streaming multi-turn settings.
