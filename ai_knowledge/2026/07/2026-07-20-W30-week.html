Search-G1: Co-Evolving Representation-Based Rewards for Selective Grounded Search
Search-G1：面向选择性有据搜索的协同演化表示奖励
selective retrieval grounded search reward design hidden-state readouts QA benchmarks
Search-G1 is a reward framework for search-augmented agents that couples retrieval necessity with evidence reliance using two intervention-calibrated hidden-state readouts: a prompt readout for closed-book sufficiency and an answer-commit readout for sensitivity to evidence deletion. Across four QA benchmarks and two model scales it reports competitive task accuracy with stronger counterfactual evidence dependence and fewer searches in the main comparisons, without process annotations or LLM-judge inference.

FlashRT：引导智能体部署实时多模态应用的智能体框架

FlashRT is an agent harness that guides coding agents through a chain-of-program process: translating a reference implementation into an IR, validating it with a sequential interpreter, and iteratively benchmarking candidate transformations to build multi-GPU deployments. NVIDIA-labs OO Agents：原生 Python 面向对象智能体
agent framework object-oriented agents tool use long-term memory agent benchmarks
NVIDIA Object-Oriented Agents (NOOA) is a model-agnostic Python framework in which an agent is a Python object: methods are the actions, fields are state, docstrings are prompts and type annotations are contracts, with `...` method bodies completed at runtime by an LLM-driven loop.
