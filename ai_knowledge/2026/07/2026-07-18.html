TurboVec: A Case Study in Cost-Efficient Private Retrieval for Enterprise RAG via Codebook-Oblivious Quantization
TurboVec：基于码本无关量化的企业 RAG 低成本私有检索案例研究
vector index quantization enterprise RAG tenant isolation recall
TurboVec is an open-source vector index built on TurboQuant, a codebook-oblivious scalar quantizer that requires no corpus-dependent training, aimed at private multi-tenant enterprise RAG. On the DBpedia OpenAI embeddings benchmark, 4-bit TurboQuant is reported to beat trained FAISS product quantization by 8.5-8.9 points in Recall@5 at the same memory budget, with 11 ms median query latency at 100K vectors and membership inference accuracy reduced to near-random 50.0%.

RECON: Benchmarking Agent Memory for Compositional Reasoning over Long Contexts
RECON：评估智能体长上下文组合推理记忆能力的基准
agent memory long context compositional reasoning benchmark
RECON is a benchmark of 24 case files spanning criminal, medical and financial domains, each 50k-100k tokens, testing six memory-intensive tasks such as reconstructing multi-hop evidence chains, propagating cascading invalidations and resolving source conflicts. The strongest non-Oracle system reaches only 22.4% accuracy, with retrieval and reasoning each surfacing as challenges.

arxiv:2607.16848 arXiv ✓
Beyond Memory Leaderboards: Evaluating Scientific Memory as Budgeted Context Restoration
超越记忆排行榜：将科学记忆评估为有预算的上下文恢复
scientific memory retrieval budget hybrid retrieval LLM-as-judge Graphiti
The paper introduces two full-text scientific-memory benchmarks, PAIM with 81 papers and 66 questions and PTr with 252 papers and 98 questions, and evaluates eight memory or retrieval systems plus a no-retrieval baseline. It reports that rankings depend on ingestion granularity, raw-text preservation, retrieval budget, modality and judge choice; on PAIM Graphiti's lead disappears after controlling for its 2.6M characters of retrieved context per query, and hybrid sparse-dense retrieval is the most significant intervention on PTr.

arxiv:2607.24824 arXiv ✓
Retrieval-based and Fine-tuned LLM Approaches for Industrial Asset Health Monitoring and Decision Support
面向工业资产健康监测与决策支持的检索式与微调 LLM 方法
retrieval hybrid search fine-tuning industrial diagnostics robustness
The study compares retrieval-only methods including TF-IDF, BM25, semantic search and hybrid search with Qwen2.5-7B-Instruct under zero-shot prompting, few-shot prompting and QLoRA fine-tuning on IBM Research's FailureSensorIQ multiple-choice benchmark. Semantic and hybrid search beat keyword matching, fine-tuning performs best among the LLM methods, and accuracy decreases as the number of answer options grows, with all methods sensitive to option shuffling, label changes, paraphrasing and added distractors.

DeepSeek arxiv:2609.19006 arXiv ✓
WordPolo: Evaluating Language Models Through Iterative Semantic Feedback
WordPolo：通过迭代语义反馈评估语言模型
reasoning evaluation semantic feedback iterative search benchmark
WordPolo is a word-finding task in which models must discover an unknown target word from semantic-similarity distance scores, making iterative reasoning and adaptive search strategies directly observable. Across 1,500 puzzles, solve rates range from 4% to 62%, and progression-based metrics show reasoning models can be hindered by overthinking and underthinking while successful models exhibit human-like strategies.

Though Language Models Err While They Strive: Conformal Prediction for Self-Correcting Scientific Generation
语言模型在努力中犯错：面向自校正科学生成的一致性预测
conformal prediction scientific reasoning factuality reasoning evaluation
Scientific Feasibility Control is a graph-structured conformal prediction framework that decomposes scientific reasoning into atomic factuality units requiring both correctness against physical laws and logical support from preceding context, branching to alternative generation paths when violations are detected. It reports 50.1% accuracy on PhyX multimodal physics, 91.7% scientific validity at alpha of 0.10 and 73% fewer scientific law violations across multiple model architectures.
