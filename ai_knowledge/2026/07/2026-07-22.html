NVIDIA-labs OO Agents: Native Python Object-Oriented Agents
NVIDIA-labs OO Agents：原生 Python 面向对象智能体
agent framework object-oriented agents tool use long-term memory agent benchmarks
NVIDIA Object-Oriented Agents (NOOA) is a model-agnostic Python framework in which an agent is a Python object: methods are the actions, fields are state, docstrings are prompts and type annotations are contracts, with `...` method bodies completed at runtime by an LLM-driven loop. It combines six model-facing ideas on one surface and is demonstrated on SWE-bench Verified, Terminal-Bench 2.0 and ARC-AGI-3.

IssueTrojanBench: Benchmarking AI Coding Agents Against Malicious Issue Requests
IssueTrojanBench：评测 AI 编码智能体抵御恶意 Issue 请求的能力
coding agents prompt injection agent security guardrails benchmark
IssueTrojanBench evaluates Cursor, Claude Code and Codex Desktop, backed by GPT-5.3 Codex/GPT-5.4 and Sonnet 4.6, against malicious issue requests built from four attack categories, six delivery vectors and perturbations. 66.5% of the malicious issues penetrated all agent- and LLM-level guardrails, rejection came almost entirely from the LLMs rather than the agent frameworks, and current agent-level defenses offered limited extra protection.

DeepSeek arxiv:2607.20712 arXiv ✓
Evaluating Large Language Models for Symbolic Security Protocol Analysis
评估大语言模型在符号化安全协议分析中的表现
formal verification reasoning models security protocols LLM evaluation
The study tests GPT and DeepSeek in chat and reasoning modes on 130 obfuscated AnB/AnBx protocols covering 388 goals, scored against ProVerif and OFMC. Enabling reasoning lifts GPT's precision from 27.3% to 64.8% while recall stays at 54.5%, verdicts are unstable across runs, and self-reported confidence showed no meaningful correlation with correctness, so the authors see LLMs at best as pre-screening filters.

Leaky Language Models: Stealing Architecture and Inference Optimizations via Per-Token Timing
泄密语言模型：通过逐 token 时序窃取架构与推理优化信息
timing side channel speculative decoding model architecture deployment privacy
LeakyLMs infers proprietary model and deployment details from token-generation timing over remote APIs, detecting speculative decoding and the draft model's context length — measured for Gemini Flash 2.5 at roughly 128K tokens — and recovering transformer layer count, hidden dimension and attention heads. On Llama models the near-correct architecture appears in the top-10 guesses more than 90% of the time.

arxiv:2607.20764 arXiv ✓
ArbiGraph: Arbitrarily Scalable Verifiable Task Graphs for Evaluating Context Management
ArbiGraph：用于评测上下文管理的任意规模可验证任务图
context management benchmark generation tool-assisted agents task graphs
ARBIGRAPH is a benchmark generator that represents each task as a natural-language problem with an executable Python solver and composes tasks through typed intermediate states, letting task-graph length, dependency structure, distractor count and value type vary under exact automatic verification. A Qwen3.5-27B tool-assisted agent scored well on isolated tasks but dropped by up to 33.3% on branching chains of dependent math tasks.

OpenAI arxiv:2607.21653 arXiv ✓
Molt: A Scalable PyTorch-Native Training Framework for Agentic Reinforcement Learning
Molt：面向智能体强化学习的可扩展 PyTorch 原生训练框架
agentic RL training framework context compaction distributed training
MOLT is a lightweight PyTorch- and Hugging Face-native framework for agentic reinforcement learning that combines direct Hugging Face model loading, OpenAI- and Anthropic-compatible agent interfaces with automatic context compaction, fully asynchronous training and distributed experience storage. The authors validate the pipeline on a one-trillion-parameter policy and show sustained learning with a 30B mixture-of-experts agent in about 9.2K lines of framework code.
→ arxiv.org
arxiv:2607.20327 arXiv ✓
PyroDash: Cost-Efficient Token-Level Small-Large Language Model Collaborative Inference
PyroDash：成本高效的 token 级小模型-大模型协同推理
collaborative inference token-level routing cost-aware RL reasoning benchmarks
PyroDash trains a small model to emit a control token when it needs help, handing the query and partial reasoning trace to a frozen LLM in a single handoff, with a cost-aware GRPO reward balancing accuracy against inference cost. Across five math reasoning benchmarks it reports 64.04% average accuracy at 20.4% lower cost with λ=0.05, and 54.55% accuracy at a 1.90% LLM token ratio with λ=0.6.
