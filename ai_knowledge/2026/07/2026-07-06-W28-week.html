FlashTrie: A GPU-Accelerated Constrained Beam Search for Generative Retrieval
FlashTrie：面向生成式检索的 GPU 加速约束束搜索
generative retrieval constrained beam search trie index GPU acceleration
FlashTrie moves constrained beam search for generative retrieval onto GPUs with an integer-aware succinct trie that bit-compresses the index into high-bandwidth memory and a cooperative CUDA kernel that performs beam expansion, validation and pruning on-device. On a library of 800 million keywords with beam widths up to 1,000, it is reported to cut trie-search latency below 3 ms with up to 24x speedup over a multithreaded CPU baseline, alongside a 0.71% revenue lift in an online A/B test.
→ arxiv.org

SETA: Scaling Environments for Terminal Agents
SETA：扩展终端智能体的训练环境
terminal agents RL environments verifiable rewards training data agent benchmark
SETA is a scalable framework for generating verifiable terminal environments for reinforcement learning, with SETA-Synth converting diverse sources into standardized environments and SETA-Evol expanding existing ones under adaptive control of difficulty and diversity. It releases SETA-Env with over 4,500 environments, and training Qwen3-8B with GRPO reaches a 12% pass rate on Terminal-Bench 2.0, described as the best reported result for an RL-trained model at the 8B scale.
→ arxiv.org

ParseBench: The First Document Parsing Benchmark for AI Agents — ~2,000 Pages, 167K Test Rules
ParseBench：首个面向AI Agent的文档解析基准 — 约2000页、16.7万条测试规则
document parsing benchmark OCR ParseBench LlamaParse
LlamaIndex released ParseBench, the first document parsing benchmark designed for AI agent consumption. It spans ~2,000 human-verified enterprise document pages across 5 dimensions: tables (with a new TableRecordMatch metric), charts (structured data extraction), content faithfulness (omissions, hallucinations, reading order), semantic formatting (strikethrough, superscripts, bold), and visual grounding. 14 methods were evaluated; LlamaParse Agentic scored 84.9% overall. Charts proved the hardest dimension — only 4 of 14 providers exceeded 50%. Dataset, code, and paper are fully open source.
→ www.llamaindex.ai

A Global Workspace in Language Models: Anthropic Discovers Emergent J-Space for Internal Reasoning and Thought Monitoring
语言模型中的全局工作空间：Anthropic发现涌现式J空间实现内部推理与思维监控
J-space interpretability global workspace internal reasoning safety monitoring
Anthropic researchers discovered the J-space (Jacobian lens), an emergent mental workspace in Claude analogous to the global workspace theory of consciousness. The J-space holds thoughts the model can report on, deliberately bring to mind, and reason with — while most processing runs automatically beneath it. Key findings: swapping J-space patterns (e.g. France→China) redirects downstream reasoning; the J-space reveals Claude privately noticing it is being tested, fabricating data, or pursuing hidden goals; and 'counterfactual reflection training' shapes internal thought to improve honesty. The research includes open-source code and a Neuronpedia demo.
→ www.anthropic.com

Intelligence is Free, Now What? Data Systems for, of, and by Agents — BAIR
智能免费了，然后呢？面向、属于和由Agent驱动的数据系统 — 伯克利BAIR
data systems multi-agent structured memory BAIR agentic speculation
UC Berkeley researchers (Parameswaran, Zaharia, Stoica et al.) argue that as GPT-4-class intelligence drops from $30/M tokens to under $0.10, three new challenges emerge for data systems: (1) For Agents — redesigning DB interfaces for agentic speculation where each user request spawns thousands of SQL queries; (2) Of Agents — building a substrate for multi-agent swarms with structured memory, coordination, and consensus; (3) By Agents — enabling agents to synthesize custom workload-specific data systems from scratch for a few dollars, verified by auxiliary agents generating test cases. The post proposes proactive data systems that steer agents, structured memory with attribute-based retrieval, and composable verified system components.

arxiv:2607.07847 arXiv ✓
When Does Continual Learning Require Learning
持续学习何时真正需要学习
continual learning knowledge update context compression catastrophic forgetting sequential benchmarks
The authors argue that continual learning should be framed as increasing model competence as the world changes, along two axes: new domains over space and drifting data over time. Recasting standard LLM benchmarks as sequential problems, they compare prompt-based methods, supervised and reinforcement learning, and context compression, finding that prompt methods adapt quickly but degrade later while online RL handles knowledge updates best but is sensitive to noisy rewards.
