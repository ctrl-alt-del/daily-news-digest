FlashRT: Agent Harness for Guiding Agents to Deploy Real-Time Multimodal Applications
FlashRT：引导智能体部署实时多模态应用的智能体框架
agent harness multimodal deployment chain-of-program latency optimization
FlashRT is an agent harness that guides coding agents through a chain-of-program process: translating a reference implementation into an IR, validating it with a sequential interpreter, and iteratively benchmarking candidate transformations to build multi-GPU deployments. It reports up to ~70x latency reduction and 2.8x throughput improvement on NVIDIA B200, and on AMD MI355X cuts Qwen3-Omni text-to-audio latency by 65% versus the expert vLLM-Omni implementation.

Search-on-Graph-R1: Training Large Language Models to Search Knowledge Graphs with Reinforcement Learning
Search-on-Graph-R1：用强化学习训练大语言模型搜索知识图谱
knowledge graph QA reinforcement learning SPARQL compact models
Search-on-Graph-R1 trains a compact 8B model to navigate knowledge graphs by supervised fine-tuning on trajectories from a frontier teacher scaffolded with each question's gold SPARQL query, then reinforcement learning against a live Freebase server. SWE-Pruner Pro: The Coder LLM Already Knows What to Prune
SWE-Pruner Pro：代码大模型早已知道该剪掉什么
context pruning coding agents internal representations token efficiency
SWE-Pruner Pro prunes tool outputs inside a coding agent by turning the agent's own internal representations into per-line keep-or-prune labels, using a small head and a length-aware embedding keyed to each output's line count. Across two open-weight backbones and four multi-turn benchmarks it saves up to 39% of prompt and completion tokens while preserving quality, and on MiMo-V2-Flash raises SWE-Bench Verified resolve rate by 3.8%.

AHEAD: Advancing Multi-Class Label Aggregation with Interpretable Cross-Annotator Modeling
AHEAD：面向多分类标签聚合的可解释跨标注者建模
label aggregation annotator embeddings graph neural networks data quality
AHEAD learns cross-annotator contexts with a graph neural network and decodes them into interpretable annotator-specific confusion matrices to aggregate noisy multi-class crowdsourced labels. On 10 real-world datasets it raises average label accuracy from 68.75% to 73.23%, with a best-case gain of 14.9%.

Aethel: A Reproducible Graph-Retrieval Framework for Multi-Hop Financial Diligence
Aethel：面向多跳金融尽职调查的可复现图检索框架
graph retrieval multi-hop QA Personalized PageRank financial diligence
Aethel combines bipartite Personalized PageRank graph retrieval, a coreference-aware teleportation layer and specialist agents to answer multi-hop questions over fragmented financial disclosures. It reports HR@5 of 100.0% on 2WikiMultiHopQA and 88.5% on MuSiQue, but on a 4,123-chunk financial corpus graph retrieval does not surpass a strong BM25 baseline at open-corpus scale.

Attacking Graph Foundation Models Through Their Shared Representation
通过共享表征攻击图基础模型
graph foundation models representation space adversarial attack alignment layer
The paper identifies the alignment layer that maps inputs into a shared representation as a distinct inference-time attack surface in graph foundation models. A directed representation-space perturbation collapses all six tested models, with OpenGraph's spectral tokenizer collapsing at a fifth of the budget a plain graph network needs, and realizable edge, feature or text edits remove at least half the correct predictions on three models.

面向智能电网的大语言模型与智能体系统：架构与应用教程
agentic AI solver grounding tool use evaluation framework
This tutorial reviews prompting strategies and agentic architectures for smart-grid LLM systems and proposes a solver-grounded principle: report a numerical result only when it comes from a trusted tool and passes explicit verification.
