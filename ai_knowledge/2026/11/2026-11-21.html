Muted Distillation: Sealing Reasoning from Teacher Unlocks Token-Efficient Agents
Muted Distillation：对教师隐藏推理过程，打造更省 token 的 Agent
reasoning distillation token efficiency on-policy distillation agent reasoning
Muted Distillation is an on-policy distillation variant that hides the student's reasoning from the teacher. On OfficeQA Pro and SpreadsheetBench it cuts output tokens per episode by 57% and 53% versus standard OPD, matches OPD accuracy on OfficeQA Pro and improves pass@1 by 4.8 points on SpreadsheetBench.

MASSys is a benchmark that runs the same multi-agent candidate-task pairs across serving substrates and load regimes, recording quality alongside latency, cost and failure evidence. arxiv:2611.29062 arXiv ✓
HyperHarness: Learning to Generate Personalized Agent Harnesses from User Histories
HyperHarness：从用户历史学习生成个性化 Agent 框架
personalized harness user history memory retrieval code generation context allocation
HyperHarness learns a shared history-to-harness generator that writes executable, user-specific retrieval and answer-guidance code from a user's permitted history, supervised by downstream task scores without reference harnesses. Across PersonaMemv3, Mem-PAL and MemoryCD with three answering models it scores highest in seven of nine settings, improving over the strongest baselines by up to 5.95 points while cutting matched answer-time tokens by 90.32% versus long-context prompting.

RecallWorld: Episodic Memory for Persistent Embodied Video World Models
RecallWorld：面向持久具身视频世界模型的片段记忆
episodic memory coverage-based retrieval video world models scene reconstruction
RecallWorld is a persistent embodied video world model that reconstructs short multi-view episodes into Scenelets while keeping geometry independent across episodes, using camera-aware ray lifting and coverage-based retrieval. Across four datasets it improves revisit PSNR by 2.6 dB on partial revisits and 3.9 dB on full cycles over the strongest evaluated baseline.

SupportChain: Trace-Calibrated Aggregation of Quote-Grounded Reasoning Chains for Multi-Hop RAG with Small Readers
SupportChain：面向小模型多跳 RAG 的引用溯源推理链聚合
multi-hop RAG quote-grounded reasoning trace calibration small readers
SupportChain splits a question into hops, binds each answer to a sentence quoted from a retrieved passage, estimates reliability from execution traces and merges runs by support. With a 9B reader under the HippoRAG 2 protocol it reaches 63.0 F1 on MuSiQue, above the prior best of 59.2 from a 20B reader, and builds no index.

LITMUS - Literature Informed Testbed for Mapping Usecases and Synthesizing Risk-Cards
LITMUS：面向用例映射与风险卡片合成的文献知情测试平台
risk cards evidence retrieval literature grounding use-case mapping
LITMUS is a pipeline that, given an AI use case, automatically produces a tailored dataset and a risk card whose risks are tied to that use case and backed by traceable evidence from peer-reviewed literature. Evaluated with the MIT Risk Taxonomy on 320 samples, it reports a 0.91 F1 score.

arxiv:2611.28787 arXiv ✓
DiscernBench: Evaluating Cooperative Discernment of LLM Agents in Institutional Settings
DiscernBench：评估机构场景中 LLM Agent 的协作判断力
cooperative discernment multi-agent deliberation escalation behavior institutional constraints
DiscernBench is a benchmark for cooperative discernment, the ability of an agent to comply, refuse or escalate a request in an institutional setting, built from real-world incident reports in domains such as aviation, law enforcement and emergency management. Role-specialized multi-agent deliberation raises average over-escalation from 3.79% under direct single-agent judgment to 28.27%, with a lone specialist sometimes disproportionately swaying the collective decision.
→ arxiv.org

From Reward Engineering to Data-Centric Reinforcement Learning for Effective Agentic Visual Tool Use
从奖励工程到数据中心强化学习：提升 Agent 的视觉工具使用
visual tool use data-centric RL perception attribution adaptive sampling
AOVO is a data-centric framework that teaches multimodal LLMs when to invoke visual tools through perception attribution and policy-adaptive data sampling, without tool-specific rewards. It counterfactually probes reasoning states to find observation-sensitive questions and reallocates training toward them, improving over competitive tool-use models across visual perception and reasoning benchmarks.

Tool-to-Self: Internalizing Visual Tool Capabilities via Scaffolded Reinforcement Learning
Tool-to-Self：通过脚手架式强化学习内化视觉工具能力
tool internalization reinforcement learning visual tools tool-free inference
Tool-to-Self is a tool-scaffolded reinforcement learning framework that treats external visual tools as temporary training scaffolds, cold-starting tool use and observation prediction before progressively annealing tool execution on a per-tool basis. It improves over explicit tool-use and implicit zooming models across benchmarks while enabling tool-free inference with lower latency.
