Trustworthy Recursive Self-Improvement with Statistical Guarantees
具有统计保证的可信递归自我改进
recursive self-improvement statistical gating agent harness online hypothesis testing
TRUST adapts an online multiple-hypothesis-testing procedure to gate updates in recursive self-improvement, controlling the rate of false evolution across rounds while an LLM analyzes historical context to decide how much evidence is needed. On HotpotQA, DROP and APPS with DeepSeek-V4-Flash and Qwen-3.8-Flash, it cuts the average ratio of accepted inferior updates from 45.59% under a greedy gate to 2.78% while achieving higher final scores than statistical-gate baselines.

Learning Biological Hierarchies in Single-Cell Foundation Models
单细胞基础模型中的生物层级学习
cell ontology single-cell foundation model hierarchical embeddings zero-shot transfer
scOntoFM is a biologically informed single-cell foundation model that embeds hierarchical cell-ontology structure into representation learning using Lowest Common Ancestor distances and offline triplet sampling. The authors report consistent gains across cell- and gene-level benchmarks, especially in zero-shot settings, while balancing batch integration with biological structure preservation.

arxiv:2611.10770 arXiv ✓
How reliable is an embedding of the seabed? Repeat-look measurement of frozen encoders on synthetic aperture sonar
海底嵌入有多可靠？合成孔径声呐上冻结编码器的重复观测测量
embedding reliability frozen encoders representation evaluation sonar imagery
The paper treats embeddings of synthetic-aperture sonar imagery as repeat measurements and measures the repeat-look reliability of a frozen DINOv3 ViT-S/16 encoder. Standard single-look metrics and a coral linear probe (AUC 0.93) remain stable, yet the embeddings' distance-based intraclass correlation is only 0.20, so patch-identity uses such as cross-pass retrieval fail while habitat-level classification still works.
→ arxiv.org
arxiv:2611.10958 arXiv ✓
Hybrid Source Code Change Impact Analysis
混合式源代码变更影响分析
change impact analysis multi-agent refinement code reasoning benchmark dataset
katIA combines static impact analysis with LLM refinement in a single-prompt variant and a three-agent variant, evaluated on a manually labeled set of 1,931 changed entities from 263 commits in 22 Java projects. With Gemini 2.5 Flash, the single-prompt variant reaches 27.0% F1 on class-and-entity matching, 2.0 points above the prior state of the art, and the multi-agent variant raises it to 33.3% at higher latency and token use.

arxiv:2611.10768 arXiv ✓
BlenderFORGE: Framework for Optimizing Reactive 3D-Graphics Editing Ability of MLLMs
BlenderFORGE：优化多模态大模型反应式 3D 图形编辑能力的框架
multimodal agents Blender code generation sandboxed reinforcement learning execution feedback
BlenderFORGE is a trainable data-environment-optimization framework for open-weight MLLM agents that edit Blender scenes by generating Blender Python code, covering object placement, shape-key editing, lighting and materials. It combines perturbation-based data generation, an isolated Blender sandbox with state export and reward computation, and a two-stage pipeline of teacher-trajectory SFT followed by sandbox-reward agentic RL, reporting gains for Qwen3-VL-8B and Qwen3.5-9B agents.
