Jais 3：面向阿拉伯语的智能体 AI
Arabic language model agentic models continual pretraining open weights long context
Jais 3 is a fleet of six open Arabic-centric agentic models from 0.9B to 375B parameters, adapted from the K2 Horizon fleet through continual pretraining, supervised fine-tuning, preference optimization and reinforcement learning with verifiable rewards, with a 512K-token context window on all but the smallest model. Route to Remember: Adaptive Memory Selection for LLM Agents
Route to Remember：面向 LLM 智能体的自适应记忆选择
weight memory on-policy self-distillation memory routing long-term memory hallucination benchmark
The paper applies on-policy self-distillation to train a context-free student from the same model conditioned on a user's memory, making weight memory competitive as a long-term factual store, and adds a verify-then-regenerate router that sends each query to weight or text memory. On HaluMem, it matches or surpasses strong text-memory baselines while reading fewer tokens per query.

arxiv:2611.11684 arXiv ✓
Self-Indexing Latent Memories for Access-Aware Continual Instruction Tuning of LLMs
自索引潜在记忆：面向 LLM 的访问感知持续指令微调
latent memory continual instruction tuning prompt-only routing catastrophic forgetting
TILA-CT is a replay-free continual instruction-tuning method that gives each task a latent memory and adapter bank in a frozen LLM, with the memory's persistent state serving as the routing prototype for a shared prompt-only router. On an 8-task CT-Pipeline stream it reaches 65.19 acquisition and 63.98 final macro score with 1.38 points of average forgetting, and final macro routing accuracy is 93.9%.

相同错误，不同恢复：错误呈现方式如何影响 LLM 智能体行为
tool error recovery error delivery agent reliability stopping behavior
