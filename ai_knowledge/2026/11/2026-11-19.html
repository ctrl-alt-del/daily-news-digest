Replication of Agentic Security Events: Audit and Investigation (ROGUE-AI)
智能体安全事件复现：审计与调查（ROGUE-AI）
incident replication agent audit hazard warnings prompt injection
ROGUE-AI is a multi-agent framework that rebuilds each reported agent incident offline together with a matched control that lacks only the blamed cause, then runs agents on both to test whether the cause reproduces the harm. It reproduced the reported harm in 89% of 108 attempted replications; five current models made the blamed mistake in 18-33% of runs versus at most 1% without the cause, and a warning after each tool output that names the hazard and its consequence lowered harm for all five.

arxiv:2611.26717 arXiv ✓
Coherence by Construction: Synthesizing CTI Knowledge Graphs and the Formal Limits of Coherence Validation
构造即一致：合成 CTI 知识图谱与一致性验证的形式极限
knowledge graph synthesis STIX 2.1 coherence validation generation by simulation threat intelligence
The paper generates cyber-threat-intelligence knowledge graphs in STIX 2.1 by simulating a process in which language-model agents propose intent and a deterministic referee resolves outcomes against an explicit world model, so a relation is emitted only when the event it represents occurs. It proves referential closure, causal grounding and identifier stability, and proves that validators a structure-matched random graph can reproduce are uninformative about coherence for such generators, realizing the failure four ways with Erdős-Rényi controls.

AstronautBench: Measuring Agent Self-Improvement Across Episodes Through Knowledge, Evidence, and Progress
AstronautBench：从知识、证据与进展三个视角衡量智能体的跨回合自我改进
self-improvement episodic memory evidence grounding embodied agents benchmark design
AstronautBench measures a single agent's self-improvement in the game Outer Wilds through three views on the same run: what it knows, whether its own cited evidence supports that knowledge, and how far it progresses in a 22-minute resetting loop. With GPT-6.1 Sol and Gemini 4 Argon planners the three views did not move together; the GPT-6.1 Sol agent's correct answers rose from 14.6% to 26.8%, but at episode 8 only 59-68% were supported by its cited evidence.

arxiv:2611.26912 arXiv ✓
Self-Evolving Beyond Human-Crafted Experience for EDA Scripting
超越人工经验的自演化：面向 EDA 脚本编写的执行锚定智能体
self-evolution execution traces three-tier memory EDA scripting anti-leakage retrieval
ZhuLong-SE is an execution-grounded LLM agent for EDA scripting that adds API retrieval, documentation responses, isolated sandbox execution and static checking to a task harness, then distills past traces into a three-tier memory store governed by ground-truth anchoring, disconfirmation filtering, held-out rollback and anti-leakage retrieval. The full task-level harness with self-evolution disabled reaches 92.4% pass@1 on the 158-task EDA-Eval-PyAether benchmark, and self-evolution from a bare configuration beats a human-crafted-experience baseline by 2.5 points (80.0% vs. 77.5%).

arxiv:2611.26510 arXiv ✓
AutoMaster: Autonomous Post-Training by Making the Same Model a Better Teacher
AutoMaster：让同一模型成为更好的教师，实现自主后训练
autonomous post-training skill-guided fine-tuning teacher trajectories behavioral shaping
AutoMaster is an autonomous post-training system in which an LLM agent designs natural-language skill interventions from trajectory analysis, data selection and rollout feedback, then fine-tunes a student on the resulting teacher trajectories. Across Terminal, Search and software-engineering tasks with 4B and 9B students it improves mean performance over vanilla SFT by 1.42-8.99 percentage points with the teacher and data held fixed, and retaining skill instructions during SFT performs better in all six settings.

Mind2Act World: A Diagnostic Benchmark for Embodied Mind, Physical Action, and Mind-Action Composition in Robotic Manipulation
Mind2Act World：机器人操作中具身思维、物理行动与思维—行动组合的诊断基准
embodied benchmark mind-action composition robotic manipulation diagnostic evaluation
Mind2Act World is a 30-task, 180-configuration benchmark that separates reasoning, physical execution and their composition in robotic manipulation. The strongest agent scores 52.7% on Mind, 39.0% on Act and only 12.0% on Mind2Act.

arxiv:2611.26613 arXiv ✓
AgentRoboCritic: Understanding the Capability of Frontier Agents on Direct Robot Control
AgentRoboCritic：理解前沿智能体直接控制机器人能力的意图锚定批评框架
action-level critique intent grounding robot control failure-mode analysis
AgentRoboCritic is an intent-grounded critique framework in which a policy agent states a local intent alongside each action and a critic evaluates the action's outcome and failure mode against that intent, applied across 12 manipulation benchmarks. The authors release 12,844 annotated actions and a fine-tuned open-source critic, Muse-Glimmer-30B, whose failure-mode accuracy rises from 32.58% to 74.24% on a 400-action human-annotated benchmark.

Beyond Demographic Discrimination: Benchmarking Normative-Descriptive Calibration in LLMs
超越人口统计歧视：评估 LLM 的规范性—描述性校准
normative reasoning benchmark calibration prompt framing fairness evaluation
The paper introduces normative-descriptive calibration, measuring whether a model treats matched candidates differently when asked to predict an outcome versus decide one, through 697 matched-pair scenarios across six domains and three metrics. Normative-descriptive separation distinguishes 13 of 15 model pairs, Claude Sonnet 4.6 and Opus 4.6 show the strongest separation, and all six models favor whichever candidate is listed first when forced to choose between identical candidates.
