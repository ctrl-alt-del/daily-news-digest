Jais 3：面向阿拉伯语的智能体 AI
Arabic language model agentic models continual pretraining open weights long context
Jais 3 is a fleet of six open Arabic-centric agentic models from 0.9B to 375B parameters, adapted from the K2 Horizon fleet through continual pretraining, supervised fine-tuning, preference optimization and reinforcement learning with verifiable rewards, with a 512K-token context window on all but the smallest model. arxiv:2611.09807 arXiv ✓
Compaction, decay and reinforcement in a two-tier conversational memory: a paired evaluation against retrieval-augmented generation
两层对话记忆中的压缩、衰减与强化：与检索增强生成的配对评估
conversational memory memory compaction retrieval-augmented generation paired evaluation
The paper compares a two-tier conversational memory that compacts each turn into atomic facts against retrieval-augmented generation on LoCoMo, with both arms answering all 1,985 questions using the same stores, generator and judge. Compaction leads by 6.8 points (71.4% versus 64.6%) on four categories at 34% fewer prompt tokens, but the lead falls to a non-significant 2.0 points when an adversarial set is included, and reverses when answers require exact source wording.
→ arxiv.org
arxiv:2611.10238 arXiv ✓
CoRA-Bench: Evaluating Evidence Preservation by Context Selectors Under Token Budgets
CoRA-Bench：在 token 预算下评估上下文选择器的证据保留能力
context selection evidence preservation token budget retrieval benchmark
CoRA-Bench evaluates whether context selection methods preserve the evidence needed to answer a query under shared token budgets, comparing truncation, BM25, dense retrieval, reranking, LLMLingua-2 and Provence on BABILong, LOONG, NoLiMa and LongMemEval. It finds task-dependent tradeoffs, with method rankings varying across evidence types and between evidence recall and downstream accuracy.
→ arxiv.org
DeepSeek arxiv:2611.10176 arXiv ✓
AVCORP: Identifying and Resisting Deception via Communication Theory and Theory of Mind
AVCORP：结合传播理论与心智理论识别并抵御欺骗
deception detection theory of mind annotated corpus multi-agent dialogue
AVCORP is a corpus of 5,000 annotated utterances from 250 games of Avalon, with 37 deception tactics mapped to a 4x4 behavior matrix and reasoning traces capturing abductive hypotheses, suspicion levels and nested theory-of-mind beliefs. A Qwen3-8B detector trained on it matches Claude Opus 5.5 on held-out games and beats GPT-5.6 Sol, Gemini 3.1 Pro and DeepSeek-V4-Pro.
→ arxiv.org
arxiv:2611.09863 arXiv ✓
Flow-Guided Target-Space Alignment via Path Consistency
基于路径一致性的流引导目标空间对齐
embedding alignment conditional flow matching multimodal alignment representation geometry
FlowAlign repurposes conditional flow matching as a training-time alignment signal that guides source-side representations toward a fixed target space while preserving paired correspondence and global target structure. Experiments on synthetic data, paired single-cell multiome benchmarks and image-text alignment show improved instance-level correspondence.
→ arxiv.org
