Recursa: Toward Recursively Self-Improving Foundation Model Systems
Recursa：迈向递归自我改进的基础模型系统
knowledge repository recursive self-improvement experiential learning skill acquisition domain adaptation
Recursa adapts foundation models to unfamiliar domains by bootstrapping a knowledge repository of domain skills, instructions on when to apply them, task memories and reflections, then refining it through recursive self-improvement with parallel learners that validate and merge local improvements. On Harvey LAB's Firm Knowledge benchmark, it raises all-pass rates on held-out tasks from 30.0% to 55.0% with DeepSeek-V4.1-Flash and from 35.0% to 46.0% with Qwen3.8-Flash.

What Is This Memory Useful For? Measuring Task-Conditioned Utility in Long-Term Agent Memory
这段记忆有什么用？衡量长期智能体记忆的任务条件效用
agent memory memory utility task-conditioned evaluation memory compression long-term memory
The paper measures task-conditioned memory utility with a task-blind writer, a frozen reader that answers with and without a memory under identical filler, and a cost ledger for forming, storing and exposing memories. On LongMemEval-V2 web-agent memories, answer-bearing memories produce a mean paired reward gain of +0.33 over matched controls, but the gains do not extend to the tested software-engineering and scientific-coding benchmarks.

arxiv:2611.04079 arXiv ✓
AlgoPilot: Cross-Paradigm Reasoning in Language Models via Strategy Selection and Guidance
AlgoPilot：通过策略选择与引导实现语言模型的跨范式推理
strategy selection problem formulation cross-paradigm reasoning small language models reasoning benchmark
AlgoPilot trains a SteerLM to select a problem-solving paradigm and mode, a GuideLM to produce structured formulation guidance for that choice, and an ExecutionLM to solve the problem conditioned on both. Built on Qwen3-8B, it raises average accuracy across 13 benchmarks and 66 domains from 38.4% to 72.9% and beats the best large-LLM prompting baseline, GLM-5, by 11.7%.
→ arxiv.org
arxiv:2611.03641 arXiv ✓
From Natural Language to Exact Cover: A Neuro-Symbolic Approach to Zebra Puzzles
从自然语言到精确覆盖：Zebra 谜题的神经符号方法
neuro-symbolic reasoning semantic parsing exact cover logical reasoning solver feedback
The framework combines neural semantic parsing with deterministic exact-cover solving: an LLM translates a natural-language Zebra puzzle into structured tool calls that build an exact-cover instance, and a symbolic solver returns a solution or feedback used to refine invalid or under- and over-constrained encodings. The authors report that the hybrid approach consistently outperforms chain-of-thought prompting and recent neuro-symbolic baselines across model scales and families.
→ arxiv.org
arxiv:2611.03826 arXiv ✓
Rethinking Next-Visit Diagnosis Prediction Beyond Aggregate Metrics: Retrieval--Memory Multi-Agent Adjudication
超越聚合指标重新思考下次就诊诊断预测：检索—记忆多智能体裁决
retrieval-memory fusion multi-agent adjudication clinical prediction electronic health records evaluation framework
LONGINUS combines evidence retrieved from patient records with structured memory of a patient's trajectory and uses cross-view agreement as a reliability heuristic to preserve shared predictions and adjudicate disagreements without revealing their source. Across MIMIC-III and MIMIC-IV with four LLM backbones, it reports the best transition-specific performance among LLM-based methods in nearly all settings while remaining competitive on aggregate metrics.
→ arxiv.org

arxiv:2611.03927 arXiv ✓
Modular and Efficient Approximate Nearest Neighbors Search with Vectorium and kANNolo
Vectorium 与 kANNolo：模块化高效的近似最近邻搜索
approximate nearest neighbor search vector index quantization open-source library retrieval infrastructure
Vectorium and kANNolo are open-source Rust libraries that separate vector data management from indexing, supporting dense, sparse and multi-vector representations with 11 encoders and generic HNSW, IVF and two-stage indexes. The authors report state-of-the-art memory-throughput trade-offs, matching Faiss product quantization in accuracy at competitive speed and outperforming Faiss IVF on their benchmarks.
