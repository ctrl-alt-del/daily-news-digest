Benchmark Factory: Agentic Benchmark Creation via Dataset Curation and Label-Free Quality Anchors
Benchmark Factory：通过数据集整理与无标签质量锚点创建智能体基准
benchmark creation coding agents quality anchors label-free validation
Benchmark Factory is an autonomous meta-agent loop with human checkpoints that writes sourcing queries over production code changes, runs models of known relative strength, diagnoses failures, and repairs candidate benchmarks until they clear label-free quality anchors. On configurations never used to build them, its benchmarks ranked Claude Opus 4.7 at high over low reasoning effort (60.6% vs 54.4%) and GPT-5.5 over GPT-5.4 (65.8% vs 60.5%), with 9 of 10 per-cohort comparisons agreeing.

arxiv:2611.18516 arXiv ✓
StreamEmbed: Real-Time Indexing from Pixels for Screenshot Retrieval
StreamEmbed：从像素进行实时索引的截图检索
incremental embedding visual memory screenshot retrieval KV cache reuse
StreamEmbed incrementally embeds screenshots by using pixel differences to prune repeated spatial tokens and reuse cached keys and values across frames, with a small learned adapter preserving fidelity to full-screenshot embeddings. On ScreenMemEval it encodes up to 3.7x faster than full encoding at no accuracy loss, beats OCR-based indexing by up to 6.3 Recall@10 points at matched latency, and stores a simulated year of screenshots in 0.13 GB of RAM.

WeightBench: Evaluating Language Models as Weight-Space Programmers
WeightBench：评估语言模型作为权重空间程序员
weight-space programming benchmark model internals agentic evaluation
WeightBench evaluates LLMs on 42 weight-space programming tasks across reading, fixing and writing weights, recognizing impossible edits, and data-free compression, with networks from 2K-parameter control policies to 7B language models. Frontier agents can read small networks and write working control policies without running them, but cannot yet patch or compress language models or distinguish impossible edits; Claude Opus 5.5 reaches a 0.535 macro score.

Context Matters: Improving LLM-Based Code Summarization with Hierarchical Information
上下文很重要：用层级信息改进基于 LLM 的代码摘要
code summarization hierarchical context documentation LLM evaluation
The study varies the function-, class- and module-level context visible to several LLMs when generating code-level documentation and compares the results with existing documentation as a proxy for developer intent. Documentation-aware prompts with class or module context consistently produce summaries closest to the original docs, with statistically significant gains over the baseline whose effect sizes range from negligible for DeepSeek to medium for Gemini.

arxiv:2611.18494 arXiv ✓
ARCHER: From Rationale Imitation to Executable Reasoning in Small Language Models
ARCHER：从小模型的有理据模仿到可执行推理
executable reasoning tool use small language models reinforcement learning
ARCHER is a two-stage framework that first compiles free-form chain-of-thought rationales into typed action traces with calculator calls, runtime observations and verification, then refines the policy with asymmetric hierarchical reinforcement learning. Across five sub-10B backbones it beats the strongest tool-augmented baseline by 5.51 points macro-average, including 8.95 points on MATH-500 and about 5.3 points on AIME-2024 and AIME-2025.

arxiv:2611.18908 arXiv ✓
MemeEconomy: Do LLM Agents Trade Ethics for Survival?
MemeEconomy：LLM 智能体会为生存而交易伦理吗？
agent ethics BDI logging harmful content alignment under pressure
MemeEconomy is a multimodal agentic market simulation in which LLM agents choose content from a five-tier harm taxonomy under low- and high-pressure environments, logging each decision in a Belief-Desire-Intention schema. Across ten models harmful selection rates rise by 15 percentage points on average under survival pressure, and a 2B verifier trained on the BDI logs reaches 97.5% accuracy on in-distribution Pass-versus-Block audits and 78% on Hateful Memes.
→ arxiv.org
arxiv:2611.18883 arXiv ✓
SPLICE: Structured Prompt Local Iterative Combinatorial Evolution
SPLICE：结构化提示的局部迭代组合演化
prompt optimization natural language optimization constrained search contract preservation
SPLICE treats natural-language optimization as constrained combinatorial search over an edit graph of block-structured, selectively mutable prompt states, with per-block mutability, elitist beam search and a length regularizer matched to three failure modes. Across seven public benchmarks under five reproduced protocols it wins on four and matches the strongest prior method on three, and it preserves contract clauses that unconstrained optimizers trade away on a contract stress test.
→ arxiv.org
