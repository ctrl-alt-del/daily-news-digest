OverServe: Resource Amplification Attacks on SaaS Agents via Tool--Prompt Co-Design
OverServe：通过工具—提示协同设计对 SaaS 智能体发起资源放大攻击
resource amplification MCP tools completion prompting SaaS agents
OverServe is a multi-agent framework that co-designs MCP status tools and completion-confirmation prompts so a SaaS agent repeatedly checks an unfinished condition while each call returns accurate status and terminates normally. Across nine benchmarks on Qwen, Nemotron, DeepSeek and Sonnet it preserves the original task checks while reaching up to 93.88x amplification of API requests, and the tested tool specifications triggered no alerts in evaluated MCP scanners.
→ arxiv.org

Continual-ARC: Measuring Skill Acquisition over a Working Lifetime
Continual-ARC：衡量整个工作生命周期内的技能获取
continual learning skill acquisition agent harness weight-based learning benchmark design
Continual-ARC is a lifelong benchmark built from the three ARC-AGI editions in which tasks return after dormant gaps with fresh instances, and learners pay for demonstrations, submissions and retries from a feedback budget. In runs with Qwen3.5-9B and GLM-5.3 Flash, harness persistence generally did not improve memorization without explicit expert guidance, most harness methods learned less than a simple demonstration-caching floor, and weight-based learning showed substantial gains on unseen tasks.
→ arxiv.org

Where Should the Code Go? Locating Foundation-Model Errors in Bitemporal Inventory Simulation
代码应放在哪里？在双时态库存仿真中定位基础模型错误
error localization tool-calling interface reasoning effort foundation-model components
The study uses a lost-sales inventory environment with 36,672 independently rescored requests across twelve closed and open-weight model configurations to test whether exact code placed before, after or inside a foundation-model call removes specific errors. It finds that canonical input removes report-selection error and exact continuation removes rollout error, neither repairs the other, and forced-answer interfaces can confound reasoning evaluation for some model and provider pairs.
→ arxiv.org
arxiv:2611.14661 arXiv ✓
Abstention Is Not Threshold Compliance: Stated Scoring Rules in Open Language Models
弃权不等于阈值合规：开放语言模型中声明的评分规则
abstention threshold compliance calibration prompt formatting
The paper probes stated-threshold scoring rules across 12 checkpoints from four open 3-8B recipes and finds that an abstention-format line raised mean abstention from 20% to 91% at t=0.75, yet raising the threshold from 0.5 to 0.9 changed abstention by only -0.8 percentage points. It concludes that a high abstention rate is not evidence of threshold compliance and recommends reporting abstention rates, threshold sensitivity and which items are answered.
→ arxiv.org

BypassGym：评估 AI 智能体端点防御规避能力的基准
endpoint evasion agent security malware generation benchmark environments
BypassGym evaluates whether LLM agents can build loaders that execute command-and-control shellcode without being blocked by endpoint detection and response systems, running real Windows systems and six EDR products in virtual machines. Together Compiler: Continual Compilation for AI Inference
Together Compiler：面向 AI 推理的持续编译
continual compilation agent context management inference optimization production agent loop
Together Compiler (TKCC) is a continual agent loop for AI inference optimization that uses a tiered persistent engine to decouple launch overhead from computation and a cost model to seed parallelism choices. It reports up to 1.7x over hand-written Megakernels on Llama 1B and up to 2.6x higher TPS than the best open-source engines on the InferenceX benchmark, with 1111 TPS on MiniMax M3.1 Flash and 1205 TPS on DeepSeek v4.1 Flash at batch size 1.
→ arxiv.org

Beyond Row-Level Prediction: Evaluating and Learning Composition for Reusable Table Representations
超越行级预测：评估与学习可复用表格表示的组合方式
table embeddings compositional representation retrieval benchmark partial-view consistency
The paper introduces a benchmark that evaluates table-level embeddings on consistency under partial views, discriminability across label granularities, robustness to perturbations and efficiency, finding lightweight schema- and text-based fingerprints among the strongest of twelve methods. Learning only a compositional rule over a frozen ConTextTab's cell states raises the Spearman correlation between embedding similarity and partial-view overlap from 0.04 to 0.43-0.50 on synthetic data.
→ arxiv.org
arxiv:2611.14357 arXiv ✓
The Unused Input: The Initial State as a Conditioning Interface for Recurrent TSFMs
未被使用的输入：初始状态作为循环时序基础模型的条件接口
recurrent state state conditioning time-series foundation model representation injection
The paper freezes an xLSTM-based TiRex time-series backbone and trains only a small head that writes a context vector into the initial recurrent state, so accuracy changes are attributable to the injected state. A learned spectral summary lowers mean GiftEval MASE by 0.175%, and a text-conditioned state gives further small gains on four of six MoTime datasets; the authors call the results preliminary.
→ arxiv.org
