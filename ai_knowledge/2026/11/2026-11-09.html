Teaching the Harness: Student-Aware Skill Transfer for LLM Agents
教授智能体框架：面向 LLM 智能体的学生感知技能迁移
skill transfer learner modeling agent harness skill library
Student-Aware Teaching builds a learner model that pairs an empirical profile with hypotheses about a student agent's limitations, tests them with diagnostic probes, and admits reusable skills only when they raise success on matched development tasks. With Claude-Sonnet-5 teaching DeepSeek-V4-Flash it reaches 86.46% task success versus 81.04% for a profile-free teacher and 75.00% for the untaught student, and saved libraries retain gains of up to 11.1 points.

ExpertCrowd-SWE: Measuring Frontier Coding Agents on Expert-Authored Engineering Tasks in Unfamiliar Codebases
ExpertCrowd-SWE：在不熟悉代码库中衡量前沿编程智能体的专家级工程任务
coding agent benchmark multi-file tasks contamination control frontier model evaluation
ExpertCrowd-SWE is a benchmark of 100 expert-authored, multi-file software engineering tasks drawn from 87 open-source projects in 11 languages, with sealed reference solutions and task-specific weighted graders. Across 3,495 scored runs, Claude Opus 5.5 (67.3%) and GPT-6 Astra (63.7%) lead without a statistically significant gap, while Qwen 3.8 Max, DeepSeek V4.1 Flash and Grok 4.6 cluster at 32-34%.

Veritas: A Verifier Generation Harness for Agent Tasks
Veritas：面向智能体任务的验证器生成框架
verifier generation self-improvement loop agent harness domain rules
Veritas is a harness that automatically generates verifiers for agent tasks by adding an evidence header, a library of domain rules that tasks leave unstated, and authoring principles partly refined through a self-improvement loop. With the model fixed, its verifiers agree better with official verdicts than those of seven other harnesses on all four execution-scored benchmarks.

F3-AGI v4.0: Bioenergetically-Gated Active Inference, Metaplastic Preconditioning, and Residual Program Synthesis for Sample-Efficient Abstract Reasoning
F3-AGI v4.0：面向样本高效抽象推理的生物能量门控主动推断、元可塑预处理与残差程序合成
neuro-symbolic reasoning program synthesis sample-efficient learning ARC-AGI
F3-AGI v4.0 is a CPU-native neuro-symbolic architecture combining mistake-gated plasticity, complexity-guided program synthesis and random-projection-driven expected-free-energy exploration. On the 400-task ARC-AGI-1 public evaluation set it solves 57 tasks (14.25% pass@2) with 1.62 s mean latency and no LLM calls, and it completes all 15 levels of a local ARC-AGI-3-inspired suite.

AgentScript-Eval: Benchmarking LLMs and Agents for Code Generation in an Enterprise DSL
AgentScript-Eval：评估 LLM 与智能体在企业 DSL 中代码生成的基准
enterprise DSL code generation benchmark agentic compile-and-edit domain guidance
AgentScript-Eval is an execution-graded benchmark of 100 real tasks for AgentScript, the declarative DSL Salesforce uses in Agentforce, covering authoring, debugging and optimizing conversational agents. The best of five zero-shot models reaches only 25.0% pass@3 and all score 0% on authoring from scratch, while an agentic compile-and-edit loop roughly doubles partial-credit accuracy.

arxiv:2611.13140 arXiv ✓
Agreeing on the Answer but Not the Reason: Measurement Limits of LLM Reasoning Failure Taxonomies
答案一致但理由不同：LLM 推理失败分类法的测量局限
failure taxonomy annotation reliability reasoning evaluation measurement validity
The paper shows that reported shares of an LLM reasoning-failure category can be largely an artifact of the measurement procedure: across six classifier orderings the share of Compositional Collapse spans 26.4% to 76.4%, and native speakers agree with the inspector at kappa 0.932 on answer correctness but only 0.093 on the category. It recommends reporting label co-occurrence, permuting tie-breaks, validating on a shared sample and auditing systematic disagreements.

ProTEUS：面向闭环蛋白质进化的突变分辨世界模型
