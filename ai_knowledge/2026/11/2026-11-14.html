VAST: Compiling Grounded Vulnerability Scenarios into Verifiable, Multi-Step Environments for Evaluating LLM Red-Team Agents
VAST：将真实漏洞场景编译为可验证多步环境，用于评估 LLM 红队 Agent
red-team agents vulnerability scenarios workflow hardening agent security evaluation
VAST is a declarative range compiler that separates vulnerability scenarios from a workflow-hardening layer, producing reproducible, multi-step environments for evaluating LLM red-team agents. In a budget-matched 270-episode prompt contrast, supplying the shared workflow protocol in full guidance lifts completion from 14/90 to 76/90 for glm-5.3, grok-4.7 and deepseek-v4-pro, and the main benchmark retains 1,387 instances.

arxiv:2611.19656 arXiv ✓
BadGCL: Towards Persistent Backdoor Attack on Graph Continual Learning Systems
BadGCL：面向图持续学习系统的持久后门攻击
graph continual learning backdoor persistence structural triggers knowledge preservation
BadGCL is a model-agnostic framework for persistent backdoor attacks on graph continual learning, learning topology-aware structural triggers through a gradient mutual-information objective. The authors show that knowledge-preservation mechanisms can also retain early poisoned updates, and report persistent attack effectiveness across task-IL and class-IL protocols on four benchmarks with limited clean-utility degradation.

product entity resolution dense blocking cross-encoder verification e-commerce knowledge

arxiv:2611.19448 arXiv ✓
CLEW: Log-Anchored Backward Tracing for Root-Cause Code Localization
CLEW：基于日志锚定的反向追踪根因代码定位
root-cause localization log-to-code anchoring backward tracing code diagnostics
CLEW combines rule-based log-to-code anchoring with LLM-guided backward code tracing, organizing observations into diagnostic states and returning ranked candidate functions with an affected module and an evidence-linked explanation. On the new LogLoc benchmark of 192 real-world issue and fault-injection cases it reaches 77.3% Acc@1 and 81.3% MRR on LogLoc-Issues, with wall-clock time about 73% lower than LocAgent averaged over all cases.

化繁为简！多项选择任务也能提升生成式推荐

InvarOrd: Self-Supervised Ordinal Knowledge Distillation with Rank-Invariant Alignment for Label-Efficient Cross-Species Hyperspectral Fish Freshness Assessment
InvarOrd：基于秩不变对齐的自监督序数知识蒸馏，用于少标签跨物种高光谱鱼类新鲜度评估
ordinal knowledge distillation rank-invariant alignment cross-species transfer label-efficient adaptation
InvarOrd adapts a hyperspectral freshness model to a new fish species from 30 labelled cubes using self-supervised spectral pretraining, rank-invariant cross-species alignment and ordinal distillation into a compact student. The 423K-parameter student reaches 1.476 days MAE and 56.1% within-1-day accuracy on paired salmon and cod data, beating target-only training by 0.29 days.

Sada-ASR：面向生产的阿拉伯语多方言语音识别系统
multidialectal speech recognition production voice agent word error rate dialect robustness
Sada-ASR is the speech recognizer behind EchoNova's production Arabic voice agent; on a 120-hour test set covering Modern Standard Arabic and eight dialects it records an 11.69% word error rate, the lowest of twelve systems and ahead of Microsoft's MAI-Transcribe-2 at 13.51%. The authors also release a 20-hour subset of the test set with their scoring code.
