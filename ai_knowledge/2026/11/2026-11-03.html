Octopus: One Brain, Many Branches for Latent-KV Multi-Agent Reinforcement Learning
Octopus：面向隐式 KV 多智能体强化学习的一脑多分支架构
KV cache sharing multi-agent RL long-horizon search context management benchmark accuracy
Octopus is a co-designed serving runtime, memory manager and RL framework that executes long-horizon agent episodes as a GPU-resident DAG over radix cursors, with fork, rewind, read_thread, wait and done primitives for sharing and mounting KV cache. Trained on Qwen3.5-4B, it raises BrowseComp-Plus accuracy under BM25 from 26.0% with 32K ReAct and 32.1% with 143K GRPO to 49.6%, and reports a 21x reduction in cache hijacking.

arxiv:2611.05636 arXiv ✓
Route to Remember: Adaptive Memory Selection for LLM Agents
Route to Remember：面向 LLM 智能体的自适应记忆选择
weight memory on-policy self-distillation memory routing long-term memory hallucination benchmark
The paper applies on-policy self-distillation to train a context-free student from the same model conditioned on a user's memory, making weight memory competitive as a long-term factual store, and adds a verify-then-regenerate router that sends each query to weight or text memory. On HaluMem, it matches or surpasses strong text-memory baselines while reading fewer tokens per query.

SlackBench: Benchmarking Agents on Collaborative Projects Grounded in Real Code Repositories
SlackBench：在真实代码仓库协作项目中评估智能体
collaborative work benchmark agentic search context recovery repository state abstention
SlackBench is a benchmark of 140 queries built from privacy-preserving reenactments of real academic research projects, requiring agents to search multi-party dialogue, inspect evolving GitHub repositories and Google Docs, reconcile stale or conflicting evidence, and abstain on unanswerable questions. Across 33 frontier models and agent harnesses, the best system scores around 80% and most agents fall below 66%.

arxiv:2611.05609 arXiv ✓
On the Generalization Limitation of On-Policy Distillation for Post-RL Consolidation
论策略内蒸馏在后强化学习能力巩固中的泛化局限
on-policy distillation capability consolidation out-of-distribution generalization catastrophic forgetting post-RL training
The paper finds that on-policy distillation and multi-teacher on-policy distillation can reach 96.04-102.73% of teachers' in-distribution scores on extrapolative tasks while scoring 2.45-16.25% below the base model out of distribution, and that compositional OOD performance remains 18.19-24.34% below the best teachers. It examines teacher capability and data coverage as bottlenecks and proposes geometry-based patching and base-preserving replay.

arxiv:2611.05345 arXiv ✓
Adversarial Speculative Reasoning Improves Long Horizon Agents
对抗式投机推理提升长程智能体
speculative decoding long-horizon reasoning context precision draft model agentic coding
The authors argue that speculative decoding is not behavior-neutral for long-horizon agents, because numerical noise within verification windows can shift the output distribution after 30 steps. They train draft models to be rejected at critical reasoning points so those tokens are sampled from the target model, and report higher end-to-end success on agentic coding benchmarks by training 0.06-0.28% of hosted parameters without changing the target model.
→ arxiv.org
OpenAI arxiv:2611.05548 arXiv ✓
Iterated creation, grading, and revision of data science projects by language models
语言模型对数据科学项目的迭代创建、评分与修订
agentic data science iterative feedback LLM-as-judge self-evaluation multi-agent workflow
The study runs 147 initial data-science project submissions from seven models across five developers through three rounds of writer grading and revision; 107 run and render, and average scores rise from 59% to 76%. It finds that self-grading tends to be about 9 percentage points above peer scores and that weaker models generally do not improve stronger ones when acting as graders.
