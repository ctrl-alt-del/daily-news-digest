DeepSeek arxiv:2611.23386 arXiv ✓
Chorus: Shared N-gram Embeddings with Layer-wise Adaptation
Chorus：共享 N-gram 嵌入与逐层自适应
n-gram embeddings parameter sharing layer-wise adaptation memory-efficient optimizer
Chorus shares one set of n-gram embedding tables across all layers of a language model, with each layer rescaling and projecting the shared embedding according to its current hidden state. It matches existing n-gram methods with 87% smaller tables, beating Engram and FactorEngram with 1.2B table parameters versus 9.6B, and pairs with the Ember optimizer to save 99.2% of table-optimizer memory.
→ arxiv.org
arxiv:2611.23588 arXiv ✓
ARISE: Practical Self-Evolving Memory for Accurate and Cost-Efficient Enterprise Agents
ARISE：面向准确且低成本企业智能体的实用自演化记忆
self-evolving memory failure attribution rule consolidation enterprise agents held-out validation
ARISE evolves an agent's memory from its own failures without changing model weights, tools, or workflow logic: it attributes failures, stores corrections as retrievable micro-memory, consolidates them into macro rules, and accepts a rule only when held-out accuracy improves. Across 14 enterprise-workflow domains with five models, ARISE-Teacher gains 10.9 points on SOP-Bench and 5.8 on τ²-bench, and also beats GEPA on both benchmarks.

Retrieval-Augmented Correction for Generalist Medical Image Segmentation
面向通用医学图像分割的检索增强校正
retrieval-augmented correction medical image segmentation verified case knowledge base shape prior dataset transfer
GRACE is a retrieval-augmented refiner that edits segmentation masks using context from a shared knowledge base of verified prior cases, trained once on a multi-organ corpus instead of one corrector per anatomy. Across 18 public CT, MRI and ultrasound datasets it adds up to +0.35 DSC on weak segmentors, while transfer to an unseen imaging modality remains partial and anatomy-dependent.
→ arxiv.org

Agent Verifiers in Counterfactual Analysis: A Pilot Study Benchmarking Agentic Heterogeneous Treatment Effects
反事实分析中的智能体验证器：智能体异质处理效应基准测试试点研究
retrieval leakage agent verifiers treatment-effect heterogeneity temporal filtering encoder leakage
This pilot study proposes a three-layer protocol for verifying agent-retrieved covariates in heterogeneous treatment-effect analysis, covering retrieval admissibility, heterogeneity validation, and encoder admissibility across 11 datasets. A persistent workspace teammate produced higher mean RATE ratios in 6 of 11 datasets for text alone and 7 for combined features, though paired tests showed neither workflow universally dominates.

arxiv:2611.23608 arXiv ✓
JEPA as a Transferable Optimizer: Learning and Understanding Black-Box Optimization from Reward-Agnostic Pretraining
JEPA 作为可迁移优化器：从无奖励预训练中学习并理解黑盒优化
black-box optimization joint-embedding predictive architecture search history zero-shot transfer
JEPA-PS pretrains a joint-embedding predictive architecture on random optimization rollouts to predict the next point in a search trajectory rather than its reward or gradient, then proposes candidates in one forward pass. It is competitive with tuned classical baselines across 15 control environments, beats an LLM optimizer by more than 2x on Swimmer at 71x lower per-step cost, and transfers zero-shot to environments excluded from pretraining.
→ arxiv.org
arxiv:2611.23454 arXiv ✓
LusoClin: A Synthetic Clinical Note Dataset for Medical Information Retrieval in European Portuguese
LusoClin：面向欧洲葡萄牙语医学信息检索的合成临床笔记数据集
synthetic clinical notes medical information retrieval semantic indexing low-resource language
LusoClin is a publicly released dataset of synthetic European Portuguese clinical notes generated by fine-tuning Llama 3.2 3B with QLoRA on pre-processed real clinical data and annotating clinical entities with a BERT-based model. Evaluations indicate it captures clinically relevant language and supports retrieval tasks, though annotators can often distinguish synthetic from real notes and some medical inconsistencies remain.

arxiv:2611.23202 arXiv ✓
Agent Trust Infrastructure (ATI): A Federated Identity, Trust, Attestation, and Accountability Architecture for Cross-Organization Autonomous AI Agents
智能体信任基础设施（ATI）：跨组织自主 AI 智能体的联邦身份、信任、证明与问责架构
agent identity remote attestation zero trust cross-organization agents
ATI is a framework-independent security architecture built on PKI, Zero Trust and remote attestation that verifies cross-organizational agent identity, approved model, tool and system-prompt configurations, and authorization before requests execute. In a simulated eight-organization federation, enabling all enforcement mechanisms raised attack containment from 43% to 84% at roughly 174 microseconds of overhead per request.

GuardAgent: A Memory-Augmented Agentic Framework for Adaptive Detection of Adversarial Promotions in LLM-Based Recommendation
GuardAgent：面向 LLM 推荐系统对抗性推广自适应检测的记忆增强智能体框架
