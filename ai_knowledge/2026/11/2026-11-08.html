Self-Indexing Latent Memories for Access-Aware Continual Instruction Tuning of LLMs
自索引潜在记忆：面向 LLM 的访问感知持续指令微调
latent memory continual instruction tuning prompt-only routing catastrophic forgetting
TILA-CT is a replay-free continual instruction-tuning method that gives each task a latent memory and adapter bank in a frozen LLM, with the memory's persistent state serving as the routing prototype for a shared prompt-only router. On an 8-task CT-Pipeline stream it reaches 65.19 acquisition and 63.98 final macro score with 1.38 points of average forgetting, and final macro routing accuracy is 93.9%.

arxiv:2611.11486 arXiv ✓
MicroSim: Contrastive Graph Neural Networks for Binary Code Similarity Detection
MicroSim：用于二进制代码相似性检测的对比图神经网络
binary code similarity graph neural networks contrastive learning representation evaluation
MicroSim represents each function as a graph built from IDA Pro Hex-Rays microcode and compares such graphs with a contrastive Siamese graph neural network. On the TREX cross-optimization benchmark with 849,072 function-level microcode graphs and a strict class-disjoint split, it reaches 0.9972 ROC-AUC and 0.9762 MCC, outperforming Gemini, SAFE and jTrans retrained on the same split.

arxiv:2611.11581 arXiv ✓
Same Error, Different Recovery: How Delivery Changes LLM Agent Behavior
相同错误，不同恢复：错误呈现方式如何影响 LLM 智能体行为
tool error recovery error delivery agent reliability stopping behavior
A study across 13 open models from 3B to 70B parameters finds that the same tool error can lead to different retry, correction or stop behavior depending on how it is delivered. Retaining the failed exchange in a new user turn avoided severe stopping failures in Llama models and, as an opt-in recovery layer on ToolMaze, raised success on explicit errors by 14.2 points for 7-8B models and 10.5 points for 32-70B models.
→ arxiv.org
arxiv:2611.11470 arXiv ✓
GOPR-CAD: Graph-of-Operations Progressive Reasoning for CAD Generation
GOPR-CAD：面向 CAD 生成的运算图渐进推理
agentic CAD generation operation graph progressive reasoning structural fidelity
GOPR-CAD is an agentic text-to-CAD pipeline in which a language model acts as a decision agent over encapsulated CAD operations and progressively builds an executable operation graph that a deterministic compiler converts into the final model. It reaches 82.7% structural yield on the new 300-part MHCAD benchmark and 87.2% on an external CADPrompt subset.

LocateAnyMesh：用视觉语言模型在二维图像中定位三维网格查询
mesh tokens multimodal grounding vision-language models object localization
