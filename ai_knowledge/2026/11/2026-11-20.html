Engram: Multi-Stage Memory for Agentic Tuning of Heterogeneous Models
Engram：面向异构模型智能调优的多阶段记忆
agent memory cross-session reuse knowledge distillation model tuning
Engram is a multi-stage memory system that links past trial outcomes to the hypotheses and rationale behind them and assesses whether that evidence applies to the current model. An online agent supplies guidance, retrieves related sessions and reviews trial candidates, while an offline agent distills validated lessons; on two ads models it reaches a no-memory control's 32-trial result with 47% fewer trials.

Topology Hub 最优传输：以闪电速度消除长上下文稀释

Who Grades the Agent? Privilege Separation for Coding-Agent Benchmarks
谁来给 Agent 打分？面向编程 Agent 基准测试的权限分离
benchmark integrity privilege separation coding agents adversarial evaluation
SplitBench is a privilege-separation framework that separates running a coding task's tests from judging their results, so an agent that takes over the whole test environment still cannot forge a pass because a trusted grader holds the expected answers. Porting Terminal-Bench and DeepSWE, 180 of 202 tasks converted with 98.7% agreement against native graders, and SplitBench blocked 75% of worst-case adversarial attempts.

Epistemic Guard: Out-of-Process MCP Receipt Proxying, Post-Turn Prose Supervision, and Provenance-Gated Memory for Tool-Using Autonomous Agents
Epistemic Guard：面向工具型 Agent 的 MCP 凭证代理、回合后文本监督与来源门控记忆
MCP tool receipts provenance-gated memory RAG deduplication tool-use verification
Epistemic Guard is an open-source Python library and out-of-process MCP receipt proxy that checks post-turn prose against signed tool receipts, gates SQLite memory writes by provenance, and collapses syndicated RAG mirrors. DM-Lab at TREC 2026 RAG: Multi-Query Retrieval, Ensemble Judging, and Claim-Pack Generation
DM-Lab 在 TREC 2026 RAG：多查询检索、集成评判与声明包生成
multi-query retrieval citation grounding listwise reranking claim verification
DM-Lab-RAG-2026 combines multi-query BM25, reciprocal rank fusion, ensemble relevance assessment, listwise reranking and adaptive retrieval depth over the 553-million-document ClimbMix-400B corpus, then generates claim-first cited answers with source verification. Correct Precedents Induce Policy Violations in On-Device LLM Agents
正确先例反而诱发违规：端侧 LLM Agent 的策略失效
policy generalization on-device agents safety alignment decision distillation
The paper identifies correct-precedent generalization, in which an on-device agent that correctly releases an item whose restriction was lifted becomes more likely to release the next still-restricted item, and finds the failure in 13 open-weight models from nine developers. Paired Decision Distillation restores the safe rate to nearly 100% in every distilled model without extra prompts or model calls.
