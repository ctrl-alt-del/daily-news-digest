FinVeriQA: Financial Research Agents for Question Answering: Routing, Retrieval, MCP Tool Use, and Provenance-Aware Evidence Verification
FinVeriQA：面向金融问答的研究智能体——路由、检索、MCP 工具使用与来源感知证据验证
financial QA provenance verification MCP tool use multi-agent routing evidence corruption
FinVeriQA is an open-source multi-agent financial QA prototype over SEC filings and live market data that routes questions with a compact typed-decision model, computes every number in Python, retrieves evidence, writes cited answers with Mistral-7B, and checks citations with a code validator, all exposed through an MCP server. In live experiments its router beat Mistral-7B (0.85 vs. 0.52), hybrid retrieval reached 76% Hit@5, and a controlled study found checking against the original passage caught 77% of corrupted-evidence errors versus 35% for a shared-evidence check.

DeepSeek arxiv:2611.24924 arXiv ✓
Agentic Harness Engineering Beta: Requirement-Centered Evolution of Agent Harnesses
Agentic Harness Engineering Beta：以需求为中心的智能体框架演化
harness evolution requirement-driven development pass@1 simulated users
AHE-Beta is a requirement-centered harness-evolution loop in which simulated users raise issues, a team implements generalizable changes, and a change is merged only when it resolves a verified requirement and passes review. On held-out tasks it raises pass@1 from 21.9% to 33.3% with 40.8% fewer tokens than the base harness, beats Claude Code, Meta-Harness and AHE, and its gains transfer to GLM-5.3 and DeepSeek-V4.1-Flash.

arxiv:2611.25123 arXiv ✓
Forget Freely, Grep Later: Lossless, Index-Free Memory for Long-Horizon LLM Agents
自由遗忘，稍后 Grep：面向长程 LLM 智能体的无损无索引记忆
lossless agent memory grep-based retrieval long-horizon agents context management
GrepMem replaces lossy summarization or structured memory with an append-only plain-text log of the agent's complete history and a regular-expression search tool for on-demand recall, requiring no embeddings, retrieval index, memory extraction, or additional models. A Qwen3.5-9B agent trained with reinforcement learning under this strategy reaches 95-97% accuracy on ContextBench versus at most 21% for lossy baselines, and beats SUPO summarization by 8.8 percentage points on BCP-Multi.
→ arxiv.org
arxiv:2611.25235 arXiv ✓
Some Memories Must Fade: Persistence and Decay of User Memories in Model Parameters
有些记忆必须淡去：模型参数中用户记忆的持久与衰减
parametric memory memory decay LoRA substrate recall-abstention tradeoff
The paper proposes parametric memory management with a fixed-capacity LoRA substrate whose k-hot rank combinations store facts with independently controlled temporal decay, plus a learned controller deciding what to remember, how deeply, and for how long. On a controlled long-horizon user-trajectory dataset the policy reaches 86% of oracle performance by balancing recall while information is valid with abstention after it expires, unlike continual-learning and RAG baselines that primarily default to one behavior.

arxiv:2611.24887 arXiv ✓
Ground, Iterate, Trace: Decomposing AI Research Ideation
扎根、迭代、追踪：拆解 AI 研究构思
research ideation semantic knowledge graph graph retrieval procedural traceability ablation study
CAR is an agentic research-ideation framework that builds a semantic knowledge graph from retrieved literature and gives an ideation agent graph-retrieval tools plus four operators—bisociation, analogy, exploration and elaboration—with each call checked and recorded. Across 40 LiveIdeaBench topics it achieves higher methodological novelty than single-shot prompting and The AI Scientist, though a ten-condition ablation found no novelty contrast surviving multiple-comparison correction.

arxiv:2611.25229 arXiv ✓
LSP-RAG: Latent Scoring Perspectives for Knowledge Graph Retrieval-Augmented Generation
LSP-RAG：面向知识图谱检索增强生成的潜在评分视角
knowledge graph RAG multi-hop retrieval soft prompts lightweight models
LSP-RAG improves hop-wise retrieval over knowledge graphs with multiple latent scoring perspectives, each induced by a perspective-specific soft prompt and paired with a contextual soft prompt that evolves across reasoning hops. The adaptively aggregated perspectives let lightweight language models outperform existing retrieval systems, including those relying on much larger models, on multiple KG question-answering benchmarks.

A Neurosymbolic Multimodal Framework for 30-Day Diabetic Readmission Prediction: Integrating Structured EHR Data, Dense Clinical Embeddings, and Knowledge-Grounded Symbolic Extraction
面向 30 天糖尿病再入院预测的神经符号多模态框架
clinical note embeddings hybrid retrieval neurosymbolic extraction readmission prediction negation auditing
This neurosymbolic framework fuses structured EHR features, SVD-compressed Bio_ClinicalBERT note embeddings, and symbolic entities from a hybrid dense/sparse retrieval pipeline with cross-encoder re-ranking and negation auditing, feeding a cost-sensitive XGBoost classifier. On the Diabetes 130-US Hospitals dataset the full model raises sensitivity by 8.28 percentage points and lowers the Brier score, and on a 500-note Hinglish benchmark grounded retrieval lifts symptom recall from 4.8% to 40.2% while cutting entity hallucinations to zero per note.

Transferring an analysis of human brain organization to language models
将人类大脑组织分析迁移到语言模型
diffusion-map embedding representation geometry reasoning training weight grafting
The study applies diffusion-map embedding, a method used to map cortical organization, to matched base and reasoning-trained language models from three families, finding broadly preserved gradient profiles with localized changes in a contiguous layer span. Grafting weights from these spans into instruction-tuned hosts improved mathematical reasoning on average.
