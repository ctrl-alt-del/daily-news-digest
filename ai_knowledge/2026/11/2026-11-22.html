Edit-Induced Dependency Mismatch: Propagation Omissions, Recovery, and Evaluation Blind Spots in Coding Agents
编辑引发的依赖失配：编程 Agent 的传播遗漏、恢复与评估盲区
dependency propagation stale context coding agents evaluation blind spots trajectory audit
The paper studies coding-agent trajectories on DeepSWE and SWE-bench Verified and finds that agents can keep relying on outdated dependency judgments whose text remains in context, leaving consumer defects that the original task evaluations do not detect. A blinded audit found recovery within a trajectory can coexist with terminal omissions in the same run, and an explicit dependency-review prompt reduced terminal omissions under the tested conditions.

arxiv:2611.29150 arXiv ✓
Can an Agent Trust Its Own Zoom? Cross-Magnification Provenance Verification for Whole-Slide Images
Agent 能信任自己的放大结果吗？全切片图像的跨倍率来源验证
provenance verification visual agents whole-slide imaging abstention
The paper formulates cross-magnification provenance verification for visual agents navigating whole-slide images, asking whether an observation supports its claimed location and allowing abstention when evidence is insufficient. Its ZoomTrace verifier reaches 0.969 AUPRC and 0.987 AUROC on 503,320 test examples from the 3.06-million-example PyraFault benchmark, versus 0.789 and 0.903 for Efficient LoFTR.

DeepSeek arxiv:2611.29120 arXiv ✓
When Can a Rewiring Control Test LLM Weight Readers? C2 and an Eligibility Protocol
重接线控制何时能检验 LLM 的权重读取？C2 与资格协议
weight readers counterfactual controls mechanistic interpretability eligibility protocol
The paper proposes C2, a counterfactual that permutes the columns of a network's final linear readout while leaving all other parameters unchanged, to separate reading weights from recognizing weight-space fingerprints, and states three eligibility conditions for such a test. No natural setting tested was eligible; a self-hosted Qwen3.8-27B followed the rewired function rather than a shortcut, and a registered replication confirmed the finding.

arxiv:2611.29112 arXiv ✓
Bridging Blind Spots With Words: Decentralized Multi-View Spatial Reasoning via Language-Constrained Communication
以语言弥合盲区：语言约束通信下的去中心化多视角空间推理
multi-agent communication spatial reasoning language-constrained messages credit assignment
The paper formalizes decentralized multi-view spatial reasoning in which N agents with distinct viewpoints exchange budget-constrained natural-language messages so a listener can answer spatial queries. A new benchmark finds the penalty of language-only communication is far smaller than prior two-agent work suggested, but a significant gap remains between current centralized performance and an oracle best-of-K ceiling, and reinforcement learning with credit assignment substantially narrows it.

DataRecycle: Trustworthy Distillation of Structured Data from Scattered Web Evidence
DataRecycle：从分散网页证据中可信蒸馏结构化数据
structured distillation provenance lineage evidence retrieval data reconciliation
DataRecycle is an interactive system that turns scattered web evidence into tables of comparable numerical facts, decomposing a query into entities and attributes, retrieving candidate evidence and aligning heterogeneous records across time, definition and scale. It visualizes lineage from retrieved snippets to extracted values so users can inspect uncertainty and conflicting sources.

MVAgent: Per-Video Agents under Global Coordination for Multi-Video Understanding
MVAgent：全局协调下的逐视频 Agent 多视频理解
multi-agent coordination multi-video understanding private observation history benchmark gains
MVAgent is a training-free framework that gives each video its own LocalAgent with a private observation history while a GlobalAgent coordinates cross-video reasoning. Across CVBench, MVU-Eval and CrossVid it improves aggregate scores by about 5 points over single-pass inference with the same Qwen3.5 models and runs 1.8-2.7 times faster than prior agents of comparable size.
