Test-Time Self-Evolving GUI Visual Grounding via Reflection-Guided On-Policy Self-Distillation
反思引导的在线策略自蒸馏：测试时自演化的 GUI 视觉定位
test-time adaptation self-distillation GUI agents visual grounding reflection
The framework enables GUI agents to keep improving after deployment without human-annotated ground truth by closing a loop of exploration, evaluation, reflection and internalization, with an MLLM reflector and reflection-guided on-policy self-distillation turning reasoning into token-level supervision. Across six benchmarks it improves average accuracy by 7.4% over the base model, which the authors describe as the first successful use of on-policy self-distillation for test-time adaptation in GUI visual grounding.

Social Chain of Thought: A Multi-Agent Architecture Grounded in Medical Differential Diagnosis Methodology
社会思维链：扎根医学鉴别诊断方法的多智能体架构
multi-agent architecture differential diagnosis deliberative reasoning medical AI
SCoT structures multi-agent interaction for medical differential diagnosis as a multi-round deliberative pipeline and evaluates it against single-agent baselines, one-agent pipeline ablations and best-of-n scaling. The authors report that its recall advantage is not reproduced by monolithic inference alone and is largest on the hardest cases, where multiple rounds of specialist conversation help recover ground-truth diagnoses.

From Prompting to Behavioral Alignment: Personalized LLM Judges for Recommendation Evaluation
从提示到行为对齐：面向推荐评估的个性化 LLM 评判器
LLM-as-judge behavioral alignment recommendation evaluation rationale alignment
The study identifies bidirectional rationalization, where zero-shot LLMs convincingly argue for both positive and negative engagement on the same item with identical evidence, and addresses it with a sequential behavioral alignment framework that pairs fine-tuning with preference optimization over correct and counterfactual rationales. On real homepage interaction logs the aligned approach gains 32.19% in Macro-F1 over the zero-shot baseline and matches the production feature-engineered baseline.

Self-Evolving Embodied Agents via Skill-Harness Evolution
通过技能-执行框架演化实现自演化具身智能体
self-evolving agents skill evolution embodied agents context-code harness
SHAPER is a train-free framework for embodied adaptation that keeps model parameters frozen and improves the non-parametric agent system by evolving reusable skills and a context-code harness through target-environment rollouts. The same frozen model serves as both planner and optimizer, and experiments on VLABench and ESI-Bench compare it with pure execution, supervised fine-tuning and test-time-scaling baselines.

Can Frontier LLMs Match Natively Multimodal Embeddings? A Comparison on Hard-Negative Text-to-Image Retrieval
前沿 LLM 能否媲美原生多模态嵌入？硬负样本文本到图像检索对比

Deployment Decision Reliability: A Generalizability-Theory Framework for Sizing Long-Horizon Agent Evaluations
部署决策可靠性：为长程智能体评估确定规模的概化理论框架
agent evaluation variance decomposition leaderboard reliability long-horizon agents
Using a four-facet Generalizability Theory variance decomposition across TheAgentCompany, τ²-bench and AppWorld, the paper finds the agent main effect accounts for less than 3% of total variance while agent-by-task interaction accounts for 7–23%, meaning leaderboards rank specialization rather than capability. It also reports that aggregate reliability collapses on the hardest task quartile and packages the findings into a one-page reporting discipline called Deployment Decision Reliability.
→ arxiv.org

From Numbers to Judgment: Specialist LLM Agents and Reinforcement Learning for European Listed Real Estate
从数字到判断：面向欧洲上市房地产的专业 LLM 智能体与强化学习
specialist agents prompt decomposition reinforcement learning financial analysis
Larix maps a 16-lens European listed real-estate analysis framework to eight lens-aligned specialists and compares monolithic versus specialist-decomposed prompting while holding model, evidence, instructions, schema and scoring fixed. Decomposition improves the numerical-task aggregate by 15.8 percentage points but can reduce judgment performance, while GRPO post-training of Qwen3.5-9B raises the judgment aggregate by 14.2 points and transfers to unseen firms.
