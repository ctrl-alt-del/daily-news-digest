A Taxonomy of Cognitive Capability Gaps in Generative and Agentic AI
生成式与智能体 AI 中认知能力缺口的分类体系
cognitive architecture capability taxonomy persistent state continual learning cognition-centric evaluation
This survey organizes the cognitive capability gaps constraining Cognitive AI around five dimensions: persistent state modeling, goal-directed autonomy, self-monitoring and control, environment interaction, and learning and adaptation. It reviews advances and limitations in each, outlines a conceptual Adaptive Cognitive Intelligence Architecture (ACIA), and discusses cognition-centric evaluation as a roadmap toward more reliable long-term reasoning.

MutMem: Cryptographically Authorized Mutation in Persistent Agent Memory
MutMem：持久化智能体记忆中的密码学授权变更
persistent memory memory integrity provenance chain poisoning defense
MutMem records signed positive and negative outcome evidence and commits each nontrivial memory-weight change as a housekeeper-authorized, Ed25519-verified transition bound to provenance and a no-fork predecessor, retaining poison-likely content with signed, revisable labels. HOM-AIMOS answers 459/500 LongMemEval questions (91.8%) and reaches 74.12% judged accuracy on LoCoMo; in a declared N=100 PoisonedRAG adaptation, no injected poison appeared in attacked top-5 disclosures.

FLARE: Few-shot Learning-based Adaptive Reflective Engine
FLARE：基于少样本学习的自适应反思引擎
prompt optimization few-shot learning reflective instruction evolution retrieval-augmented reasoning
FLARE combines reflective instruction evolution with a small set of few-shot reference examples, evaluated against GEPA on retrieval-augmented reasoning, tool calling and emotion classification with GPT-5-series models. It wins on every task-model pair, including +14.2 points on HotPotQA (52.2 vs 42.2) and 87.0% on tool calling, and reaches peak GoEmotions performance with as few as 100 validation examples.

arxiv:2608.02585 arXiv ✓
GradCuit: Credit-Assigned Gradient Flow Enables Robust and Interpretable Test-Time Latent Reasoning
GradCuit：信用分配的梯度流实现稳健且可解释的测试时潜在推理
latent reasoning test-time optimization credit assignment interpretability
GradCuit inserts optimizable latent states at a selected Transformer layer between prompt and continuation representations, letting reward-weighted gradients from the whole continuation be assigned directly to those latents at test time while model parameters stay frozen. Across five instruction-tuned backbones it averages 64.5% accuracy, 6.6 points above chain-of-thought prompting, and is more stable than LatentSeek across learning rates.
→ arxiv.org
arxiv:2608.06410 arXiv ✓
ADIAS: Automated Design of Interactive Agentic Systems
ADIAS：交互式智能体系统的自动化设计
self-evolving agents harness evolution issue tracking agent optimization
ADIAS reframes self-evolving agents as issue-centric optimization: an Issue Manager keeps stable issue identities, lifecycle status, evidence and intervention-outcome histories, while an Issue-Guided Optimizer proposes repair targets and performs focused harness revision without updating model weights. On five interactive benchmarks it beats the strongest baseline by 25.2% on average across four backbone models, and removing either component reduces performance by up to 40.7%.
→ arxiv.org
arxiv:2608.02558 arXiv ✓
Benchmarking Sheaf Neural Networks for Inductive Tasks
面向归纳任务的 Sheaf 神经网络基准评测
sheaf neural networks graph representation learning message passing inductive benchmark
The authors run a systematic benchmark of sheaf neural networks under inductive protocols, sweeping three diffusion mechanisms, three restriction-map parameterizations, three stalk dimensions and six modern GNN components over 1,890 controlled experiments on 14 datasets. They find restriction maps dominate design choices, larger stalks add capacity but not long-range reach, and architectural components explain more performance variation than the sheaf-specific design space, while SNNs transfer to inductive settings but do not reach the strongest baselines.
