post-graph-rag: A PostgreSQL-Native Bi-Temporal Graph RAG Engine with Temporal Grounding at Synthesis
post-graph-rag：具备合成阶段时间锚定的 PostgreSQL 原生双时态 Graph RAG 引擎
Graph RAG bi-temporal graph long-term memory temporal grounding PostgreSQL engine
post-graph-rag is an open-source Graph RAG engine that keeps chunks, embeddings, a canonical entity graph and community summaries in one PostgreSQL database, adding validation of extraction output before writing and a bi-temporal layer that records when relations held and when the system believed them. It scores 94.0% on LongMemEval versus 71.2% for Zep's gpt-4o and 60.2% for full context, and 0.807 on ECT-QA versus 0.599, 0.406 and 0.405 published for TG-RAG, LightRAG and GraphRAG.

arxiv:2608.14490 arXiv ✓
Twin: Playing an Unknown Game with a Test-Time Digital Twin
Twin：用测试时数字孪生玩未知游戏
world model test-time learning ARC-AGI-3 continual learning
Twin is a test-time world-model inference system in which a frontier coding agent writes an executable world model, validates every action against a replay of observed transitions, and repairs the model from each mismatch. It clears 179 of 183 ARC-AGI-3 levels (97.8%) and beats human action efficiency on 158 of them, raising the same base model from 7.8% played directly to 93.3% with the twin harness.

A Parameter-Free Few-Shot Evaluation for Elephant Vocalisation Classification
大象叫声分类的无参数少样本评估
few-shot evaluation nearest-centroid classification pretrained embeddings bioacoustics
The authors evaluate parameter-free nearest-centroid classification on fixed pretrained embeddings for elephant vocalisation, varying the number of exemplars per class under episodic N-way k-shot evaluation. On the smaller EV dataset Perch embeddings overtake trained baselines from one or two exemplars, while on the larger LDC dataset recurrent baselines retain their advantage.

arxiv:2608.14886 arXiv ✓
Where Does Retrieval Fail? Evaluating RAG Architectures for Agricultural Advisory
检索在哪里失败？面向农业咨询的 RAG 架构评估
RAG evaluation multilingual retrieval embedding models low-resource retrieval
The authors build a Bengali agricultural advisory test collection of 1,000 queries and 2,882 knowledge nodes from 284 official publications, then evaluate five retrieval architectures and six embedding models under three language conditions. They find no consistently best retriever: BM25 reaches R@10 0.506 on native Bengali queries but drops to 0.004 on English queries, while dense retrieval falls only from 0.464 to 0.425, and embedding task configuration or passage length can each change R@10 sevenfold.

arxiv:2608.14791 arXiv ✓
CEDAR-GRPO: Process-Aware Reinforcement Learning for General Abductive Reasoning in LLMs
CEDAR-GRPO：面向 LLM 通用溯因推理的过程感知强化学习
abductive reasoning RL post-training process rewards transfer evaluation
CEDAR-GRPO is a process-aware RL framework that combines final-answer correctness with abductive rewards for evidence coverage and evidence-to-explanation directionality, post-training four open-weight LLMs on a domain-neutral mixture of hypothesis-generation and hypothesis-selection tasks. It improves every model on all 11 held-out tasks over both base models and correctness-only GRPO, with average gains of 7.4 and 2.7 points and a maximum gain of 30.8 points.
→ arxiv.org
arxiv:2608.14825 arXiv ✓
Emergent Misaligned Communication in Long-Horizon Multi-Agent LLM Commerce
长周期多智能体 LLM 商业环境中涌现的失准沟通
multi-agent communication misalignment long-horizon simulation speech-act analysis
The authors study 2,583 inter-agent emails from 20 one-year Vending-Bench Arena runs spanning 13 frontier LLMs, classifying false factual claims, manipulation, collusion and threats against ground-truth simulator state. Under their primary classifier 12.6% of emails are misaligned, appearing in all 20 runs, with receiving a misaligned email raising the odds of a misaligned reply by 1.65x and low-inventory conditions raising them by 1.58x.
→ arxiv.org
arxiv:2608.14863 arXiv ✓
Evaluating Agentic Code Repair Capabilities in Distributed Systems
分布式系统中智能体代码修复能力评估
code repair benchmark distributed systems debugging context agent evaluation
DDBench is a code-repair benchmark of 60 historical bugs from 13 open-source distributed systems, evaluated under a symptom-only condition and a matched condition that adds bounded debugging context such as logs, traces and runtime state. Across ten LLMs, bounded context lifts aggregate pass rate by 18.1 points, with weaker models gaining accuracy and stronger models gaining efficiency, though even faithful context can sometimes mislead.
