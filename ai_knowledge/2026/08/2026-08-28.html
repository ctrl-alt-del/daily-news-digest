ContextPilot: Teaching Agents for Proactive Context Management via Fine-grained RL
ContextPilot：通过细粒度强化学习教会 Agent 主动管理上下文
proactive context management long-term memory long-horizon agents reinforcement learning
ContextPilot is a proactive context management framework for long-horizon agentic reasoning that augments the toolset with planning, long-term memory and soft context offloading, and uses an RL method that identifies critical context-editing decisions for branch sampling and estimates action-level advantages from branched trajectories. Experiments on long-context QA and deep search show stronger performance with a more compact working context across base models and benchmarks.

Blind Men and the Elephant: Probing the Epistemic Myopia of LLMs under Long-Tail Divergent Knowledge
盲人摸象：探测大模型在长尾分歧知识下的认知短视
epistemic myopia long-tail knowledge knowledge probe graph-based benchmark construction
The paper introduces ElephantBench, a closed-book knowledge probe of 1,094 questions built through an auditable graph-based pipeline that mines naturally occurring disagreements in a low-exposure web corpus and converts them into multi-account QA records verified against source documents and reviewed by human annotators. Across 32 models, even the strongest recovers both accounts on only 52.4% of questions, and scaling model size and inference-time reasoning improve recall but do not eliminate the incompleteness.

The Halt Vector: Internalizing a Causal Steering Intervention for Efficient Reasoning
停止向量：将因果引导干预内化以实现高效推理
reasoning efficiency activation steering interpretability chain-of-thought
The authors identify a halt vector at layer 18 of DeepSeek-R1-Distill-Qwen-7B whose steering strength controls thinking length, and internalize the intervention into the weights by reconstructing the whole steered activation with off-axis dimensions pinned to their natural values. Fit from 24 problems without reinforcement learning, it removes about a quarter of the thinking at held accuracy across five unseen benchmarks and tracks each problem's own removable slack at 0.70.

arxiv:2608.28490 arXiv ✓
LLM-Based Agents for Software and Systems Security: Approaches, Applications, and Assessment
基于 LLM 的软件与系统安全 Agent：方法、应用与评估
agent architecture agent memory security agents trajectory evaluation
This systematic literature review covers peer-reviewed work from 2023 to 2026 on LLM-based agents for software and systems security, organizing agent architecture, perception, memory, reasoning and planning, action space, orchestration and self-improvement, along with the security tasks served and the datasets and trajectory metrics used for assessment. It concludes that the field has built agents able to act but not yet agents whose authority is bounded or whose behavior is auditable.

arxiv:2608.28481 arXiv ✓
NL2AGBench: Benchmarking LLM Auto-Formalization for AlphaGeometry
NL2AGBench：评估 LLM 面向 AlphaGeometry 的自动形式化能力
auto-formalization geometric reasoning execution-based verification few-shot prompting
NL2AGBench evaluates LLMs on translating English geometry problems into AlphaGeometry-compatible formal representations, using execution-based verification inside AlphaGeometry rather than textual similarity. Across ten open- and closed-source models, leading closed-source models exceed 80% executable translation rates while even the largest open-source models struggle to consistently preserve geometric constraints.

arxiv:2608.28790 arXiv ✓
ASTRA - Agentic System for Ticket Resolution and Analysis
ASTRA：面向工单解决与分析的 Agent 系统
dense retrieval multi-agent orchestration claim-evidence grounding Model Context Protocol
ASTRA is an agentic system for ticket resolution in which an orchestrator coordinates ticket-similarity, log and domain-knowledge agents and runs a judge-orchestrator refinement loop to produce evidence-backed reports whose claims link to verbatim source passages. On 987 real-world telecom fault tickets it achieves a mean quality score of 4.13/5.0, with 59.9% of reports identifying the fault area at component-family level or better.

arxiv:2608.28725 arXiv ✓
Beyond the Answer Key: Robustness Evaluation of Large Language Models for Step-Level Mathematical Verification
超越答案键：大语言模型逐步数学验证的鲁棒性评估
process verification robustness LLM-as-a-judge mathematical reasoning
The paper introduces a controlled linear-equation benchmark that asks LLMs to judge final-answer correctness, step-level trace correctness and the first incorrect step, then tests them on perturbed but logically equivalent solutions. Base models that handle canonical traces degrade sharply on perturbed ones, with false-rejection rates of 75.6–85.3% on valid perturbed traces across GPT-OSS 20B, Qwen3-14B and Phi-4-Reasoning.
