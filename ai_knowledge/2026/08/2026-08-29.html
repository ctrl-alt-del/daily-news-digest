LiteSearch-VL: Small Multimodal Search Agents via Trajectory Distillation and Synthetic Step-DPO
LiteSearch-VL：通过轨迹蒸馏与合成逐步 DPO 构建小型多模态搜索 Agent
multimodal search trajectory distillation preference optimization small vision-language models
LiteSearch-VL is a low-compute recipe that distills released OpenSearch-VL agent trajectories into Qwen3-VL-2B and 4B backbones using LoRA adapters and synthetic step-level preferences targeting five local failure modes such as premature answers and wrong tools. Across 12,400 GPT-5-judged rollouts, full-trajectory supervised fine-tuning transfers the agent contract and lifts the 2B model from almost never emitting a usable answer to 28.4% macro Pass@1, and a step-budget ablation identifies answer verification rather than search depth as the next bottleneck.

arxiv:2609.29647 arXiv ✓
AgentKernel: The Trust-Native Agentic Operating System
AgentKernel：信任原生的 Agent 操作系统
agent operating system memory governance prompt injection trust boundary
AgentKernel argues that agents need an operating-system substrate with mandatory, non-bypassable services for identity, input mediation, memory governance and execution control, organized into Identity, Perception, Cognition and Execution pillars that adapt classical OS security principles to delegation abuse, prompt injection, memory poisoning and tool misuse. The paper positions it as the missing OS layer beneath orchestration frameworks, agent runtimes, governance platforms and execution sandboxes, supporting the case with systematic comparison and security analysis.
→ arxiv.org
arxiv:2608.29263 arXiv ✓
RACER: Reinforced Agent Collaboration for Explainable Reasoning on Knowledge Graphs
RACER：面向知识图谱可解释推理的强化 Agent 协作
knowledge graph reasoning multi-agent collaboration shared memory reinforcement learning
RACER is a reinforced agent-collaboration framework for explainable reasoning over knowledge graphs that uses semantic-aware action pruning and teacher-guided reinforcement learning to extract reasoning paths, plus a cross-task shared memory graph and attention-driven multi-path refinement. A four-role system of GraphAgent, TemplateAgent, AnswerAgent and CriticAgent outperforms KG-enhanced LLM baselines on CommonsenseQA and OpenBookQA by an average of 5%.

A Pinch of SFT, A Dash of RL: When Reinforcement Learning Helps Long-Horizon Advertising Agents
一撮 SFT，一撮 RL：强化学习何时能帮助长程广告 Agent
long-horizon agents reinforcement learning tool use SFT/RL routing
The paper studies how to balance supervised fine-tuning and reinforcement learning for long-horizon advertising agents, separating checkpoint trajectories into imitation, lift and discovery regimes and using teacher support and reward-observable headroom to route features. Across 18 follow-up experiments the diagnostic predicted 15 of 18 trajectories, and targeted SFT-then-RL produced positive point estimates on 7 of 8 advertiser skills, while a separate audit found that targeted RL reduces standard leakage from 11.8% to 2.9% relative to SFT.

arxiv:2608.29345 arXiv ✓
BIRD-History: A Benchmark for History-Driven Text-to-SQL with Fine-Grained Knowledge Annotations
BIRD-History：带细粒度知识标注的历史驱动 Text-to-SQL 基准
text-to-SQL knowledge annotation retrieval reranking benchmark design
BIRD-History is a benchmark of 1,393 tasks across 11 databases that evaluates whether text-to-SQL systems can ground underspecified questions in historical SQL scripts, with labels marking which historical queries contain relevant knowledge and which clauses encode it. A plug-in retriever that extracts five types of external knowledge from query logs improves four text-to-SQL systems without requiring prompt modifications.

arxiv:2608.29313 arXiv ✓
Hyper3-CLIP: Hierarchy-Conditioned Hyperbolic Vision-Language Training
Hyper3-CLIP：层级条件化的双曲视觉-语言训练
multimodal embeddings hyperbolic geometry hierarchical structure contrastive learning
Hyper3-CLIP is a hierarchy-conditioned hyperbolic vision-language model that combines global, local and global-local contrastive learning with query-conditioned visual pooling, training on lightweight query hierarchies built from captions, sentence fragments, part descriptions and extracted phrases. Query-conditioned pooling is active only during training, and the model improves R@5 and R@10 retrieval on COCO and Flickr plus multi-label classification on VOC and COCO while remaining competitive on hierarchy metrics.
→ arxiv.org

arxiv:2608.29410 arXiv ✓
Agents as Knowledge Integrator and Utilizer in Multimodal Recommendation
Agent 作为多模态推荐中的知识整合者与使用者
knowledge memory knowledge integration graph construction agent architecture
AgentMMRec is an agent-based multimodal recommendation framework with an Integrator Agent that infers behavior- and multimodal-aware user preferences and item properties into a reusable knowledge memory, and a Utilizer Agent that converts that memory into refined item-item graphs and reranked candidate lists. Experiments on three Amazon datasets show consistent Recall and NDCG gains over recent multimodal baselines, including under sparsity and item cold-start, and the constructed knowledge transfers to existing backbones.
→ arxiv.org

Item-Mean Surrogates: Why Richer Persona Data Fail to Improve LLMs as Human Surrogates
题目均值替代：为何更丰富的人设数据无法提升 LLM 作为人类替代品的效果
LLM simulation human surrogates persona prompting benchmark validity
Across four datasets covering over 400,000 participants and more than 6,000 survey items and experimental outcomes, the study tests whether richer persona data makes LLMs better substitutes for specific individuals. After removing each item's human mean, LLM predictions explain only 3.05% of remaining respondent-specific variation versus a 53.6% human test-retest benchmark, and richer personas, model variants and fine-tuning do not close the gap.
