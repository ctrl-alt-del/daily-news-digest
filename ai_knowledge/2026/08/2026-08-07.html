Fisher-R1: Training LLM Agents for Reliable Hypothesis Testing
Fisher-R1：训练 LLM 智能体进行可靠的假设检验
hypothesis testing statistical reasoning reinforcement learning benchmark design
The authors introduce P-Bench, a 425-task benchmark for open-ended hypothesis testing across economics, biology and medicine, and Fisher-R1, an open-weight agent trained with reinforcement learning on verified statistical rewards. Towards Researcher Agents for Knowledge-Graph Question Answering
面向知识图谱问答的研究型智能体
text-to-SPARQL self-improving agents DBpedia agentic retrieval
The paper presents an agentic text-to-SPARQL system whose researcher agent proposes and tests changes to its own prompts, rules and tool-orchestration code after each validation round. Evolving nine versions on DBpedia reached 0.22 overall accuracy on the 2025 validation set, with basic graph pattern predicate selection identified as the main bottleneck.

Who Verifies the Benchmark? Decentralizing Trust in Large Language Model Evaluation
谁来验证基准？去中心化大语言模型评测中的信任
LLM-as-a-judge evaluator bias benchmark transparency audit trail
The study measures identity-aware bias in seven LLM judges scoring anonymous versus identity-disclosed answers, finding small effects on factual questions and large shifts on geopolitically sensitive topics. It also proposes a blockchain-based commit-reveal protocol using Autonomous Economic Agents to create a tamper-evident audit trail for evaluations.

OpenAI arxiv:2608.07440 arXiv ✓
Blast Radius
Blast Radius：面向智能体编码的可逆上下文驱逐与预测式记忆管理
context eviction memory management token efficiency agentic coding
Blast Radius is a predictive memory-management layer that estimates an incoming prompt's reach across coupled context and code channels and supports reversible eviction of dead context by archiving it verbatim. Across seven OpenAI models it reduced token consumption by 17-26% while remaining byte-exact reversible and achieving the lowest overflow rate among tested policies.
→ arxiv.org

When the Judge Should Not Decide: Evidence-Locked, Non-Compensatory Selection Bounds LLM-Judge Failure in Reasoning Pipelines
当评审不应裁决：证据锁定、非补偿式选择如何限制推理流程中的 LLM 评审失败
LLM judge reasoning pipelines decision rules evidence grounding
The paper shows that an unconstrained DeepSeek-R1-7B judge adds little over majority vote and can be 10 points worse on a confirmation split, then places the same judge inside Evidence-Locked Derive-Gate-Repair. The rule reaches 58.2% on GSM8K and 17.33 EM on HotpotQA without changing the judge, candidates or budget.

arxiv:2608.07796 arXiv ✓
CliniCARE-Bench: Clinical Calibrated Audit of Medical Reasoning in EHR
CliniCARE-Bench：电子病历医疗推理的临床校准审计基准
clinical agents EHR benchmark evidence grounding calibrated abstention
CliniCARE-Bench evaluates clinical agents on 750 patient-specific cases derived from MIMIC-IV, scoring verdict accuracy plus evidence and policy grounding, process adherence, calibrated abstention and efficiency. Across 16 agentic systems four-way accuracy spans 65.3-76.1%, but defect-free accuracy is 4.8-14.8 points lower.

arxiv:2608.07642 arXiv ✓
Contextual Value Alignment via Multilayer Combinatorial Fusion
通过多层组合融合实现情境化价值对齐
multi-agent alignment value alignment combinatorial fusion moral reasoning
MCF-CVA instantiates multiple moral agents, expands their outputs combinatorially through score and rank aggregation, then reduces them back to the same number of agents across layers. The authors report that the expansion-and-reduction framework outperforms single-agent, multi-agent single-layer and previous aggregation baselines.
