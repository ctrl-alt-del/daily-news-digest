Context Compaction Theory
上下文压缩理论
context compaction context window communication complexity agent state
The paper initiates a formal study of context compaction, modeling selection-based and generation-based strategies as two games and proving that the Context Generation Game is equivalent to one-way communication complexity. It shows known communication-complexity bounds transfer directly to compaction budgets, proves generation can need strictly less budget than selection for some query sets, and includes a case study of Anthropic's context compaction endpoint on set-membership queries.

Deep Agentic Search for Repository-Level Code Question Answering: An Empirical Study
面向仓库级代码问答的深度智能体搜索：一项实证研究
semantic search context pollution subagent delegation code question answering failure taxonomy
The authors compare semantic search with deep agentic search — a planner delegating exploration to a subagent in an isolated context window — on the SWE-QA repository-level code QA benchmark. Semantic search answered 65.2% of questions correctly versus 46.2% at less than half the cost, and 41.8% of deep agentic search's failures occurred at the planner-to-subagent hand-off, usually ending in a fluent and confident but wrong answer.

G-ReAct: Graph-Guided Deep Search via Structure-State Co-Evolution
G-ReAct：通过结构-状态协同演化实现图引导深度搜索
deep search query graph state tracking multi-hop reasoning
G-ReAct organizes deep-search reasoning as state evolution over a fixed-topology query graph, explicitly tracking search progress and constraints to counter context forgetting and search drift. With only 1.9K generated trajectories, Qwen3-30B-A3B-Thinking-2507 reaches 52.6% on BrowseComp-ZH and 79.0% on XBench, and the method also improves strong LLMs at inference time without extra fine-tuning.

EDATracer: An Agentic Framework for Large-Scale EDA Artifact Analysis
EDATracer：面向大规模 EDA 产物分析的智能体框架
knowledge graph semantic vector index evidence grounding agent benchmark
EDATracer organizes electronic-design artifacts into a knowledge graph paired with a semantic vector index so LLM agents can retrieve evidence across source files, logs, netlists and reports. Built on an 18.9 GB dataset of 2,787 open-source chip designs and a 90-question benchmark, it reports the best pass@1, beating Cursor and Claude Code by 6.4 and 7.2 percentage points on average while using 2.0–3.2× fewer tokens.

Why Formal Monitors Fail: Attack Distribution Entropy as a Coverage Bound for LTL-Based LLM Agent Safety
形式化监控为何失效：以攻击分布熵作为基于 LTL 的 LLM 智能体安全覆盖上界
runtime monitoring LTL safety attack distribution tool-call sequences
The paper proves that the recall of any fixed-invariant finite-automaton runtime monitor is bounded by the concentration of the attack distribution, so dispersed attack patterns cannot be covered by a tractable invariant set. Across eight frontier LLM architectures, GPT-class and DeepSeek backends produced concentrated attacks (H ≈ 0.24 bits) with 68–75% coverage, Gemini variants produced high-entropy attacks (H ≈ 2.81 bits) with 6–13% coverage, and entropy explained 76% of coverage variance.

Asking Questions the Right Way: A Multi-Agent Conversational System for Prompt Formulation in Complex Task Resolution
正确提问：面向复杂任务求解中提示构建的多智能体对话系统
prompt formulation multi-agent dialogue self-evolving knowledge base user study
PAWNI is an eight-agent conversational interface that turns unstructured queries into structured prompts through guided question-and-answer dialogue backed by a self-evolving knowledge base, and the authors propose a three-tier framework of 18 prompt elements. In an exploratory within-subjects study with four participants, prompts covered 42% to 91% of assessed elements, every participant reached satisfactory output in one turn instead of 1–12, and reported workload was lower, though effect sizes are unstable given the sample size.

Plasticity of Growing and Elastic Neural Networks in Online Continual Learning
在线持续学习中生长型与弹性神经网络的塑性
continual learning plasticity loss catastrophic forgetting network pruning
The paper studies whether growing and elastic neural networks preserve plasticity in online continual learning, where networks add randomly initialized hidden units and elastic variants also prune estimated dead units at the start of each task. Experiments in supervised settings show adaptive growing networks maintain high accuracy without losing plasticity despite rising dead-unit proportions, while elastic networks keep a near-constant compact size with excellent accuracy.
