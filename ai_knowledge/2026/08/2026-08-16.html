HyMem: Hierarchical Context Management for Long-Horizon Agents via Information Isolation
HyMem：通过信息隔离实现长程智能体的分层上下文管理
hierarchical context long-horizon agents context isolation GAIA benchmark
HyMem is a hierarchical framework that separates an agent's context into distinct functional layers, isolating complex reasoning from the persistent planning context and preserving task progress across context refreshes through structured summaries. With DeepSeek-V4 it reaches average Pass@1 of 66.7% on GAIA and 61.3% on Browsecomp-plus, beating the strongest baseline by 6.1 and 4.7 percentage points.

Navigation-Informed Embeddings: Dense-Retriever Adaptation from Agent Search Traces
导航信息嵌入：利用智能体搜索轨迹自适应稠密检索器
dense retrieval agent search traces embedding adaptation retrieval benchmark
Navigation-Informed Embeddings adapts a deployed dense retriever using query, retrieval and stopping traces from agentic search, without new relevance labels, synthetic queries or LLM judgments. A BGE encoder adapted with NIE raises Recall@20 on an independent target benchmark from 72.2 to 78.0 overall and long-path performance from 46.7 to 55.4.

NVIDIA arxiv:2608.15763 arXiv ✓
Training Agents to Evolve with Their Harness: TaoLive Digital Avatar Agent Technical Report
训练智能体随其运行框架进化：TaoLive 数字人智能体技术报告
agent harness tool schemas on-policy distillation live-stream QA
The report proposes Harness-Aware Training, which trains compact models to adapt to changing agent harnesses by augmenting skill identifiers, tool schemas, prompt structures and hooks during supervised fine-tuning, on-policy distillation and reinforcement learning. HAT scores 94.8 on Live-Stream QA and 94.6 on Harness-Variant QA, and its Taobao Live deployment reports positive online A/B results with P50 and P95 latency of 3.4 s and 8.1 s on one NVIDIA H20 GPU.

arxiv:2609.27770 arXiv ✓
Improving LLM-based Autonomous Web Agents with Filtering
利用过滤改进基于 LLM 的自主网页智能体
web agents HTML filtering context window WebArena
The paper reproduces GPT-3.5 and LLaMA-2-70B baselines on WebArena, identifies common failure modes, and proposes DeBERTa- and T5-based retrievers that rank HTML elements by task relevance. The DeBERTa-based filter raises the LLaMA-2-70B agent's WebArena success rate from 1.97% to 2.96%, and a zero-shot ColBERT retriever reaches 0.52 recall on Mind2Web and 0.47 on WebArena.

arxiv:2608.15962 arXiv ✓
SEER: Long-Context Reasoning via Selective Visual-Text Compression
SEER：通过选择性视觉—文本压缩实现长上下文推理
visual-text compression long-context reasoning selective retrieval LongBench
SEER learns to select query-relevant rendered text images through visual scanning and to retrieve the underlying text only where needed, combining visual compression with text-based reasoning via supervised fine-tuning on tool-interaction trajectories. On LongBench it reaches 51.11% average accuracy, 2.33 points above the Glyph-9B visual-text baseline and 3.49 points above Qwen3-8B, while retaining average prompt-token savings.
→ arxiv.org
arxiv:2608.15854 arXiv ✓
Geometry of Forgetting: Representation Flux in Continual Learning
遗忘的几何：持续学习中的表征通量
catastrophic forgetting representation flux continual learning replay regularization
The paper introduces representation flux, a geometric measure of sample-level representation displacement during sequential learning, and shows it is strongly associated with catastrophic forgetting, with elevated flux preceding later performance degradation. FlowLess-R, a representation-space regularization term compatible with replay methods, improves final average accuracy and reduces forgetting with ER, DER++ and ER-ACE on four split datasets.
→ arxiv.org
arxiv:2608.18167 arXiv ✓
Adversarial Review: Structured Disagreement for Grounded Agentic Code Review
对抗式评审：面向有据可依的智能体代码评审的结构化分歧
multi-agent review structured disagreement code review false consensus
Adversarial Review is a minimal three-agent code-review protocol that pairs a main coding agent with a reviewer and a critic that audits the review through structured disagreement before any edits are made. It reports the highest pass rate on LiveCodeBench and, on SWE-PRBench, the highest F1 for a single prompt iteration that makes disagreement explicit while avoiding a false-consensus failure mode.
