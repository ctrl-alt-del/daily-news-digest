SSE-Bio: A Structured Self-Evolving Agent with Agentic Retrieval Policy for Multi-Hop Biomedical Reasoning
SSE-Bio：面向多跳生物医学推理、具备智能体检索策略的结构化自演化智能体
agentic retrieval self-evolving agent reasoning memory biomedical QA knowledge triplets
SSE-Bio is a structured self-evolving agent for biomedical multi-hop QA that maintains a structured state, retrieves knowledge triplets and prior templates through a trainable proxy policy, and improves its reasoning memory through fine-grained template editing instead of globally rewriting instructions. Across three biomedical multi-hop QA benchmarks it beats the strongest self-evolving baseline by 6.56 absolute points on BioHopR.

arxiv:2608.21946 arXiv ✓
EDGE: Experience-Distillation for Guided Exploration in Agentic Reinforcement Learning
EDGE：面向智能体强化学习引导式探索的经验蒸馏
experience distillation agentic reinforcement learning experience bank exploration long-horizon tasks
EDGE treats retrieved experiences as temporary training-time scaffolds, partitioning each rollout group into experience-conditioned and experience-free trajectories so only positive marginal gains are admitted, then distilling the induced behavior into the base policy with a reverse-KL objective. A co-evolutionary experience bank synthesizes guidance from emerging failure modes and prunes obsolete entries, and the method improves over strong RL baselines by up to 12.5 points across embodied, web and search-based QA tasks.

arxiv:2608.21939 arXiv ✓
Enhancing Group Recommendation with Memory-Augmented Reasoning in LLM Agent
AGR：面向群体推荐的 LLM 智能体记忆增强推理
agent memory group recommendation hash-table memory explainable recommendation GRPO
AGR is an LLM-based agent for group recommendation whose memory module uses a token-based hash table to insert, update, retrieve, forget and summarize evolving group and user profiles, while its reasoning module performs multi-step consensus refinement and explainable recommendation. Trained with supervised fine-tuning followed by GRPO, it outperforms state-of-the-art methods on LastFM and Douban, and the model is open-sourced on Hugging Face.

arxiv:2608.22014 arXiv ✓
DynaContext: Self-Improving Dynamic Contextualization of Optimized Prompts for Heterogeneous Parameter Extraction
DynaContext：为异构参数抽取实现优化提示词的自改进动态上下文化
dynamic prompting demonstration memory prompt optimization human-in-the-loop validation parameter extraction
DynaContext pairs an offline-optimized extraction core with inference-time contextual adaptation, routing each item through internal, external or fallback evidence paths and composing an item-specific prompt from schema, evidence, unresolved fields and validated demonstrations. On 850 heterogeneous gold parameter facts it lifts average field-level F1 from 51.8% for an unoptimized control to 71.0% with both components, 17.3 F1 points above the deployed static-prompting pipeline.

More Accurate or More Efficient? Evaluating Locally Deployed Compact Open-Weight Language Models for Mathematical Reasoning
更准确还是更高效？评估本地部署的紧凑开源权重语言模型的数学推理能力
local inference evaluation methodology energy efficiency mathematical reasoning open-weight models
The paper documents a controlled procedure for evaluating locally hosted LLMs on mathematical reasoning that combines fixed inference settings, hierarchical answer extraction, failure-mode classification and per-question resource measurement with paired significance tests. In a preliminary study of Gemma3:4b, Phi3:3.8b and Qwen3:4b, no model dominates: Qwen3:4b is most accurate on two datasets, but Gemma3:4b returns roughly three times more correct answers per watt-hour on every dataset.

arxiv:2608.21925 arXiv ✓
ESCRAG-R1: Retrieval-Augmented Reinforcement Learning for Emotional Support Conversation
ESCRAG-R1：面向情感支持对话的检索增强强化学习
retrieval-augmented RL emotional support dialogue GRPO preference data reasoning
ESCRAG-R1 integrates retrieval-based psychological guidance into GRPO so that external knowledge becomes a learning signal stimulating explicit internal reasoning before generation. The authors also build ESC-Preference, a dataset produced with a Client-Counselor-Judge framework, and report that the method outperforms baselines by avoiding superficial splicing of clinical strategies and generic reassurance.

Development and Feasibility Evaluation of an Edge AI as Medical Device System for Breast Cancer Multidisciplinary Team Meetings
面向乳腺癌多学科团队会议的边缘 AI 医疗器械系统开发与可行性评估
on-device RAG clinical decision support speech recognition feasibility evaluation privacy-preserving AI
The authors built a fully on-device pipeline that uses open-source ASR and LLMs on a single NVIDIA Jetson AGX Orin to transcribe breast cancer multidisciplinary team discussions, structure clinical information and generate NICE-grounded treatment recommendations via RAG. Evaluation on recorded and synthetic discussions found lower ASR word error rates and more MDT-concordant interventions than a proprietary cloud comparator.
