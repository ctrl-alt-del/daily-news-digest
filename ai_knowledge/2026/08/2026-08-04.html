Video-DeepResearch: Towards the Next-Generation Multimodal Deepresearch Agent
Video-DeepResearch：迈向新一代多模态深度研究智能体
multimodal deep research video grounding tool-augmented exploration GRPO multimodal benchmark
Video-DeepResearch extends multimodal agents from static images to continuous video streams with a decoupled perception-exploration pipeline and stage-wise tool unlocking, trained by supervised fine-tuning followed by Group Relative Policy Optimization. Its 35B-A3B model reaches 64.0% average accuracy on the new 200-instance Video-DR-Bench, 5.0 points above Claude-4.5-Sonnet, while a 30B-A3B variant reaches 59.3%.

TSG Suggester: Tree-Structured Knowledge-Graph Retrieval for Troubleshooting Guide Recommendation in Cloud Incident Management
TSG Suggester：面向云事故管理的树结构知识图谱检索式故障排查指南推荐
knowledge-graph retrieval tree-structured retrieval hybrid retrieval structural alignment RAG evaluation
TSG Suggester converts each troubleshooting guide into a tree that preserves its section hierarchy, attaches LLM-generated problem abstractions to internal nodes and builds a per-guide entity knowledge graph, then fuses embedding similarity with entity-level matching at query time. On 314 real incidents it reaches 54.78% Top-1 and 82.48% Top-5 accuracy, 8.58 points above text-only RAG, while captioning guide screenshots actively hurts retrieval.

When Agentic Executions Fail: Detecting and Localizing Runtime Faults from Telemetry
当智能体执行失败：从遥测数据检测并定位运行时故障
agent reliability runtime fault localization execution telemetry MCP tool calls chaos benchmark
The authors present AGENTCHAOSBENCH, a benchmark that injects ten operational fault types at the tool, model, guardrail and inter-agent boundaries of five Agent-to-Agent applications that call tools through MCP, producing 275 sanitized traces. Zero-shot baselines remain far from solved: local detectors up to 14B reach only 13.6-19.2% top-1 fault-type accuracy, DeepSeek-v4-pro reaches 24.8%, and jointly identifying fault type and location tops out at 22%.

Neighborhood-Aware Dual Biomedical Entity Linking
邻域感知的双路生物医学实体链接
biomedical entity linking ontology-aware retrieval entity embeddings dual reranking
PILOT is a three-stage framework for biomedical entity linking that combines neighborhood-aware retrieval, dual reranking over surface forms and context, and score fusion, injecting ontological structure from both the query and knowledge-base sides. It reports state-of-the-art average performance across five widely used benchmarks while remaining efficient at inference.

Strategic Evaluation of Planning Strategies for LLM Agents in Cyber-Physical Systems
网络物理系统中 LLM 智能体规划策略的策略性评估
agent planning planning evaluation cyber-physical systems objective substitution
The paper introduces a controlled benchmark of planning-induced control trajectories in which four coded executors manage demand response for 40 prosumers on a radial feeder, with an LLM declaring typed policies while schedules and power flow remain in code. Llama-3.3-70B experiments find forced search acts as the oracle in all five baseline seeds, while injected objective substitution keeps mode agreement at 1.0 but raises cumulative voltage shortfall by 2.68x.

神经符号 AI 的 RAIL 原则：推理、保证、接口与学习
neurosymbolic AI formal reasoning trustworthy AI tool-augmented LLMs
The authors propose RAIL - Reasoning, Assurances, Interfacing and Learning - as four principles for analyzing neurosymbolic AI systems, arguing that combining machine learning with formal reasoning is central rather than niche for reliable systems. arxiv:2608.04095 arXiv ✓
FinPerMA: A Theory-Informed, Event-Grounded Personalized-Memory Benchmark for LLM Agents
FinPerMA：面向 LLM 智能体的理论驱动、事件锚定个性化记忆基准
personalized memory memory benchmark preference adaptation long-horizon memory
FinPerMA evaluates personalized agent memory against frozen longitudinal investor trajectories, using theory-informed impact rules, controlled LLM narration and a Post-Shock checkpoint that tests whether a material event has been integrated into the persistent user model. Across 2,994 questions from 276 personas, no full-context configuration exceeds roughly 0.47 overall accuracy, and summary-based memory often keeps facts while losing the preference signals needed for personalization.
