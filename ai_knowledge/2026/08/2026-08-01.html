A Triple-Robustness Analysis of Retrieval-Augmented Generation for Multi-Hop Requirements Traceability
面向多跳需求可追溯性的检索增强生成三重稳健性分析
GraphRAG citation attribution multi-hop QA LLM-as-judge faithfulness
The authors test GraphRAG against vector and agentic RAG pipelines across two embedders, two corpora and two LLM judges, spanning 2×4,440 main-matrix runs, 600 cross-corpus runs and over 5,000 faithfulness judgments. They find that scoring the retrieved set as the attribution set inverts the architecture ranking, that answer-level citation winners are corpus-conditional but embedder-robust, and that single-judge LLM faithfulness varies sharply with retrieval state.

Adversarial Attacks in Multi-Agent LLM Pipelines: Unveiling Structural Vulnerabilities in Agentic AI Architectures
多智能体 LLM 流水线中的对抗攻击：揭示智能体 AI 架构的结构性脆弱性
multi-agent security memory poisoning boundary verification prompt injection
The authors argue that multi-agent LLM pipelines lack boundary verification, so adversarial content accepted by one agent propagates as trusted input and enables content injection, agent impersonation, plan deviation and memory poisoning. Using annotated traces from GAIA and SWE-Bench and controlled tests with GPT-5-mini, Claude Sonnet 4.5 and Kimi K2.5, they find attack success tracks pipeline structure rather than model capability.

AgentSLABench: Evaluating and Benchmarking Agentic Systems Under Resource Constraints
AgentSLABench：资源约束下的智能体系统评测基准
agent benchmark resource budgets agentic systems efficiency-adjusted success rate
AgentSLABench profiles autonomous agents on correctness plus latency, cost, compute, memory and network usage under declared budgets, across 16 Docker-isolated task environments in six categories. Profiling five general-purpose baselines and four task-specialized agents, it introduces an Efficiency-Adjusted Success Rate and reports that high accuracy at unbounded cost is not production-viable.

GARDRec: Decision-Level Graph Grounding for Large Language Model Recommendation
GARDRec：面向大语言模型推荐的决策级图锚定方法
graph grounding graph propagation item representation next-item ranking
GARDRec builds semantic-structural item representations from textual node features and graph propagation, derives personalized graph contexts from temporally weighted histories and first-order neighborhoods, and aligns them with a frozen LLM through continuous multimodal prompts. Experiments on three public benchmarks with multiple LLM backbones show it generally improves next-item ranking over representative baselines.

Tracing the Cascade: A Topology-Aware Evaluation Framework for Scientific Agent Hallucinations
追踪级联：面向科学智能体幻觉的拓扑感知评测框架
hallucination evaluation scientific agents concept graph knowledge topology trajectory audit
SCHEMA builds scientific concept graphs from benchmark seeds and literature, synthesizes graph-grounded tasks, and audits agent reasoning with a topology-weighted severity score plus counterfactual attribution. It finds hallucinations concentrate at a small set of highly connected knowledge hubs and that final-answer accuracy decouples from trajectory honesty, so agents can reach correct conclusions through structurally flawed reasoning.

TreeProbe : A Tibetan Medicine Benchmark for Cultural Bias in LLMs
TreeProbe：面向大语言模型文化偏见的藏医药基准
cultural bias Tibetan medicine ontology drift expert-adjudicated benchmark
TreeProbe is a cultural-bias benchmark organized around the native Tree of Medicine framework in Tibetan medicine, with 4,719 expert-adjudicated items covering 467 diseases and 10 subtasks. Experiments show current LLMs remain limited in native Tibetan medical contexts and exhibit systematic external ontology drift, diverging toward biomedical or TCM reasoning depending on pretraining data.

AOSpec: Action and Observation Co-Speculation for Low-Latency Agent Serving
AOSpec：面向低延迟智能体服务的动作与观测协同推测
agent serving speculative execution tool invocation end-to-end latency
AOSpec co-speculates agent actions and observations across the full agent-environment loop: Expected Value Decoding targets observations with the greatest expected latency benefit, while isolated forks and joint action-state verification safely overlap execution. Across Terminal-Bench serving settings spanning four harnesses, five actor models and five serving speeds it cuts mean end-to-end latency by 11.8–32.5% and p99 latency by up to 42.8%.
→ arxiv.org

AdvPlan-Bench: Adversarial Evaluation of Structured Plan-Generation Agents
AdvPlan-Bench：结构化规划生成智能体的对抗评测
adversarial planning plan generation multi-agent critique benchmark design
AdvPlan-Bench is an offline benchmark that represents plans as typed action chains with optional branches and scores opposing plans with BLUE-vs-RED advantage and Nash-gap diagnostics. In 150 synthetic scenarios, a sampled best-response policy reduced BLUE advantage from .518 to .486 and win rate from .900 to .820, and the authors stress the artifact provides no evidence about real-world decision quality.
