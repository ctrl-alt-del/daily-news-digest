Teach and Grow: An Agent-Centered Architecture for General Robot Learning
教与成长：面向通用机器人学习的以智能体为中心的架构
skill library experience memory robot learning demonstration learning
Teach-and-Grow Learning is a training-free architecture that turns a few successful demonstrations into reusable closed-loop Skill Blocks, backed by a persistent Skill Library and an Experience Memory that records conditions and repairs for later decisions. Using OpenAI GPT-6 Astra for multimodal reasoning and Codex to connect the agent to robot tools, it reaches 99.9% mean success on four LIBERO suites and 92.4% on seven LIBERO-Plus perturbation categories.

KernelArc: A Multi-Agent Framework for GPU Kernel Optimization
KernelArc：面向 GPU 内核优化的多智能体框架
multi-agent coordination shared memory kernel optimization SOL-ExecBench
KernelArc is a multi-agent framework for autonomous GPU kernel optimization in which strategy-specialized agents run in parallel and coordinate through conclusions-only shared memory, a deterministic benchmark guard and read-only cross-agent state. In a public SOL-ExecBench leaderboard snapshot, it ranked first on every representative L1, L2, quantization and FlashInfer task evaluated on NVIDIA H100 and B200 GPUs.

DeepSeek arxiv:2608.17153 arXiv ✓
When Detection Does Not Guarantee Resistance: Reasoning and Poisoned Context in RAG
检测并不等于抵御：RAG 中的推理与投毒上下文
knowledge poisoning retrieval-augmented generation deliberative reasoning attack success rate
The paper measures Cordon Rate, the probability a model detects poisoned retrieved context yet still answers in line with it, and Leakage Rate, the probability poisoned context influences an answer despite instructions to ignore it. Across 200 SciFact questions, enabling reasoning in DeepSeek-V4-Flash lowers Cordon Rate from 0.205 to 0.075 and Leakage Rate from 0.235 to 0.140, even as attack success rises from 0.233 to 0.298 and poison detection falls from 0.965 to 0.665.

AISA: AI Safety Assistant Framework for Continuous Improvement of Highway Construction
AISA：面向公路施工持续改进的 AI 安全助手框架
incident retrieval text embeddings safety planning local inference
AISA is an LLM-centered framework for highway construction safety reporting and planning that classifies incident narratives against OIICS fields, scores their quality, and retrieves historical accidents, imagery and industry documents for daily safety plans. On more than 15,000 test narratives, OIICS classification reaches 75% held-out accuracy, and an open-weight decoder embedding model outperforms proprietary models on document question answering.

Can LLMs Reason in a Legally Meaningful Manner? A Small-scale Study on European Court of Human Rights Cases
LLM 能以法律上有意义的方式推理吗？基于欧洲人权法院案件的小规模研究
legal reasoning LLM-as-a-judge prompt design case forecasting
The study evaluates OpenAI GPT 5.4 on European Court of Human Rights case forecasting under prompting strategies that vary how strongly they suggest legally meaningful reasoning, with responses judged by both humans and LLMs. It finds structurally complete but substantively shallow analyses, and that LLM-as-a-Judge evaluators are internally consistent yet align only weakly with trained annotators.

Looped Language Models Improve Compositional Tool Calling
循环语言模型提升组合式工具调用能力
looped language models compositional tool calling recurrent depth API-Bank
The paper evaluates native and retrofitted looped language models on API-Bank, BFCL and NESTful under matched supervised fine-tuning recipes and varying recurrent depth at inference time. Recurrent computation generally benefits compositional and dependency-aware tool use, with multi-step accuracy increasing with depth, while adaptive inference gives a more favorable compute-performance trade-off.

arxiv:2608.17188 arXiv ✓
Token Optimization and Context Window Management in Multi-Agent AI Workflows
多智能体 AI 工作流中的 Token 优化与上下文窗口管理
context window token optimization semantic caching multi-agent workflows
The paper presents six practitioner patterns for token optimization and context-window management, including context stratification, fetch-once/process-locally architecture, schema-contracted prompts, token-aware fallback chains, semantic caching and inter-agent communication compression. In production they cut cold-load latency to 61-116 seconds from roughly 3.5-10.5 minutes with an estimated 60-70% token reduction, and a 2,420-trial study reports that mixing high- and low-relevance context improved relevance accuracy by 0.077 over high-relevance items alone.
