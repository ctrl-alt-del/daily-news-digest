Harness Continual Learning: Continual Adaptation Beyond Model Parameters
Harness 持续学习：超越模型参数的持续适应
harness continual learning harness-level forgetting experience memory adaptive router stability-plasticity
The paper formulates Harness Continual Learning, in which an agent's harness of prompts, memories, tools, skills and routing rules evolves around a frozen foundation model, and defines the resulting loss of earlier behavior as harness-level forgetting. It instantiates four components — Task Interface, Experience Memory, Capability Map and Adaptive Router — with guarded harness evolution that separates proposal from commitment, and reports relative gains above 10% over baselines across textual reasoning, multimodal perception and open-world interaction.

arxiv:2608.19072 arXiv ✓
What is Missing from AI Post-Training AI: An Empirical Analysis
AI 后训练 AI 还缺什么：一项实证分析
recursive self-improvement strategy revision post-training agents agent benchmark
The authors analyze 1,338 post-training trajectories from frontier agents and separate execution-level capability from strategy-level capability, finding that agents execute training reliably but lock into a default strategy, with only 2.1% of transitions between adjacent runs changing strategy. Extra experience and reasoning compute improve execution or refine the committed strategy rather than replacing it, while a single mid-run human instruction outperforms the agent's own continuation by up to 17.44 points under the same budget.

SPADE: Self-Play in Adaptive Synthetic Executable Environments
SPADE：自适应合成可执行环境中的自我对弈
self-play RL synthetic environments tool use reasoning benchmarks
SPADE is a self-play reinforcement learning framework in which a single LLM plays both Environment Designer, writing executable training environments, and Reasoning Agent, learning to act in them. Scaled to 30B parameters, it improves over the strongest fixed-environment baseline by 5.3 points on average across eight held-out math, science, code and reasoning benchmarks, and lifts tool use by 5.7 on BFCL-v4 multi-turn and 13.9 on ACEBench-Agent.

Adaptive Memory and Reflection Multi-Agent System for Medical Question Answering
面向医疗问答的自适应记忆与反思多智能体系统
agent memory reflection multi-agent system medical QA
The paper introduces an adaptive memory and reflection multi-agent system for medical question answering in which specialized agents use dedicated memory and reflection feedback to retrieve relevant prior cases and improve later reasoning. Complexity assessment routes questions through solo, collaborative or escalated workflows, and ablations on MedQA and MedMCQA show that agent-specific memory, reflection and external retrieval together perform best.

BF1: A Causal Dyadic Sparse-Attention Retrofit for Efficient Long-Context Transformers
BF1：面向高效长上下文 Transformer 的因果二元稀疏注意力改造
sparse attention long-context inference model retrofit time-to-first-token
BF1 is a deterministic block-aligned dyadic sparse-attention pattern that combines a small exact local neighborhood, a global first block and logarithmically spaced historical blocks, and is retrofitted into pretrained models under correctness gates. On an RTX PRO 6000 it reaches a 10.91x per-layer prefill speedup at 32K tokens, and retrofitting 8 of 28 Qwen3-0.6B layers lowers warm time-to-first-token by 7.7%, 11.3% and 15.3% at 8K, 16K and 32K.

DeepWeaver: Bridging the Evidence Synthesis Gap in Open-Ended Question Answering
DeepWeaver：弥合开放式问答中的证据综合鸿沟
evidence synthesis citation grounding Thought Block Chains open-ended QA
DeepWeaver is a retrieval-augmented answering method that maintains Thought Block Chains grouping claims, salient information, keywords and supporting evidence so that noisy retrieved evidence is woven into comprehensive, well-cited answers. Across multiple LLMs it improves content sufficiency, citation grounding and detail preservation on the new LoQA benchmark, with deeper insights on DeepResearch Bench.
