arxiv:2608.08768 arXiv ✓
BOUND: Brief-Guided Corrective Preference Distillation at Search-Control Boundaries
BOUND：搜索控制边界上的简报引导式纠偏偏好蒸馏
deep search preference distillation search drift DPO
BOUND targets persistent drift in LLM deep-search agents by having a teacher construct a search-state brief at student decision points and decide whether to form a corrective or termination preference pair, which DPO then distills into the student. It leads on five of six rerun benchmarks and 12 of 14 metrics, beating Trajectory SFT by 5.6 EM on Bamboogle and 4.8 accuracy points on BrowseComp-Plus.

Improving Generalization Robustness of Multimodal RLVR
提升多模态 RLVR 的泛化鲁棒性
RLVR prompt invariance reward design robustness
The authors trace brittle multimodal RLVR gains to a binary verifier that conflates format with content and a training distribution narrower than deployment prompts, and propose Prompt-Invariant RLVR with a dynamic trinary reward and an embedding-space consistency regularizer. Under stress testing PIRL's average accuracy drops by at most 1%, versus about 3% for GRPO.

理论引导的欺骗检测：基于 RAG 的人工智能探索
RAG deception detection response bias theory grounding
Seven theory-grounded RAG models were compared with baselines across 700 statements, four LLMs and 39,200 deception judgments, yielding 54.5% accuracy for RAG versus 54.6% for baselines. arxiv:2608.08940 arXiv ✓
Difficulty-Gated Fusion of Reasoning Views for Temporal Retrieval
面向时序检索的推理视图难度门控融合
temporal retrieval query reformulation rank fusion score calibration
The method expands a query into several temporally explicit reformulations, reads an eight-dimensional score-distribution signature from each view, and uses a roughly one-thousand-parameter gate to set per-query fusion weights without relevance labels, re-ranking or retriever fine-tuning. It improves all six evaluated retrievers on the Tempo benchmark, with the strongest reaching 0.297 nDCG@10 and a per-query oracle at 0.364.

arxiv:2608.08939 arXiv ✓
Not an A11y: How Android Accessibility Exposes Mobile AI Agents to Indirect Prompt Injection
并非无障碍：Android 无障碍服务如何使移动 AI 智能体面临间接提示注入
prompt injection mobile agents agent security attack taxonomy
The paper shows that mobile agent frameworks relying on Android accessibility trees and screenshots are systematically vulnerable to indirect prompt injection, causing goal hijacking, context drift and unauthorized device actions. Attack success reaches 0.822 for MobileRun with Gemma4:31B and 0.150 for Mobile-Use with Qwen3.6:35B, and the authors propose an attack taxonomy and zero-trust input validation.

arxiv:2608.08942 arXiv ✓
Same Question, Different Answer? Measuring and Mitigating Prompt Privilege for Equitable AI Access
同样的问题，不同的答案？衡量并缓解提示特权以实现公平的 AI 访问
prompt equity prompt sensitivity accessibility prompt rewriting
The paper defines Prompt Privilege as performance disparities between semantically equivalent requests phrased differently, and introduces the Prompt Equity Score plus the Prompt Equity Transformer, an agent that rewrites requests into equivalent accessibility-oriented prompts. On MedQA, PET eliminated measurable disparities between low-literacy and expert-prompting cohorts while preserving semantic fidelity.
