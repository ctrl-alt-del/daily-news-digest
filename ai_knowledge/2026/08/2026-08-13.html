面向编码智能体的本体锚定项目记忆
project memory knowledge graph MCP interface supersession neurosymbolic retrieval

TeachMateGPT: A Multi-Agent Knowledge-Grounded Framework for Pedagogical Assessment Generation from Science Curriculum Materials
TeachMateGPT：基于科学课程材料生成教学评估的多智能体知识锚定框架
curriculum-grounded RAG hierarchical knowledge base multi-agent pipeline source-attributed verification assessment generation
TeachMateGPT is a multi-agent system for generating textbook-grounded science assessments, combining a hierarchical curriculum knowledge base (COPE), a fail-closed staged agent pipeline, and a source-attributed verification protocol (SAVER). It raises faithfulness from 0.68 to 0.96 and answer relevancy from 0.60 to 0.89 over a vanilla RAG baseline.

arxiv:2608.13495 arXiv ✓
TraVEL: Trajectory-Guided Video Embedding Learning for Driving-Video Retrieval
TraVEL：面向驾驶视频检索的轨迹引导视频嵌入学习
driving-video retrieval multimodal embeddings trajectory-guided learning GRPO
TraVEL fine-tunes a general-purpose multimodal embedding model for driving-video retrieval, using ego-trajectory similarity as a reward in GRPO because caption supervision alone misses fine-grained motion understanding. Relative to supervised fine-tuning it raises longitudinal and lateral mAP by 9.8 and 4.7 points at 2B, and by 7.2 and 1.5 points at 8B.
→ arxiv.org

AaLLM: An End-to-End Analog Circuit Design Framework from Topology Generation to Sizing Using Large Language Models
AaLLM：从拓扑生成到尺寸优化的端到端模拟电路设计框架
retrieval-augmented design multi-agent workflow analog circuit design tri-agent feedback
AaLLM is an open-source multi-agent LLM workflow that turns user specifications into a netlist, covering both topology generation and circuit sizing. It builds a RAG knowledge base from papers and textbooks and uses Designer, Critic and Evaluator agents, reporting 3x–4.5x fewer SPICE calls at inference and 40x lower wall-clock time than existing multi-agent pipelines.
→ arxiv.org

CLAIR-Fin: An Adversarial Multi-Agent Framework for Claim-Level Verification and Adaptive Debate in Cross-Modal Financial QA
CLAIR-Fin：跨模态金融问答中主张级验证与自适应辩论的对抗多智能体框架
claim-level verification adversarial debate hallucination risk cross-modal grounding
CLAIR-Fin is a nine-agent framework that decomposes financial questions into atomic claims held in a typed Claim Ledger, with claim-type-specific evidence authority, hand-off verification and adaptive adversarial debate. On the 500-question BB-FinQA-X set it raises faithfulness from 0.780 to 0.889 over single-pass RAG, abstaining on 5.4% of questions when evidence is insufficient.

MARC v1: An Open-Source Multi-Agent Framework for Clinical AI Reasoning and Coordination
MARC v1：面向临床 AI 推理与协作的开源多智能体框架
clinical multi-agent orchestration prompt decomposition traceable reasoning open-source framework
MARC is an open-source framework that replaces monolithic LLM prompting with deterministic multi-agent orchestration for clinical reasoning, coordinating extraction, reasoning, answer-generation and evaluation agents with traceable intermediate outputs. It adds a Decomposer that generates task-specific agent prompts from plain language and is configured entirely through YAML, with API-based and local CPU deployments.
