Model Card for OpenAI Privacy Filter
OpenAI Privacy Filter 模型卡
PII redaction token classification long context data minimization
OpenAI Privacy Filter is a compact bidirectional token-classification model that detects and redacts personally identifiable information and secrets in unstructured text, labeling a sequence in a single forward pass with a constrained Viterbi decoder over eight privacy categories. It has 1.5 billion total parameters, 50 million active parameters per token and a 128,000-token context window, and is positioned as a configurable data-minimization component rather than an anonymization or compliance guarantee.

DeepSeek arxiv:2608.17911 arXiv ✓
CABLE: Extending the Reach of Memory Retrieval via Complementary Antecedent-Based Linking and Expansion
CABLE：通过互补的前因链接与扩展提升记忆检索覆盖
memory retrieval memory graph long-term memory LLM-as-a-judge
CABLE is a plug-in augmentation for long-term conversational memory that builds a sparse directed graph of retriever-complementary associations by generating antecedent-oriented queries, subtracting candidates already in the direct semantic neighborhood and verifying the remainder. Evaluated with A-MEM on LoCoMo and MA-LongMemEval and integrated into SimpleMem and Mem0g, it yields higher mean LLM-judge scores in every system-level setting, with the largest gains where useful evidence is spread across memories or sessions.

arxiv:2608.17950 arXiv ✓
Do Large Language Models Play Six Degrees of Separation? Measuring Topological Compression in Long-Context Manifolds
大语言模型也遵循六度分隔吗？度量长上下文流形中的拓扑压缩
small-world networks latent geometry hallucination detection long-context reasoning
The paper sparsifies similarity matrices of long-context hidden states into unweighted graphs and finds that deep reasoning layers compress conceptual distances into paths bounded by six semantic hops, while early syntactic layers remain fractured. Applied to zero-shot hallucination detection in RAG on the RAGognize dataset, grounded generations stay about three hops from their source context whereas hallucinations show severe topological collapse.

Rigorous Evaluation of Large Language Models for Malaria Drug Discovery: Trade-offs in Performance, Scale, and Resource Utility
严格评估用于疟疾药物发现的大语言模型：性能、规模与资源效用的权衡
domain fine-tuning instruction tuning out-of-distribution evaluation open-weight models
The paper introduces Malaria-Instruct, an instruction-following dataset derived from the ChEMBL Legacy Malaria corpus, and evaluates five open-source LLMs against classical ML and proprietary models on an out-of-distribution split. Fine-tuned TxGemma-9B reaches the highest ROC-AUC of 0.731, while the same model falls to 0.499 under its best few-shot condition, and neither Gemini 2.5 nor o3 achieves reliable discrimination without fine-tuning.

EvoTS-Agent: A Self-Evolving LLM Agent for Financial Time Series Change Point Detection
EvoTS-Agent：用于金融时间序列变点检测的自进化 LLM 智能体
self-evolving agent change-point detection validation-guided search benchmark evaluation
EvoTS-Agent is a validation-guided self-evolving LLM agent for financial time-series change-point detection that initializes candidate models through curated exploratory data analysis, then evolves executable experiment trajectories with revision, alternative-strategy and recombination operators. Across four benchmark datasets it outperforms existing LLM-based agents while maintaining a 100% execution success rate on all evaluated backbone LLMs.

arxiv:2608.18351 arXiv ✓
Task-Conditioned Least-Privilege Learning for Executable Terminal and MCP Agents
面向可执行终端与 MCP 智能体的任务条件化最小权限学习
least privilege MCP agents post-training safe success
The paper post-trains a 4B-parameter model to choose task-conditioned authority in executable terminal and Model Context Protocol environments, auditing each action before execution and again from observed effects along six risk dimensions. After training Qwen3.5-4B on 1,500 tasks, the selected seed reaches 98.48% safe success across 2,896 evaluation episodes versus 64.36% for the base policy, and reduces excess-authority errors from 4.56% to 0.79%.

arxiv:2608.18280 arXiv ✓
What Makes Software Issue Resolution Tasks Difficult for Agents?
软件问题解决任务对智能体而言难在哪里？
task difficulty coding agents benchmark construction trajectory analysis
The study extracts patch, repository and prompt features from CoderForge-Preview trajectories and tests how well static properties predict agent success on issue resolution tasks. Task difficulty is substantially predictable from static features (AUC 0.863), driven largely by patch fragmentation and repository scale, with prompt linguistic features contributing mainly in the mid-difficulty band.
