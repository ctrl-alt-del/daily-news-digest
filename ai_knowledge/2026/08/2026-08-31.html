Context Window Failures in Relational Foundation Models
关系型基础模型中的上下文窗口失效
relational foundation models context window tabular reasoning benchmark dataset
The paper introduces Animus, a synthetic financial dataset in which predicting customer income requires aggregating up to tens of thousands of transactions, exposing the constrained neighborhood budgets of relational foundation models. Three recent models achieve R² of at most 0.18 on the raw representation, while a single routine temporal pre-aggregation step recovers R² up to 0.65, questioning readiness for high-cardinality real-world data.

SpecMind: Enabling Spectrum Intelligence via Multi-Agent Hybrid Retrieval-Augmented Generation
SpecMind：通过多 Agent 混合检索增强生成实现频谱智能
multi-agent RAG heterogeneous retrieval domain QA benchmark dataset
SpecMind is a multi-agent retrieval-augmented generation system for spectrum intelligence in which autonomous agents coordinate specialized sub-agents that retrieve and synthesize knowledge across policy proceedings, legal regulations and license databases. The authors also build SpecBench, a question-answering dataset based on real license records and policy proceedings, and report over an 80% win rate against strong general-purpose RAG baselines.

arxiv:2609.01660 arXiv ✓
How Fast Do Agents Rot? An Empirical Study of Long-Horizon Degradation in LLM Agents for Production Decision-Making
Agent 衰减有多快？生产决策中 LLM Agent 长程退化的实证研究
long-horizon agents agent reliability horizon-aware evaluation agent orchestration
Across nine models, four task families, five horizons and three context regimes, the study finds task success follows a geometric law governed by a per-step reliability parameter that rises with model scale but saturates well below 1. On the agentic tool-use task every model tested falls from near-perfect success to near zero within sixteen steps, and bounding the context window steepens decay, indicating degradation is driven by step count rather than context length.
→ arxiv.org
arxiv:2609.00237 arXiv ✓
Learning What to Retain: Gated-Memory Routing for Efficient Collaboration in Multi-Agent LLM Systems
学习保留什么：多 Agent LLM 系统中高效协作的门控记忆路由
agent memory multi-agent orchestration memory gating adaptive halting
Gated-Memory Routing conditions each orchestration decision on the query and a learned execution memory, with a Memory Write Gate that commits only non-redundant reasoning steps, a Retrieval Gate that supplies each agent a compact relevant subset, and an Adaptive Halting Controller. Across five reasoning and code-generation benchmarks it attains the best average accuracy, exceeding the strongest baseline by 2.44 points while cutting HumanEval inference cost by 31.9%.

EGT-KG: Evidence-Grounded Typed KG Retrieval for Practical Scientific QA with Small Language Models
EGT-KG：面向小模型实用科学问答的证据接地类型化知识图谱检索
knowledge graph retrieval small language models evidence grounding RAG evaluation
EGT-KG is an evidence-grounded typed knowledge graph retrieval framework for scientific question answering with local small language models, evaluated against vanilla RAG with automatically generated and expert-defined relation schemas. On a biopolymer-bound soil composite literature benchmark scored by a six-dimensional framework, it outperforms vanilla RAG in most settings, with the best gain from llama3:8b at a final score of 70.37 (+14.67%).

arxiv:2609.00228 arXiv ✓
Bridging Lexical Divergence: LLM-Assisted, Cost-Efficient, Zero-shot Scientific Entity Linking
弥合词汇差异：LLM 辅助、低成本、零样本的科学实体链接
entity linking ontology alignment pseudo-labelling zero-shot evaluation
Sci-ZSEL is a zero-human-annotation framework for scientific entity linking that selectively generates entity aliases with an LLM to control cost, applies an ontology-aware filter to remove aliases drifting toward ontology neighbours, and uses the filtered aliases to construct pseudo-labelled mention-entity pairs for fine-tuning. Across five benchmarks it outperforms the non-fine-tuned baseline and is most useful on non-overlapping mentions, and the authors release a new animal-science benchmark linked to three livestock trait ontologies.
→ arxiv.org

arxiv:2609.00474 arXiv ✓
Exploring Collaboration between a language and a non-language agent
探索语言智能体与非语言智能体的协作
latent state transfer multi-agent collaboration representation bottleneck benchmark design
The paper introduces LLAMIA-Bench, six collaborative chess tasks spanning behavioral imitation, state assessment and natural-language explanation, to test whether verbalizing a non-language agent's continuous representations creates a bottleneck. It proposes latent state internalization, which projects those representations into the LLM token stream as learned state tokens, and a 14B model trained this way matches or exceeds task specialists and frontier models including GPT-5.1 with tool access while generalizing out of distribution.
