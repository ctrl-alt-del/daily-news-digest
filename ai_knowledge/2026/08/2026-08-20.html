Can Agent Memory Systems Track Evolving State?
智能体记忆系统能否跟踪不断演化的状态？
agent memory state tracking memory benchmark memory wrapper
The authors introduce StateMemBench, a 234-scenario benchmark testing whether agent memory systems track evolving world state, and propose StateMem, which improves current-state accuracy by 1.8x on DeepSeek-V4-Flash and 1.6x on Qwen-3.5-9B over strong baselines. StateMem also works as a lightweight single-call wrapper over existing memory systems.

Applying Anthropic Primitives at Large Enterprises: Harness Paradigm for Knowledge Work
将 Anthropic 原语应用于大型企业：面向知识工作的 Harness 范式
harness paradigm enterprise governance agent infrastructure benchmark variance
The paper argues that enterprises should treat the coding-agent harness as centrally governed infrastructure rather than building a custom orchestrator per use case, citing recent findings that harness choice accounts for more variance in agent benchmark results than model choice. It proposes one unmodified harness backbone with credential-scoped tooling, authorization logic outside the harness and registration as a side effect of pushing code, built on the microcc reference harness.

arxiv:2608.20317 arXiv ✓
CMASS: A ClimbMix Agentic Search Suite for Evaluating Search Agents Across Heterogeneous Tasks
CMASS：面向异构任务的 ClimbMix 智能体搜索评测套件
agentic search benchmark suite evidence coverage multi-hop QA
CMASS projects BrowseComp-Plus, Total Recall QA, DeepSearchQA and HotpotQA onto ClimbMix, a fixed pre-training corpus of 553M documents and about 400B tokens assembled independently of the benchmark questions. The 423 questions span entity identification, multi-hop reasoning, exhaustive answer sets and aggregation, and evaluations of three models show substantial headroom while high answer accuracy can coexist with incomplete evidence coverage.

NVIDIA arxiv:2608.20614 arXiv ✓
Evaluating Skills, Not Just Agents: Agentic Continuous Evaluation of Skills
评估技能而非仅评估智能体：技能的智能体持续评估
skill evaluation agent skills trajectory normalization Skill Lift
ACES is a repository-native framework that evaluates skills and capability packages through paired live agent trials with and without a target skill, normalizing trajectories into ATIF and reporting Skill Lift for a fixed task, harness, workspace and scorer. Across 145 real skills and 947 scored paired cases from 58 of 64 production skills, mean composite Skill Lift is 0.2134 and positive in 72.8% of cases, while scan-only gates measure complementary facets with a Spearman correlation of 0.14 against LLM-judge scores.

Balancing Reasoning and Hardware Constraints in RAG Pipelines for Ukrainian Multi-Domain Document Understanding
在 RAG 流水线中平衡推理与硬件约束：面向乌克兰多领域文档理解
hybrid retrieval reranking document understanding resource-constrained inference
The paper describes a UNLP 2026 shared-task system that extracts answers, document IDs and page numbers from Ukrainian PDFs under a 9-hour offline Kaggle limit, where OCR consumed 5–7 hours and left about two hours of LLM inference for 500 questions. Its hybrid BM25, BGE-M3 and cross-encoder reranking pipeline used a 4-bit LapaLLM 12B model on dual NVIDIA T4 GPUs instead of heavier reasoning models and scored 0.8095, placing 10th among 15 active teams.

An integrated diffusion-weighted imaging processing and interpretation platform for MR-guided radiotherapy
面向 MR 引导放疗的弥散加权成像处理与解读一体化平台
clinical RAG traceable citations knowledge base expert evaluation
The platform couples deep-learning DWI processing — distortion correction, denoising and IVIM/ADC fitting — with longitudinal region-of-interest analysis and a RAG interpretation agent that reasons over a two-layer knowledge base of curated publications. Across 54 expert ratings on nine glioblastoma cases it received a pooled mean of 4.65 out of 5, with 93% of ratings at 4 or above and raters agreeing within one point on 85% of paired ratings.

MidTool: Mid-training Data Synthesis for Agentic Tool Use
MidTool：面向智能体工具使用的训练中期数据合成
tool use mid-training MCP data synthesis
MidTool is an open corpus pipeline for agentic tool-use mid-training that combines web, PDF and code data with synthesized supervision from real-world tool APIs, MCP skills and document workflows. Mid-training Qwen3-4B/8B on MidTool-Mix consistently improves tool-use performance under both SFT and RL on BFCL, tau2-Bench and MCP Universe.

arxiv:2608.20318 arXiv ✓
AI4AI-Bench: Benchmarking LLM Agents in Algorithmic Design for Recursive Self-Improvement
AI4AI-Bench：面向递归自我改进的算法设计智能体基准
recursive self-improvement algorithm design benchmark training algorithms
AI4AI-Bench provides ten frozen research repositories spanning ten training-algorithm families, in which an agent has four hours on one B300 to rewrite the training algorithm before its code is rerun for up to 12 hours and scored by a hidden evaluator. Across 29 configurations of six systems the mean score is 0.166 and the best is 0.250, with most submissions never changing how the model learns and more reasoning effort mainly increasing willingness to attempt it.

G-CARL: Grounded Checklist-Aligned Reward Learning for Patient-Oriented Medical Report Interpretation
G-CARL：面向患者医疗报告解读的锚定清单对齐奖励学习
claim verification checklist reward medical report interpretation retrieval grounding
The paper introduces the Patient-oriented Medical Report Interpretation task and G-CARL, a grounded checklist-aligned reinforcement learning framework that combines multi-source retrieval for atomic claim verification with context-aware, instance-specific weighted checklists for response coverage. It also builds MMedReport, a real-world benchmark with a clinician-designed three-dimensional evaluation protocol, and reports gains over post-training baselines in overall quality, claim-level precision and checklist recall.

ContractScrub: A benchmark for final review of legal contracts
ContractScrub：法律合同终审的评测基准
legal benchmark contract review consistency checking
ContractScrub is presented as the first benchmark for evaluating LLMs on contract scrubbing, the final review of transactional agreements, using contracts hand-crafted by experienced lawyers. Frontier models perform surprisingly poorly, with only one reaching 0.75 macro average recall.
