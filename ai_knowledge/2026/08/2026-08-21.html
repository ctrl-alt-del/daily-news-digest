Utility Under Attack: Agent Memory Poisoning and the Limits of Content Screening and Provenance Ranking
效用遭受攻击：智能体记忆投毒与内容筛查、来源排序的局限
memory poisoning provenance ranking content screening retrieval defense
The paper measures how far a small amount of false information persists in agent memory: poisoning 1.2% of a LongMemEval corpus reduces accuracy from 0.850 to 0.300 with plainly worded assertions and no retriever optimization. A four-stage write-time screening pipeline with 0.832 recall on indirect prompt injection rejects 0 of 360 poisoned memories, and the shipped provenance-weighted retrieval weight is statistically indistinguishable from no defense.

EnSI-RAG: Entity-Structure-Indexed Retrieval-Augmented Generation for Long-Document Question Answering
EnSI-RAG：面向长文档问答的实体—结构索引检索增强生成
entity-centric index RAG long-document QA traceable evidence
EnSI-RAG builds a query-independent, entity-centered index whose records of entity, type, semantic category and value act as retrieval handles while retaining links to the original source passages, separating evidence localization from answer synthesis. Across Loong and Oolong it reaches 78.24 average accuracy, 6.62 points above the published baseline scores used as references.

MidTool: Mid-training Data Synthesis for Agentic Tool Use
MidTool：面向智能体工具使用的训练中期数据合成
tool use mid-training MCP data synthesis
MidTool is an open corpus construction pipeline for agentic tool-use mid-training that combines large-scale web, PDF and code data with synthesized supervision from real-world tool APIs, MCP skills and document-grounded workflows. It aims to teach models to recognize tool affordances, ground arguments from context, compose tool-call workflows and recover from incomplete information.

Automating Multi-Hop RAG Evaluation via TRIAD: From Context Extraction to Validated Dataset Generation
通过 TRIAD 自动化多跳 RAG 评测：从上下文抽取到经验证的数据集生成
RAG evaluation dataset generation multi-hop QA domain knowledge base
TRIAD is a three-stage automated approach that generates question-answer pairs for a domain-specific RAG knowledge base, validates each pair in a feedback loop, and extends the pairs with relevance-labeled context documents for downstream evaluation. Comparisons with MuSiQue and HotpotQA show similar performance trends across RAG setups, and human validation finds the questions suitable for evaluating domain-specific RAG systems.

arxiv:2608.21606 arXiv ✓
Can LLMs Truly Forget? Revealing Unlearning Gaps Through Adversarial Evaluation
LLM 真的能遗忘吗？通过对抗性评估揭示遗忘缺口
machine unlearning adversarial evaluation knowledge removal prompt attacks
The paper evaluates prompt-based and fine-tuning-based unlearning on TOFU with Llama-3.2-3B-Instruct, then stress-tests the strongest methods with eight adversarial attack suites using an LLM-as-judge Attack Success Rate metric. Several fine-tuning methods reach Forget Quality above 0.91 yet still leak targeted information with ASRs of 72.8% to 84.3%, close to the 87.5% of the unprotected base model, while clean multilingual reformulations yield only 2.95% measured leakage.

arxiv:2608.21544 arXiv ✓
Forgotten in Weights, Recovered by Tools: Agentic Tool Unlearning for LLM Agents
权重中遗忘，工具中找回：面向 LLM 智能体的工具遗忘
tool unlearning agent memory tool use trajectory RL
The paper identifies tool-mediated recovery, where an agent recovers a supposedly forgotten target through web search, retrieval or database lookup, as a failure mode for LLM unlearning, and proposes Agentic Tool Unlearning. Its first stage applies parametric unlearning and its second performs trajectory-level reinforcement learning in simulated tool-augmented environments; on RWKU and MUSE it achieves a better balance between target forgetting and retained utility.
→ arxiv.org
arxiv:2608.20220 arXiv ✓
InsufficiencyBench: Evaluating LLM legal advice on underspecified user queries
InsufficiencyBench：评估 LLM 对信息不足法律咨询的处理
legal benchmark underspecified queries legal reasoning
InsufficiencyBench is described as the first legal benchmark targeting query-side insufficiency: whether a model recognizes that a query lacks legally material information, identifies what is missing and refrains from premature conclusions. It contains 202 items across six legal domains and 24 US jurisdictions annotated by practicing attorneys, and none of the ten evaluated frontier models fully solves the task.

arxiv:2608.20106 arXiv ✓
OenoBench: A Wine-Domain Benchmark for Knowledge-Grounded Evaluation of Large Language Models
OenoBench：面向大语言模型知识评测的葡萄酒领域基准
knowledge benchmark source grounding domain knowledge
OenoBench is a wine-domain knowledge benchmark of 3,266 multiple-choice questions across six pillars — regions, grape varieties, viticulture, winemaking, producers and business — built from 38,104 source-anchored facts extracted from government registries and journals. Every claim traces to a URL and the questions are audited against a human gold sheet.
