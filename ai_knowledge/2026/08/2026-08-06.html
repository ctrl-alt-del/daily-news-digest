NeSy-RAG: Neuro-Symbolic RAG for Explainable Question Answering
NeSy-RAG：面向可解释问答的神经符号 RAG
neuro-symbolic RAG explainable QA knowledge-gap detection Prolog joint embeddings
NeSy-RAG synthesizes attributable Prolog modules from retrieved text chunks, generating predicates for Boolean claims that may depend on user facts and composing them into queries via joint natural language-code embeddings. A symbolic knowledge-gap detector flags missing user facts whose values affect the query outcome and triggers follow-up interactions; on ShARC the framework reaches 61.1% accuracy versus 42.8% for a same-model RAG baseline without domain-specific training.

WebGrader: Training LLMs for Web Development with Self-Evolving Programmatic Grader
WebGrader：用自演化程序化评分器训练 Web 开发 LLM
programmatic grader RL reward design verifier skills web agents
WebGrader is a self-evolving programmatic grader that derives required interaction flows from each website request, encodes them as executable Flow Contracts and uses their execution outcomes as RL reward, issuing a Pass verdict only after observing the requested transition. On WebGen-Bench it trains an 8B policy to 52.01% functional success, 7.88 points above a matched appearance-plus-script reward and ahead of o4-mini and DeepSeek-v4-flash.

A Six-Dimensional Taxonomy of Post-Training Adaptation Techniques with Applications in AI Governance
后训练适配技术的六维分类体系及其 AI 治理应用
post-training adaptation taxonomy retrieval augmentation model editing AI governance
This survey organizes post-training adaptation techniques - including retraining, fine-tuning, parameter-efficient adaptation, alignment, retrieval augmentation, model editing, unlearning and calibration - into a six-dimensional taxonomy covering mechanism, goal, data requirement, persistence, structural scope and model type. It distinguishes commonly conflated terms such as fine-tuning, retrieval augmentation and prompting, and maps inheritance, supersession, hybridization and layered deployment relationships.

Shape Your Feed：面向对话式推荐的 LLM 智能体系统
conversational recommendation persistent profile DPO LLM-as-a-judge
Shape Your Feed is an LLM-based agentic recommendation framework with a Perception Flow that captures intent from text, voice and UI interactions, a Serving Flow that reranks candidates against a persistent Semantic Profile, and a Self-Evolution Flow aligned through DPO and an LLM-as-a-Judge ensemble. arxiv:2608.06477 arXiv ✓
StepJack: Benchmarking Computer-Use Agent Safety Against Multi-Step Indirect Prompt Injection
StepJack：面向多步间接提示注入的计算机使用智能体安全基准
prompt injection agent safety computer-use agents safety benchmark
StepJack introduces multi-step indirect prompt injection, an attack class that decomposes an adversarial goal into innocuous-looking sub-steps distributed across a chain of pages along the agent's navigation path, and provides a 480-example benchmark. Across six computer-use agents, multi-step attacks raise attack success rates on three of six at fixed depth, by up to 31.2 points, with GPT-5.4-mini rising from 41.7% at single-step to 72.9% at three-step.
→ arxiv.org
arxiv:2608.06503 arXiv ✓
Towards Reliable Context Compression for Long-Horizon Agents: An Empirical Study of Execution Instability
面向长程智能体的可靠上下文压缩：执行不稳定性实证研究
context compression long-horizon agents execution stability verifier-guided optimization
This preliminary empirical study shows that recurrent context compression can weaken the influence of recent interactions, increasing blocked actions, repeated exploration and run-to-run instability in long-horizon agents. TRACE addresses this with verifier-guided evaluation of individual compaction events using paired closed-loop continuations from the same environment state, optimizing a natural-language compression prompt with all models frozen; initial AppWorld results improve task performance, multi-run reliability and context-execution efficiency.
→ arxiv.org
