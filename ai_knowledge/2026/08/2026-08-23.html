CONTRAMEM: Learning Self-Evolving Procedural Memory from Contrasting Multi-Model Trajectories
CONTRAMEM：从对比式多模型轨迹中学习自演化程序性记忆
procedural memory self-evolving memory skill cards computer-use agents knowledge transfer
CONTRAMEM is a training-free framework that treats same-task outcome variation across heterogeneous model trajectories as supervision, distilling differences in correctness, efficiency, recovery and failure modes into a compact bank of app-level Function Cards and task-level Skill Cards that evolves through localized curation. On held-out GAIA2/ARE computer-use tasks it more than doubles success across three source models (26.2% to 55.3%) and transfers unchanged to the unseen Qwen3.7 Plus (18.5% to 35.5%).

Clinical Graph-JEPA: Predictive Patient-State Knowledge Graphs for Cognitive Decision Support
Clinical Graph-JEPA：面向认知决策支持的预测性患者状态知识图谱
clinical knowledge graph graph refinement ontology normalization patient-state representation relation recovery
The framework builds an evidence-scored patient-state knowledge graph per admission from structured MIMIC-IV records and inferred clinical cross-links, combining multi-agent relation proposal, ontology-aware normalization, deterministic evidence scoring and JEPA-based latent refinement. Under a leakage-free leave-one-out protocol, injecting real discharge-note representations only into note-grounded entities improves overall MRR by 31% relative.

arxiv:2608.22610 arXiv ✓
Coalition-Aware Skill Reliability for Self-Evolving Agents
面向自演化智能体的联盟感知技能可靠性
skill bank self-evolving agents skill selection Shapley marginals cross-domain transfer
The authors audit agent skill banks across alternative compositions and deployment domains and identify two reliability failures: coalition pollution, where bank-level gains hide negative coalition-level skill contributions, and cross-domain utility reversal after transfer. They propose Coalition-Aware Skill Selection using sampled Shapley marginals and an unsupervised skill-masking optimizer, which improve task performance and cross-domain generalization on LoCoMo, LongMemEval, HotpotQA and ALFWorld.

Claim-Level Confidence Calibration for Reliable Decision Making with Large Language Models
面向 LLM 可靠决策的断言级置信度校准
confidence calibration claim decomposition hallucination selective retrieval uncertainty evaluation
The paper decomposes each LLM response into atomic, verifiable claims and assigns each claim a calibrated confidence from inference-time consistency and self-verification signals, operating in closed-box settings without logits or fine-tuning. Across TriviaQA and TruthfulQA with six recent models, claim-level decomposition with post-hoc calibration reduces expected calibration error on factual questions but exposes failure modes on adversarial false-premise questions.

GeoRisk-RAG: A Hierarchy-Aware Risk Framework for Improving RAG Reliability through Selective Answering
GeoRisk-RAG：通过选择性回答提升 RAG 可靠性的层次感知风险框架
RAG reliability selective answering geographic hierarchy abstention risk estimation
GeoRisk-RAG estimates geographic applicability before generating a response, using a DAG-based distance over geographic hierarchies to decide when to answer selectively in natural-hazard domains. On a held-out wildfire QA dataset it cuts false-confidence rates to 0.009 versus about 0.090 for semantic-similarity and reranking baselines, while achieving higher human preference alignment.

arxiv:2608.22472 arXiv ✓
Small Reasoning Models are Instruction Followers in Function Calling
小型推理模型在函数调用中是指令遵循者
function calling instruction following small models on-device deployment quantization
The paper shows that LLMs achieve higher function-calling accuracy in instruction-following contexts than in tool-calling contexts, and proposes Instruction-Followed Function Calling (IFFC), which decouples function-calling logic from the primary model and delegates it to a smaller dedicated model. IFFC outperforms native and prompt-based function calling, with particularly strong gains on reasoning-oriented LLMs, and remains robust under aggressive quantization for on-device deployment.

arxiv:2608.22566 arXiv ✓
From Diagnosis to Redesign: Using Quantitative Ethnography to Improve Multi-Agent LLM Reasoning
从诊断到重设计：用定量民族志改进多智能体 LLM 推理
multi-agent debate discourse analysis prompt redesign agent diagnostics
The authors apply Epistemic Network Analysis to the discourse of a five-agent debate system used for automated essay scoring, finding that correct decisions featured rubric-grounded justification, agreement and elaboration while incorrect ones featured extended proposition-challenge-response exchanges less tied to rubric criteria. Prompt revisions based on these findings raised exact scoring accuracy from 27.78% to 40.28% and shifted the discourse of incorrect debates toward the pattern of correct ones.

Learning Generalizable Behaviors for Terminal Agents
为终端智能体学习可泛化行为
terminal agents RL post-training skill composition process rewards environment filtering
The paper proposes the Agentic Compositional Generalization hypothesis, that RL mainly shapes high-level decision-making which composes and routes skills acquired during pretraining and SFT, and introduces River, a recipe that filters low-quality environments and augments outcome rewards with process-level behavior regularization. River reaches the best performance among evaluated open-source RL-trained 8B models on four terminal-agent benchmarks and improves RL gains by 106% and 30% using fewer than 30% of the TMax training environments.
