Tunable Tool-Call Rates in LLM Agents via Representation Steering
通过表征引导可调控 LLM 智能体的工具调用率
representation steering tool use inference-time intervention open-domain QA
The authors show that whether an instruction-tuned model calls a tool can be controlled by a single linear direction in its residual stream, extracted without training from the model's own tool-use preference signal and applied as an inference-time intervention without prompt changes. Sweeping the steering strength moves call rates monotonically from near 0% to over 90%, transfers to unseen tools and multiple model architectures, and nearly doubles open-domain QA accuracy (0.29 to 0.56) with live tool execution.

arxiv:2608.24848 arXiv ✓
BrowserForge: Scaling Web Episode via Parallel Browser Sandboxes
BrowserForge：通过并行浏览器沙箱扩展 Web 交互回合
web agents trajectory synthesis browser sandboxes multimodal agents
BrowserForge generates web-agent interaction data at scale by driving many browser sandboxes in parallel over the open web, combining open-web sourcing, a cluster manager for hundreds of concurrent browsers, and a Proposer-Solver loop that turns a page into an executable task and collects a verified trajectory. The resulting corpus contains 203,238 trajectories each from a distinct website, and fine-tuning a compact multimodal model on it raises live Online-Mind2Web success from 25.66% to 33.33%.

arxiv:2608.24846 arXiv ✓
FedV-KGQA: Multi-Hop Question Answering over Vertically Partitioned Knowledge Graphs
FedV-KGQA：垂直分区知识图谱上的多跳问答
federated KGQA knowledge graph embeddings multi-hop reasoning data sovereignty
FedV-KGQA is a framework for multi-hop question answering over knowledge graphs where organizations share entities but own disjoint relation sets, combining local graph enrichment with knowledge graph embeddings so raw triples and relation parameters never leave each silo. A topic-entity anchoring mechanism grounds questions in the right neighborhood without runtime inter-silo communication, and across 12 model configurations and three benchmarks it stays close to centralized performance and generalizes to 3-hop reasoning.

Federation Is Nearly Free, Reasoning Is Not: Tradeoffs for AI Co-Scientists in Protein Characterization Workflows
联邦几乎免费，推理并非如此：蛋白质表征工作流中 AI 协同科学家的权衡
AI co-scientist federation topology reasoning traces model selection
A controlled ablation on a production agentic science platform for protein function characterization varied federation topology, classic RL versus LLM-driven harnesses, model choice and prompt expertise. Model choice dominated prediction quality (Opus roughly 92–94% versus o4-mini roughly 40–50%), a PPO policy reached 88% at zero token cost with perfect consistency but no reasoning trace, and federation imposed a negligible performance penalty.

Transaction Foundation Models for Retrieval-Augmented Generation over Financial Transaction Data: A Comparative Evaluation with Text Embeddings
面向金融交易数据检索增强生成的事务基础模型：与文本嵌入的对比评估
retrieval-augmented generation transaction embeddings domain-specific retrieval feature aggregation
The authors build a deterministic 1,026-question QA benchmark with retrieval-level gold-document annotations over IBM's synthetic Anti-Money-Laundering transaction dataset, comparing NVIDIA's 29M-parameter Transaction Foundation Model with five general-purpose and financial text embedding models. The TFM beats every size-matched generic embedder on retrieval (Recall@5 0.81 vs. 0.25–0.39) and end-to-end accuracy (66.7% vs. 27.5%), but a pipeline embedding a hand-engineered aggregated summary with a generic encoder matches or exceeds it overall and dominates on several low-cardinality entity categories.

arxiv:2608.25054 arXiv ✓
SPECTRA: Subspace-Preserving Embedding Calibration, Transport, and Replay for Fully Few-Shot Class-Incremental Audio Classification
SPECTRA：面向完全少样本类增量音频分类的子空间保持嵌入校准、迁移与回放
embedding calibration subspace replay continual learning audio classification
SPECTRA is a frozen-encoder framework for fully few-shot class-incremental audio classification that adds a lightweight trainable adapter, exemplar-free subspace feature replay that samples old classes from their stored low-rank subspaces, and transductive optimal-transport prototype refinement at test time. On NSynth-100, FSC-89 and LS-100 it improves average accuracy and reduces forgetting over prior state-of-the-art, with ablations indicating that subspace replay outperforms equal-variance Gaussian replay.

arxiv:2608.25148 arXiv ✓
Can You Trust Frozen Hematology Foundation Models under Acquisition Shift?
采集偏移下冻结血液学基础模型可信吗？
embedding robustness calibration domain shift frozen encoders
The authors audit 15 frozen hematology, pathology and general vision encoders across four public single-cell acquisition domains for accuracy robustness and calibration, finding in-domain macro-F1 saturated at 0.98–0.997 while cross-dataset macro-F1 drops 34–72% and model rankings reorder. Source-trained probes are nearly calibrated in-domain (ECE 0.004) but confidently wrong off-domain (ECE 0.35), and a training-free Class-Balanced Re-standardization improves all target-prior scenario means while leaving residual miscalibration.

arxiv:2608.25220 arXiv ✓
FLARE: Verifying MILP Reformulations with LLM-Based Theorem Proving
FLARE：基于 LLM 定理证明的 MILP 重构验证
theorem proving formal verification MILP reformulation agentic verification
The paper introduces a constructive definition of MILP reformulation that can be formalized and machine-checked in Lean, plus FLARE, an LLM-based agent paired with Lean that verifies proposed reformulations against a reference formulation. On the new FormulationBench (20 problems and 109 formulations) FLARE reports 100% accuracy on the NP-hard subset and produces a machine-checkable certificate for every reformulation it accepts, while a cheaper LLM-only proxy matches its accuracy without certificates.
