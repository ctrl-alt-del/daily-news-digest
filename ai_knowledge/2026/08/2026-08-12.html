AVA-Encoder: Towards Agent-Native Video Representation Learning
AVA-Encoder：迈向智能体原生的视频表征学习
film knowledge graph agent-native representation self-evolution multimodal assets reconstruction benchmark
AVA-Encoder works backward from finished films, encoding each into a Film Knowledge Graph of structured-text nodes, typed dependency edges and linked multimodal assets, then regenerating the film with a fixed decoder so reconstruction residuals become textual gradients for dual-loop self-evolution. It improves reconstruction fidelity by 20.7 percentage points over the strongest baseline, and its learned policy beats a finely human-tuned policy with over 70% fewer system-prompt tokens.

Governed Persistent Memory: Source-Bound State Semantics and Fail-Closed Release for Long-Horizon Agents
受治理的持久记忆：长程智能体的源绑定状态语义与故障关闭式释放
persistent memory memory governance provenance fail-closed release memory benchmark
Governed Persistent Memory introduces an auditable bitemporal state-transition model with source-bound admission, derived lifecycle state and fail-closed structured release, so contradictory, superseded, retracted or stale records cannot support an outgoing claim. On a hash-frozen 3,600-case GPM-ReleaseBench it matches all complete outcomes, and in a sealed service evaluation the governed lane is correct on 2,400/2,400 clusters versus 600/2,400 for an ungoverned local Qwen2.5-7B, repairing all 1,800 baseline failures.

VAKRA: Evaluating Multi-Hop Reasoning Across APIs and Retrieval Under Tool-Use Policies
VAKRA：评估工具使用策略下跨 API 与检索的多跳推理
agent benchmark multi-hop reasoning API retrieval tool-use policy
VAKRA is a benchmark of over 8,000 executable APIs across 62 domains, with tasks covering diverse API interaction styles, multi-hop reasoning over structured APIs and multi-source reasoning under natural-language tool-use policies, verified by re-executing predicted calls against live APIs. Even the best model reaches only 70.4% on single-hop endpoint-style tasks and 50–51% on compositional APIs, with policy-constrained questions exposing failures as low as 2.4% on unanswerable queries.

CAKE: Compiler-Agent Co-Design for Frontier Kernel Evolution
CAKE：面向前沿内核演化的编译器-智能体协同设计
agent harness compiler co-design kernel optimization harness evolution
CAKE has agents author a typed, hardware-explicit schedule IR that exposes warp roles, memory movement, synchronization and pipelines, while recurring failures become verifier rules, IR primitives, model calibrations and reusable optimization tactics in an evolving harness. On B200 the best CAKE IR candidate runs at 1.144x the tuned FlashML baseline at an 80-million-token budget, and agent-generated Kimi Delta Attention achieves a 2.05x geometric-mean speedup over official FlashKDA.

Diagram-MMU: A Multi-Modal Benchmark for Scientific Diagrams
Diagram-MMU：面向科学图表的多模态基准
multimodal benchmark scientific diagrams diagram-to-code agentic evaluation
Diagram-MMU is a multimodal benchmark with 3.7k curated scientific diagrams and 18.3k human-validated questions across six domains, testing diagram-to-code parsing, diagram-to-code editing and diagram question answering alongside agentic settings. Evaluating 12 MLLMs shows diagram-to-code tasks are harder than question answering, and most models improve on parsing and editing under agentic settings but degrade on question answering.

Beyond Trial-and-Error: Agentic Optimization for Image-to-Video Adherence
超越试错：面向图像到视频一致性的智能体优化
prompt optimization agentic self-improvement video generation human preference
The Agentic Self-Improvement framework reframes image-to-video synthesis as a closed-loop optimization, using an mLLM to iteratively refine prompts with scene-graph queries and common-mistake questions, then applying Bayesian optimization to seeds and CFG scales guided by a Video-Text Adherence score. In human preference studies its videos were preferred over baseline outputs with win rates up to 69%.

Convergent Detour Hijacking: Task-Preserving Resource Amplification in Skill-Based LLM Agents
收敛式绕行劫持：技能型 LLM 智能体中保持任务的资源放大攻击
agent security skill ecosystem tool-use attacks trajectory integrity
Convergent Detour Hijacking is a text-only attack that uses a skill description to win selection and an aligned instruction body to fabricate dependencies during planning, recruiting an attacker-controlled coordinator and unnecessary benign skills into a bounded detour before re-entering the original route. Across 491 held-out tasks on DeepSeek-V4-Pro the matched coordinator is selected in 80.02% of tasks, and among completed runs token consumption and execution time rise by 66.91% and 92.45% while task completion remains comparable.
