MemoBrain: Executive Memory as an Agentic Brain for Reasoning
MemoBrain：作为推理代理大脑的执行记忆
executive memory dependency-aware memory context budget sub-trajectory folding tool-augmented agents
MemoBrain is proposed as an executive memory layer for agents that use tools, maintaining a dependency-aware record of reasoning steps while discarding invalid ones and collapsing finished sub-trajectories so the core reasoning trace fits a fixed context budget. The authors report gains over strong baselines on GAIA, WebWalker and BrowseComp-Plus.

Cost and Accuracy of Long-Term Memory in Distributed Multi-Agent Systems Based on Large Language Models
基于大语言模型的分布式多智能体系统中长期记忆的成本与准确率
long-term memory memory backend comparison graph memory retrieval completeness total cost of ownership
The authors build an independent, reproducible cloud-edge testbed that measures accuracy, latency, CPU time, peak RAM, disk I/O and network use for mem0, Graphiti and cognee alongside RAG and full-context baselines on LoCoMo. mem0, RAG and full-context score 77% to 81%, whereas Graphiti and cognee score 55% to 56% because of incomplete retrieval, and RAG matches the top group while costing 8.4 times less overall than mem0.

arxiv:2601.16993 arXiv ✓
BibAgent: An Agentic Framework for Traceable Miscitation Detection in Scientific Literature
BibAgent：面向科学文献可追溯错误引用检测的智能体框架
citation verification knowledge integrity evidence aggregation miscitation taxonomy agentic retrieval
BibAgent is an end-to-end agentic framework for citation verification that combines retrieval, reasoning and adaptive evidence aggregation, using an Evidence Committee mechanism to infer citation validity for paywalled references. The authors contribute a five-category miscitation taxonomy and MisciteBench, a cross-disciplinary benchmark of 6,350 miscitation samples spanning 254 fields, and report better accuracy and interpretability than LLM baselines.

arxiv:2601.07782 arXiv ✓
Beyond Single-Shot: Multi-step Tool Retrieval via Query Planning
超越单次检索：通过查询规划实现多步工具检索
tool retrieval query planning dense retrieval reinforcement learning multi-step retrieval
TOOLQP models tool retrieval as iterative query planning, decomposing an instruction into sub-tasks and dynamically generating queries instead of relying on single-shot dense matching. It is trained on synthetic query trajectories with reinforcement learning from verifiable rewards and reports state-of-the-art performance, zero-shot generalization and downstream agentic gains.

arxiv:2601.07794 arXiv ✓
Kinship Data Benchmark for Multi-hop Reasoning
面向多跳推理的亲属关系数据基准
multi-hop reasoning kinship systems compositional reasoning benchmark contamination cultural knowledge
KinshipQA is a procedurally generated benchmark covering seven documented kinship systems and up to six reasoning hops, with a tunable simulator horizon intended to eliminate exact-instance pretraining overlap. Evaluating six LLMs, the authors find a 40.9% accuracy drop when reasoning shifts from biological multi-hop relations to culturally marked classification on the five non-descriptive systems, and the drop persists under chain-of-thought and few-shot prompting.
→ arxiv.org
arxiv:2601.08058 arXiv ✓
Triggering Chain-of-Thought via Latent Feature Interventions in Large Language Models
通过潜在特征干预触发大语言模型的思维链
sparse autoencoders latent feature steering chain-of-thought activation intervention mechanistic interpretability
With sparse autoencoders, the authors isolate a handful of latent features associated with reasoning and find that nudging just one or a few of them triggers reasoning-like behavior without an explicit chain-of-thought prompt, at accuracy close to CoT. Suppressing those features hurt performance even when CoT prompting was used, which the authors read as evidence of a causal role.

Benchmarking Small Language Models and Small Reasoning Language Models on System Log Severity Classification
小语言模型与小推理模型在系统日志严重性分类上的基准测试
RAG prompting small language models retrieval integration log comprehension model efficiency
Using real journalctl data from Linux production servers, the authors evaluate nine models drawn from small language models and small reasoning language models under zero-shot, few-shot and RAG prompting, treating severity classification as a probe of runtime log comprehension. Qwen3-4B reaches 95.64% with RAG and Gemma3-1B improves from 20.25% to 85.28%, while several small reasoning models degrade substantially when paired with retrieval.

arxiv:2601.07696 arXiv ✓
Exploring the Meta-level Reasoning of Large Language Models via a Tool-based Multi-hop Tabular Question Answering Task
通过基于工具的多跳表格问答任务探索大语言模型的元级推理
meta-level reasoning tool selection tabular QA task decomposition numeracy
The authors distinguish meta-level reasoning, or reasoning about the intermediate steps needed for a task, from object-level execution, and design a tool-based multi-hop tabular QA task over geopolitical indicators with "essential actions" for comparing tool calls. They find LLMs show good meta-level reasoning but flawed task understanding, that n-shot prompting has little effect on accuracy, and provide further evidence of poor numeracy.
