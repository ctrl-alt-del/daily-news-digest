Agentic Observability: Automated Alert Triage for Adobe E-Commerce
智能体可观测性：Adobe 电商的自动化告警分诊
alert triage ReAct retrieval-augmented analysis production deployment
The paper presents an agentic observability framework deployed in Adobe's e-commerce infrastructure that autonomously triages alerts using a ReAct paradigm, identifying affected services, correlating logs and planning actions such as handbook consultation or retrieval-augmented analysis of recent code. Production results reportedly show a 90% reduction in mean time to insight versus manual triage while maintaining comparable diagnostic accuracy.

Optimizing Agentic Reasoning with Retrieval via Synthetic Semantic Information Gain Reward
通过合成语义信息增益奖励优化智能体检索推理
agentic retrieval information gain reward reinforcement learning semantic clustering
InfoReasoner is a framework that rewards agentic retrieval with a synthetic semantic information-gain signal, redefining information gain as uncertainty reduction over the model's belief states and estimating it from output distributions via semantic clustering. Trained with GRPO, it reportedly outperforms strong retrieval-augmented baselines across seven QA benchmarks by up to 5.4% average accuracy.

Uncertainty and Fairness Awareness in LLM-Based Recommendation Systems
基于大语言模型的推荐系统中的不确定性与公平性意识
recommendation evaluation predictive uncertainty fairness benchmark prompt perturbation
The paper introduces a benchmark with curated metrics and a dataset annotated for eight demographic attributes across movies and music, and studies how uncertainty and fairness evaluations affect LLM recommendation quality. It reports that Gemini 1.5 Flash shows systematic unfairness for some sensitive attributes, with similarity-based gaps of 0.1363 (SNSR) and 0.0507 (SNSV) that persist under typographical and multilingual prompt perturbations.

abstraction learning hierarchical planning in-context learning reinforcement learning

Continuous-Utility Direct Preference Optimization
连续效用直接偏好优化
preference optimization reasoning strategies sample complexity model alignment
CU-DPO replaces binary preference labels with continuous scores that capture fine-grained reasoning quality and aligns models to a portfolio of prompt-based cognitive strategies. On mathematical reasoning benchmarks it reportedly raises strategy-selection accuracy from 35-46% to 68-78% across seven base models, with downstream gains up to +6.6 points and transfer to code generation and causal reasoning.

arxiv:2602.00871 arXiv ✓
Beyond Output Critique: Self-Correction via Task Distillation
超越输出批评：通过任务蒸馏实现自我纠正
self-correction task abstraction cross-model transfer reasoning evaluation
SELF-THOUGHT inserts a task-abstraction step before solution refinement, distilling an input and initial response into a structured template of key variables, constraints and problem structure that guides a revised answer. The authors show these abstractions can transfer from larger to smaller models, improving accuracy, robustness and generalization on diverse reasoning tasks without heavy fine-tuning or external verifiers.

arxiv:2602.00899 arXiv ✓
Domain-Adaptive and Scalable Dense Retrieval for Content-Based Recommendation
面向内容推荐领域自适应且可扩展的稠密检索
dense retrieval bi-encoder contrastive learning CPU serving
The paper casts content-based recommendation as retrieval and fine-tunes a two-tower bi-encoder on Amazon Reviews 2023 (Fashion) with supervised contrastive learning. On a review-to-title benchmark over 826,402 items it reportedly raises Recall@10 from 0.26 with BM25 to 0.66, with 6.1 ms median CPU latency and a 4x model-size reduction using FAISS HNSW and INT8 ONNX Runtime.
