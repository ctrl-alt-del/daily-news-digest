Agent Drift: Quantifying Behavioral Degradation in Multi-Agent LLM Systems Over Extended Interactions
智能体漂移：量化多智能体 LLM 系统在长期交互中的行为退化
agent drift multi-agent systems episodic memory consolidation behavioral stability AI safety
The paper defines agent drift as progressive degradation of agent behavior, decision quality and inter-agent coherence over extended interaction sequences, distinguishing semantic, coordination and behavioral drift. It proposes the Agent Stability Index across twelve dimensions, and theoretical analysis suggests that episodic memory consolidation, drift-aware routing protocols and adaptive behavioral anchoring can reduce drift-related errors.

arxiv:2601.04131 arXiv ✓
ContextFocus: Activation Steering for Contextual Faithfulness in Large Language Models
ContextFocus：面向大语言模型上下文忠实度的激活引导
contextual faithfulness activation steering knowledge conflict ConFiQA parametric knowledge
ContextFocus is a lightweight activation-steering method that improves faithfulness to retrieved context when it conflicts with parametric knowledge, without fine-tuning and with minimal inference overhead. On ConFiQA it reports significant gains over baselines including ContextDPO and COIECD, and the authors say it is complementary to prompting strategies and remains effective on larger models.

arxiv:2601.04086 arXiv ✓
KDCM: Reducing Hallucination in LLMs through Explicit Reasoning Structures
KDCM：通过显式推理结构减少大语言模型幻觉
knowledge graph exploration hallucination mitigation code-guided reasoning knowledge distillation HIT@1
KDCM extends chain-style knowledge distillation with a programmable module that guides knowledge graph exploration as executable code inside the reasoning prompt. On public benchmarks with GPT-4 and LLaMA-3.3 it reports HIT@1, HIT@3 and HIT@5 gains of 15.64%, 13.38% and 13.28% and reduced prompt-induced hallucination.
→ arxiv.org
arxiv:2601.04171 arXiv ✓
Agentic Rubrics as Contextual Verifiers for SWE Agents
智能体评分细则：面向 SWE 智能体的上下文验证器
agentic rubrics SWE agents context grounding test-time scaling code verification
Agentic Rubrics has an expert agent interact with a repository to build a context-grounded checklist, then scores candidate patches against it without executing tests. On SWE-Bench Verified under parallel test-time scaling it reaches 54.2% with Qwen3-Coder-30B-A3B and 40.6% with Qwen3-32B, at least 3.5 percentage points above the strongest baseline.
→ arxiv.org

XGrammar-2: Dynamic and Efficient Structured Generation Engine for Agentic LLMs
XGrammar-2：面向 Agentic LLM 的动态高效结构化生成引擎
structured generation grammar caching agentic LLM serving inference efficiency
XGrammar-2 is a structured generation engine for dynamic agentic workloads that introduces tag-triggered structure switching and cross-grammar cache reuse. It reports over 6x faster compilation than prior engines with near-zero end-to-end serving overhead.
