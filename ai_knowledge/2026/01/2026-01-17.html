LSTM-MAS: A Long Short-Term Memory Inspired Multi-Agent System for Long-Context Understanding
LSTM-MAS：受长短期记忆启发的长上下文多智能体系统
long-context understanding gated memory multi-agent system error accumulation hallucination propagation
LSTM-MAS is a chained multi-agent system inspired by LSTM gates for long-context understanding, with worker, filter, judge, and manager agents controlling information flow between segments. Compared with the prior CoA multi-agent approach, it reports gains of 97.97%, 65.75%, 122.19%, 39.61%, and 10.80% on NarrativeQA, Qasper, HotpotQA, 2WikiMQA, and MuSiQue.

Learn Like Humans: Use Meta-cognitive Reflection for Efficient Self-Improvement
像人类一样学习：利用元认知反思实现高效自我改进
self-improvement metacognitive reflection instruction optimization self-evolving agents
MARS is a self-improvement framework that updates an agent's instructions within a single recurrence cycle by combining principle-based reflection, which abstracts rules that avoid errors, with procedural reflection, which derives step-by-step strategies. Across six benchmarks it is reported to outperform state-of-the-art self-evolving systems while significantly reducing computational overhead.

arxiv:2601.12075 arXiv ✓
To Copy or Not to Copy: Copying Is Easier to Induce Than Recall
复制还是不复制：复制比回忆更容易被诱发
parametric knowledge retrieval arbitration activation steering mechanistic interpretability context copying
Extracting an arbitration vector from model activations across 27 relations, the authors steer whether retrieval-augmented models rely on parametric knowledge or copy from context in three architectures and two open-domain QA benchmarks. They find an asymmetry: inducing copying is an easy reactivation that can be triggered from different input locations, while restoring recall is a more fragile suppression tied to object-token interventions.

ARC: Active and Reflection-driven Context Management for Long-Horizon Information Seeking Agents
ARC：面向长程信息检索智能体的主动反思式上下文管理
context management context rot reflection-driven revision long-horizon search BrowseComp-ZH
ARC formulates context management for long-horizon information-seeking agents as an active, reflection-driven process that monitors for misalignment and reorganizes the working context instead of passively accumulating or summarizing it. On long-horizon benchmarks it beats passive compression methods, with up to an 11% absolute accuracy gain on BrowseComp-ZH using Qwen2.5-32B-Instruct.

VeRVE: Versatile Retrieval for Videos via Unified Embeddings
VeRVE：通过统一嵌入实现通用视频检索
video retrieval unified embeddings multimodal queries zero-shot retrieval LoRA adaptation
VeRVE is a multimodal-LLM video retrieval framework that handles corpus-level retrieval, moment localization, and composed multimodal queries within one architecture. Its embedding model, trained with LoRA on 700K paired visual-text samples, beats other MLLM-based methods on zero-shot video retrieval and approaches specialized state-of-the-art systems when reranking is added.

arxiv:2602.00028 arXiv ✓
ELLMPEG: An Edge-based Agentic LLM Video Processing Tool
ELLMPEG：基于边缘的智能体式 LLM 视频处理工具
tool-aware RAG edge agents self-reflection command generation local inference
ELLMPEG is an edge-enabled agentic LLM framework that combines tool-aware retrieval-augmented generation with iterative self-reflection to produce and locally verify FFmpeg and VVenC commands, avoiding cloud APIs. On a 480-query benchmark, Qwen2.5 inside the framework reached 78% average command-generation accuracy with no recurring API cost.

arxiv:2601.12154 arXiv ✓
Analyzing Cancer Patients' Experiences with Embedding-based Topic Modeling and LLMs
结合嵌入主题建模与大语言模型分析癌症患者体验
neural topic modeling clinical embeddings BERTopic topic labeling patient narratives
The study applies neural topic modeling to 13 transcribed interviews with cancer patients (132,722 words), comparing BERTopic and Top2Vec and using GPT-4 for topic labeling. Domain-specific clinical embeddings improved topic precision and interpretability, with BioClinicalBERT giving the most consistent results; the authors note the text was machine-translated from Dutch and that clinicians were not involved in the evaluation.

arxiv:2601.12091 arXiv ✓
Mitigating Cultural Bias in LLMs via Multi-Agent Cultural Debate
通过多智能体文化辩论缓解大语言模型中的文化偏见
cultural bias multi-agent debate cultural personas cross-cultural evaluation
The authors introduce CEBiasBench, a Chinese-English benchmark with a Multi-Agent Vote scheme that permits explicit no-bias judgments, and find that Chinese prompting shifts rather than removes Western-centric bias. Their training-free Multi-Agent Cultural Debate assigns agents distinct cultural personas and reaches 57.6% average No Bias Rate under an LLM judge and 86.0% under MAV, versus 47.6% and 69.0% for a GPT-4o baseline, and also generalizes to the Arabic CAMeL benchmark.

arxiv:2602.11165 arXiv ✓
Assessing LLM Reliability on Temporally Recent Open-Domain Questions
评估大语言模型在时效性开放域问题上的可靠性
temporal knowledge open-domain QA semantic-lexical paradox benchmark reliability
RECOM is a benchmark of 15,000 recent Reddit questions from September 2025 paired with community-derived reference answers, used to evaluate four open-source LLMs. The authors report a semantic-lexical paradox, with over 99% cosine similarity despite under 8% BLEU-1 overlap, and find that scale did not predict performance, as Mistral-7B outperformed GPT-OSS-20B on all metrics.
