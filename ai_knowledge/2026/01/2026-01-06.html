Enhancing Model Context Protocol (MCP) with Context-Aware Server Collaboration
通过上下文感知的服务器协作增强模型上下文协议（MCP）
shared context store MCP multi-agent coordination context management TravelPlanner
The paper designs CA-MCP, which offloads execution logic to specialized MCP servers that read from and write to a shared context store so agents can coordinate without repeated prompting. On TravelPlanner and REALM-Bench it reports fewer LLM calls and fewer response failures than traditional MCP.

arxiv:2601.03192 arXiv ✓
MemRL: Self-Evolving Agents via Runtime Reinforcement Learning on Episodic Memory
MemRL：通过对情景记忆进行运行时强化学习实现自我进化智能体
episodic memory self-evolving agents reinforcement learning stability-plasticity dilemma memory retrieval
MemRL is a non-parametric approach that evolves agents through reinforcement learning over episodic memory, decoupling stable reasoning from plastic memory and using two-phase retrieval to filter noise and identify high-utility strategies from environmental feedback. Experiments on HLE, BigCodeBench, ALFWorld and Lifelong Agent Bench report gains over state-of-the-art baselines without weight updates.
→ arxiv.org
arxiv:2601.03204 arXiv ✓
InfiAgent: An Infinite-Horizon Framework for General-Purpose Autonomous Agents
InfiAgent：面向通用自主智能体的无限时程框架
state externalization long-horizon agents context management file-centric workspace DeepResearch
InfiAgent keeps an agent's reasoning context bounded by externalizing persistent state into a file-centric abstraction and rebuilding context at each step from a workspace snapshot plus a fixed window of recent actions. With a 20B open-source model it is competitive with larger proprietary systems on DeepResearch and an 80-paper literature review task, with higher long-horizon coverage than context-centric baselines.
→ arxiv.org

MAGMA: A Multi-Graph based Agentic Memory Architecture for AI Agents
MAGMA：面向 AI 智能体的多图智能体记忆架构
agentic memory multi-graph memory graph traversal retrieval long-horizon reasoning LoCoMo
MAGMA represents each memory item across orthogonal semantic, temporal, causal and entity graphs, then formulates retrieval as policy-guided traversal over those relational views for query-adaptive context construction. It reports consistent gains over state-of-the-art agentic memory systems on LoCoMo and LongMemEval long-horizon reasoning tasks.

Accurate Table Question Answering with Accessible LLMs
使用可及的大语言模型实现准确的表格问答
multi-agent workflow table question answering prompt complexity open-weight LLMs WikiTQ
Orchestra is a multi-agent approach that splits table question answering into simpler agent tasks in a structured layered workflow, reducing the prompt complexity each small open-weight model must handle. With Qwen2.5-14B it reaches 72.1% accuracy on WikiTQ, approaching GPT-4's prior 75.3%, and reports new state-of-the-art results with larger Qwen, Llama and DeepSeek models.

DeepSeek arxiv:2601.04254 arXiv ✓
Scaling Trends for Multi-Hop Contextual Reasoning in Mid-Scale Language Models
中等规模语言模型多跳上下文推理的扩展趋势
multi-hop reasoning multi-agent systems task-method dissociation MoE scaling active parameters
A controlled study with 120 trials across four mid-scale models finds a task-method dissociation: rule-based matching reaches 100% on structured retrieval but 6.7% on cross-document reasoning, while LLM multi-agent systems reach up to 80% on the latter. Multi-agent gains appear only for models with sufficient base reasoning ability, with improvements up to 46.7 percentage points.
→ arxiv.org
arxiv:2601.03471 arXiv ✓
EpiQAL: Benchmarking Large Language Models in Epidemiological Question Answering and Reasoning
EpiQAL：流行病学问答与推理的大语言模型基准
epidemiological QA multi-step inference benchmark design literature QA
EpiQAL is presented as the first diagnostic benchmark for epidemiological question answering over research literature, with three subsets covering factual recall, multi-step inference and conclusion reconstruction. Across fifteen models, multi-step inference was the hardest task and scale alone did not predict success.

Grading Scale Impact on LLM-as-a-Judge: Human-LLM Alignment Is Highest on 0-5 Grading Scale
评分量表对 LLM-as-a-Judge 的影响：0-5 量表上人机一致性最高
LLM-as-a-judge grading scale human-LLM alignment benchmark heterogeneity rater reliability
A study comparing human and LLM raters across three grading scales and six benchmarks found that a 0–5 scale produced the strongest human–LLM agreement. It also reports that pooled reliability can mask benchmark heterogeneity and reveals systematic alignment differences across gender groups.

Multi-RADS Synthetic Radiology Report Dataset and Head-to-Head Benchmarking of 41 Open-Weight and Proprietary Language Models
多 RADS 合成放射学报告数据集及 41 个开放权重与专有语言模型的头对头基准测试
medical benchmark small language models guided prompting radiology reporting model scaling
The study releases RXL-RADSet, 1,600 radiologist-verified synthetic reports across 10 RADS frameworks, and benchmarks 41 quantized small language models against GPT-5.2 under guided prompting. GPT-5.2 reached 99.8% validity and 81.1% accuracy, while pooled small models reached 96.8% validity and 61.1% accuracy, with top 20–32B models approaching proprietary performance.
