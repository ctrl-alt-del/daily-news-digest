Digital Metabolism: Decoupling Logic from Facts via Regenerative Unlearning -- Towards a Pure Neural Logic Core
数字代谢：通过再生式遗忘将逻辑与事实解耦——迈向纯神经逻辑核心
parametric forgetting logic-fact decoupling regenerative unlearning chain-of-thought neural logic core
The authors propose "digital metabolism," a thermodynamic hypothesis that targeted forgetting is needed to distill a pure neural logic core by decoupling reasoning from factual knowledge in shared weights. Applying their Regenerative Logic-Core Protocol to Qwen2.5-0.5B produced near-zero retention of targeted facts (accuracy below 7%) and behavior the authors interpret as spontaneous chain-of-thought scaffolding on GSM8K, though they say the causal mechanism needs further study.

DeepSeek arxiv:2601.10825 arXiv ✓
Reasoning Models Generate Societies of Thought
推理模型生成“思维社会”
societies of thought multi-agent debate mechanistic interpretability reasoning traces reinforcement learning
Analyzing reasoning traces from models such as DeepSeek-R1 and QwQ-32B, the authors find that enhanced reasoning is associated with simulating multi-agent-like internal debate among perspectives with distinct personality traits and expertise, not extended computation alone. Controlled reinforcement-learning experiments show that base models increase conversational behaviors when rewarded only for reasoning accuracy, and conversational scaffolding accelerates later reasoning gains.

arxiv:2601.10702 arXiv ✓
Grounding Agent Memory in Contextual Intent
将智能体记忆锚定于情境意图
contextual intent intent-aware retrieval long-horizon memory CAME-Bench retrieval noise
STITCH indexes each step of a long-horizon agent trajectory with a structured "contextual intent" cue—latent goal, action type, and salient entity types—and retrieves history by matching the current step's intent. Across the new CAME-Bench and LongMemEval it reports state-of-the-art results, beating the strongest baseline by 35.6%, with gains growing as trajectories lengthen.
→ arxiv.org
arxiv:2601.10657 arXiv ✓
PACEvolve: Enabling Progress-Aware Consistent Evolution
PACEvolve：实现进度感知的一致性演化
self-evolving agents hierarchical context management memory pruning mode collapse search dynamics
PACEvolve targets self-evolving LLM agents that become anchored to local hypotheses and suffer context pollution and mode collapse, governing memory and search with hierarchical context management, momentum-based backtracking, and an adaptive collaborative evolution policy. The framework decouples high-level idea generation from low-level code evaluation and reports state-of-the-art results on complex evolutionary benchmarks.
→ arxiv.org

arxiv:2601.10809 arXiv ✓
A Concise Agent is Less Expert: Revealing Side Effects of Using Style Features on Conversational Agents
简洁的智能体显得更不专业：揭示对话智能体风格特征使用的副作用
style-feature entanglement conciseness bias activation steering LLM-as-judge conversational agents
A systematic study of 127 conversational-agent papers identifies 12 frequently used style features and uses controlled synthetic dialogues with pairwise LLM-as-judge evaluation to show that prompting for one style causally affects others—for example, prompting for conciseness significantly reduces perceived expertise. Prompt-based and activation-steering mitigations can partially restore suppressed traits but often degrade the primary intended style.
→ arxiv.org
arxiv:2601.10775 arXiv ✓
LLMs for Game Theory: Entropy-Guided In-Context Learning and Adaptive CoT Reasoning
面向博弈论的 LLM：熵引导的上下文学习与自适应思维链推理
entropy-guided reasoning adaptive retrieval chain-of-thought in-context learning uncertainty
The paper combines in-context learning with entropy-guided chain-of-thought reasoning and adaptive context retrieval, adjusting the number of retrieved examples and reasoning paths to token-level uncertainty in discrete game-theoretic tasks. In 100 Tic-Tac-Toe games against a sub-optimal algorithmic opponent, average game outcome improved from -11.6% for the baseline LLM to +9.5% with the entropy-guided method.
→ arxiv.org
