Self-Distillation Enables Continual Learning
自蒸馏实现持续学习
continual learning catastrophic forgetting self-distillation on-policy learning in-context learning
The authors introduce Self-Distillation Fine-Tuning (SDFT), which uses a demonstration-conditioned model as its own teacher to generate on-policy training signals without explicit reward functions. Across skill-learning and knowledge-acquisition tasks it reportedly outperforms supervised fine-tuning, with higher new-task accuracy and substantially less catastrophic forgetting, and it lets one model accumulate multiple skills sequentially without regression.

arxiv:2601.20048 arXiv ✓
Insight Agents: An LLM-Based Multi-Agent System for Data Insights
Insight Agents：面向数据洞察的 LLM 多智能体系统
multi-agent system plan-and-execute domain knowledge injection agent routing human evaluation
Insight Agents is a conversational multi-agent data-insight system for e-commerce sellers built on a plan-and-execute paradigm, with a manager agent plus data-presentation and insight-generation workers. It combines out-of-domain detection with BERT-based routing and dynamically injects domain knowledge; the system launched for Amazon sellers in the US and reportedly achieved 90% human-evaluated accuracy with P90 latency below 15 seconds.
→ arxiv.org

arxiv:2601.20107 arXiv ✓
Structural Anchor Pruning: Training-Free Multi-Vector Compression for Visual Document Retrieval
结构锚点剪枝：视觉文档检索的免训练多向量压缩
visual document retrieval multi-vector retrieval index compression token pruning
The paper proposes Structural Anchor Pruning, a training-free, query-agnostic index-time framework for compressing multi-vector visual document retrieval indexes. It reportedly retains 93–96% of NDCG@5 on ViDoRe v1 while pruning 90% of visual tokens.

Counterfactual Cultural Cues Reduce Medical QA Accuracy in LLMs: Identifier vs Context Effects
反事实文化线索降低大模型医疗问答准确率：身份标识与语境效应
benchmark perturbation medical QA cultural bias robustness
The paper introduces a counterfactual benchmark that expands 150 MedQA items into 1,650 variants with cultural identifier tokens and contextual cues. Across GPT-5.2, Llama-3.1-8B, DeepSeek-R1 and MedGemma, cultural cues significantly affected accuracy, with the largest degradation when identifier and context co-occurred.
→ arxiv.org
arxiv:2601.20105 arXiv ✓
FFE-Hallu:Hallucinations in Fixed Figurative Expressions:Benchmark of Idioms and Proverbs in the Persian Language
FFE-Hallu：波斯语固定比喻表达中的幻觉基准
hallucination benchmark figurative language multilingual LLMs translation evaluation
The paper introduces FFEHallu, a 600-instance benchmark for figurative hallucination in Persian idioms and proverbs spanning generation, fabricated-expression detection and English-to-Persian translation. It reports systematic weaknesses across six multilingual LLMs.
→ arxiv.org
DeepSeek arxiv:2601.19802 arXiv ✓
Zero-Shot Stance Detection in the Wild: Dynamic Target Generation and Multi-Target Adaptation
野外零样本立场检测：动态目标生成与多目标适配
stance detection knowledge extraction zero-shot learning social media analysis
The authors define zero-shot stance detection in the wild with dynamic target generation and multi-target adaptation, aiming to identify multiple target-stance pairs from text without prior target knowledge. On a new Chinese social-media dataset, a two-stage fine-tuned Qwen2.5-7B reached a 66.99% comprehensive target-recognition score, while an integrated fine-tuned DeepSeek-R1-Distill-Qwen-7B reached 79.26% stance-detection F1.
→ arxiv.org
