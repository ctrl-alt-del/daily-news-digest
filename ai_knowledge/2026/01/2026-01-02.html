FinRetrieval: A Benchmark for Financial Data Retrieval by AI Agents
FinRetrieval：面向 AI 智能体财务数据检索的基准
agent retrieval financial data tool availability agent benchmark structured data
FinRetrieval benchmarks whether AI agents can retrieve specific numeric values from structured financial databases, with 500 questions and tool-call traces from 14 configurations across Anthropic, OpenAI and Google models. Tool availability dominates results: Claude Opus scores 90.8% with structured data APIs but only 19.8% with web search alone, a 71-point gap.

SearchGym: A Modular Infrastructure for Cross-Platform Benchmarking and Hybrid Search Orchestration
SearchGym：跨平台基准测试与混合检索编排的模块化基础设施
hybrid retrieval RAG infrastructure embedding strategies reproducible benchmarking vector search
SearchGym decouples data representation, embedding strategy and retrieval logic into Dataset, VectorSet and App abstractions, enabling reproducible composition of RAG systems from hierarchical configurations. It also analyzes how the optimal ordering of semantic ranking and structured filtering depends on filter strength, and reports a 70% Top-100 retrieval rate on the LitSearch benchmark.

DeepSeek arxiv:2601.00514 arXiv ✓
The Illusion of Insight in Reasoning Models
推理模型中的“洞察幻觉”
reasoning traces self-correction inference stability entropy reasoning evaluation
Analyzing more than one million reasoning traces across hundreds of training checkpoints, the authors find that mid-reasoning strategy shifts are rare, do not become more frequent with training, and seldom improve accuracy. They conclude such shifts reflect unstable inference rather than intrinsic self-correction, and show that artificially triggering shifts under high entropy reliably improves accuracy.
→ arxiv.org
arxiv:2601.00756 arXiv ✓
Memory Bank Compression for Continual Adaptation of Large Language Models
面向大模型持续适应的记忆库压缩
memory compression continual learning codebook optimization catastrophic forgetting knowledge retention
MBC compresses an LLM's external memory bank through codebook optimization during online adaptation, adding an online resetting mechanism to prevent codebook collapse and key-value low-rank adaptation in attention layers. On question-answering benchmarks it reduces the memory-bank size to 0.3% of the strongest baseline while maintaining high retention accuracy.

arxiv:2601.00930 arXiv ✓
AlignUSER: Human-Aligned LLM Agents via World Models for Recommender System Evaluation
AlignUSER：基于世界模型的人类对齐大模型智能体用于推荐系统评估
world models synthetic users recommender evaluation persona alignment
AlignUSER learns world-model-driven user agents from human interaction rollouts by framing world modeling as next-state prediction, then aligns actions with human personas using counterfactual trajectories and comparisons with human choices. Across multiple datasets it reproduces genuine human behavior more closely than prior synthetic-user approaches at both micro and macro levels.
→ arxiv.org

Feedback Indices to Evaluate LLM Responses to Rebuttals for Multiple Choice Type Questions
评估大模型对多项选择题反驳反馈的指标
sycophancy LLM evaluation rebuttal reasoning effort
The authors propose a fictitious-response rebuttal method and a set of indices to quantify sycophancy and stubbornness when LLMs are challenged on multiple-choice answers. In tests with OpenAI models on physics problems, newer models and those using greater reasoning effort show less sycophantic behavior.
