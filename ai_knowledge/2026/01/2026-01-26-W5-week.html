Self-Distillation Enables Continual Learning
自蒸馏实现持续学习
continual learning catastrophic forgetting self-distillation on-policy learning in-context learning
The authors introduce Self-Distillation Fine-Tuning (SDFT), which uses a demonstration-conditioned model as its own teacher to generate on-policy training signals without explicit reward functions. Across skill-learning and knowledge-acquisition tasks it reportedly outperforms supervised fine-tuning, with higher new-task accuracy and substantially less catastrophic forgetting, and it lets one model accumulate multiple skills sequentially without regression.

arxiv:2601.22269 arXiv ✓
JAF: Judge Agent Forest
JAF：评审智能体森林
judge agents ensemble evaluation in-context learning locality-sensitive hashing critique propagation
JAF is a framework in which a judge agent performs joint inference across a cohort of query-response pairs from a primary agent, rather than evaluating responses in isolation, so cross-instance patterns can feed back into improvement. It can be instantiated through in-context learning and uses a learned locality-sensitive hashing scheme to select diverse exemplars, validated on cloud misconfiguration triage.

The $\mathbf{P}$-Completeness of Inverted Index Traversal: On the Complexity of Evaluating Boolean Query DAGs
倒排索引遍历的 P-完全性：布尔查询 DAG 的求值复杂性
inverted index Boolean query evaluation computational complexity query DAGs
The paper formalizes a DAG-based retrieval language and proves that evaluating its Boolean queries over an inverted index is P-complete, exposing worst-case exponential blowup for document-at-a-time evaluation and a universal-scan penalty for term-at-a-time materialization. It introduces ComputePN, a sparsity-aware algorithm with a positive-negative dual representation that bounds evaluation time to O(|Q|·|U_active|).
