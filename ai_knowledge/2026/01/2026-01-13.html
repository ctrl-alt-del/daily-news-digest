Ctrl-G: Controlling Structural and Interaction Exposure in Knowledge Graph Augmented LLM Reasoning
Ctrl-G：控制知识图谱增强 LLM 推理中的结构与交互暴露
KG-RAG structural exposure privacy-preserving retrieval multi-hop reasoning experience memory
Ctrl-G is a KG-RAG framework that jointly controls structural and interaction exposure to a remote LLM, locally constructing query-conditioned sanitized graph views and using a hierarchical controller that couples remote planning with local connected-path exploration. A local experience memory reuses abstract, verified reasoning traces to reduce repeated disclosure, and the method achieves the highest accuracy on five of six benchmarks, exceeding the strongest baseline by up to 13.8 points.
→ arxiv.org
arxiv:2601.08741 arXiv ✓
From Rows to Reasoning: A Retrieval-Augmented Multimodal Framework for Spreadsheet Understanding
从行到推理：面向电子表格理解的多模态检索增强框架
multimodal RAG spreadsheet understanding hybrid retrieval reciprocal rank fusion enterprise documents
The authors introduce FRTR-Bench, a benchmark of 30 enterprise Excel workbooks spanning nearly four million cells and more than 50 embedded images, and propose FRTR, a multimodal RAG framework that decomposes workbooks into row, column and block embeddings with hybrid lexical-dense retrieval and reciprocal rank fusion. FRTR reaches 74% answer accuracy with Claude Sonnet 4.5 versus 24% for prior state-of-the-art approaches, and 87% on SpreadsheetLLM with GPT-5 while cutting token usage by roughly half.
→ arxiv.org
arxiv:2601.08699 arXiv ✓
RAGShaper: Eliciting Sophisticated Agentic RAG Skills via Automated Data Synthesis
RAGShaper：通过自动化数据合成激发复杂的智能体 RAG 技能
agentic RAG data synthesis adversarial distractors error correction retrieval robustness
RAGShaper is a data-synthesis framework for agentic RAG that builds dense information trees with adversarial distractors at perception and cognition levels, then uses constrained navigation to force a teacher agent to demonstrate error correction and noise rejection. Models trained on the synthesized corpus reportedly outperform existing baselines and show greater robustness on noise-intensive and complex retrieval tasks.

ART: Action-based Reasoning Task Benchmarking for Medical AI Agents
ART：面向医疗 AI 智能体的基于行动的推理任务基准
clinical agents EHR reasoning action-based benchmark aggregation errors retrieval failures
ART is an action-based reasoning benchmark for medical AI agents that mines real electronic health record data into tasks targeting threshold evaluation, temporal aggregation and conditional logic. On 600 tasks, GPT-4o-mini and Claude 3.5 Sonnet show near-perfect retrieval after prompt refinement but substantial gaps in aggregation (28% to 64%) and threshold reasoning (32% to 38%).

arxiv:2601.08773 arXiv ✓
Reliable Graph-RAG for Codebases: AST-Derived Graphs vs LLM-Extracted Knowledge Graphs
面向代码库的可靠 Graph-RAG：AST 派生图与 LLM 抽取知识图谱的对比
Graph-RAG AST-derived graph code retrieval indexing cost hallucination risk
The paper benchmarks vector-only RAG, LLM-generated knowledge graph RAG and deterministic AST-derived graph RAG on Java codebases using architecture and code-tracing queries. The AST-derived graph builds in seconds, achieves the highest correctness on the Shopizer suite, and avoids the indexing incompleteness and higher cost seen with the LLM-extracted graph, while the vector-only baseline performs worst on upstream architectural queries.

OpenDecoder：在 RAG 中引入文档质量的开放大模型解码
document quality decoding query performance prediction retrieval signals
OpenDecoder passes explicit signals about retrieved documents, such as relevance, ranking and query-performance-prediction scores, into the LLM's generation step. The authors report improved robustness and results over baselines on five benchmark datasets.

Multicultural Spyfall：通过动态多语言社会推理游戏评估 LLM
