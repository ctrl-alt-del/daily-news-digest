Amory: Building Coherent Narrative-Driven Agent Memory through Agentic Reasoning
Amory：通过智能体推理构建连贯的叙事驱动型智能体记忆
narrative memory memory consolidation coherence-driven retrieval LOCOMO agentic reasoning
Amory is a working-memory framework that constructs structured memory offline by organizing conversational fragments into episodic narratives, consolidating memories with momentum and semanticizing peripheral facts. On LOCOMO it reports considerable gains over the prior state of the art, performance comparable to full-context reasoning and a 50% reduction in response time.

Don't Break the Cache: An Evaluation of Prompt Caching for Long-Horizon Agentic Tasks
别破坏缓存：长时程智能体任务中提示缓存的评估
prompt caching long-horizon agents API cost time-to-first-token DeepResearch Bench
The paper evaluates prompt caching across OpenAI, Anthropic and Google on DeepResearch Bench, covering over 500 agent sessions with 10,000-token system prompts. It finds API cost reductions of 41–80% and time-to-first-token improvements of 13–31%, and reports that strategic cache-block control beats naive full-context caching, which can increase latency.

Agentic LLMs as Powerful Deanonymizers: Re-identification of Participants in the Anthropic Interviewer Dataset
作为强大去匿名化工具的智能体 LLM：Anthropic Interviewer 数据集参与者再识别
re-identification agentic web search data privacy qualitative datasets
Focusing on the 125-scientist subset of Anthropic's 1,250-interview public dataset, the author shows that off-the-shelf LLMs with web search and agentic capabilities linked six of twenty-four interviews to specific scientific works and in some cases uniquely identified interviewees. The paper argues such re-identification is now low-effort and outlines mitigations and open problems.

arxiv:2601.06328 arXiv ✓
C-World: A Computer Use Agent Environment Creator
C-World：计算机使用智能体环境创建器
agent environments computer-use agents tool use environment synthesis reward signals
C-World lets users build agent environments from an action space of 5,571 format-unified tools across 204 applications, a task distribution engine, a state controller that injects failures and a combined verifiable/LLM reward. Evaluating nine LLMs, it finds execution rather than planning is the bottleneck and constraint following is the dominant failure mode; fine-tuning on 1,170 trajectories outperforms baselines trained on 119k samples.

Can We Predict Before Executing Machine Learning Agents?
我们能在执行前预测机器学习智能体的结果吗？
world models execution prediction ML agents predict-then-verify
The paper formalizes data-centric solution preference with a corpus of 18,438 pairwise comparisons and shows LLMs can predict outcomes at 61.5% accuracy when primed with a verified data analysis report. It instantiates FOREAGENT with a predict-then-verify loop that reports 6x faster convergence and +6% over execution-based baselines.
