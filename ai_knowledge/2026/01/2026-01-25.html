Neuro-Symbolic Verification on Instruction Following of LLMs
面向 LLM 指令遵循的神经符号验证
instruction following neuro-symbolic verification constraint satisfaction agent reliability verification benchmark
NSVIF is a general-purpose neuro-symbolic verifier that models user instructions as logical and semantic constraints and checks whether an LLM's output satisfies them, using a unified solver for constraint satisfaction. The authors release VIFBENCH and report that NSVIF significantly outperforms LLM-based verifiers, provides interpretable feedback, and improves instruction following without post-training.

Think Locally, Explain Globally: Graph-Guided LLM Investigations via Local Reasoning and Belief Propagation
局部思考、全局解释：基于图引导的 LLM 调查与信念传播
abductive reasoning dependency graph belief propagation context management agent reliability
EoG formulates open-ended investigation as abductive reasoning over a dependency graph, with an LLM performing bounded local evidence mining and cause-versus-symptom labeling while a deterministic controller manages traversal, state and belief propagation. On a representative ITBench diagnostics task it improves both accuracy and run-to-run consistency over ReAct baselines.

EFT-CoT: A Multi-Agent Chain-of-Thought Framework for Emotion-Focused Therapy
EFT-CoT：面向情绪聚焦疗法的多智能体思维链框架
multi-agent framework chain-of-thought emotion-focused therapy instruction tuning
EFT-CoT is a multi-agent chain-of-thought framework grounded in Emotion-Focused Therapy that runs a three-stage workflow of embodied perception, cognitive exploration and narrative intervention with eight specialized agents. The authors build EFT-Instruct from about 67,000 real help-seeking texts and fine-tune EFT-LLM, which they report outperforms strong baselines and human responses in empathic depth and structural professionalism.

LLM-Based SQL Generation: Prompting, Self-Refinement, and Adaptive Weighted Majority Voting
基于 LLM 的 SQL 生成：提示、自我改进与自适应加权多数投票
text-to-SQL self-refinement majority voting multi-agent collaboration schema linking
The paper proposes SSEV, a single-agent self-refinement pipeline with weighted majority voting built on PET-SQL, reporting 85.5% execution accuracy on Spider 1.0-Dev, 86.4% on Spider 1.0-Test and 66.3% on BIRD-Dev. It then introduces ReCAPAgent-SQL, a multi-agent framework for planning, retrieval, critique, action and refinement that reaches 31% execution accuracy on the first 100 queries of Spider 2.0-Lite.

arxiv:2601.17755 arXiv ✓
HyperGraphPro: Progress-Aware Reinforcement Learning for Structure-Guided Hypergraph RAG
HyperGraphPro：面向结构引导超图 RAG 的进度感知强化学习
graph RAG hypergraph retrieval reinforcement learning multi-hop QA
HyperGraphPro is a hypergraph RAG framework that makes evidence-path progress the shared objective for retrieval and policy optimization, reranking hyperedges by query-conditioned structural distinctiveness. It adds stepwise progress-aware rewards based on coverage of answer-guided target hyperedges, and reports consistent multi-hop QA accuracy gains over existing GraphRAG methods.

Evaluating Semantic and Syntactic Understanding in Large Language Models for Payroll Systems
评估大语言模型在薪资系统中的语义与句法理解
structured reasoning prompt engineering numerical accuracy enterprise AI
The study uses a synthetic payroll system as a high-stakes test of whether LLMs can understand a schema, apply rules in the right order and produce cent-accurate results, across GPT, Claude, Perplexity, Grok and Gemini model families. It identifies regimes where careful prompting is sufficient and regimes where explicit computation is required.

Spelling Bee Embeddings for Language Modeling
面向语言建模的拼写嵌入
token embeddings spelling information language modeling compute efficiency
The authors modify the token embedding layer to infuse embeddings with spelling information, and scaling studies from 40M to 800M parameters suggest the gains are equivalent to needing about 8% less compute and data for the same test loss.
