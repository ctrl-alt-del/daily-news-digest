RAPTOR-AI for Disaster OODA Loop: Hierarchical Multimodal RAG with Experience-Driven Agentic Decision-Making
RAPTOR-AI：面向灾害 OODA 回路的层次化多模态 RAG 与经验驱动智能体决策
hierarchical multimodal RAG knowledge trees ColVBERT embeddings OODA loop disaster response
RAPTOR-AI is an agentic multimodal RAG framework for disaster response that builds hierarchical knowledge trees from 46 tsunami-related PDFs (2,378 pages) using BLIP image understanding, ColVBERT embeddings, and long-context summarization inside an OODA loop. It reports 23% better retrieval precision, 31% better situational grounding, and 27% improved task decomposition, scaling to 3,000 document chunks.

A Survey of Agentic Reasoning for Large Language Models: Towards Recursively Self-Improving and Collective Agents
大语言模型智能体推理综述：迈向递归自我改进与集体智能体
agentic reasoning self-evolving agents collective multi-agent in-context reasoning post-training RL
This survey organizes agentic reasoning for LLMs into foundational single-agent reasoning, self-evolving reasoning through feedback, memory, and adaptation, and collective multi-agent reasoning with coordination and knowledge sharing. It separates in-context reasoning from post-training reasoning, reviews applications and benchmarks across science, robotics, healthcare, autonomous research, and mathematics, and outlines challenges such as personalization, long-horizon interaction, and scalable multi-agent training.

Improved Bug Localization with AI Agents Leveraging Hypothesis and Dynamic Cognition
CogniGent：利用假设与动态认知改进 AI 智能体的缺陷定位
bug localization causal reasoning call-graph analysis context engineering hypothesis testing
CogniGent is a multi-agent bug-localization technique that combines causal reasoning, call-graph-based root cause analysis, context engineering, and hypothesis testing to mimic dynamic cognitive debugging. On 591 bug reports it reports MAP improvements of 23.33-38.57% and MRR improvements of 25.14-53.74% over six baselines at document and method levels.

Disagreement as Data: Reasoning Trace Analytics in Multi-Agent Systems
把分歧当作数据：多智能体系统中的推理轨迹分析
reasoning traces multi-agent systems disagreement detection semantic similarity
The study treats reasoning traces from multi-agent LLM systems as process data for qualitative coding and uses cosine similarity to detect disagreement across nearly 10,000 agent-pair coding instances. It finds that semantic reasoning similarity separates consensus from disagreement and correlates with human coding reliability.

arxiv:2601.12449 arXiv ✓
AgenTRIM: Tool Risk Mitigation for Agentic AI
AgenTRIM：面向智能体 AI 的工具风险缓解
tool risk mitigation least privilege prompt injection runtime validation
AgenTRIM targets unbalanced tool-driven agency in LLM agents, where excessive permissions or missing tool calls enlarge the attack surface. It reconstructs and verifies the tool interface offline from code and execution traces, then enforces per-step least-privilege tool access at runtime; on AgentDojo it substantially reduces attack success while maintaining task performance.
→ arxiv.org
arxiv:2601.12560 arXiv ✓
Agentic Artificial Intelligence (AI): Architectures, Taxonomies, and Evaluation of Large Language Model Agents
智能体 AI：大语言模型智能体的架构、分类与评估
agent taxonomy MCP inference-time reasoning evaluation practices
The paper proposes a unified taxonomy for agentic AI that decomposes agents into perception, brain, planning, action, tool use, and collaboration, and traces the shift from linear reasoning to inference-time reasoning models and from fixed API calls to standards such as MCP. It also groups operating environments and reviews evaluation practices, flagging challenges including hallucination in action, infinite loops, and prompt injection.

arxiv:2601.12331 arXiv ✓
Efficient Privacy-Preserving Retrieval Augmented Generation with Distance-Preserving Encryption
基于距离保持加密的高效隐私保护检索增强生成
privacy-preserving RAG encrypted embeddings distance-preserving encryption query analysis
ppRAG is a privacy-preserving RAG framework for untrusted cloud storage that uses CAPRISE, a symmetric encryption scheme preserving only relative distance ordering so the cloud can compare an encrypted query with encrypted embeddings without exposing inter-database distances. Query embeddings are perturbed with differential privacy to resist query analysis, and the authors report efficient throughput, high retrieval accuracy, and strong privacy guarantees.

arxiv:2601.12359 arXiv ✓
Zero-Shot Embedding Drift Detection: A Lightweight Defense Against Prompt Injections in LLMs
零样本嵌入漂移检测：抵御大语言模型提示注入的轻量防御
prompt injection detection embedding drift zero-shot defense adversarial prompts
ZEDD detects direct and indirect prompt injection by measuring semantic drift in embedding space between benign and suspect inputs, using adversarial-clean prompt pairs and cosine similarity without model internals or attack-specific training. On a re-annotated LLMail-Inject dataset it reports over 93% classification accuracy across Llama 3, Qwen 2, and Mistral with a false positive rate below 3%.

A Cloud-based Multi-Agentic Workflow for Science
面向科学的云端多智能体工作流
multi-agent workflow supervisor agent task routing
The paper presents a domain-agnostic, model-independent cloud workflow in which a supervisor agent coordinates specialized agents for literature review, data analysis, and simulation. In a catalyst-focused proof of concept, it routed tasks to the correct agent 90% of the time and completed 97.5% of synthetic tasks and 91% of real-world tasks.
