ArenaRL: Scaling RL for Open-Ended Agents via Tournament-based Relative Ranking
ArenaRL：通过锦标赛式相对排序为开放式智能体扩展强化学习
relative ranking reinforcement learning open-ended agents reward models Open-Travel
ArenaRL replaces pointwise scalar rewards with intra-group relative ranking, using process-aware pairwise evaluation with multi-level rubrics and a tournament scheme to obtain stable advantage signals. It reports near-equivalent advantage accuracy to full pairwise comparison at O(N) instead of O(N²) complexity, introduces the Open-Travel and Open-DeepResearch benchmarks, and substantially outperforms standard RL baselines.

arxiv:2601.06606 arXiv ✓
CEDAR: Context Engineering for Agentic Data Science
CEDAR：面向智能体数据科学的上下文工程
context engineering agentic data science history rendering code generation Kaggle
CEDAR automates data-science tasks with an agentic setup that structures the initial prompt with domain-specific fields and materializes the solution as interleaved plan and code blocks from separate LLM agents. It keeps data local by injecting only aggregate statistics into prompts and manages context through iterative code generation and smart history rendering, demonstrated on canonical Kaggle challenges.

arxiv:2601.06644 arXiv ✓
Do Language Models Reason Across Languages?
语言模型能跨语言推理吗？
multilingual reasoning two-hop QA sub-question prompting composition failure bridging inference
Using a two-hop question-answering setting over two multilingual documents, the authors find models are more sensitive to language variation in answer-span documents than in bridging documents. Up to 33% of multilingual cases answer correctly without inferring the bridge and about 18% show composition failure; a three-stage SUBQ prompting method raises accuracy from 10.1% to 66.5%.
→ arxiv.org
arxiv:2601.06607 arXiv ✓
Pragya: An AI-Based Semantic Recommendation System for Sanskrit Subhasitas
Pragya：面向梵文 Subhasita 的 AI 语义推荐系统
retrieval-augmented generation sentence embeddings semantic recommendation cultural heritage
Pragya is a retrieval-augmented generation framework that recommends Sanskrit Subhasitas from a 200-verse thematic dataset, using IndicBERT sentence embeddings for top-k retrieval and a Mistral model to generate transliterations, translations and explanations. The authors report that semantic retrieval outperforms keyword matching in precision and relevance and describe it as the first attempt at integrating retrieval and generation for this corpus.
→ arxiv.org
arxiv:2601.06596 arXiv ✓
Are LLMs Vulnerable to Preference-Undermining Attacks (PUA)? A Factorial Analysis Methodology for Diagnosing the Trade-off between Preference Alignment and Real-World Validity
大语言模型易受偏好削弱攻击吗？诊断偏好对齐与现实有效性权衡的因子分析方法
preference alignment manipulative prompting truthfulness factorial analysis RLHF
The paper introduces Preference-Undermining Attacks, manipulative prompts that exploit an aligned model's desire to please users at the expense of truthfulness, and proposes a factorial 2×2⁴ diagnostic framework. It finds that more advanced models are sometimes more susceptible, with reality denial the dominant factor and model-specific interactions suggesting tailored defenses.
→ arxiv.org

Evaluating Accounting Reasoning Capabilities of Large Language Models
评估大语言模型的会计推理能力
domain evaluation accounting reasoning prompt design GPT-4
The authors define vertical-domain accounting reasoning, derive evaluation criteria from GLM training-data characteristics, and test GLM-6B, GLM-130B, GLM-4 and GPT-4 on accounting tasks. Prompt design significantly affected performance, GPT-4 was strongest, and the models remained insufficient for real-world enterprise accounting.

Agentic AI Empowered Intent-Based Networking for 6G
面向 6G 的智能体 AI 赋能意图网络
multi-agent orchestration intent-based networking ReAct prompt engineering 6G
The paper presents a hierarchical multi-agent framework in which LLM agents decompose natural-language intents, consult RAN and core-network specialists and synthesize feasible network-slice configurations through ReAct-style cycles. It reports gains over monolithic agents, rule-based systems and direct prompting, and argues that structured prompts encoding domain thresholds and policies are essential for reliable automation.
