Warp-Cortex: An Asynchronous, Memory-Efficient Architecture for Million-Agent Cognitive Scaling on Consumer Hardware
Warp-Cortex：在消费级硬件上实现百万级智能体认知扩展的异步内存高效架构
multi-agent architecture KV-cache sparsification memory efficiency topological data analysis context management
Warp-Cortex decouples agent logic from physical memory through singleton weight sharing and a topological KV-cache sparsification scheme, reducing weight memory to O(1) and context to O(N·k). On a single RTX 4090 it demonstrates 100 concurrent agents in 2.2 GB of VRAM, with a theoretical capacity above 1,000 agents before compute latency becomes the bottleneck.

Recursive Language Models
递归语言模型
recursive inference long context context decomposition inference paradigm
Recursive Language Models treat long prompts as an external environment that the model can examine, decompose and recursively query, handling inputs up to two orders of magnitude beyond its context window. The authors report outperforming vanilla frontier LLMs and common long-context or coding scaffolds on four long-context tasks at comparable cost, and post-train an initial model at small scale.
→ arxiv.org
arxiv:2601.01291 arXiv ✓
Curator: Efficient Vector Search with Low-Selectivity Filters
Curator：面向低选择性过滤的高效向量搜索
vector search filtered ANNS index architecture low-selectivity filters
Curator is a partition-based index for filtered approximate nearest-neighbor search, building label-specific indexes inside a shared clustering tree to avoid the connectivity breakdown that graph indexes suffer on low-selectivity filters. Combined with state-of-the-art graph indexes, it cuts low-selectivity query latency by up to 20.9x versus pre-filtering while adding only 5.5% construction time and 4.3% memory.
→ arxiv.org

arxiv:2601.01195 arXiv ✓
Reinforcement Learning Enhanced Multi-hop Reasoning for Temporal Knowledge Question Answering
面向时序知识图谱问答的强化学习增强多跳推理
temporal knowledge graph multi-hop reasoning reinforcement learning question answering T-GRPO
The MRE framework improves temporal knowledge-graph question answering by generating diverse reasoning trajectories, fine-tuning on valid ones as a cold start, and then applying Tree-Group Relative Policy Optimization that explores each hop with feedback from later hops. On two TKGQA benchmarks it consistently surpasses state-of-the-art methods and shows better robustness to noisy temporal annotations.
→ arxiv.org
arxiv:2601.01162 arXiv ✓
Bridging the Semantic Gap for Categorical Data Clustering via Large Language Models
BREVE：借助大模型弥合类别数据聚类的语义鸿沟
categorical clustering external knowledge base value embedding semantic enrichment
BREVE enriches each categorical value with a dense embedding drawn from an external knowledge base, appends a lightweight one-hot component to preserve value identity, and uses cluster-compactness-guided weights to control how much enrichment enters the representation. Across eight benchmark datasets it achieves an average ARI rank of 1.3 against seven competitors.
→ arxiv.org
arxiv:2601.01118 arXiv ✓
ScienceDB AI: An LLM-Driven Agentic Recommender System for Large-Scale Scientific Data Sharing Services
ScienceDB AI：面向大规模科学数据共享服务的 LLM 驱动智能体推荐系统
agentic recommender trustworthy RAG memory compression scientific data multi-turn dialogue
ScienceDB AI is an LLM-driven conversational recommender for a large scientific data-sharing platform, combining a Scientific Intention Perceptor, a Structured Memory Compressor for multi-turn dialogue and a two-stage Trustworthy RAG that returns citable dataset references via CSTR identifiers. It was evaluated on more than 10 million real-world datasets in offline and online experiments.

arxiv:2601.06113 arXiv ✓
Towards Infinite Length Extrapolation: A Unified Approach
迈向无限长度外推：一种统一方法
length extrapolation positional encoding long context attention bias
The paper recasts positional encoding as a multiplicative transformation plus an additive bias in the attention score, then introduces Adaptive Positional Encoding with adaptive frequency modulation and a combined linear, logarithmic and square-root decay bias. It derives conditions for infinite-context extrapolation and tests the approach on TinyStories and a synthetic dataset with stories up to 32,000 words.
