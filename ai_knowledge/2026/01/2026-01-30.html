DETOUR: An Interactive Benchmark for Dual-Agent Search and Reasoning
DETOUR：面向双智能体搜索与推理的交互式基准
dual-agent retrieval memory agent underspecified queries multimodal benchmark
DETOUR is a dual-agent benchmark of 1,011 prompts for tip-of-the-tongue search, in which a primary agent must identify a remembered entity by querying a consistent memory agent. Current state-of-the-art models reportedly reach only 36% accuracy across text, image, audio and video, highlighting weakness in underspecified retrieval.

arxiv:2602.00299 arXiv ✓
Agentic Framework for Epidemiological Modeling
流行病学建模的智能体框架
agentic modeling program synthesis flow graph representation epidemiological simulation
EPIAGENT is an agentic framework that synthesizes, calibrates, verifies and refines epidemiological simulators by treating disease progression as iterative program synthesis. A key design choice is an explicit epidemiological flow-graph intermediate representation that enables modular correctness checks before code generation; case studies reportedly show it captures complex growth dynamics and produces consistent counterfactual projections.

KEPO: Knowledge-Enhanced Preference Optimization for Multimodal Reasoning with Applications to Medical VQA
KEPO：面向多模态推理的知识增强偏好优化及其在医学视觉问答中的应用
knowledge-enhanced reasoning on-policy distillation medical VQA out-of-distribution generalization
KEPO is a post-training framework that combines quality-gated on-policy distillation with knowledge-enhanced exploration, applying teacher guidance only to high-quality trajectories. On a medical visual question answering benchmark it reportedly showed improved training stability and out-of-distribution performance over RL and distillation baselines.

Clause-Internal or Clause-External? Testing Turkish Reflexive Binding in Adapted versus Chain of Thought Large Language Models
从句内还是从句外？在适配型与思维链大语言模型中检验土耳其语反身代词约束
reflexive binding linguistic knowledge chain-of-thought probing evaluation
The study tests whether state-of-the-art LLMs capture Turkish reflexive binding using 100 balanced sentences that pit local against non-local antecedents for kendi and kendisi. Trendyol-LLM-7B favored local bindings in about 70% of trials, while OpenAI's o1 Mini distributed choices nearly evenly, suggesting weaker sensitivity to locality in this configuration.

Bridging the Semantic Chasm: Synergistic Conceptual Anchoring for Generalized Few-Shot and Zero-Shot OOD Perception
跨越语义鸿沟：面向广义少样本与零样本 OOD 感知的协同概念锚定
multi-agent framework vision-language embeddings out-of-distribution few-shot adaptation
The paper presents SynerNet, a multi-agent framework with four specialized units for visual perception, linguistic context, nominal embedding and global coordination that exchange messages to counter cross-modal alignment degeneration in vision-language models on out-of-distribution concepts. On the VISTA-Beyond benchmark it reports precision improvements of 1.2% to 5.4% in few-shot and zero-shot settings.

Autonomous Data Processing using Meta-Agents
使用元智能体的自主数据处理
meta-agents pipeline orchestration hierarchical planning adaptive refinement
ADP-MA is a framework that dynamically constructs, executes and iteratively refines data-processing pipelines through hierarchical agent orchestration. Meta-agents analyze data and task specifications to design multi-phase plans, instantiate ground-level agents and monitor performance, with context-aware optimization, adaptive workload partitioning and reuse of previously designed agents.
