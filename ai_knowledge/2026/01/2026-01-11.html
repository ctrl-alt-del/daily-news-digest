Overcoming the Retrieval Barrier: Indirect Prompt Injection in the Wild for LLM Systems
跨越检索门槛：LLM 系统中真实场景的间接提示注入
indirect prompt injection retrieval poisoning embedding models multi-agent workflow data exfiltration
The authors show that malicious content can be divided into a trigger piece engineered to be retrieved and a separate payload, achieving near-perfect retrieval on 11 benchmarks and eight embedding models for as little as $0.21 per targeted query. In a demonstration, one poisoned email caused GPT-4o to leak SSH keys in more than 80% of attempts within a multi-agent workflow.

arxiv:2601.07055 arXiv ✓
Dr. Zero: Self-Evolving Search Agents without Training Data
Dr. Zero：无需训练数据的自进化搜索智能体
self-evolving agents agentic search automatic curriculum reinforcement learning search engine grounding
Dr. Zero is a framework that lets multi-turn search agents self-evolve without human-annotated training data, relying only on an external search engine as their knowledge environment. A proposer generates structurally diverse questions to train a solver, and hop-grouped relative policy optimization (HRPO) reduces the compute needed for proposer training; the authors report it matches or surpasses fully supervised search agents on several question answering benchmarks.

Explore with Long-term Memory: A Benchmark and Multimodal LLM-based Reinforcement Learning Framework for Embodied Exploration
带着长期记忆探索：具身探索的基准与多模态 LLM 强化学习框架
long-term memory embodied exploration episodic memory memory-based QA reinforcement learning
The authors introduce Long-term Memory Embodied Exploration (LMEE) and the LMEE-Bench dataset, which combines multi-goal navigation with memory-based question answering to evaluate both the process and outcome of embodied exploration. Their MemoryExplorer method fine-tunes a multimodal LLM with reinforcement learning and a multi-task reward over action prediction, frontier selection and question answering, reporting advantages on long-horizon embodied tasks.

arxiv:2601.07023 arXiv ✓
CloneMem: Benchmarking Long-Term Memory for AI Clones
CloneMem：面向 AI 克隆的长期记忆基准
long-term memory AI clones memory benchmark personalization digital traces
CloneMem is a benchmark for long-term memory in AI clone scenarios, built from non-conversational digital traces such as diaries, social media posts and emails spanning one to three years rather than temporally fragmented chat histories. It defines tasks that assess an agent's ability to track evolving personal states and reports that current memory mechanisms struggle in this setting.

arxiv:2601.06853 arXiv ✓
DAGGER: Distractor-Aware Graph Generation for Executable Reasoning in Math Problems
DAGGER：面向数学问题可执行推理的干扰感知图生成
executable reasoning graph distractor robustness structured representations math reasoning token efficiency
DAGGER's authors release DISTRACTMATH-BN, a Bangla benchmark that adds information which reads as relevant but does not affect the calculation to MGSM and MSVAMP; standard models lose as many as 41 points under these distractors. Their method recasts math solving as generating an executable computation graph that includes explicit distractor nodes, and Gemma-3 models fine-tuned this way match weighted accuracy with 89% fewer tokens than reasoning models.

arxiv:2601.06860 arXiv ✓
ET-Agent: Incentivizing Effective Tool-Integrated Reasoning Agent via Behavior Calibration
ET-Agent：通过行为校准激励有效的工具集成推理智能体
tool-integrated reasoning behavior calibration self-evolving data tool use agent training
ET-Agent is a training framework that calibrates an LLM agent's tool-use behavior through a self-evolving data flywheel and two-phase behavior-calibration training, targeting ineffective patterns such as redundant or insufficient tool calls. The authors report gains in correctness, efficiency, reasoning conciseness and tool execution accuracy across multiple experiments.

SDUs DAISY: A Benchmark for Danish Culture
SDU 的 DAISY：丹麦文化基准测试
cultural knowledge factual knowledge benchmark design low-resource languages knowledge coverage
DAISY is a factual-knowledge test derived from the 2006 Danish Culture Canon, containing 741 closed-ended question-answer pairs that were checked by hand. Current models did badly: Llama-3.3-70B was the strongest but scored just 0.17 BLEU and 0.27 F1.
