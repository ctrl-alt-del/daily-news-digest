JAF: Judge Agent Forest
JAF：评审智能体森林
judge agents ensemble evaluation in-context learning locality-sensitive hashing critique propagation
JAF is a framework in which a judge agent performs joint inference across a cohort of query-response pairs from a primary agent, rather than evaluating responses in isolation, so cross-instance patterns can feed back into improvement. It can be instantiated through in-context learning and uses a learned locality-sensitive hashing scheme to select diverse exemplars, validated on cloud misconfiguration triage.

RedSage: A Cybersecurity Generalist LLM
RedSage：网络安全通用大模型
cybersecurity LLM continual pretraining agentic data augmentation domain benchmark
RedSage is an open-source, locally deployable cybersecurity assistant trained on 11.8B tokens of domain-focused continual-pretraining data and 266K multi-turn samples generated by an agentic augmentation pipeline. At the 8B scale it reportedly beats baselines by up to 5.59 points on cybersecurity benchmarks and 5.05 points on Open LLM Leaderboard tasks, and the authors release models, data and code along with a new RedSage-Bench.

Joint Continual Learning of Local Language Models and Cloud Offloading Decisions with Budget Constraints
本地语言模型与云端卸载决策的联合持续学习（带预算约束）
continual learning cloud offloading catastrophic forgetting budget constraints
The paper proposes DA-GRPO, a dual-advantage extension of Group Relative Policy Optimization that puts cloud-usage constraints into advantage computation so a local small model can learn task competence and collaboration behavior together. Experiments on math reasoning and code generation reportedly improve post-switch accuracy, reduce forgetting and keep cloud usage stable versus prior collaborative and routing approaches.

Why Are AI Agent Involved Pull Requests (Fix-Related) Remain Unmerged? An Empirical Study
AI 智能体参与的修复类拉取请求为何仍未合并？一项实证研究
coding agents pull request integration failure analysis human-AI collaboration
The study analyzes 8,106 fix-related pull requests authored by five AI coding agents from the AIDEV POP dataset, then manually reviews a sample of 326 closed-but-unmerged PRs to build a catalog of 12 failure reasons. Test-case failures and prior resolution of the same issue by other PRs were the most common causes of non-integration, while build or deployment failures were comparatively rare.

SCALAR: Quantifying Structural Hallucination, Consistency, and Reasoning Gaps in Materials Foundation Models
SCALAR：量化材料基础模型中的结构幻觉、一致性与推理差距
hallucination benchmark materials science chain-of-thought structural consistency
SCALAR is a benchmark for geometric scale generalization in materials foundation models, using about 100,000 DFT-validated structures from a few atoms to over 18,000 atoms across property prediction, chain-of-thought and inverse retrieval tasks. Experiments reportedly show large model-dependent shifts under explicit reasoning, often reducing hallucination and error but frequently destabilizing consistency or validity.

arxiv:2601.22386 arXiv ✓
Specialists or Generalists? Multi-Agent and Single-Agent LLMs for Essay Grading
专家还是通才？用于作文评分的多智能体与单智能体 LLM
multi-agent evaluation essay grading in-context examples
Using the ASAP 2.0 corpus and GPT-5.1, the authors find that a multi-agent grading system was significantly better at identifying weak essays while a single-agent system performed better on mid-range essays. Providing two examples per score level raised QWK by about 26% for both architectures.
