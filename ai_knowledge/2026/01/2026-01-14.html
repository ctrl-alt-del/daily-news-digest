Aeon: High-Performance Neuro-Symbolic Memory Management for Long-Horizon LLM Agents
Aeon：面向长时程 LLM 智能体的高性能神经符号记忆管理
neuro-symbolic memory vector index long-horizon agents INT8 quantization episodic graph
Aeon is a neuro-symbolic cognitive operating system that treats memory as a managed resource, organizing it into a Memory Palace spatial index built on a SIMD-accelerated page-clustered vector index and a neuro-symbolic episodic graph called the Trace. It introduces symmetric INT8 scalar quantization for 3.1x spatial compression, a write-ahead log for crash recoverability, and a semantic lookaside buffer designed to exploit conversational locality, with benchmarks run on Apple M4 Max.
→ arxiv.org
arxiv:2601.09694 arXiv ✓
LLMs can Compress LLMs: Adaptive Pruning by Agents
LLM 可以压缩 LLM：由智能体驱动的自适应剪枝
model pruning factual knowledge retention agent-guided compression self-reflection LLM compression
The authors introduce agent-guided pruning, in which a foundation model acts as an adaptive pruning agent that selects which layers to prune at each iteration using layer-wise sensitivity profiles and self-reflection, with checkpoint rollback when perplexity degradation exceeds a threshold. On Qwen3 4B and 8B models at roughly 45% sparsity, they report a 56% relative MMLU improvement, 19x better factual knowledge retention on FreebaseQA and 69% lower perplexity degradation than structured pruning baselines, without retraining.

Optimizing the Landscape of LLM Embeddings with Dynamic Exploratory Graph Analysis for Generative Psychometrics: A Monte Carlo Study
用动态探索性图分析优化 LLM 嵌入空间：一项蒙特卡洛研究
embedding landscape embedding depth exploratory graph analysis dimensional structure Monte Carlo study
The study reframes LLM embeddings as searchable landscapes and adapts Dynamic Exploratory Graph Analysis to traverse embedding dimensions, using a Monte Carlo simulation with OpenAI's text-embedding-3-small model on items representing five dimensions of grandiose narcissism. It finds that the Total Entropy Fit Index and normalized mutual information favor competing depth ranges, and that a weighted composite criterion balances structural accuracy and entropy-based organization better than single-metric optimization.

Continuum Memory Architectures for Long-Horizon LLM Agents
面向长时程 LLM 智能体的连续记忆架构
continuum memory persistent state consolidation stateless RAG long-horizon agents
The paper characterizes Continuum Memory Architecture as a family of systems that maintain and revise internal state using persistent storage, selective retention, associative routing, temporal chaining and consolidation. Its argument is that the stateless lookup approach of RAG is inadequate for agents operating over long horizons.

DeepSeek arxiv:2601.09876 arXiv ✓
Patient-Similarity Cohort Reasoning in Clinical Text-to-SQL
临床 Text-to-SQL 中的患者相似性队列推理
clinical text-to-SQL cohort reasoning schema grounding execution evaluation EHR analytics
CLINSQL is a new benchmark of 633 tasks annotated by experts on MIMIC-IV v3.1, where success requires multi-table joins, clinically meaningful filters and runnable SQL over time windows and patient-similarity groups. Across 22 models, results remain short of clinical reliability: GPT-5-mini scores 74.7% on execution, DeepSeek-R1 is the best open-source model at 69.2%, and Gemini-2.5-Pro falls from 85.5% on Easy to 67.2% on Hard.
→ arxiv.org

PROPER Agents: Proactivity Driven Personalized Agents for Advancing Knowledge Gap Navigation
PROPER Agents：以主动性驱动的个性化智能体，助力知识缺口导航
knowledge gaps personalized agents proactivity response generation
PROPER represents a user's knowledge gaps along explicit dimensions plus implicit ones that it generates, with one agent producing the dimensions and another producing the response. In single-turn evaluation it reports quality and win-rate improvements of as much as 84%.
