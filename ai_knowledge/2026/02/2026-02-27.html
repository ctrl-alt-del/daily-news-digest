Multi-Sourced, Multi-Agent Evidence Retrieval for Fact-Checking
面向事实核查的多源多智能体证据检索
fact-checking knowledge graph evidence retrieval LLM agent Markov decision process
WKGFC treats an authorized open knowledge graph as the core evidence source: an LLM agent retrieves the most relevant knowledge subgraphs for a claim, supplements them with web content, and runs the process as a Markov decision process tuned through prompt optimization. The authors position the approach as addressing the limits of text-similarity retrieval for multi-hop fact-checking.

Query Disambiguation via Answer-Free Context: Doubling Performance on Humanity's Last Exam
借助无答案上下文消解查询歧义：在 Humanity's Last Exam 上性能翻倍
query rewriting RAG grounding ambiguity reduction answer-free context benchmark
The authors find that rewriting a question to reduce ambiguity using answer-free grounding context improves accuracy without changing the answer, and that the gain cannot be fully recovered by inference-time prompting alone. Using gpt-oss-20b to rewrite a subset of Humanity's Last Exam raises gpt-5-mini accuracy from 0.14 to 0.37.

A Mixed Diet Makes DINO An Omnivorous Vision Encoder
混合“食谱”让 DINO 成为杂食性视觉编码器
vision encoder cross-modal alignment modality-agnostic features distillation
The authors observe that DINOv2 features for an RGB image and its depth map are nearly as dissimilar as features of unrelated images, and propose an Omnivorous Vision Encoder that post-trains an encoder toward a modality-agnostic feature space. A dual objective aligns different modalities of the same scene while distilling from a frozen teacher, and the model weights are released.

How Well Do Multimodal Models Reason on ECG Signals?
多模态模型在心电图信号上的推理能力如何？
multimodal reasoning reasoning evaluation agentic verification retrieval-based assessment clinical criteria
The paper proposes a reproducible framework that splits multimodal ECG reasoning evaluation into perception, checked by agent-generated code verifying the described temporal structures, and deduction, checked for alignment with a structured database of clinical criteria via retrieval. The authors present this dual verification as a scalable alternative to manual clinician review and proxy QA metrics.

Quantifying Catastrophic Forgetting in IoT Intrusion Detection Systems
量化 IoT 入侵检测系统中的灾难性遗忘
continual learning catastrophic forgetting intrusion detection experience replay benchmark
The study formulates intrusion detection in RPL-based IoT networks as domain continual learning and benchmarks five strategies across multiple domain orderings on a multi-attack dataset comprising 48 domains. Replay-based methods perform best overall, while Synaptic Intelligence shows near-zero forgetting with high training efficiency, pointing to stable deployment under shifting attacks.

arxiv:2602.24265 arXiv ✓
Beyond the Click: A Framework for Inferring Cognitive Traces in Search
超越点击：推断搜索中认知轨迹的框架
cognitive traces user simulation information foraging search logs annotation dataset
The paper infers cognitive traces from behavioral search logs with a multi-agent LLM system grounded in Information Foraging Theory and validated by human experts. It annotates three public datasets with over 530,000 cognitive labels across 50,000 sessions; on MovieLens the cognitive model improves F1 by up to 6.6% over a behavioral baseline, while gains are near zero on AOL.
→ arxiv.org
arxiv:2603.00349 arXiv ✓
COOP$^2$: Defining, Observing, and Repairing Cooperation in LLM Multi-Agent Systems
COOP²：定义、观测并修复 LLM 多智能体系统中的协作
multi-agent cooperation constraint satisfaction failure repair evaluation framework
COOP² is an evaluation framework that grounds cooperation dynamics in LLM multi-agent systems in task progress, paired with COOP²-Repair, which predicts constraint failures from group plans and opens targeted repair channels. Across two environments and three communication structures, repair improved task success and constraint satisfaction while adding decision overhead and communication load.
→ arxiv.org
arxiv:2603.02258 arXiv ✓
Universal Conceptual Structure in Neural Translation: Probing NLLB-200's Multilingual Geometry
神经翻译中的通用概念结构：探测 NLLB-200 的多语言几何
multilingual embeddings representation geometry phylogenetic structure concept similarity
Probing Meta's 200-language NLLB-200 in six experiments, the author finds that embedding distances correlate with phylogenetic distances and that frequently colexified concept pairs are significantly more similar, among other evidence of language-universal conceptual structure. The InterpretCognates toolkit is released openly.
