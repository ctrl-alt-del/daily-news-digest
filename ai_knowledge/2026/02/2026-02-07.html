GraphAgents: Knowledge Graph-Guided Agentic AI for Cross-Domain Materials Design
GraphAgents：知识图谱引导的跨领域材料设计智能体
knowledge graph multi-agent systems graph traversal materials discovery hypothesis generation
GraphAgents is a multi-agent framework guided by large-scale knowledge graphs in which agents specialize in problem decomposition, evidence retrieval, design-parameter extraction and graph traversal to search for sustainable PFAS substitutes. Ablations show the full pipeline beats single-shot prompting, and by tailoring traversal the system alternates exploitative searches with exploratory ones; a biomedical tubing example yields PFAS-free design candidates balancing tribological performance, thermal stability, chemical resistance and biocompatibility.

arxiv:2602.07652 arXiv ✓
Agent-Fence: Mapping Security Vulnerabilities Across Deep Research Agents
Agent-Fence：绘制深度研究智能体的安全漏洞图谱
agent security retrieval poisoning trust boundaries security benchmark multi-turn agents
AgentFence is an architecture-centric security evaluation that defines 14 trust-boundary attack classes across planning, memory, retrieval, tool use and delegation, and detects failures through trace-auditable conversation breaks. Holding the base model fixed, eight agent archetypes showed mean security break rates from 0.29 (LangGraph) to 0.51 (AutoGPT), with Denial-of-Wallet, authorization confusion, retrieval poisoning and planning manipulation the highest-risk classes.

AD-MIR: Bridging the Gap from Perception to Persuasion in Advertising Video Understanding via Structured Reasoning
AD-MIR：通过结构化推理弥合广告视频理解中的感知与说服鸿沟
structured memory semantic retrieval self-correction video understanding
AD-MIR builds a structure-aware memory from raw advertising video by combining semantic retrieval with exact keyword matching, then uses a structured reasoning agent that decomposes the narrative and validates insights against specific frames with evidence-based self-correction. On the AdsQA benchmark it surpasses the strongest general-purpose agent by 1.8% strict and 9.5% relaxed accuracy.

Developing an AI Assistant for Knowledge Management and Workforce Training in State DOTs
面向州交通部门知识管理与员工培训的 AI 助手
retrieval-augmented generation multi-agent architecture knowledge management document retrieval workforce training
The paper proposes a retrieval-augmented generation framework with specialized agents for retrieval, answer generation, evaluation and query refinement to help state transportation agencies preserve institutional expertise and train staff. An open-weight vision-language model converts technical figures into semantic text so figure-based knowledge can be indexed and retrieved alongside documents before an open-weight LLM generates grounded answers.

arxiv:2602.07642 arXiv ✓
Efficient Table Retrieval and Understanding with Multimodal Large Language Models
基于多模态大模型的高效表格检索与理解
table retrieval multimodal retrieval reranking table understanding benchmark
TabRAG answers queries over large collections of table images by retrieving candidate tables with jointly trained visual-text foundation models, reranking them with MLLMs, then reasoning over the selected tables. On a newly constructed dataset of 88,161 training and 9,819 test samples across eight benchmarks it improves retrieval recall by 7.0% and answer accuracy by 6.1%.

arxiv:2602.07721 arXiv ✓
ParisKV: Fast and Drift-Robust KV-Cache Retrieval for Long-Context LLMs
ParisKV：面向长上下文 LLM 的快速抗漂移 KV 缓存检索
KV-cache retrieval long-context vector search inference efficiency
ParisKV is a GPU-native KV-cache retrieval framework that pairs collision-based candidate selection with quantized inner-product reranking for long-context LLMs. It reports up to 2.8x higher throughput and decode-latency reductions of 17x and 44x versus MagicPIG and PQCache at million-token scale.
