A-MapReduce: Executing Wide Search via Agentic MapReduce
A-MapReduce：通过智能体式 MapReduce 执行宽搜索
wide search agentic map-reduce task decomposition experiential memory multi-agent systems
A-MapReduce recasts wide search as a horizontally structured retrieval problem, using task-adaptive decomposition, parallel processing of massive retrieval targets and experiential memory that evolves query-conditioned task allocation. On five agentic benchmarks it reports state-of-the-art results on WideSearch and DeepWideSearch, 5.11%–17.50% average Item F1 gains over strong o3/Gemini 2.5 Pro baselines and 45.8% lower running time, with code released.

RE-MCDF: Closed-Loop Multi-Expert LLM Reasoning for Knowledge-Grounded Clinical Diagnosis
RE-MCDF：面向知识驱动临床诊断的闭环多专家大模型推理
medical knowledge graph multi-expert collaboration clinical diagnosis generation-verification-revision EMR reasoning
RE-MCDF combines a primary diagnosis expert, a laboratory expert that reweights heterogeneous clinical indicators, and a multi-relation evaluation expert group guided by a medical knowledge graph. The generation–verification–revision loop enforces inter-disease constraints such as mutual exclusivity and pathological compatibility, and reports consistent gains over state-of-the-art baselines on neurology EMR benchmarks.

arxiv:2602.01472 arXiv ✓
ConPress: Learning Efficient Reasoning from Multi-Question Contextual Pressure
ConPress：从多问题上下文压力中学习高效推理
chain-of-thought self-compression contextual pressure reasoning efficiency self-supervised fine-tuning
The authors identify a reproducible Self-Compression effect in which models produce shorter reasoning traces when several independent questions share one prompt, and turn it into a self-supervised fine-tuning method. With 8k examples, ConPress cuts reasoning tokens by 59% on MATH500 and 33% on AIME25 while keeping competitive accuracy, without external teachers, manual pruning or reinforcement learning.

LLM-Driven Ontology Construction for Enterprise Knowledge Graphs
LLM 驱动的企业知识图谱本体构建
ontology construction enterprise knowledge graph RDF LLM pipeline knowledge extraction
OntoEKG is an LLM-driven pipeline that splits enterprise ontology construction into an extraction module for core classes and properties and an entailment module that structures them into a hierarchy before serializing RDF. On a new evaluation dataset spanning Data, Finance and Logistics documents it reaches 0.724 fuzzy-match F1 in the Data domain, while exposing limitations in scope definition and hierarchical reasoning.

Understanding QA generation: Extracting Parametric and Contextual Knowledge with CQA for Low Resource Bangla Language
理解问答生成：用 CQA 提取低资源孟加拉语中的参数化与上下文知识
counterfactual QA parametric knowledge contextual knowledge low-resource languages chain-of-thought
The authors release BanglaCQA, described as the first counterfactual QA dataset for Bangla, with counterfactual passages and answerability annotations, and compare fine-tuned and prompting pipelines on factual and counterfactual settings. They report that chain-of-thought prompting is uniquely effective for extracting parametric knowledge in counterfactual scenarios, especially for decoder-only LLMs.

Task-Aware LoRA Adapter Composition via Similarity Retrieval in Vector Databases
基于向量数据库相似度检索的任务感知 LoRA 适配器组合
LoRA adapters vector database similarity retrieval adapter merging
The framework dynamically composes LoRA adapters by retrieving similar training examples from a vector database built from 22 datasets and merging adapters with retrieval-weighted fusion. Linear merging reaches 70.95% on PIQA and 77.62% on RTE, and the approach needs no retriever training and operates with frozen embeddings.

Predicting and improving test-time scaling laws via reward tail-guided search
通过奖励尾部引导搜索预测并改进测试时扩展规律
test-time scaling reward modeling guided search compute allocation
The paper estimates the tail distribution of rewards to predict LLM test-time scaling laws without exhaustive evaluation, then introduces Scaling-Law Guided Search, which allocates compute to intermediate states with the highest predicted potential. The authors prove vanishing regret against perfect-information oracles and report higher reward yields than Best-of-N at identical compute budgets.
