ContextCov: Deriving and Enforcing Executable Constraints from Agent Instruction Files
ContextCov：从智能体指令文件推导并执行可执行约束
agent instructions executable guardrails constraint compliance coding agents SWE-bench
ContextCov turns passive natural-language agent instruction files such as AGENTS.md into executable guardrails, compiling documented constraints into static AST queries, runtime shell shims and architectural validators that intercept agent actions with reproducible violation traces. On SWE-bench Lite across 12 repositories and 300 tasks it reaches 88.3% constraint compliance versus 67.0% for prompt-only and 50.3% for reflection baselines, at 3.4x lower feedback cost while maintaining functional correctness.

arxiv:2603.00578 arXiv ✓
Draft-Thinking: Learning Efficient Reasoning in Long Chain-of-Thought LLMs
Draft-Thinking：在长思维链大模型中学习高效推理
draft reasoning chain-of-thought reinforcement learning token efficiency
Draft-Thinking learns a model-adapted draft chain of thought through progressive supervised fine-tuning and two-stage reinforcement learning, avoiding post-hoc trajectory compression or an explicit length penalty. With 847 training problems and 120 RL optimization steps, its draft mode cuts MATH500 average response length from 5,668 to 986 tokens (82.6%) while reaching 90.6% accuracy versus 93.0% for the original long-CoT model.

A Comprehensive Evaluation of LLM Unlearning Robustness under Multi-Turn Interaction
多轮交互下 LLM 遗忘鲁棒性的综合评估
machine unlearning knowledge erasure multi-turn interaction evaluation robustness
The paper examines whether LLM unlearning remains stable in interactive settings through self-correction and dialogue-conditioned querying, and finds that knowledge appearing forgotten in static evaluation can often be recovered through interaction. Stronger unlearning improves apparent robustness but often produces behavioral rigidity rather than genuine knowledge erasure, suggesting static evaluation may overestimate real-world effectiveness.

arxiv:2603.00624 arXiv ✓
IDER: IDempotent Experience Replay for Reliable Continual Learning
IDER：面向可靠持续学习的幂等经验回放
continual learning catastrophic forgetting uncertainty calibration experience replay idempotence
IDER introduces idempotent experience replay for continual learning, adapting the training loss so the model is idempotent on current data streams and adding an idempotence distillation loss that feeds current model outputs back through an old checkpoint. The authors report improved prediction reliability, higher accuracy and reduced forgetting across continual-learning benchmarks, with code released.

arxiv:2603.00569 arXiv ✓
TopoEdge: Topology-Grounded Agentic Framework for Edge Networking Code Generation and Repair
TopoEdge：面向边缘网络代码生成与修复的拓扑锚定智能体框架
topology-grounded RAG graph neural network multi-agent repair code generation network configuration
TopoEdge represents each target network topology as a router-level graph embedded by a contrastively trained GNN, retrieves a verified reference configuration and driver, and assembles them into a topology-grounded RAG context. Planning, generation and verification agents then run an execution-centric generate-verify-repair loop over an FRRouting Topotest/pytest harness.

arxiv:2603.00634 arXiv ✓
BLUFF: Benchmarking the Detection of False and Synthetic Content across 58 Low-Resource Languages
BLUFF：跨 58 种低资源语言的虚假与合成内容检测基准
multilingual benchmark synthetic content detection low-resource languages LLM-generated text dataset
BLUFF is a benchmark for detecting false and synthetic content spanning 79 languages and over 202,000 samples, covering human-written, LLM-generated, LLM-translated and hybrid text with 39 textual modification techniques. Experiments show state-of-the-art detectors suffer up to 25.3% F1 degradation on low-resource versus high-resource languages, and the dataset and code are released.

arxiv:2603.00829 arXiv ✓
Constitutional Black-Box Monitoring for Scheming in LLM Agents
面向 LLM 智能体阴谋行为的宪法式黑盒监控
scheming detection black-box monitoring synthetic trajectories prompt optimization AI oversight
The authors study constitutional black-box monitors, prompted classifiers that detect scheming in LLM agents from externally observable inputs and outputs, optimized on synthetic trajectories from two generation pipelines. Monitors selected purely on synthetic data generalize to 7,500 held-out ControlArena trajectories, but performance saturates quickly, with simple prompt sweeps matching more extensive optimization and further pushing leading to overfitting.

NERFIFY: A Multi-Agent Framework for Turning NeRF Papers into Code
NERFIFY：将 NeRF 论文转化为代码的多智能体框架
paper-to-code multi-agent framework grammar-constrained synthesis visual feedback
NERFIFY is a multi-agent framework that converts NeRF research papers into trainable Nerfstudio plugins, constraining LLM code synthesis with a context-free grammar and refining artifacts through visual feedback. The authors report visual quality matching expert human code on papers without public implementations while reducing implementation time from weeks to minutes.
