FAMOSE: A ReAct Approach to Automated Feature Discovery
FAMOSE：面向自动化特征发现的 ReAct 方法
ReAct feature engineering iterative discovery context window
FAMOSE applies the ReAct paradigm to automated feature engineering, using an agent to explore, generate and refine features while integrating selection and evaluation tools. It reports near-state-of-the-art classification results, a 0.23% average ROC-AUC gain on tasks with more than 10K instances, and a 2.0% average RMSE reduction on regression, while remaining more robust to errors.

arxiv:2602.17875 arXiv ✓
MultiVer: Zero-Shot Multi-Agent Vulnerability Detection
MultiVer：零样本多智能体漏洞检测
multi-agent ensemble vulnerability detection zero-shot union voting
MultiVer is a zero-shot multi-agent vulnerability detector whose four-agent ensemble (security, correctness, performance and style) uses union voting. It reaches 82.7% recall on PyVul, above fine-tuned GPT-3.5 at 81.3%, and 91.7% on SecurityEval, though precision falls to 48.8% and F1 to 61.4%.
→ arxiv.org

Ontology-Guided Neuro-Symbolic Inference: Grounding Language Models with Mathematical Domain Knowledge
本体引导的神经符号推理：以数学领域知识为语言模型提供依据
ontology neuro-symbolic reasoning hybrid retrieval cross-encoder reranking
Implements a neuro-symbolic pipeline that uses the OpenMath ontology with hybrid retrieval and cross-encoder reranking to inject relevant definitions into prompts, evaluated on the MATH benchmark with three open-source models. Ontology-guided context improves performance when retrieval quality is high, while irrelevant context actively degrades it.

arxiv:2602.17623 arXiv ✓
Unmasking the Factual-Conceptual Gap in Persian Language Models
揭示波斯语模型中的事实-概念差距
cultural benchmark factual retrieval situational reasoning acquiescence bias
DivanBench is a diagnostic benchmark of 315 questions across factual retrieval, paired scenario verification and situational reasoning, testing seven Persian LLMs on superstitions and customs. It finds severe acquiescence bias, continuous Persian pretraining amplifying that bias rather than improving reasoning, and a 21% performance gap between retrieving cultural facts and applying them in scenarios.
→ arxiv.org

Catastrophic Forgetting Resilient One-Shot Incremental Federated Learning
抗灾难性遗忘的单轮增量联邦学习
federated learning catastrophic forgetting synthetic data embeddings
OSI-FL is a one-shot incremental federated learning framework that sends category-specific embeddings from a frozen vision-language model in a single communication round, then uses a pretrained diffusion model at the server to synthesize client-like data. Selective Sample Retention keeps the most informative samples per category and task to bound forgetting, and the method outperforms traditional and one-shot federated baselines in class- and domain-incremental settings.
→ arxiv.org
arxiv:2602.17868 arXiv ✓
MantisV2: Closing the Zero-Shot Gap in Time Series Classification with Synthetic Data and Test-Time Strategies
MantisV2：用合成数据与测试时策略弥合时间序列分类的零样本差距
time series zero-shot synthetic data embedding fusion
Mantis+ is pretrained entirely on synthetic time series, MantisV2 is a refined, lighter encoder, and an enhanced test-time methodology leverages intermediate-layer representations with self-ensembling and cross-model embedding fusion. Across UCR, UEA, human activity recognition and EEG benchmarks the approach reports state-of-the-art zero-shot performance.
→ arxiv.org
arxiv:2602.17867 arXiv ✓
ADAPT: Hybrid Prompt Optimization for LLM Feature Visualization
ADAPT：面向 LLM 特征可视化的混合提示优化
feature visualization prompt optimization sparse autoencoders activation analysis
ADAPT combines beam-search initialization with adaptive gradient-guided mutation to find inputs that strongly activate directions in LLM activation space, evaluated on Sparse Autoencoder latents from Gemma 2 2B. It proposes metrics grounded in dataset activation statistics and consistently outperforms prior feature-visualization methods across layers and latent types.
→ arxiv.org
