Learning to Remember: End-to-End Training of Memory Agents for Long-Context Reasoning
学会记忆：面向长上下文推理的记忆智能体端到端训练
memory agents long-context reasoning CRUD memory reinforcement learning
The paper introduces Unified Memory Agent (UMA) for a one-to-many setting in which query-agnostic external memory is built once from a stream and reused across future QA sessions, with a single policy maintaining a structured memory bank through CRUD operations. Task-Stratified GRPO supervises memory maintenance using QA trajectory rewards, and UMA-Generalist achieves the highest average score among compared methods at a 16k budget and transfers to the new Ledger-QA benchmark without task-specific training.

arxiv:2602.13530 arXiv ✓
REMem: Reasoning with Episodic Memory in Language Agent
REMem：语言智能体中的情景记忆推理
episodic memory memory graph agentic retrieval benchmark
REMem is a two-phase framework for episodic memory in language agents: offline indexing converts experiences into a hybrid memory graph linking time-aware gists and facts, while online inference uses an agentic retriever with curated tools for iterative retrieval over the graph. Across four episodic memory benchmarks it outperforms systems such as Mem0 and HippoRAG 2 by 3.4% and 13.4% absolute on recollection and reasoning tasks, and shows more robust refusal behavior for unanswerable questions.

arxiv:2602.13517 arXiv ✓
Think Deep, Not Just Long: Measuring LLM Reasoning Effort via Deep-Thinking Tokens
深度思考，而非仅仅更长：通过深度思考 token 衡量 LLM 推理投入
reasoning effort test-time scaling deep-thinking tokens inference efficiency
The paper identifies deep-thinking tokens, where internal predictions undergo significant revisions in deeper layers before convergence, and shows that the deep-thinking ratio correlates robustly with accuracy across AIME 24/25, HMMT 25 and GPQA-diamond, outperforming length- and confidence-based baselines. It introduces Think@n, a test-time scaling strategy that prioritizes samples with high deep-thinking ratios and matches or exceeds self-consistency while reducing inference costs through early rejection based on short prefixes.
→ arxiv.org

Arming Data Agents with Tribal Knowledge
为数据智能体装上部落知识
tribal knowledge NL2SQL agents misconception correction retrieval
Tk-Boost is a bolt-on framework that augments NL2SQL agents with tribal knowledge correcting misconceptions accumulated through experience, first probing the agent on database queries, analyzing its mistakes and generating knowledge indexed with applicability conditions. Across BIRD and Spider 2.0 it improves NL2SQL agent accuracy by up to 16.9% and 13.7%, respectively.

arxiv:2604.20850 arXiv ✓
Association Is Not Similarity: Learning Corpus-Specific Associations for Multi-Hop Retrieval
关联并非相似：为多跳检索学习语料特定关联
multi-hop retrieval reranking corpus-specific associations dense retrieval
Association-Augmented Retrieval trains a small 4.2M-parameter MLP with contrastive learning on co-occurrence annotations to capture associative relationships between passages, then reranks dense retrieval candidates using bi-directional association scoring. On HotpotQA it raises passage Recall@5 from 0.831 to 0.916, and an inductive model shows no significant improvement, suggesting the method captures corpus-specific co-occurrences rather than transferable patterns.
→ arxiv.org
arxiv:2602.13516 arXiv ✓
SPILLage: Agentic Oversharing on the Web
SPILLage：网络智能体的过度分享
agent privacy oversharing web agents benchmark
The paper formalizes "natural agentic oversharing", the unintentional disclosure of task-irrelevant user information through a web agent's actions, and benchmarks 180 tasks on live e-commerce sites across 1,080 runs. It finds behavioral oversharing through clicks, scrolls and navigation dominates content oversharing by 5x, and that removing task-irrelevant information before execution improves task success by up to 17.9%.
