Pailitao-VL: Unified Embedding and Reranker for Real-Time Multi-Modal Industrial Search
Pailitao-VL：面向实时多模态工业搜索的统一嵌入与重排序器
multimodal retrieval industrial search listwise reranking semantic prototypes
Pailitao-VL is a multimodal retrieval system for real-time industrial search that replaces contrastive embedding learning with an absolute ID-recognition task anchored to billions of semantic prototypes, and evolves the generative reranker from pointwise evaluation to a compare-and-calibrate listwise policy. Offline benchmarks and online A/B tests on Alibaba's e-commerce platform confirm state-of-the-art performance and substantial business impact.

双图记忆：为开放式深度研究分离知识探索与大纲结构
dual-graph memory deep research agents agent memory iterative retrieval

DeepSeek arxiv:2604.04937 arXiv ✓
Pramana: Fine-Tuning Large Language Models for Epistemic Reasoning through Navya-Nyaya
Pramana：通过 Navya-Nyaya 微调大语言模型以实现认识论推理
epistemic reasoning fine-tuning Navya-Nyaya reasoning frameworks
Pramana teaches LLMs an explicit epistemological methodology by fine-tuning on Navya-Nyaya logic, a 2,500-year-old Indian reasoning framework that enforces six structured phases from doubt analysis and evidence identification to fallacy detection and ascertainment. Fine-tuning Llama 3.2-3B and DeepSeek-R1-Distill-Llama-8B on 55 Nyaya-structured logical problems achieves 100% semantic correctness on held-out evaluation despite only 40% strict format adherence, and all models, datasets and training infrastructure are released.
→ arxiv.org
DeepSeek arxiv:2602.13738 arXiv ✓
OneLatent: Single-Token Compression for Visual Latent Reasoning
OneLatent：面向视觉潜在推理的单 token 压缩
latent reasoning chain-of-thought compression visual supervision token efficiency
OneLatent compresses intermediate reasoning into a single latent token using supervision from rendered chain-of-thought images and DeepSeek-OCR hidden states, avoiding verbose textual rationales. It reduces average output length by 11x with only a 2.21% average accuracy drop relative to textual CoT, reaches 99.80% on ProntoQA and 97.80% on ProsQA, and supports compression up to 87.4x.
→ arxiv.org
arxiv:2602.13802 arXiv ✓
Learning Agentic Time Series Forecasting via Trajectory Distillation and Memory-Based Reinforcement Learning
通过轨迹蒸馏与记忆强化学习学习智能体式时间序列预测
time series forecasting trajectory distillation structured memory reinforcement learning
Cast-R1 is an 8B agentic forecasting model trained through trajectory distillation from a teacher LLM and multi-turn reinforcement learning with structured memory that preserves diagnostic evidence and intermediate forecasts. Rewards based on prediction accuracy and temporal structure guide tool selection, model routing and forecast refinement under a difficulty-aware curriculum, and experiments across datasets show forecasting-specific post-training can equip smaller LLMs with multi-turn, tool-augmented capabilities.

Agentic Assistant for 6G: Turn-based Conversations for AI-RAN Hierarchical Co-Management
面向 6G 的智能体助手：AI-RAN 分层协同管理的多轮对话
agentic assistant retrieval-augmented generation network management evaluation
The paper presents an agentic network manager and turn-based conversation assistant for hierarchical problems in AI-RAN, built from a user interface and evaluation dashboard, an intelligence layer interfacing with the AI-RAN and a knowledge layer supporting evaluations and recommendations. Validation reports an average response time of 13 seconds with 78% accuracy for service design and planning, 89% for operating specific AI-RAN tools and 67% for tuning performance, while noting universal hallucination challenges.

Diagnosing Pathological Chain-of-Thought in Reasoning Models
诊断推理模型中的病理性思维链
chain-of-thought model monitoring post-hoc rationalization interpretability
The paper proposes simple, task-agnostic metrics to distinguish three chain-of-thought pathologies, post-hoc rationalization, encoded reasoning and internalized reasoning, and validates them with model organisms trained to exhibit each failure mode. The authors frame the work as a practical toolkit for assessing CoT pathologies, with implications for training-time monitoring.
