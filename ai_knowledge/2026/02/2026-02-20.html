Decoding ML Decision: An Agentic Reasoning Framework for Large-Scale Ranking System
GEARS：面向大规模排序系统的智能体推理框架
agentic ranking experimentation environment reusable agent skills validation hooks
GEARS reframes ranking optimization as autonomous discovery inside a programmable experimentation environment, packaging ranking expertise into reusable agent skills and adding validation hooks to filter brittle policies. Experiments across product surfaces show it finds near-Pareto-efficient policies while keeping deployment stable.
→ arxiv.org
arxiv:2603.06620 arXiv ✓
GraphSkill: Documentation-Guided Hierarchical Retrieval-Augmented Coding for Complex Graph Reasoning
GraphSkill：面向复杂图推理的文档引导分层检索增强编码
hierarchical retrieval retrieval-augmented coding self-debugging graph reasoning benchmark dataset
GraphSkill is an agentic hierarchical retrieval-augmented coding framework that traverses technical documentation top-down with early pruning and uses a self-debugging coding agent with automatically generated small test cases to catch logical errors. It also introduces a dataset spanning small-scale, large-scale and composite graph reasoning tasks, and reports higher task accuracy at lower inference cost than baselines.
→ arxiv.org
arxiv:2602.18425 arXiv ✓
RVR: Retrieve-Verify-Retrieve for Comprehensive Question Answering
RVR：面向全面问答的检索-验证-再检索
multi-round retrieval verifier answer coverage query augmentation
RVR is a multi-round retrieve-verify-retrieve framework in which a verifier selects a high-quality subset of candidate documents and later rounds augment the query with verified documents to uncover answers not yet covered. It reports at least 10% relative and 3% absolute gains in complete recall on QAMPARI and consistent gains on QUEST and WebQuestionsSP across base retrievers.
→ arxiv.org
arxiv:2602.18429 arXiv ✓
VIRAASAT: Traversing Novel Paths for Indian Cultural Reasoning
VIRAASAT：探索印度文化推理的新路径
cultural knowledge graph multi-hop QA symbolic manipulation benchmark
VIRAASAT builds more than 3,200 multi-hop questions from a knowledge graph of over 700 expert-curated Indian cultural artifacts covering 13 attributes across all 28 states and 8 union territories. The authors propose Symbolic Chain-of-Manipulation (SCoM), which trains a model to simulate atomic knowledge-graph manipulations internally and outperforms standard chain-of-thought baselines by up to 20% under supervised fine-tuning.
→ arxiv.org
arxiv:2602.18351 arXiv ✓
Validating Political Position Predictions of Arguments
验证论证的政治立场预测
knowledge base validation political stance human annotation graph-based reasoning
Uses a dual-scale validation framework combining pointwise and pairwise human annotation to predict political positions in argumentative discourse, building a knowledge base of predictions for 23,228 arguments from 30 Question Time debates with 22 language models. Pointwise agreement is moderate (Krippendorff's alpha 0.578), while pairwise validation reaches 0.86 for the best model, supporting graph-based reasoning and RAG over subjective continuous knowledge.
→ arxiv.org
arxiv:2604.09572 arXiv ✓
ACE-TA: An Agentic Teaching Assistant for Grounded Q&A, Quiz Generation, and Code Tutoring
ACE-TA：面向有据问答、测验生成与代码辅导的智能体助教
agentic teaching assistant grounded QA quiz generation code tutoring
ACE-TA is an agentic teaching assistant that routes conceptual queries from programming course material to three coordinated modules: retrieval-grounded conceptual Q&A, adaptive multi-topic quiz generation and an interactive code tutor with sandboxed execution and iterative feedback.
