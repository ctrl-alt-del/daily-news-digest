PlugMem：面向 LLM 智能体的任务无关插件式记忆模块
long-term memory knowledge graph memory retrieval task-agnostic agents episodic memory
PlugMem is a task-agnostic plug-in memory module that structures episodic memories into a compact, extensible knowledge-centric memory graph of propositional and prescriptive knowledge, making knowledge rather than entities or text chunks the unit of memory access.
