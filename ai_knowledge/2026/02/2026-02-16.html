Panini: Continual Learning in Token Space via Structured Memory
Panini：通过结构化记忆在 token 空间进行持续学习
agent memory structured memory continual learning reasoning chains token efficiency
Panini is a non-parametric continual-learning framework that keeps the base model fixed and integrates each new document into a Generative Semantic Workspace, an entity- and event-aware network of question-answer pairs, so retrieval traverses the memory rather than verbatim chunks. Across six QA benchmarks it reports the highest average performance, 5-7% above competitive baselines, while using 2-30x fewer answer-context tokens and reducing unsupported answers.

Tool-Aware Planning in Contact Center AI: Evaluating LLMs through Lineage-Guided Query Decomposition
联络中心 AI 中的工具感知规划：通过谱系引导的查询分解评估 LLM
tool-aware planning query decomposition plan evaluation text-to-SQL agentic planning
Presents a domain-grounded framework and benchmark for tool-aware plan generation in contact centers, where queries must be decomposed into steps over Text2SQL and RAG tools with explicit dependencies. Across 14 LLMs, compound queries and plans longer than four steps remain difficult, with the best total metric score at 84.8% and the strongest one-shot A+ match rate at 49.75%.

基于 LLM 的联络中心坐席质检系统反事实公平性评估

Evaluates LLM-based contact-center quality assurance across 13 identity, context and behavioral-style dimensions using counterfactual flip rate and mean absolute score difference on 3,000 real transcripts and 18 LLMs. It finds systematic disparities, with contextual priming of historical performance causing the largest degradations, and fairness-aware prompting yielding only modest improvements.

ScrapeGraphAI-100k: Dataset for Schema-Constrained LLM Generation
ScrapeGraphAI-100k：面向模式约束 LLM 生成的数据集
schema-constrained generation structured extraction knowledge base construction dataset
Introduces ScrapeGraphAI-100k, a public corpus of 93,695 schema-constrained extraction events spanning 25,453 schemas and 15 named languages, collected from opt-out telemetry and paired with structural conformance labels. A case study finds sharp failure thresholds as schema complexity grows and shows a 1.7B student fine-tuned on the data closely tracking its GPT-5-nano teacher while trailing a 30B-A3B reference on schema compliance.
→ arxiv.org
