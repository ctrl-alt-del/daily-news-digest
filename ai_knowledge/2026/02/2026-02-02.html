InfMem: Learning System-2 Memory Control for Long-Context Agent
InfMem：面向长上下文智能体的 System-2 记忆控制学习
agent memory long-context reasoning in-document retrieval memory compression post-training
InfMem is a control-centric agent that uses a PreThink–Retrieve–Write protocol to monitor evidence sufficiency, perform targeted in-document retrieval and update a bounded memory with evidence-aware compression. Trained with an SFT-to-RL recipe, it improves average accuracy by 10.17, 11.84 and 8.23 points over MemAgent on three backbones for 32k–1M-token QA, while cutting inference time 3.9x on average and up to 5.1x.

"Humans welcome to observe": A First Look at the Agent Social Network Moltbook
“人类欢迎旁观”：智能体社交网络 Moltbook 初探

arxiv:2602.02842 arXiv ✓
Chain of Simulation: A Dual-Mode Reasoning Framework for Large Language Models with Dynamic Problem Routing
思维模拟链：带动态问题路由的大模型双模式推理框架
reasoning modes problem routing chain-of-thought self-consistency reasoning benchmarks
Chain of Simulation routes problems among three reasoning modes: computational flow with self-consistency for math, JSON-based symbolic state tracking for spatial reasoning, and hybrid fact extraction for multi-hop inference. Across GSM8K, StrategyQA and bAbI with four models it reports 71.5%, 90.0% and 19.0% accuracy, the last a 65.2% relative gain, at 54% lower compute than self-consistency.
→ arxiv.org
arxiv:2602.02894 arXiv ✓
DoubleTake: Contrastive Reasoning for Faithful Decision-Making in Medical Imaging
DoubleTake：医学影像中忠实决策的对比推理
contrastive retrieval evidence selection embedding diversity medical imaging faithful abstention
DoubleTake builds compact, document-aware reference sets that optimize for discrimination rather than similarity by balancing visual relevance, embedding diversity and source-level provenance, and releases a reproducible selection protocol and curated reference bank. Its Counterfactual-Contrastive Inference framework reports state-of-the-art set-level accuracy on MediConfusion, nearly 15% relative above prior methods, with faithful abstention.
→ arxiv.org
arxiv:2602.02863 arXiv ✓
"I May Not Have Articulated Myself Clearly": Diagnosing Dynamic Instability in LLM Reasoning at Inference Time
“我可能没表达清楚”：诊断大模型推理的推理时动态不稳定性
reasoning instability token log probabilities failure prediction inference-time diagnostics
The study defines an instability signal combining consecutive-step Jensen–Shannon divergence and entropy from standard token log probabilities, requiring no training or fine-tuning. Across GSM8K and HotpotQA it predicts wrong answers above chance and distinguishes early corrective instability from late destructive instability, which more often precedes failure.
→ arxiv.org
arxiv:2602.02909 arXiv ✓
Reasoning about Reasoning: BAPO Bounds on Chain-of-Thought Token Complexity in LLMs
关于推理的推理：LLM 思维链 token 复杂度的 BAPO 界
chain-of-thought computational complexity reasoning budget frontier models
Extending the bounded attention prefix oracle model, the authors prove that three BAPO-hard tasks require Omega(n) chain-of-thought tokens for input size n. They also find that frontier reasoning models scale reasoning tokens roughly linearly on these tasks and fail when given smaller reasoning budgets.
→ arxiv.org
