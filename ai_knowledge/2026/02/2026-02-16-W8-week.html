The Limits of Long-Context Reasoning in Automated Bug Fixing
自动化缺陷修复中长上下文推理的局限
long-context reasoning agentic coding SWE-bench context capacity task decomposition
Systematically evaluates long-context code debugging and patch generation on SWE-bench Verified, finding that agentic trajectories succeed mainly through decomposition into short steps: successful runs typically stay under 20k-30k tokens and longer accumulated contexts correlate with lower success. With relevant files placed in a 64k-token context and perfect retrieval recall, Qwen3-Coder-30B-A3B resolves only 7% and GPT-5-nano none, revealing a gap between nominal and usable context capacity.

ILION: Deterministic Pre-Execution Safety Gates for Agentic AI Systems
ILION：面向智能体 AI 系统的确定性执行前安全门
agent safety execution gating adversarial robustness interpretable verdicts
ILION is a deterministic pre-execution gate that classifies proposed agent actions as BLOCK or ALLOW through a five-component cascade, requiring no statistical training or labeled data and producing interpretable verdicts at sub-millisecond latency. On the 380-scenario ILION-Bench v2 it reports F1 0.8515 at a mean latency of 143 microseconds, outperforming Lakera Guard, the OpenAI Moderation API and Llama Guard 3.

arxiv:2602.15156 arXiv ✓
Panini: Continual Learning in Token Space via Structured Memory
Panini：通过结构化记忆在 token 空间进行持续学习
agent memory structured memory continual learning reasoning chains token efficiency
Panini is a non-parametric continual-learning framework that keeps the base model fixed and integrates each new document into a Generative Semantic Workspace, an entity- and event-aware network of question-answer pairs, so retrieval traverses the memory rather than verbatim chunks. Across six QA benchmarks it reports the highest average performance, 5-7% above competitive baselines, while using 2-30x fewer answer-context tokens and reducing unsupported answers.
