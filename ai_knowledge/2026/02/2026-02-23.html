Structured Prompt Language: Declarative Context Management for LLMs
结构化提示语言：面向 LLM 的声明式上下文管理
context management declarative prompting RAG integration persistent memory query optimization
SPL is a declarative, SQL-inspired language that treats LLMs as generative knowledge bases and context windows as constrained resources, adding token budgets, an automatic query optimizer, EXPLAIN-style transparency, RAG and persistent memory in one framework. It ships a formal grammar and two pip-installable packages, claims a 65% average reduction in prompt boilerplate, and surfaces a 68x cost spread across model tiers before execution.

隐性智能——评估智能体对用户未言明需求的理解
implicit requirements agent evaluation underspecified instructions interactive worlds
Implicit Intelligence is an evaluation framework with an Agent-as-a-World harness that defines interactive worlds in YAML and simulates them with language models, testing whether agents infer unstated accessibility, privacy, safety and contextual constraints. Across 205 scenarios and 16 frontier and open-weight models, the best model passed only 48.3%.

CodeCompass: Navigating the Navigation Paradox in Agentic Code Intelligence
CodeCompass：穿越智能体代码智能中的导航悖论
code navigation dependency graphs MCP server agent tool adoption
CodeCompass is a Model Context Protocol server that exposes dependency graphs, and in 258 trials across 30 tasks on a production FastAPI repository it reached 99.4% completion on hidden-dependency tasks, 23.2 points above vanilla agents. The study also finds an adoption gap: 58% of trials with graph access made no tool calls, so agents needed explicit prompting to use structural context.

CaDrift: A Time-dependent Causal Generator of Drifting Data Streams
CaDrift：随时间变化的因果漂移数据流生成器
concept drift causal models data streams continual learning
CaDrift is a synthetic data-stream generator based on structural causal models that drifts mapping functions to create distributional and covariate shifts, and uses causal interventions to model occasional perturbations. Experiments show classifier accuracy drops after distributional shift events and then gradually recovers, and the framework is available on GitHub.
→ arxiv.org

Learning to Rewrite Tool Descriptions for Reliable LLM-Agent Tool Use
学习重写工具描述，让 LLM 智能体更可靠地使用工具
tool descriptions curriculum learning tool use agent reliability
The paper introduces Trace-Free+, a curriculum-learning framework that rewrites tool descriptions for LLM agents and transfers supervision from trace-rich settings to trace-free deployment. On StableToolBench it reports a 29.23% reduction in accuracy degradation and 60.89% higher average query-level success when tool catalogs grow beyond 150 candidates.
→ arxiv.org
