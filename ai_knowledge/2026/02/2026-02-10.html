Training-free retrieval-augmented generation with reinforced reasoning for flood damage nowcasting
面向洪水损失临近预报的训练无关检索增强生成与强化推理
retrieval-augmented generation case-based reasoning training-free knowledge base disaster assessment
R2RAG-Flood builds a reasoning-centric knowledge base from labeled tabular records, each with structured predictors, a compact text summary and a model-generated reasoning trajectory, and at inference retrieves geographically local neighbors and selected free-shots without task-specific fine-tuning. In a Hurricane Harvey case study across seven LLM backbones it reaches 0.613-0.668 overall accuracy and 0.757-0.896 accuracy on damaged classes, with lighter variants more cost-efficient than a supervised baseline and larger LLM backbones.

ACE-RTL couples an RTL-specialized LLM trained on 1.7 million RTL samples with a frontier reasoning LLM through generator, reflector and coordinator components that iteratively refine code toward functional correctness. arxiv:2602.10356 arXiv ✓
Autonomous Continual Learning for Environment Adaptation of Computer-Use Agents
面向计算机使用智能体环境适应的自主持续学习
continual learning computer-use agents curriculum learning automatic evaluation catastrophic forgetting
ACuRL is an autonomous curriculum reinforcement learning framework that adapts computer-use agents to specific environments with zero human data, using a curriculum task generator that synthesizes new tasks from prior experience and feedback. Its CUAJudge evaluator agrees with human judgments 93% of the time, and the method yields 3-29% absolute gains on target environments without catastrophic forgetting while updating only about 20% of parameters.

DECKBench: Benchmarking Multi-Agent Frameworks for Academic Slide Generation and Editing
DECKBench：面向学术幻灯片生成与编辑的多智能体框架基准
multi-agent systems slide generation multi-turn instruction following evaluation framework
DECKBench is an evaluation framework for multi-agent academic slide generation and editing, built on curated paper-to-slide pairs augmented with simulated editing instructions, and scores slide-level and deck-level fidelity, coherence, layout quality and multi-turn instruction following. It also provides a modular multi-agent baseline that parses and summarizes papers, plans slides, creates HTML and iteratively edits.
