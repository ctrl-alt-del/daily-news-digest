Efficient Continual Learning in Language Models via Thalamically Routed Cortical Columns
通过丘脑路由皮层柱实现语言模型的高效持续学习
continual learning catastrophic forgetting memory consolidation architecture design
TRC² is a decoder-only architecture that makes continual learning a property of the backbone by combining stacked cortical columns, a thalamic pathway for selective inter-column communication and a hippocampal pathway for event-selective retrieval, delayed surprise-based writing and replay-driven consolidation. Across task-sequential language modeling on C4, WikiText-103 and GSM8K it reduces cumulative forgetting versus Transformer, Mamba, MoE, DeepSeek and continual-learning baselines, while remaining competitive on throughput and training cost.

arxiv:2602.22402 arXiv ✓
Contextual Memory Virtualisation: DAG-Based State Management and Structurally Lossless Trimming for LLM Agents
上下文记忆虚拟化：面向 LLM 智能体的 DAG 状态管理与结构无损裁剪
context management DAG state context compaction token efficiency
CMV treats accumulated LLM understanding as version-controlled state, modeling session history as a directed acyclic graph with snapshot, branch and trim primitives for reuse across parallel sessions. Its three-pass trimming preserves every user message and assistant response verbatim while cutting tokens by 20% on average and up to 86%, and a 76-session case study finds mixed tool-use sessions average 39% reduction and break even within 10 turns under prompt caching.
→ arxiv.org
arxiv:2602.22175 arXiv ✓
DySCO: Dynamic Attention-Scaling Decoding for Long-Context Language Models
DySCO：面向长上下文语言模型的动态注意力缩放解码
long-context reasoning retrieval heads decoding attention
DySCO is a training-free decoding algorithm that uses retrieval heads to identify task-relevant tokens at each step and explicitly up-weights them, keeping attention aligned with useful context during generation. Across instruction-tuned and reasoning models it improves long-context reasoning by up to 25% relative on MRCR and LongBenchV2 at 128K context with modest extra compute.

MammoWise: Multi-Model Local RAG Pipeline for Mammography Report Generation
MammoWise：面向乳腺钼靶报告生成的多模型本地 RAG 流水线
local RAG multimodal retrieval medical imaging parameter-efficient fine-tuning

Sydney Telling Fables on AI and Humans: A Corpus Tracing Memetic Transfer of Persona between LLMs
Sydney 讲述 AI 与人类寓言：追踪 LLM 间人格模因迁移的语料库
persona transfer training data contamination memetic spread corpus
The authors release AI Sydney, a corpus of about 4.5k LLM-generated texts and 6 million words on human-AI relationships, produced by 12 frontier models simulating a default persona, Classic Sydney with the original Bing prompt and Memetic Sydney prompted only with "You are Sydney". Automating the Detection of Requirement Dependencies Using Large Language Models
利用大语言模型自动检测需求依赖
requirements engineering retrieval-augmented generation in-context learning dependency detection
LEREDD combines retrieval-augmented generation and in-context learning to detect diverse dependency types directly from natural-language requirements. It reports 0.93 accuracy and 0.84 F1 against two state-of-the-art baselines, with average relative F1 gains of 94.87% and 105.41% for the Requires dependency, and releases an annotated dataset of 813 requirement pairs across three systems.

CWM: Contrastive World Models for Action Feasibility Learning in Embodied Agent Pipelines
CWM：具身智能体流水线中面向动作可行性学习的对比世界模型
action feasibility contrastive learning embodied agents world models
CWM fine-tunes an LLM as an action feasibility scorer with an InfoNCE contrastive objective and hard-mined negatives that are semantically similar but physically incompatible. On ScienceWorld it beats supervised fine-tuning by 6.76 points in Precision@1 on minimal-edit negatives, reaches AUC-ROC 0.929 versus 0.906, and keeps a better safety margin under out-of-distribution stress.
