CM2: Reinforcement Learning with Checklist Rewards for Multi-Turn and Multi-Step Agentic Tool Use
CM2：面向多轮多步智能体工具使用的清单奖励强化学习
checklist rewards agentic tool use reinforcement learning simulated environments
CM2 is an RL framework that replaces verifiable outcome rewards with checklist rewards, decomposing each turn's intended behavior into fine-grained binary criteria with evidence grounding and structured metadata, and trains in a scalable LLM-simulated tool environment. Starting from an 8B base model and an 8k-example RL dataset, it improves over the SFT counterpart by 8 points on tau^-Bench, 10 on BFCL-V4 and 12 on ToolSandbox.

先文本后视觉：分阶段知识注入对超高分辨率遥感智能体 RLVR 至关重要
knowledge injection agentic RLVR remote sensing multimodal reasoning
The paper compares cold-start SFT, RLVR and agentic RLVR for ultra-high-resolution remote sensing and finds that high-quality Earth-science text-only QA is a primary driver of visual reasoning gains. Its staged recipe first cold-starts on knowledge-graph-verified Earth-science text QA and then pre-warms on hard image-text examples during SFT, achieving 60.40% Pass@1 on XLRS-Bench and outperforming larger general-purpose models such as GPT-5.2 and Gemini 3.0 Pro.

arxiv:2602.13530 arXiv ✓
REMem: Reasoning with Episodic Memory in Language Agent
REMem：语言智能体中的情景记忆推理
episodic memory memory graph agentic retrieval benchmark
REMem is a two-phase framework for episodic memory in language agents: offline indexing converts experiences into a hybrid memory graph linking time-aware gists and facts, while online inference uses an agentic retriever with curated tools for iterative retrieval over the graph. Across four episodic memory benchmarks it outperforms systems such as Mem0 and HippoRAG 2 by 3.4% and 13.4% absolute on recollection and reasoning tasks, and shows more robust refusal behavior for unanswerable questions.
→ arxiv.org

Diffusion-Pretrained Dense and Contextual Embeddings
扩散预训练的稠密与上下文嵌入
embedding models diffusion pretraining contextual embeddings late chunking multilingual retrieval
The report introduces pplx-embed, a family of multilingual embedding models that apply multi-stage contrastive learning on a diffusion-pretrained backbone for web-scale retrieval, using mean pooling and late chunking to preserve global context. pplx-embed-v1 is competitive on MTEB, MTEB(Code), MIRACL, BERGEN and ToolRet, while pplx-embed-context-v1 sets new records on ConTEB, and the models are tested on an internal suite built from 1B production web pages.
