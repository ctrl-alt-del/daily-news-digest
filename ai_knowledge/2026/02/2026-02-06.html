Adaptive Retrieval helps Reasoning in LLMs -- but mostly if it's not used
自适应检索有助于大模型推理——但主要是在不使用检索时
adaptive retrieval retrieval-augmented generation metacognition chain-of-thought in-context learning
The authors compare an LLM agent that decides when to query an external knowledge base against chain-of-thought and static retrieval on GSM8K and MATH-500. Static retrieval underperformed CoT, and traces without retrieval actually did better than CoT, suggesting retrieval only rarely helps reasoning and that choosing not to retrieve is a useful metacognitive signal; retrieval frequency scaled with problem difficulty.

DeepSeek arxiv:2602.06960 arXiv ✓
InftyThink+: Effective and Efficient Infinite-Horizon Reasoning via Reinforcement Learning
InftyThink+：通过强化学习实现高效无限视野推理
iterative reasoning reinforcement learning context summarization long chain-of-thought inference efficiency
InftyThink+ is an end-to-end reinforcement learning framework that trains a model to choose when to summarize intermediate thoughts, what to preserve and how to resume reasoning, using a supervised cold-start followed by trajectory-level RL. On DeepSeek-R1-Distill-Qwen-1.5B it improves AIME24 accuracy by 21%, outperforms conventional long chain-of-thought RL by a clear margin and reduces inference latency.

arxiv:2603.03296 arXiv ✓
PlugMem: A Task-Agnostic Plugin Memory Module for LLM Agents
PlugMem：面向 LLM 智能体的任务无关插件式记忆模块
long-term memory knowledge graph memory retrieval task-agnostic agents episodic memory
PlugMem is a task-agnostic plug-in memory module that structures episodic memories into a compact, extensible knowledge-centric memory graph of propositional and prescriptive knowledge, making knowledge rather than entities or text chunks the unit of memory access. Across conversational QA, multi-hop retrieval and web-agent benchmarks it beats task-agnostic baselines and task-specific memory designs while achieving the highest information density, with code released.

arxiv:2602.21231 arXiv ✓
ACAR: Adaptive Complexity Routing for Multi-Model Ensembles with Auditable Decision Traces
ACAR：面向多模型集成的自适应复杂度路由与可审计决策追踪
model routing multi-model ensembles self-consistency retrieval augmentation decision traces
ACAR routes tasks among one-, two- and three-model execution modes using self-consistency variance from three probe samples, evaluated on 1,510 tasks and more than 7,550 auditable runs with Claude Sonnet 4, GPT-4o and Gemini 2.0 Flash. Sigma-based routing reached 55.6% accuracy versus a 54.4% two-model baseline while avoiding full ensembling on 54.2% of tasks, and retrieval augmentation reduced accuracy by 3.4 percentage points because median retrieval similarity was only 0.167.
→ arxiv.org
arxiv:2602.07181 arXiv ✓
PACIFIC: Can LLMs Discern the Psychometric Traits Influencing Your Preferences? Personality-Driven Preference Alignment in LLMs
PACIFIC：基于人格特质的 LLM 偏好对齐
preference alignment persona-aware retrieval contrastive retrieval personalization
PACIFIC uses Big-Five personality traits as a latent signal for organizing and reasoning over user preference histories, evaluated on a 1,200-pair psychometric dataset spanning travel, movies and education. With clean trait-aligned context LLMs reached up to 99% accuracy, while a persona-aware contrastive retriever (PiRAG) raised label-free accuracy from 30% to 43%, identifying retrieval as the bottleneck.

Multi-Agentic AI for Fairness-Aware and Accelerated Multi-modal Large Model Inference in Real-world Mobile Edge Networks
面向移动边缘网络多模态大模型推理的多智能体公平加速框架
multi-agent coordination prompt routing edge inference fairness
The paper proposes a multi-agent framework with a long-term global planning agent, a short-term prompt scheduling agent and on-node deployment agents that reason in natural language over runtime telemetry to route prompts and place multimodal models in mobile edge networks. On a city-wide testbed it reduces average end-to-end latency by 42.9% versus an online-learning baseline and 80.6% versus full activation, maintaining a mean service-type Jain's index of 0.925.
