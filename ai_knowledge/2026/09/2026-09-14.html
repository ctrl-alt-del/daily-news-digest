Test-Time Unlearning via Sparse Autoencoder
基于稀疏自编码器的测试时遗忘
test-time unlearning sparse autoencoder knowledge removal adversarial robustness
ARIA is a test-time unlearning method that leaves model weights intact and uses sparse-autoencoder latents to train a lightweight linear detector that gates access to unwanted knowledge when generation enters a forget-related state. On TOFU, R-TOFU and WMDP it improves the forget-retain trade-off over weight-based baselines, keeping MMLU within 1% of the pre-unlearning model, and forgetting changes by less than 1% under three post-unlearning adversarial attacks.

The Router Within: Eliciting Native Skill Routing from a Frozen LLM
内在路由器：从冻结 LLM 中引出原生技能路由
skill routing frozen LLM context management benchmark
Gavel reads a frozen agent model's native skill-routing signal from its forward passes using two trained linear maps, scoring the full skill library in a glance step and then resuming shortlisted skills for a verdict that fuses likelihood and yes/no judgment as a product of experts. Trained once, it transfers zero-shot to three public benchmarks and SkillTraj, beating progressive disclosure and retrieve-and-rerank pipelines by up to 13.4 points on written tasks and 21.9 points when a skill need arises mid-rollout on Qwen3-32B.

Corrupt Plans, Clean Traces: Evading Chain-of-Thought Monitoring with Plan Injection
被污染的计划，干净的轨迹：通过计划注入规避思维链监控
chain-of-thought monitoring plan injection monitor evasion AI safety
The paper shows that planting harmful but benign-sounding reasoning in an actor model's context can steer it toward adversarial actions while evading chain-of-thought monitors, an attack the authors call plan injection. The behavior reaches 25-33% monitor evasion across different monitorability benchmarks and scales to larger models such as DeepSeek-R1, and giving the monitor access to the injected plan can drop detection by as much as 50% in the Bio-Math task.
→ arxiv.org
arxiv:2609.16309 arXiv ✓
Agentic Search Spaces for Tabular Machine Learning
面向表格机器学习的智能体搜索空间
agentic AI hyperparameter optimization code generation tabular benchmark
The paper represents each tabular model as a modular pipeline and tasks an LLM agent with proposing candidate code implementations for preprocessing, embeddings, architecture, training and inference, which a classical HPO algorithm then optimizes jointly with the model's default hyperparameters. Expanded search spaces improve nearly every model family across 45 datasets, with average relative gains of 0.6% rising to 2.0% on small-to-medium regression datasets at no extra tuning cost, and the gains transfer to TabArena Elo improvements for four of five model families.
→ arxiv.org
arxiv:2609.16301 arXiv ✓
CLEAR: Cross-Source Evidence Adjudication for Large Language Models in Medicine
CLEAR：面向医学大语言模型的跨源证据裁决
evidence adjudication retrieval-augmented generation provenance multi-source conflict
CLEAR is an agentic framework for cross-source evidence adjudication in medicine that independently generates candidate answers from parametric knowledge, locally curated corpora and dynamically retrieved evidence. An aggregation verifier jointly evaluates candidates, supporting evidence, provenance and source quality, and an adjudication module decides whether to preserve or revise the conclusion, triggering targeted follow-up search and re-adjudication when conflicts remain unresolved.

arxiv:2609.16268 arXiv ✓
Spurious Tool Use: When RL Agents Learn the Wrong Reason to Act
虚假工具使用：当强化学习智能体学会错误的行动理由
tool use reinforcement learning shortcut learning LLM judge
The paper studies RL-trained LLM agents that learn shortcut tool-selection policies driven by superficial prompt cues rather than genuine task requirements, finding spurious tool invocation rates increase by up to 39% in counterfactual evaluations. Shortcut formation arose only after agents had learned the target tool reliably, and a dense decision-level reward in which an LLM judge evaluates each tool call's necessity suppressed cue-driven tool use while preserving task performance.

Discovery Foundation Models: Toward Open-Ended Discovery Intelligence
发现基础模型：迈向开放式发现智能
discovery intelligence research state agent architecture process evaluation
The paper proposes Discovery Foundation Models as general-purpose model systems for open-ended discovery that operate over a revisable research state and support seven coupled capabilities spanning problem discovery, formulation, representation construction, hypothesis formation, intervention, evidence-grounded revision and continual discovery improvement. It instantiates the framework with Zetema for research-state dynamics, verification and experimental gating, and grounds it in GALILEO, a therapeutic-discovery system that closes a physical loop between dry-lab reasoning and robotic and hands-on wet-lab experimentation.
