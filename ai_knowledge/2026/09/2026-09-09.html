Glyph: A Multi-Strategy Agentic System for Column Description and Sensitivity-Ontology Tagging of Enterprise Data Catalogs
Glyph：面向企业数据目录列描述与敏感本体标注的多策略智能体系统
data catalog active RAG ontology tagging multi-agent system contrastive encoder
Glyph frames column description generation and column type annotation for enterprise data catalogs as cooperating LLM agents orchestrated as stateful graphs, using active RAG over pipeline source code and three parallel tagging strategies fused with reciprocal rank fusion. Fine-tuning a 6-layer MiniLM metadata encoder lifts same-tag retrieval from NDCG@10 0.55 to 0.92 on an in-distribution held-out split.

Fortunate Recall: Ontology-Driven Memory Lifecycle Management for Persistent Coherence in LLMs
Fortunate Recall：面向 LLM 持久连贯性的本体驱动记忆生命周期管理
memory lifecycle temporal decay ontology confabulation
Fortunate Recall classifies personal facts into a 10+1 behavioral ontology and applies category-specific lifecycle policies such as differential temporal decay, slot-key supersession and category-aware retrieval routing. Its FR-Bank implementation reaches 76.9% on LifecycleBench and 75.2% on LongMemEval-S, and cuts confabulation from Mem0's 45.1% to 22.4% over answered queries.

arxiv:2609.10750 arXiv ✓
When Synthetic Data Hurts: On Catastrophic Forgetting in Skill Retrieval for LLM Agents
当合成数据有害：LLM 智能体技能检索中的灾难性遗忘
skill retrieval catastrophic forgetting synthetic data continual learning
The paper studies skill retrieval over 34,396 skills and finds that synthetic-data fine-tuning improves in-distribution retrieval while causing catastrophic forgetting on real and out-of-distribution skills. Continual-learning mitigations such as embedding-anchor regularization, LwF and EWC retain OOD retrieval and improve synthetic in-distribution retrieval by 13.98% for a 0.6B Qwen retriever and reranker.

arxiv:2609.10892 arXiv ✓
DriftNet: A Dual-Head Trajectory Transformer for Detecting and Localizing Prompt Injection in LLM Agents
DriftNet：用于检测与定位 LLM 智能体提示注入的双头轨迹 Transformer
prompt injection trajectory analysis agent security tool calls
DriftNet is a dual-head trajectory Transformer that reads a logged tool-call trajectory and, in one forward pass, classifies it as compromised or not while labeling each step as benign, injection point, hijacked or failed injection. On the task-disjoint split of AgentDrift it reports trajectory-level F1 of 0.983 and exact injection-point recovery on 98.7% of attacked trajectories without access to the agent's model.

Think Before You Link: Rarity, Reasoning, and Retrieval in Multilingual Entity Linking
链接之前先思考：多语言实体链接中的稀有性、推理与检索
entity linking multilingual retrieval reasoning rare entities
The paper broadens entity rarity beyond popularity metrics using knowledge-graph structural metrics, finding state-of-the-art entity-linking accuracy drops by 15.4-39.9% on the resulting rare-entity slices. A training-free framework in which a reasoning-capable vision-language model iteratively searches and reasons over Wikipedia improves over the prior state of the art by 6.9% overall and up to 23.3% on rare entities.

CMNIE: An Information Extraction Benchmark for Chinese Military News
CMNIE：中文军事新闻信息抽取基准
information extraction knowledge base construction benchmark schema adherence
CMNIE is a Chinese military news information-extraction benchmark with 13,000 instances jointly annotated for event triggers, event arguments, named entities and entity relations under a unified schema. Evaluations show relation extraction and exact event-argument span matching remain difficult, with zero-shot LLMs often identifying relevant semantic units but missing gold span boundaries.

Multilingual in Name Only? Cultural and Linguistic Weaknesses of LLMs in Urdu
多语言只是名义上的？LLM 在乌尔都语中的文化与语言弱点
multilingual LLM cultural knowledge low-resource languages story generation
The authors generate 93 Urdu stories with GPT-5.1, Qwen-3-Max and DeepSeek-3.1 and manually annotate errors under a nine-label linguistic, semantic and cultural taxonomy. They find basic grammar and semantic errors, incoherent stories, unnatural repetition and pervasive cultural shallowness, which few-shot prompting largely fails to resolve.

A Verifier Can Leak the Answer: Diagnosability Before Optimization in Closed-Loop Agent Debugging
验证器可能泄露答案：闭环智能体调试中的可诊断性先于优化
agent debugging verifier leakage diagnosis evaluation design
The paper reports a closed-loop agent debugger case in which exact minimum hitting set and a propagation-aware greedy method returned identical supports in 12/12 development cases, and an audit found that exact-anchor predicates produced the planted pair in 9/9 cases. It proposes a support-gated verification contract that checks evidence eligibility and non-revelation before optimizing the component selector.
