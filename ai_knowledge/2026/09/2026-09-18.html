Defusing Explosive Prompts: Understanding and Preventing Trigger-Based Prompt Injections in LLM Agents
拆除爆炸性提示：理解与防范 LLM 智能体中基于触发器的提示注入
indirect prompt injection trigger-based payload injection detection agent security retrieval poisoning
The paper introduces explosive prompts, conditional indirect-injection payloads that remain dormant until an attacker-chosen trigger and can be planted in a single piece of retrieved content. Across nine production agents, they achieve 43-83% attack success versus at most 3% for imperative injection, and the DeFuse detector reduces live tool-execution success to 3.0% at a calibrated 5% false-positive budget.

arxiv:2609.22562 arXiv ✓
AdaMerge: Tuning-Free Patch Compression for Multi-Vector Visual Document Retrieval
AdaMerge：面向多向量视觉文档检索的免调优补丁压缩
multi-vector retrieval patch compression visual document retrieval cluster centroids
AdaMerge compresses multi-vector visual document retrieval by detecting each document's merge-cosine cliff through gap analysis and building attention-weighted cluster centroids, removing the need for a per-dataset cluster budget. It outperforms tuned Prune-then-Merge across the ViDoRe-V2 operating range and matches it on ViDoRe-V1 with about 10 ms overhead per document.
→ arxiv.org

An Interpretable Memory Decision Controller for LLM Agents Based on Three-Signal Complementarity: Decoupling Confidence and Consistency
基于三信号互补的 LLM 智能体可解释记忆决策控制器：解耦置信度与一致性
memory trust conflicting memories hallucination mitigation abstention interpretable control
The Memory Decision Layer is a zero-parameter controller between retrieval and generation that fuses relevance, reliability and task risk into an interpretable trust representation, decoupling confidence from consistency and supporting risk inversion and abstention. It reduces hallucination under conflicting memories by about 56.04% in general scenarios and approaches zero in high-risk scenarios, adding about 0.14 ms per decision.

Benchmarking World Models for Continual Learning on Compositional Tasks
面向组合任务的世界模型持续学习基准
continual learning knowledge reuse world models compositional tasks benchmark
The authors propose a compositional continual-learning benchmark for world models in robot manipulation, designing task curricula that combine aspects of previously seen tasks and factorizing composition along action and perception. Modular world models balance knowledge reuse against forgetting better than conventional methods, but none fully solve the problem.

IntLawNER: A Named Entity Recognition Dataset and Benchmark in International Law
IntLawNER：国际法领域的命名实体识别数据集与基准
named entity recognition legal knowledge annotation pipeline benchmark few-shot prompting
IntLawNER provides 2,987 gold-annotated sentences and 8,094 entity spans from ICJ decisions, UN Security Council resolutions and ECtHR judgments, labeled with seven institution-specific entity types. A hybrid retrieval, LLM-vetting and human-review pipeline produced the data, and the analysis shows aggregate human-machine agreement can mask missing entities, boundary errors and label corrections.

arxiv:2609.21940 arXiv ✓
AutoViewMem: Self-Configuring Orthogonal Views for Conversational Long-Term Memory
AutoViewMem：面向对话长期记忆的自配置正交视图
long-term memory semantic views memory consolidation provenance personalization
AutoViewMem discovers self-configuring, low-overlap semantic views from interaction traces and uses them to guide write-time extraction of provenance-grounded memories, followed by offline consolidation. On LoCoMo and PersonaMem with Qwen3-8B and Qwen3-14B backbones, it improves long-horizon question answering and personalization over strong memory baselines while keeping top-K retrieval simple.

ufakzeka-1: Building and Evaluating a 151M-Parameter Turkish Language Model from Scratch
ufakzeka-1：从零构建并评估 1.51 亿参数土耳其语模型
small language model Turkish evaluation gates reproducibility decontamination
The paper documents ufakzeka-1, a 151M-parameter Turkish decoder-only model pretrained on 13.5B tokens and instruction-tuned for chat at a total cost of about $286 in cloud GPU, API and notebook time, with weights and recipes released under Apache-2.0. It reports that a safety gate trained on its own questions scored 64/64 while the honest result was 34/64, and that training-seed variance matched the spread across recipes.
