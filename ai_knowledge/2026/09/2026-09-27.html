R$^2$ Flow: Recursive Self-Improvement via Recursive Skill Evolution
R² Flow：通过递归技能进化实现递归自我改进
skill evolution self-improvement skill library orchestration graph
R² Flow is a recursive self-improvement framework that alternates policy learning, independent verification and versioned skill-library updates on a shared-state orchestration graph that merges histories differing only in the order of independent steps. It improves task accuracy and library-edit precision over heuristic, reinforcement-learning and skill-evolution baselines across question answering, math reasoning, interactive decision making and code generation, with code released.

arxiv:2609.33822 arXiv ✓
Vestrum: Improving Agent Harnesses by Adapting Their Verification, Structure and Memory
Vestrum：通过适配验证、结构与记忆改进智能体框架
agent harness verification persistent lessons knowledge synthesis
Vestrum turns failures in execution traces into scoped changes to an agent harness's verification, retrieval, decomposition and knowledge synthesis without training the task model, while a persistent lessons file informs later proposals. Frozen harnesses improve held-out performance, including UltraHorizon from 47.6 to 59.8 over GAM and Terminal-Bench 4 Hard from 63.7% to 70.3% of checks over Claude Code at 1.03x test cost.

Artificiality's First Exam: An LLM-Referenced C-test for Supraintelligence
人工性的第一场考试：面向超智能的 LLM 参照 C-test
benchmark design Kolmogorov complexity LLM evaluation supraintelligence
The paper presents the first C-test built on Levin's Kt with LLMs as representational machines, allowing fresh items to be generated at difficulties estimated in bits before any human or frontier model can solve them. A first battery of certified items was administered to twelve LLMs, producing agent characteristic curves that extend into a high-difficulty supra-intelligence window.

arxiv:2609.34004 arXiv ✓
RICE-Alpha: Reliability-Informed Correction with Event Graphs for LLM-Agent Stock Forecasting
RICE-Alpha：面向 LLM 智能体股票预测的事件图可靠性校正
event graphs multi-tier memory stock forecasting point-in-time evaluation
RICE-Alpha is a point-in-time stock-scoring framework that separates a history-aware multi-view Base Alpha from a reliability-calibrated residual correction derived from historical event continuation, using a multi-tier memory layer and typed event graphs. On Nasdaq-100 and Hang Seng panels from 2024 to 2026 it reports the strongest results among evaluated LLM-based agents, with ICIR more than double the strongest baseline and net Sharpe ratios of 1.656 and 1.725.
→ arxiv.org
arxiv:2609.33980 arXiv ✓
DynGraphAgentBench: A Benchmark for Agentic Lifecycle Control in Dynamic Graph Anomaly Detection
DynGraphAgentBench：动态图异常检测中智能体生命周期控制的基准
dynamic graphs agent lifecycle delayed feedback anomaly detection
DynGraphAgentBench is an executable benchmark for agentic lifecycle control under delayed feedback, spanning seven temporal graph datasets, eleven selectable detectors and eight chronological deployment windows per dataset. Controllers see only time-causal aggregate context, model cards and their own matured history, and must choose a detector before current-window training or scores exist.

Conformal Factuality Control for Multi-Hop Retrieval-Augmented Generation
多跳检索增强生成中的保形事实性控制
conformal prediction multi-hop RAG factuality abstention
The study applies split-conformal claim filtering to multi-hop RAG on HotpotQA, Natural Questions and TriviaQA with Llama 3.1 8B and GPT-4o-mini. At a 95% target, the share of responses whose retained claims are fully supported rises to 95.80%-97.20%, but only 4.41%-31.09% of generated claims are retained and 9.70%-51.40% of responses remain non-empty.

arxiv:2609.33838 arXiv ✓
ChemOPD: Multi-Teacher On-Policy Distillation for Multi-Task Chemical Reasoning
ChemOPD：面向多任务化学推理的多教师同策略蒸馏
multi-teacher distillation capability integration chemical reasoning specialization
ChemOPD organizes chemical reasoning specialists into partially overlapping groups using task affinities estimated from supervised fine-tuning gradients and a constrained mixed-integer program, then distils them while retaining a generalist teacher. On ChemCoTBench, affinity-guided specialization yields task-dependent gains, and its anchor-residual objective improves most metrics over specialist-only distillation.
