Breaking Babel: A Self-Evolving Multi-Agent System for Long-Form Subtitle Translation
打破巴别塔：面向长篇字幕翻译的自演化多智能体系统
multi-agent translation episodic memory self-evolution MQM evaluation
SMART is a self-evolving multi-agent system for long-form subtitle translation: a test-time training stage builds persistent episode-level memory, dynamic routing and a Mixture-of-Agents layer translate partial sentences, and a judge-refine loop updates agent prompts and routing without retraining the base LLM. The authors release the Subtitle Arena and SubMQM framework and report the best MQM score across all 15 directions, a 6.9% lower average penalty than the strongest competing agent system, and 4.50/5 in human evaluation.

重排序与后期交互驱动检索质量：科学问答中 RAG 策略的受控比较
RAG pipelines late interaction reranking benchmark dataset agentic retrieval
The authors compare six retrieval strategies for scientific question answering — dense top-k retrieval, LLM query rephrasing, rephrasing plus LLM reranking, reciprocal rank fusion, agentic tool-call retrieval and ColBERTv2 late interaction — over 463,971 arXiv papers with a shared Llama-3.1-8B generator and evaluation protocol. They release the code and a synthetic dataset of 19,484 questions and assess answer quality and gold-paper retrieval with an LLM judge.

LVMH: A Meta-Optimization Harness for Long-Video Agent Memory
LVMH：长视频智能体记忆的元优化框架
agent memory memory policy search long video meta-optimization
LVMH is an automated multi-agent harness that frames long-video memory-policy development as multi-objective code search around a fixed answer model, separating implementation from independent review and keeping persistent meta-memory of past proposals, traces and failures. It discovers SEEM, a text-first, vision-second policy that reaches 65.7% average accuracy across three benchmarks with GPT-5, 7.7 points above the prior state of the art, at roughly 32x lower evaluation token use and 91x shorter response time.

arxiv:2609.38460 arXiv ✓
NAQD Env: A benchmark for selective withdrawal in language agents
NAQD Env：语言智能体选择性撤回基准
agent reliability selective withdrawal policy compliance benchmark
NAQD-Env is a synthetic benchmark that evaluates language agents' selective withdrawal — suspending affected actions, preserving unaffected work and resuming after repair — against a deterministic reference policy over explicit evidence, authorization and constraint dependencies. Across 3,150 model-prompt episodes, withdrawal recall is at most 0.06, no valid resumption is observed, and only one episode matches the full reference policy; supervised fine-tuning probes raise Qwen2.5-3B decision accuracy from 0.45–0.54 to 0.83–0.92.

SecureVibe: Making Vibe Coding More Secure
SecureVibe：让氛围编程更安全
secure code generation agent planning RL training security benchmark
SECUREVIBE is a training recipe that explicitly targets planning and testing for code security, combining supervised fine-tuning on four security tasks with reinforcement learning from verifiable execution feedback and hint-based self-supervision. It improves security pass@1 by 6.9 points on BaxBench and 11.5 points on SusVibes, and functionality pass@1 by 13.6 points on SusVibes and 4.1 points on SWE-bench Verified.

Benchmarking System One decision models against trained classifiers and language models for automated decision gates
System One 决策模型、分类器与语言模型在自动决策门禁上的基准比较
decision models calibration LLM classifiers automated gates
The authors send the same semantic requests to eight typed decision-model checkpoints, the hosted model Jev and four open generative models, and score trained and zero-shot classifiers on the same workflow, intent, emotion and social-science items. With labels, a fine-tuned DeBERTa-v3-large is the most accurate on every benchmark but one; without labels no decision model is significantly more accurate than Jev on workflows or intents, and the paper documents calibration and label-order sensitivity issues that shape design rules for automated decision gates.

arxiv:2610.14025 arXiv ✓
Contrastive Covariance Subspaces for Activation Steering
用于激活引导的对比协方差子空间
activation steering representation subspaces deconfounding controllability
Contrastive Covariance Steering is a training-free method that projects activation-steering vectors into a low-dimensional subspace obtained in closed form from a contrastive variance objective, retaining directions along which the target concept varies while suppressing directions shared with nuisance classes. Across three LLMs and four steering domains it beats all baseline steering methods in all 12 settings, with the largest relative improvements of 48–70% on AxBench and 13–27% on Emotion.

arxiv:2609.38641 arXiv ✓
Vision-Language-Action Autonomous Driving Agent with Language-based Memory
具备语言记忆的视觉-语言-动作自动驾驶智能体
language memory VLA agent chain-of-thought autonomous driving
AD-Memo is a general vision-language-action driving agent that outputs memories of key surrounding objects as an extension of its chain of thought and makes that memory part of subsequent input. Trained in two stages with supervised fine-tuning and a semi-closed-loop reinforcement learning algorithm called Da Capo, it improves driving quality and driving-scene question answering at all-way-stop intersections and in general driving, and produces memory that other models can plug in.

arxiv:2609.38652 arXiv ✓
AgBench: Agentic AI Benchmarks for Personal AI Devices
AgBench：面向个人 AI 设备的智能体基准
on-device agents execution architectures latency and cost privacy exposure
AgBench is a benchmark and set of open artifacts for reproducibly evaluating agentic AI on personal devices across local, hybrid and cloud execution, measuring task success, latency, cloud API cost and data exposure. Based on more than 162 million data points, it finds purely local execution has lower success rates and longer completion times that worsen with concurrency, but removes cloud API cost and sensitive-data exposure; no architecture wins on every metric.
