LIMBO: Lifelong Inference-Time Memory and Budget Optimization for LLM Agents
LIMBO：面向 LLM 智能体的终身推理时记忆与预算优化
agent memory experience replay inference budget lifelong learning cost-accuracy tradeoff
LIMBO treats replayed experience as a controllable inference-time resource and jointly optimizes memory strategy and inference budget for each incoming task, learning the allocation online in a single pass without modifying the underlying agent. Across three LLM backbones on LifelongAgentBench it achieves better cost-accuracy tradeoffs than memory-augmented baselines, nearly matching the strongest at up to about 83% lower inference cost (53% on average).

arxiv:2609.14066 arXiv ✓
GraMRAG: Orchestrating Multi-Agent Multi-Step Reasoning via Graph Memory with Reinforcement Learning
GraMRAG：通过图记忆与强化学习编排多智能体多步推理
graph memory multi-agent RAG multimodal reasoning reinforcement learning credit assignment
GraMRAG is a graph-memory-guided multi-agent RAG framework that formalizes agent reasoning as a dynamic directed acyclic graph, explicitly modeling action-observation dependencies to reduce state blindness and redundant retrieval. It combines a vision-text bridged ReAct-style toolchain with Topology-Aware Policy Optimization for critical-path identification and node pruning, reporting state-of-the-art performance on long-horizon multimodal reasoning benchmarks.

ClinAgent: A ReAct-Based Agent for Conversational Access to Clinical Trial Information
ClinAgent：基于 ReAct 的临床试验信息对话式智能体
agentic RAG ReAct tool use clinical knowledge expert evaluation
ClinAgent is a conversational agentic RAG system that lets clinicians and researchers query clinical trial information in natural language across multi-turn interactions, using a ReAct LLM agent that selects among ClinicalTrials.gov search, PubMed and a Python analyzer over a locally cached trial dataset. In a three-phase evaluation comparing Gemini 3.0 Flash with DeepSeek V3.2 thinking and non-thinking variants, DeepSeek thinking excelled in planning quality while Gemini achieved the highest overall performance and expert ratings.

arxiv:2609.14100 arXiv ✓
RA-CoA: Training-free Fashion Image Captioning via Retrieval-Augmented Chain-of-Attributes
RA-CoA：通过检索增强属性链实现免训练时尚图像描述
retrieval-augmented generation product knowledge base attribute reasoning vision-language model
RA-CoA is a training-free framework that retrieves relevant attribute sets from a product knowledge base and then performs attribute-level reasoning with a frozen vision-language model to generate fashion captions. Across diverse VLM families and prompting paradigms, it reports an average 26.3% METEOR gain over zero-shot captioning.

arxiv:2609.13856 arXiv ✓
ShopEase: A Generative AI-Based Multi-Agent Framework for Intelligent Enterprise Customer Support Using Hybrid Retrieval-Augmented Generation
ShopEase：基于混合检索增强生成的企业智能客服多智能体框架
hybrid retrieval dense retrieval multi-agent system customer support retrieval evaluation
ShopEase is a multi-agent customer-support framework combining intent, CRM, memory, hybrid RAG, escalation and supervisor components, with LLaMA 3.2 served locally through Ollama. On 2,632 held-out customer queries, FAISS-only dense retrieval reached 85.37% accuracy versus 55.74% for BM25-only, and cross-encoder reranking did not improve accuracy while adding latency.
