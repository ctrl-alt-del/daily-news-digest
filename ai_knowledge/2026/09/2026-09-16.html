Characterizing Web Search by Conversational LLM Agents: From Search Decisions and Strategies to Results and Responses
对话式 LLM 智能体的网络搜索特征：从搜索决策、策略到结果与响应
agentic web search query formulation source attribution conversational agents response grounding
The study examines web search across ChatGPT, Claude, Grok and DeepSeek using real user interactions and controlled API experiments, covering when agents search, how they formulate queries, which domains results come from and how responses are grounded. It finds search decisions vary by platform and model, more frequent search does not necessarily improve quality, and some claims rely on uncited results.

arxiv:2609.19491 arXiv ✓
Efficiently Linking Unstructured Data for Multi-step Reasoning
为非结构化数据高效建立关联以支持多步推理
multi-vector search semantic join evidence retrieval multi-step reasoning query engine
DASE is a query engine that ranks candidate evidence tuples for multi-step reasoning over structured predicates, multiple vectors and relational links, using a sparse materialized embedding-similarity join index for rare near-neighbor pairs. On scientific-discovery workloads it retrieves evidence 6x to 46x faster than RDBMS, rerank and vector-database baselines at comparable recall, and on SemBench E-Commerce it raises BigQuery answer quality from 0.67 to 0.80 while cutting cost from $2.42 to $0.54.

ScienceIDE: Turning World's Scientific Codebase into Agent Learnable Environments
ScienceIDE：将全球科学代码库转化为智能体可学习环境
scientific code agent learning environments supervised fine-tuning reinforcement learning knowledge transfer
ScienceIDE converts scientific code repositories into executable environments for agent task generation, execution and verification, guided by expert-defined scientific cases and acceptance criteria. Using verified interaction trajectories, the authors train PhAI-IDE models at 72B, 9B and 4B parameters that improve held-out scientific-code repair and show gains on selected general code, reasoning and knowledge benchmarks.

BI-Agent 与 BI-Bench：迈向端到端商业智能自动化
business intelligence tool-augmented reasoning task decomposition benchmark post-training
BI-Bench harvests real business-intelligence questions and ground-truth answers from public dashboards, and finds frontier LLMs score below 50% on end-to-end BI. 双过程语言智能体的认知扩展：交互环境中的记忆与自我反思
episodic memory self-reflection dual-process agent execution-time control
