Subagents vs Agent Skills: Executing Reusable Knowledge for Long-Horizon Agentic Tasks
子智能体与智能体技能：为长时程智能体任务执行可复用知识
agent skills subagent execution context window long-horizon tasks reusable knowledge
The paper compares executing reusable skill packages by loading their instructions into an agent's context against invoking them as subagents with fresh context windows. It reports that subagent execution works better when skills expose clear input-output contracts and encode procedural knowledge, at the cost of extra coordination tokens.

arxiv:2609.07821 arXiv ✓
A*-Thought-V2: Efficient Latent Reasoning via Geometric Dynamics of LLM
A*-Thought-V2：基于 LLM 几何动态的高效潜在推理
latent reasoning chain-of-thought compression hidden-state trajectory accuracy per computation
A*-Thought-V2 treats chain-of-thought as a hidden-state trajectory in a 3D PCA space, keeping aligned steps as explicit text and compressing deviating steps into latent tokens. On Qwen3.5-9B and Qwen3.6-27B across six benchmarks it improves average accuracy by up to 2.6% while cutting response length by up to half.
→ arxiv.org
arxiv:2609.07712 arXiv ✓
APPSim-Bench: Bridging Real-world Apps and Reproducible Evaluation for Mobile GUI Agents
APPSim-Bench：连接真实应用与可复现评估的移动 GUI 智能体基准
GUI agents reproducible evaluation mobile automation task completion
The benchmark uses controllable simulated apps that preserve task-relevant interaction logic to evaluate mobile GUI agents reproducibly, covering 557 tasks across 17 Chinese and English apps. Across 19 agents, the best completes only 50.27% of tasks and 28.55% of tasks are solved by no agent.

arxiv:2609.07937 arXiv ✓
TDDN: Text-aligned Diffused DINO Network for Puzzle Understanding
TDDN：面向拼图理解的对齐扩散 DINO 网络
image-text retrieval visual representations dense prediction perception encoder
TDDN fuses DINOv3 and CleanDIFT features into a perception encoder aligned with RoBERTa-L, using frozen backbones and about 590K alignment pairs. It surpasses CLIP ViT-L/14 on image-text retrieval and more than triples CLIP's dense-prediction accuracy on ADE20K and COCO-Stuff.

BanglaMemeX: Advancing Cultural Metaphoric Image Interpretation in Bangla with a Multimodal Explainable Dataset
BanglaMemeX：推进孟加拉语文化隐喻图像理解的多模态可解释数据集
cultural knowledge multimodal benchmark metaphor understanding low-resource languages
BanglaMemeX is a benchmark of 3,000 Bangla memes annotated for humor, sarcasm, offensiveness, motivational intent and sentiment, with human-written explanations of textual and visual metaphors. The authors find that current VLMs struggle with implicit cultural cues despite reasonable surface-level accuracy.

Better Call CineCrew: Consistent Ultra-Long Narrative-to-Film Generation
Better Call CineCrew：一致的超长叙事到电影生成
multi-agent orchestration structured specification FilmDSL long-horizon generation
CineCrew adds a structured multi-agent orchestration layer between screenplays and off-the-shelf video generators, centered on FilmDSL, a domain-specific language for shot, camera, asset and continuity constraints. A generation agent builds asset packs and storyboard keyframes while a critic agent produces structured QA signals for targeted refinement without retraining the base model.
