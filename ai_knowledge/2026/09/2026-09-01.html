arxiv:2609.01556 arXiv ✓
Retrieved but not ranked: surface-form bias in structural retrieval, from mathematics to agent trajectories
检索到了却没排对：从数学到智能体轨迹的结构化检索中的表层形式偏差
surface-form bias embedding retrieval agent trajectories structural retrieval retrieval benchmark
The authors evaluate embedding retrieval when surface form and meaning are deliberately pulled apart, in competition mathematics (500 queries, 117,088 items) and embodied-agent trajectories. Strict Hit@1 at the heaviest disguise tier is 0.0% for both production embedders in mathematics, and on trajectories the same models land at or near chance, suggesting retrieval anchors on literal tokens rather than task structure.

arxiv:2609.01567 arXiv ✓
Selective Agent Guidance via Entropy: Learning Autonomous Policies from Imperfect VLM Teachers
通过熵进行选择性智能体引导：从不完美 VLM 教师学习自主策略
VLM teacher guidance distillation autonomous policy uncertainty gating sparse-reward tasks
SAGE queries a vision-language model teacher only when the learner is uncertain, executes the suggested action during training and distills the guidance into a lightweight RL policy, weighting advice by environment-derived advantages. Across sparse-reward visual reasoning and navigation tasks the learned policy acts without VLM guidance at evaluation time and improves over unguided RL in several environments.

arxiv:2609.01931 arXiv ✓
Agent Flight Recorder: Tamper-Evident Audit Trails with On-Chain Anchoring for Long-Horizon Tool-Using Agents
智能体飞行记录仪：面向长时工具调用智能体的防篡改审计轨迹与链上锚定
audit trails tamper evidence long-horizon agents provenance
The Agent Flight Recorder captures each agent action as a structured, canonically serialized event across eight semantic fields, using hash chaining and Merkle batching for tamper evidence. Periodic on-chain anchoring of epoch roots lets outside verifiers check records without a trusted intermediary, adding about 48 microseconds and 512 bytes per event.

arxiv:2609.01865 arXiv ✓
ExecRetrieval: Measuring the Functional-Correctness Gap in Code-Embedding Retrieval
ExecRetrieval：衡量代码嵌入检索中的功能正确性差距
code retrieval code embeddings functional correctness counterfactual benchmark
ExecRetrieval is a benchmark of 939 Python tasks, each paired with an execution-verified canonical implementation and up to four execution-verified buggy distractors made by a single targeted edit. The top hosted system reaches exec@10 of 1.00 but only exec@1 of 0.331, and rank-1 misses are paired buggy variants 91.5-99.4% of the time across the four leading systems.
→ arxiv.org
arxiv:2609.01564 arXiv ✓
From Confusion to Clarity: Confusion-Aware Retrieval and Knowledge Injection for Text Classification
从困惑到清晰：面向文本分类的困惑感知检索与知识注入
label retrieval knowledge injection text classification rule generation
The framework identifies which label pairs a model struggles to distinguish, expands the retrieved candidate set to include confusable labels and generates targeted rules to separate them, without fine-tuning. On WOS, Flipkart and LEDGAR it improves Macro F1 by up to 10.0 points over retrieval baselines, and the rules transfer to 2B-20B models with gains up to 11.5 points.
→ arxiv.org
arxiv:2609.01913 arXiv ✓
MERGED: Multimodal Entity Resolution via Generated Expert Reasoning Distillation
MERGED：通过生成式专家推理蒸馏实现多模态实体解析
entity resolution reasoning distillation vision-language models preference optimization
MERGED distills structured reasoning, not just labels, from multiple large vision-language teachers into a compact 7B student for product entity resolution, using teacher agreement for supervised fine-tuning and meta-judge-resolved disagreements for DPO. On a multilingual e-commerce dataset the student improves PR-AUC by 13.79% over the same backbone trained on human labels, surpasses a Qwen2.5-32B-VL baseline by 6.32% at 6x lower cost, and adapts to a new relationship definition with 10K samples.
→ arxiv.org
arxiv:2610.00025 arXiv ✓
Measuring the Microtask Eligibility Gap: When Is an Off-the-Shelf SLM Enough for an Agent Harness?
衡量微任务合格性差距：现成小模型何时足以支撑智能体执行框架？
small language models agent harness memory writing tool selection eligibility benchmark
The authors build a benchmark of four agent-harness microtasks - including writing memory, selecting tools and ranking past turns - with pre-specified, confidence-aware eligibility thresholds. None of 16 Qwen3 configurations (0.6B-8B) passes, and 4-bit quantization moves no configuration into eligibility, so the gap tracks model size more than precision.
