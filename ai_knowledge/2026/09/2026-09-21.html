From Decorative to Load-Bearing: Task Difficulty Shapes the Causal Role of Chain-of-Thought
从装饰到承重：任务难度塑造思维链的因果作用
chain-of-thought causal testing reasoning faithfulness error propagation
The paper introduces continuation-based causal testing, which perturbs one reasoning step, truncates the chain and forces the model to continue, to measure how load-bearing chain-of-thought is for the final answer. Across three models and three benchmarks it finds CoT load-bearingness tracks task-relative difficulty, with error propagation rising 16x from GSM8K to BBH multistep arithmetic and 98.8% of explained deviance attributed to task difficulty.

arxiv:2609.29649 arXiv ✓
OBLIQ-IR: Training a Dense Retriever for Oblique Queries
OBLIQ-IR：为隐晦查询训练稠密检索器
dense retrieval oblique queries knowledge distillation open checkpoints
OBLIQ-IR is a single-vector dense retriever trained with per-mechanism synthetic queries and kNN-graph distillation from a frozen authorship encoder to handle oblique queries whose relevance has little surface expression. A 3B retriever fine-tune reaches NDCG@10 of 0.211 on Writing-Style, 0.171 on Math, 0.177 on Twitter and 0.281 on Congress, improving over the GPT-5.2 Multi-Hop Agent on every reported task, with code and checkpoints released.

DolphinBench: Mapping the Pareto Frontier of Agent Memory
DolphinBench：绘制智能体记忆的帕累托前沿
agent memory memory benchmark long-horizon tasks cost and latency
DolphinBench evaluates memory through an agent's task completion rather than conversational question answering, with three knowledge-work personas of roughly 500k tokens each and 200 tasks per persona verified to succeed with the relevant history and fail without it. It requires every evaluation to report total cost and latency alongside accuracy.

arxiv:2609.25286 arXiv ✓
Learned Enterprise Data Comprehension: Compression and Routing for Data Agents
学习式企业数据理解：面向数据智能体的压缩与路由
enterprise data data agents evidential routing benchmark
The paper introduces latent equivalence learning, which separates persistent task-relevant identities from dataset-relative realizations and uses a learned query-prototype system to route evidence for data agents. On the Data Agent Benchmark it reports 94.67% dataset-macro stratified Pass@1 over five trials, versus 55.51% for the Claude Opus 4.6 reference agent, ranking first among 40 leaderboard entries at submission.
→ arxiv.org
arxiv:2609.24972 arXiv ✓
RRSI: Regularized Recursive Self-Improvement of Agent Harnesses
RRSI：智能体框架的规范化递归自我改进
agent harness recursive self-improvement regularization out-of-distribution
RRSI adds regularization to automated harness self-improvement, using a temporally annealed proposal budget, exploration of unseen trajectories, a critic that screens benchmark-specific proposals and a pruner for changes that are too small, expensive or no longer useful. Across eight benchmarks it gains up to 6.0 points in-distribution and up to 4.3 points on five out-of-distribution benchmarks, with a harness that uses 30% fewer policy tokens.
→ arxiv.org

Trains but Doesn't Learn: A Post-Training Delivery Benchmark for LLM Agents as Forward-Deployed Engineers
训练却不学习：面向作为前置部署工程师的 LLM 智能体的后训练交付基准
post-training agent evaluation forward-deployed engineer delivery reliability
The paper seats LLM agents in the forward-deployed-engineer role on a governed delivery plane where an oracle scores ten post-training stages from platform-recorded facts, and identifies the silent failure of runs that train but do not learn. It runs four frontier agents end to end on metered L40S, A100 and H200 GPUs across 8B to 70B open bases and compares each against a human FDE arm under the same oracle.

ShowTellArena: Evaluating Business Workflow Understanding from Demonstrations
ShowTellArena：从演示中评估业务流程理解
workflow understanding demonstration learning benchmark dataset task comprehension
ShowTellArena is a benchmark protocol and public dataset for testing what an agent understood from narrated business demonstrations, with 50 workflow tasks, recordings, screenshots, narration and 502 questions across finance, hiring, procurement, inventory and logistics. Pilot analysis covers 218 selected attempts across 39 workflow cases and is described as exploratory rather than a controlled product ranking.

RAG-NAROK: Retrieval-Aware Knowledge Corpus Poisoning in RAG with Source-specific Refutation
RAG-NAROK：具备来源特定反驳的检索感知型 RAG 知识库投毒
RAG poisoning knowledge base security source refutation adversarial attack
RAG-NAROK is an adaptive knowledge-base poisoning framework that extracts the legitimate source identities retrieved for a query, then generates Anchor-Specific Refutation documents that name and devalue those sources while exploiting recency and authority biases. It reports significantly outperforming static poisoning baselines across diverse domains.
