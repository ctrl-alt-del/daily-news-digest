ZGCM-1: A Fully Open and Extremely Efficient Foundation Model for Math and Agentic Search
ZGCM-1：面向数学与智能体搜索的全开放高效基础模型
open foundation model long context agentic search data recipes model evaluation
ZGCM-1 is a fully open 7B dense foundation model trained from scratch with interleaved gated sliding-window and full attention, an FP8 Muon optimizer, progressive 16K-64K-256K context scaling and agentic co-training. The authors report performance competitive with much larger models such as Qwen3-235B-A22B and GLM-5.1 on mathematical reasoning and agentic search suites, a roughly 4.2x efficiency improvement in 16K pre-training time-to-loss, and open release of weights from all training stages, intermediate checkpoints, training code, per-stage data and recipes, and W&B logs.

Anchoring Clinical Events in Time: UID-Preserving Multimodal Reconstruction and Source-Grounded Adjudication
将临床事件锚定在时间中：保留 UID 的多模态重建与来源可追溯裁定
clinical timeline provenance multimodal grounding LLM judge
The paper presents a UID-preserving framework that links each narrative clinical event to its source span and retains that identity through text-only estimation, structured-evidence retrieval, timestamped source-row grounding and joint revision. Across six open-weight models and 40 mixed-critical-care summaries, multimodal GLM 5.2 revision improved temporal agreement without reducing event recovery and performed competitively with clinician annotations, while the UID and judge pipeline demonstrated 43% increased event recovery.

arxiv:2609.13602 arXiv ✓
$τ$-Elicitation: Benchmarking multi-turn entity extraction in voice agents
τ-Elicitation：语音智能体多轮实体抽取基准
entity extraction voice agents multi-turn interaction benchmark
τ-Elicitation is a 200-task voice benchmark spanning 10 entity types, controlled difficulty, caller realisms and three environments, where a matched text agent passes all tasks but four voice configurations achieve robust exact success from 0.14 to 0.41. A scaffold that prescribes spelling, read-back, correction and confirmation raises robust Pass^3 by 14-31 points at a cost of 21-28 seconds per call.

arxiv:2609.13543 arXiv ✓
Asclepius: An Adaptive Harness for Long-Horizon Clinical Agents
Asclepius：面向长时程临床智能体的自适应脚手架
long-horizon agents self-evolving harness skills library clinical evaluation
Using a clinical environment simulator in which an agent manages an entire emergency-department shift, the authors identify instruction-adherence drift, treatment incompleteness and a severity-equity gap as coupled long-horizon failure modes. Asclepius, an adaptive scaffolding with a self-evolving harness, an externalized clinical skills library and three isolated subagents, improves critical-action correctness by 22% on held-out batches and up to 25% on the full ten-batch set while preserving diagnostic accuracy.

arxiv:2609.13548 arXiv ✓
AutoTailor: Automatic, User-Aligned Capability Selection and Adaptation for Web Agents
AutoTailor：面向 Web 智能体的自动、用户对齐能力选择与适配
MCP tool selection capability curation web agents benchmark
AutoTailor is a meta-agentic framework that converts web trajectories into parameterized MCP browser-automation APIs, filters them for granularity, redundancy and usage likelihood, and dynamically reselects capabilities as task outcomes are observed. On 106 WebArena Postmill tasks, offline filtering cuts 1,283 unrefined APIs to 87 and dynamic reselection yields a 33-API set that reaches 90.6% correctness with ReAct fallback versus 87.5% for ReAct alone, while reducing request-token cost by 57.8% and latency by 29.4%.

arxiv:2609.13582 arXiv ✓
Same Patient, Different Order: Action-Level Reliability of Clinical LLM Agents Under Repeated Runs
同一患者，不同医嘱：重复运行下临床 LLM 智能体的动作级可靠性
agent reliability clinical agents reproducibility action-level evaluation
The authors introduce a same-input rerun protocol that replays a task with every input held fixed and compares the resulting orders rather than the score, applying it to 1,000 MedAgentBench runs across 50 tasks with two quantized open-weight models below ten billion parameters at two temperatures. They find action-level divergence across identical runs that often passes unrecorded by the benchmark score, arguing for repeated-run evaluation and action-level stability reporting.
