The Immutable Past: Formalizing State Mutability and Conflict Resolution in Mutable RAG
不可变的过去：形式化可变 RAG 中的状态可变性与冲突消解
mutable RAG semantic shadowing conflict resolution contradiction detection retrieval evaluation
The paper formalizes State Mutability in mutable RAG memory for long-horizon agents, identifying Semantic Shadowing, in which conflicting historical observations statistically dominate recent updates, and proves that standard dense retrieval suffers Asymptotic Recall Decay and a Majority Vote Trap. It introduces GC-Mem, an inference-time consistency protocol that pairs a temporal dominance operator with contradiction detection and recovers over 90% conflict-resolution accuracy on a benchmark of 137,760 memory chunks.

TriCalRAG: A Three-Strategy, Retrieval-Augmented Benchmark for On-Premise LLM-Based Root Cause Analysis in AIOps
TriCalRAG：面向 AIOps 本地化 LLM 根因分析的三策略检索增强基准
retrieval-augmented generation root cause analysis AIOps prompt calibration benchmark
TriCalRAG is a reproducible benchmark for on-premise log-anomaly detection and root-cause analysis across BGL, HDFS, Thunderbird and OpenStack, comparing Qwen2.5-14B and Mistral-Small-22B under zero-shot, few-shot and RAG prompting; Mistral-Small attains higher macro-averaged F1 (0.644 versus 0.560) while Qwen provides roughly twice the throughput. Supplementary runs with 4-bit Llama-3.1-70B and Claude Haiku 4.5 found RAG improved F1 on all four datasets for both models, with Claude's aggregate F1 rising from 0.566 to 0.695 as estimated API cost rose from $0.94 to $2.15 per 1,000 incidents.

ANASSA: An Agentic AI Orchestration Framework for Spatial Intelligence
ANASSA：面向空间智能的智能体 AI 编排框架
agent orchestration spatial reasoning multi-agent system provenance uncertainty handling
ANASSA is an architecture-level agentic orchestration framework for geospatial workflows that integrates structured spatial reasoning, multi-agent orchestration, execution feedback, authoritative spatial validation, provenance, uncertainty handling and human decision authority. It specifies eleven components across four layers and a six-step Geospatial AI Cognitive Loop, and notes that empirical evaluation is reserved for implementation and deployment studies.

Another Blueprint In The Wall: How to Ask Frontier AI Like a Kid?
墙上的另一张蓝图：如何像孩子一样向前沿 AI 提问？
prompt framing architecture convergence persistent latent state model behavior
The paper reports ten sessions per model type for six frontier models from OpenAI, Anthropic, xAI and Google DeepMind, using a three-stage prompt sequence, and finds that a school-audience framing led responses to converge on a shared architecture motif built around persistent latent state, adaptive computation, memory, specialist routing, verification and delayed decoding. Control runs without the school framing produced substantially more heterogeneous answers, and the author uses the term epistemic jailbreak for the loss of technical provenance as requested specificity increases.

AlgoRAG: Retrieval-Augmented Generation for Theoretical Computer Science Education -- A Comprehensive Evaluation Framework for Algorithm Analysis and Complexity Theory
AlgoRAG：面向理论计算机科学教育的检索增强生成——算法分析与复杂性理论的综合评估框架
domain RAG knowledge base curation notation-aware retrieval pedagogical evaluation
AlgoRAG couples an LLM with a curated theoretical-computer-science knowledge base of textbooks, 847 lecture slides, 312 practice problems, 156 proof templates and 89 complexity worksheets, adding mathematical entity recognition, notation-aware retrieval and pedagogical re-ranking. On 179 exam-style questions it reports a 100% success rate with a 38-second mean response time and a pedagogical quality score of 0.7620, though the authors note BLEU-4 is zero because n-gram matching fits mathematical proofs poorly.

Building Legal Reward Models for Grounding and Abstention
构建面向证据接地与弃权的法律奖励模型
reward models grounded generation abstention preference data legal knowledge
The paper converts existing legal QA datasets into contextual preference data to build LegalRewardBench, a benchmark for grounded legal generation under noisy and insufficient retrieval. Contextual DPO with length-balanced legal and general preference data improves grounded evaluation by up to 25.6 points over baseline, and models refined primarily on Victorian criminal-law data transfer to US legal benchmarks with a 16.2-point gain on Housing Statute QA.

El Agente Potente: High-Throughput Agentic Atomistic Simulations
El Agente Potente：高通量智能体原子尺度模拟
typed execution graphs LLM planning scientific agents reproducibility
El Agente Potente is an agentic system for machine-learning interatomic potential simulations that combines typed execution graphs, in which LLMs are restricted to planning and routing while deterministic Python components perform computation and validation, with a complementary coding mode for customized workflows. It is demonstrated on computational materials discovery, molecular energy-landscape exploration and adsorption and catalytic reaction workflows, alongside benchmarks of reproducibility and LLM token cost.

Enemray: Toward Capable Language Models for Hassaniya
Enemray：迈向具备能力的哈桑尼亚语语言模型
continual pretraining low-resource language stability-plasticity multilingual evaluation
Enemray is a Hassaniya-centric language model trained with a stability-plasticity objective that separates language acquisition from behavioral specialization through layer-selective continual pretraining and supervised post-training with policy-generated replay. It reports the strongest English-to-Hassaniya translation among the compared open and proprietary models and the highest overall score on Mauritanian translation error detection, while retaining most general capabilities of its instruction-tuned base on mathematical reasoning, knowledge, code generation and function calling.
