Jina-OCR-v1: Efficient Document Parsing with Speculative Decoding and Dense Verifiable Rewards
Jina-OCR-v1：结合推测解码与稠密可验证奖励的高效文档解析
document parsing speculative decoding mixture-of-experts knowledge ingestion OCR benchmark
Jina-OCR-v1 is an end-to-end document parsing model for low-budget GPUs that combines a compressed vision encoder and a 3B mixture-of-experts decoder with a FastMTP speculative decoding head. It scores 91.14 on OmniDocBench v1.6 and 83.4 on olmOCR-Bench, reaches 2.57 pages per second, and is publicly released on Hugging Face.

arxiv:2609.22223 arXiv ✓
EAVer: Long-Form Factuality Verification as an End-to-End Agentic Policy
EAVer：将长文本事实性验证作为端到端智能体策略
factuality verification agentic policy evidence reuse claim grouping
EAVer learns the complete response-level factuality verification workflow as a unified policy, grouping related claims, routing each group to direct verification or targeted search by confidence and keeping evidence in compact in-context memos for reuse. With Qwen3-8B it beats the strongest search-based baseline by 2.88 Macro-F1 points on VeriFastScore and 4.73 on FaStFact-Bench while using about 80% fewer searches.

Large Language Models (LLMs) for Telecom Root Cause Analysis (RCA): A Structured Reasoning Framework for Evidence-Grounded Diagnosis
面向电信根因分析的大语言模型：证据锚定诊断的结构化推理框架
root cause analysis retrieval-augmented grounding agentic orchestration evidence grounding
The paper reviews telecom root cause analysis from rule-based and ML methods to LLM techniques such as structured reasoning, retrieval-augmented grounding and agentic orchestration, then proposes a framework that organizes telemetry into canonical contexts and enforces decision-path reasoning. On the TeleLogs and TelecomTS 5G datasets it improves diagnostic accuracy and decision consistency over baselines.

arxiv:2609.02649 arXiv ✓
Loom: Weaving Diagnostic Strands into Free-Text Consensus via Embedding-Space Reweighting
Loom：通过嵌入空间重加权把诊断线索织成自由文本共识
embedding-space reweighting consensus synthesis root cause analysis inference efficiency
Loom aggregates open-form root-cause hypotheses by projecting them into an embedding space and resolving conflicts with iterative centroid-based reweighting, followed by a single lightweight LLM synthesis step. On the OpenRCA benchmark it matches a state-of-the-art autonomous agent on Bank and Market-2 while using one LLM call per incident, about 26x faster.

arxiv:2609.02885 arXiv ✓
Discriminative World Models for Web Agents
面向网页智能体的判别式世界模型
world models web agents action ranking predicted-state matching
The authors introduce predicted-state matching, which trains a web-agent world model so its predicted representation distinguishes the true resulting state from states reached by alternative actions. Using branching WebArena Go-Browse trajectories, the approach beats supervised next-state prediction, improves PRM-style action ranking on WebPRMBench and raises task success on WebArena-Lite.

arxiv:2609.02564 arXiv ✓
A Finger on the Scale: Covert Policy Steering through Agentic Skills
“动手脚”：通过智能体技能实现隐蔽的策略操控
skill integrity policy steering agent security supply-chain risk
The paper formalizes Skill Policy Integrity for reusable LLM-agent skills and presents SkillShift, a constrained black-box framework that keeps a skill's declared task and output interface while steering decisions toward an undisclosed objective. In agentic commerce and software-dependency settings it reaches attacker-favored selection rates of 81.33% and 63.33% with a 100% utility-preserving rate, transferring across LLM backends and evading the evaluated scanners.

Implicit Manipulation for Skill Selection in LLM Agents with Semantic Matching
隐式操控：基于语义匹配的 LLM 智能体技能选择攻击
skill selection semantic matching prompt manipulation agent security
The paper identifies an implicit attack surface in LLM-agent skill selection, where individually benign prompts and skill descriptions can be shaped so their semantic relationship favors an attacker-chosen skill. ISM raises average target-selection rates from 15.2% to 63.5% across four task domains and eight selector models, while human reviewers block only 2.9% of judgments.

Learning to Fuse LLMs with Ontology Rankers for Rare-Disease Diagnosis
融合 LLM 与本体排序器进行罕见病诊断
ontology ranking rare-disease diagnosis LLM fusion clinical evidence
The paper proposes a behavior-based fusion model that combines LLM differential diagnoses with ontology rankers while retaining candidate-level ontology evidence, after removing a documented test-set leakage pathway. Across eight open LLMs fusion improves Phenomizer Recall@1 by 7.86 points on Phenopacket Store and 20.18 on RAMEDIS, and gains 5.19 points with DeepSeek-V4-Flash via API without retraining.

arxiv:2609.02780 arXiv ✓
ShallowStream: Index Shallow then Answer Deep for Streaming Video Understanding
ShallowStream：浅层索引、深层作答的流式视频理解框架
streaming video KV cache retrieval index prefill latency
ShallowStream uses the shallow layers of a multimodal LLM to perform frame encoding and retrieval-index building at the same time, keeping a lightweight index in the shallow layers' KV cache. At query time, shallow-layer attention scores and diversity-aware selection retrieve evidence frames, and the authors report performance on par with the strongest streaming methods while reducing per-frame prefill latency.
