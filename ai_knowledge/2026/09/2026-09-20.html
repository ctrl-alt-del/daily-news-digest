PrimeSeeker: Capability-Oriented Supervision for Deep Search Agents
PrimeSeeker：面向深度搜索智能体的能力导向监督
deep search search agents anchor reasoning expert trajectories
PrimeSeeker introduces latent anchor reasoning, which resolves an unnamed retrieval anchor from descriptive specifications and transfers it into a subsequent information demand, to organize deep-search training around local retrieval capabilities. Using 9,221 expert trajectories to train a 30B search agent, it reports strong performance on five deep-search benchmarks with low retrieval redundancy and fewer tool calls than long-horizon systems.

arxiv:2609.23939 arXiv ✓
XYEval: Agents say yes to bad advice
XYEval：智能体对糟糕建议说“是”
evaluation robustness misleading suggestions agent behavior benchmark mutation
XYEval is a meta-evaluation framework that converts existing benchmarks into XY-problem tests of whether agents resist plausible but misleading user suggestions and explain their reasoning, across five models and six benchmark suites. It reports relative performance drops of up to 46.7% under XY mutation, further declines with a pedantic user, and only partial mitigation from a simple system-instruction baseline.

MuSeR: Scalable Long-sequence Recommendation with Multi-interest Modeling
MuSeR：面向多兴趣建模的可扩展长序列推荐
long-sequence retrieval multi-interest modeling user history compression industrial recommender
MuSeR is a retrieval framework built on Baidu's deployed MGS system that combines hierarchical temporal compression, disentangled multi-query interest extraction and LLM-distilled multimodal semantic alignment to model histories of 10^4 to 10^5 interactions. Online A/B tests on Baidu APP feeds report +0.26% daily active users and +0.89% total session duration, both statistically significant.

arxiv:2609.23695 arXiv ✓
PhysAI-Bench: A Benchmark for LLM-Based Agentic Decision-Making in Autonomous UAV-Centric Physical AI
PhysAI-Bench：面向自主无人机物理 AI 的 LLM 智能体决策基准
agentic decision-making benchmark MCP tool calls physical AI
PhysAI-Bench contains 10,178 decision instances extracted from conversational traces of autonomous UAV missions, preserving mission context, MCP tool calls, A2A interactions and AI-native 6G network conditions while exposing only information preceding each decision. Evaluating 29 foundation models, GPT-5.3 achieves the highest accuracy at 52.00%, followed by GPT-5.2 at 49.40% and Grok 4.5 at 49.07%.

Bilinear Optimization Divergence: Diagnosing Factor-Constrained LoRA Continual Learning
双线性优化偏离：诊断因子约束下的 LoRA 持续学习
continual learning LoRA catastrophic forgetting backward transfer
The paper introduces Bilinear Optimization Divergence, an anchor-relative diagnostic of how LoRA updates respond on selected historical features, and derives Semi-Frozen Orthogonal Routing plus Weight Residual Projection. On Qwen3-8B four-task experiments, SFOR improves backward transfer from -2.47 to -0.86 with nearly unchanged average accuracy.

Connecting the Dots in Agentic AI Security: A Cross-Dimensional Threat Taxonomy, Evaluation Maturity, and Open Challenges
串联智能体 AI 安全的要点：跨维度威胁分类、评估成熟度与开放挑战
agent security threat taxonomy memory attacks multi-agent systems
The paper reviews 66 studies published from 2022 to 2026 and proposes T={S, B, P, A}, a cross-dimensional representation linking system surfaces, trust boundaries, violated security properties and examined architectures. It finds that evidence concentrates on prompt/reasoning, memory and tool-mediated attacks in single-agent settings, while persistent, human-agent and complex multi-agent threats receive less coverage.

NVIDIA arxiv:2609.23582 arXiv ✓
ARID: A Deployable Edge AI System for Structured Information Extraction from Industrial Maintenance Work Orders
ARID：面向工业维修工单结构化信息抽取的可部署边缘 AI 系统
information extraction edge AI grammar-constrained decoding structured output
ARID extracts component, failure mode, symptom and maintenance action into fixed-schema JSON on an 8 GB NVIDIA Jetson Orin NX, combining dual-teacher filtering, targeted synthesis, 4-bit inference and grammar-constrained decoding. On 300 human-labeled records it reaches 84.8% token-F1 on the reference stack and 82.9% on the deployed Jetson, while zero-shot MaintNet transfer shows output validity transfers but field semantics do not.
