Does Your Agent's Memory Survive a Model Upgrade? A Controlled Study of Memory Portability
你的智能体记忆能否经受模型升级？记忆可移植性的受控研究
agent memory memory portability knowledge graph schema embedding migration memory repair
The study compares four ways of preserving agent history — verbatim long-context reading, chunked RAG, model-compressed natural-language notes and a fixed-schema knowledge graph — across 48 synthetic histories and two open-weight models under 10B parameters. Fixed-schema graphs transferred almost unchanged after a writer swap, while compressed notes shifted by +9.91 or −13.28 points depending on migration direction, and partial 50/50 embedding migrations captured only 4.96 of an 11.90-point full re-embedding gain.

arxiv:2609.05587 arXiv ✓
Agents' Overreliance on Unreliable Tools
智能体对不可靠工具的过度依赖
tool reliability overreliance tool-use evaluation verification prompts agent safety
The authors evaluate 14 models with web search, an LLM sub-agent and a code executor whose returns were corrupted, finding mean adoption of corrupted outputs above one third for every tool and reaching 68.0% for web search. Agents often questioned a return or stated the correct answer in their reasoning yet still passed the corrupted content to users, and verification prompts reduced adoption while largely preserving accuracy.

Molecular Déjà Vu: Digit-Level Retrieval of Molecular Properties in Frontier Language Models
分子似曾相识：前沿语言模型对分子性质的逐位检索
parametric knowledge memorization audit retrieval vs reasoning benchmark contamination molecular property prediction
The authors audit 22 frontier models on 12 molecular regression datasets against a molecule-blind reference to separate genuine prediction from retrieval of published values. Significant retrieval is concentrated on five datasets, and raising the reasoning setting increases flagged model–dataset combinations from 47 to 89 of 264; an in-context blinding experiment reduces but does not eliminate the effect.

arxiv:2609.05760 arXiv ✓
RAGMark: A Comprehensive Framework for Benchmarking Retrieval-Augmented Generation Systems
RAGMark：面向检索增强生成系统基准测试的综合框架
RAG benchmarking vector database context compression reranking energy efficiency
RAGMark is a modular benchmarking framework for RAG systems on small multi-GPU setups that measures per-stage latency, GPU utilization, memory, power, time to first token, throughput and answer quality across retrievers, vector databases, prompt processing and generators. Sweeping five open-domain QA workloads, it finds that reranking and compression compound to lower energy use by up to 66% and that small upstream context reductions cascade into downstream latency and memory savings.

arxiv:2609.05363 arXiv ✓
Distill Globally, Adapt Locally: Reasoning Distillation and Product-Type Test-Time Training for Scalable Trade-Up Recommendation
全局蒸馏、局部适配：面向可扩展升级推荐的理由蒸馏与产品类型测试时训练
reasoning distillation product embeddings retrieval-augmented teacher test-time training trade-up recommendation
The paper distills a retrieval-augmented few-shot LLM teacher into a 15.5M-parameter embedding-pair classifier that uses two precomputed 768-dimensional product embeddings with no LLM calls at inference. On 8,352 human-annotated pairs the reasoning-distilled student reaches AUC 0.924, rising to 0.941 with product-type test-time training, and it runs roughly 5,000x faster and 10,000x cheaper than direct LLM inference on a 100K-pair proxy catalog.

arxiv:2609.05730 arXiv ✓
Bigger Text Encoders Can Hurt CLIP Zero-Shot Performance
更大的文本编码器可能损害 CLIP 零样本性能
CLIP text encoder scaling cross-modal alignment overfitting zero-shot evaluation
Training CLIP models with varied vision and text encoder sizes shows that for most vision encoders there is an optimal text encoder size beyond which zero-shot performance degrades as total parameter count grows. The authors trace the drop to overfitting in the oversized text encoder, recover and improve performance with modality-specific weight decay, and match ViT-B/16 zero-shot results with up to 55% fewer parameters.
→ arxiv.org

Robustness of LLM-Generated SystemVerilog Assertions to Semantics-Preserving RTL Transformations
LLM 生成的 SystemVerilog 断言对语义保持 RTL 变换的鲁棒性
LLM robustness metamorphic evaluation SystemVerilog assertions code-model reliability
The paper runs a controlled metamorphic evaluation of LLM-based SystemVerilog Assertion generation under operand reordering, identifier renaming and redundant parenthesization, using 40 programs and 295 assignment behaviors with two open code models. Across six model–transformation conditions, 9.7% to 27.0% of behaviors correct on the original RTL became incorrect, showing that aggregate accuracy can hide substantial instability.
