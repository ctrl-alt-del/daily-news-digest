SPINE：衡量 LLM 在持续多轮压力下的谄媚行为

An Experimental Evaluation of Multimodal Prompt Injection Attacks on Agentic AI Frameworks
多模态提示注入攻击对智能体 AI 框架的实验评估
prompt injection multimodal security agent benchmark tool calling
MMPIBench delivers fixed prompt-injection attacks through six visual carriers and records how far each injected instruction travels from perception through planning to tool calls across 720 runs. Attacks complete in about 1% of runs but are attempted in 12.8%, with the model mattering far more than the framework; audio attacks complete in 49% of cells where the signal arrives.

From Fixed Keys to Readable Schemas: Small Language Models for Vehicle Agent Function Calls
从固定键到可读模式：面向车载智能体函数调用的小语言模型
function calling schema prompting small language models tool interfaces
The paper compares dedicated functional tokens with schema-in-prompt representations for vehicle function calling on a benchmark of 9,822 examples spanning 79 functions and four small models from 270M to 1.7B parameters. Schema-in-prompt generalizes to held-out functions and refuses out-of-scope requests more reliably, at the cost of higher inference latency.
