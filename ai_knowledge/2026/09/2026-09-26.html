The Epistemics of Agent Memory: Measuring, and Governing, the Consolidation Decision in Long-Horizon LLM Agents
智能体记忆的认识论：度量与治理长程 LLM 智能体的整合决策
agent memory memory consolidation governance ConsolidationBench
The paper outlines a four-phase research program on how long-horizon LLM agents decide what to keep, compress, abstract into reusable skills or forget, extending to the ConsolidationBench benchmark and governed consolidation with poison-resistance, reversibility and auditability. It reports a verified +22.7% task-success gain at 7x compression and finds governance quality is statistically distinct from consolidation quality (r-squared = 0.43).

arxiv:2609.35875 arXiv ✓
Beyond Symmetric Agents: Cognitive Diversity and Multi-Agent Debate in Small Language Models
超越对称智能体：小型语言模型中的认知多样性与多智能体辩论
multi-agent debate cognitive diversity self-consistency budget-matched evaluation
Across 23 models, five tasks and more than 5,500 budget-matched runs, the authors reject cognitive diversity as the driver of multi-agent debate gains on the personas, temperature and model-identity axes. Debate beats single-agent inference by 3-7 points where headroom exists but ties or loses to self-consistency sampling at 1.6x wall-clock and 3.4x token cost, with most benefit coming from the first exchange.

arxiv:2609.32862 arXiv ✓
RoboFoundry: System-as-Policy Evolution for Self-Learning Embodied Agents
RoboFoundry：自学习具身智能体的系统即策略进化
self-evolving agents skill library persistent memory embodied agents
RoboFoundry treats the supporting agent system as a unified policy, diagnosing capability gaps and converting execution traces into validated updates to a context system and a hierarchical skill system. It improves GPT-5.5 by 27.8% on EmbodiedBench, beats all baselines on RoboMemArena by at least 39.0%, and demonstrates zero-shot transfer and online evolution across real robots.

arxiv:2609.32852 arXiv ✓
ARSM: Auto-Regressive State Machine for Agentic Reasoning Compression
ARSM：用于智能体推理压缩的自回归状态机
reasoning compression agent memory state machine long-horizon agents
ARSM is a lightweight, training-free framework that compresses long agent interaction histories into Hypothesis-Action-Result micro-chains and regulates hierarchical memory through a dynamic state machine with atomic operations. On Webshop, Multi-Objective Multi-Hop QA and SWE-Bench Lite it maintains task performance while reducing token consumption.

arxiv:2609.32870 arXiv ✓
Counterfactual Self-Evolving Agents for Evidence-Grounded Reasoning
面向证据支撑推理的反事实自进化智能体
counterfactual reasoning self-evolution in-context memory evidence grounding
The framework generates counterfactual context for evidence-identifiable tasks: a trainable Proposer constructs targeted evidence edits with causal explanations, and accepted counterfactuals accumulate in memory that supplies in-context evidence to a frozen Solver. It is applied to clinical reasoning, fact verification and business reasoning, with performance tracked as counterfactual memory grows.

arxiv:2609.32895 arXiv ✓
PILAR: A Page-Grounded Unified Evidence Representation via an Entity-Linked Assertion Graph for Open-Domain QA Agents over Multimodal Document Corpora
PILAR：面向多模态文档开放域问答智能体的实体链接断言图页面级统一证据表示
multimodal RAG assertion graph evidence linking open-domain QA
PILAR represents sentence-, table- and figure-derived facts in a common assertion space as an entity-linked graph that acts as a controlled linking layer over page retrieval for multimodal open-domain QA. Across four agent frameworks and fourteen retrieval backends it achieves the best end-to-end EM/ANLS, with +1.6 EM over flat retrieval that rises to +2.9 on compositional and +5.9 on 3-hop questions.
→ arxiv.org
arxiv:2609.32917 arXiv ✓
Planner-as-Router: Joint Plan-Time Model Routing for Cost-Efficient Multi-Agent Workflows
Planner-as-Router：面向成本高效多智能体工作流的联合规划期模型路由
model routing cost efficiency multi-agent workflows enterprise benchmark
Planner-as-Router folds model-tier selection into planning, assigning each subtask a small, mid or frontier tier so workflow dependencies are visible before any specialist runs and no separate router model is needed. On the 54-task EntBench it stays on the observed cost-accuracy frontier and cuts cost 44% against all-frontier routing while giving up 2.9 accuracy points.

arxiv:2609.33017 arXiv ✓
Trust and Task Completion in the World of Consumer AI Agents
消费级 AI 智能体世界中的信任与任务完成
agent trust task completion consumer agents simulated environment
The authors build an evaluation that scores trust and task completion on the same runs in a simulated world of businesses, pairing every trap with a matched control where acting is correct. Wajo's assistant Fo completes 71% of errands and keeps the user's trust on 94% of trap runs, versus 50-64% completion and 59-75% trust for base models.
