IndustryLLM: Failure-Driven LLM Training for Industrial Procurement
IndustryLLM：面向工业采购的失败驱动 LLM 训练
industrial procurement failure-driven training domain adaptation constraint evaluation
Alibaba presents IndustryLLM, an open-weight 35B-parameter industrial model built on Qwen3.5-35B-A3B-Base and trained with a failure-driven continued-pretraining and supervised fine-tuning recipe on a roughly 100B-token corpus. Offline procurement-query structuring improves by 2.97 exact-match points, while production A/B tests report 4.25% higher GMV, 8.3% more satisfied inquiries and latency falling from 6-7 s to 1.5 s.

COUNTERMEM：面向语言智能体的世界模型验证反事实记忆
counterfactual memory world models memory-use policy benchmark evaluation
COUNTERMEM is a reinforcement-learning framework that builds verified counterfactual memory by testing local alternative actions against executable world models such as tests, proof checkers and solvers after a failure. With gpt-oss-120b it improves ReAct and Reflexion on all 12 benchmarks across six domains, averaging a 12.6-point gain while cutting task-run tokens by 7.7-42.0% in a four-domain comparison.

EngramRAG: Dynamic Usage-Weighted Topology and Synaptic Consolidation for Multi-Hop Agentic Memory
EngramRAG：面向多跳智能体记忆的动态使用加权拓扑与突触巩固
agentic memory multi-hop retrieval graph topology memory consolidation
EngramRAG couples a low-latency waking retrieval reflex with asynchronous dreaming-state consolidation, adding usage-modulated PageRank, topology-aware decay, a SUPERSEDES DAG filter and hybrid dense, BM25 and graph retrieval. On all 1,982 LoCoMo QA pairs it reports +38.9% relative Recall@5 and +43.1% MRR over dense-vector RAG, and cuts split-brain hallucinations from 70.0% to 0.0% in mutation tests.

Metro-WM: Long-Horizon Latent Planning with Realisable Sub-Goals
Metro-WM：以可实现的子目标进行长程潜空间规划
latent planning sub-goal retrieval graph search model-predictive control
Metro-WM replaces unconstrained latent sub-goal prediction with retrieval of genuine observed frames from a graph built from offline expert demonstrations, so a hierarchical planner only issues physically realisable sub-goals. It reports long-horizon success gains of up to 37.33 points over the strongest hierarchical baseline while being up to 10.9x faster and requiring 13-56x less offline compute.

EmailBench: A Benchmark for Evaluating LLM Agents on Enterprise Email and Productivity Tasks
EmailBench：评估 LLM 智能体企业邮件与生产力任务的基准
agent benchmark enterprise email tool use task completion
EmailBench contains 206 email and productivity scenarios across 16 task categories, pairing a typed email API with a deterministic synthetic Enron-inspired corpus and a hybrid protocol of 258 static assertions and 211 LLM rubrics. The best of eight LM configurations passes only 33.5% of scenarios even though 99.7% of its tool calls complete without an observed API failure.

GameBoyWorlds：具身电子游戏自我改进的测试平台
agent self-improvement embodied agents benchmark testbed multimodal memory
GameBoyWorlds is a testbed for agentic self-improvement in video games, with an Execution split of 500 tasks across five game series and a Playthrough split requiring end-to-end completion of two fan-made Pokémon games. Out-of-the-box frontier models complete fewer than 50% of execution tasks, and a pipeline with multimodal memory and hierarchical subgoals fails to reach the first major milestone in either playthrough.

arxiv:2609.32081 arXiv ✓
Toward Interactive Understanding of Code APIs
迈向代码 API 的交互式理解
code understanding black-box probing tool understanding benchmark
The paper introduces PAU, a benchmark that gives models only black-box API-level access to Python snippets so they must probe the code and infer its behaviour, framing this as unsupervised tool understanding. Claude-4-Opus fails to understand over 45% of the test set, and Asymmetric Actor Critic post-training lets an AAC-tuned Qwen3-8B match GPT-5-mini.
