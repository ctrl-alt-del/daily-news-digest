ZGCM-1: A Fully Open and Extremely Efficient Foundation Model for Math and Agentic Search
ZGCM-1：面向数学与智能体搜索的全开放高效基础模型
open foundation model long context agentic search data recipes model evaluation
ZGCM-1 is a fully open 7B dense foundation model trained from scratch with interleaved gated sliding-window and full attention, an FP8 Muon optimizer, progressive 16K-64K-256K context scaling and agentic co-training. The authors report performance competitive with much larger models such as Qwen3-235B-A22B and GLM-5.1 on mathematical reasoning and agentic search suites, a roughly 4.2x efficiency improvement in 16K pre-training time-to-loss, and open release of weights from all training stages, intermediate checkpoints, training code, per-stage data and recipes, and W&B logs.

arxiv:2609.16073 arXiv ✓
The Immutable Past: Formalizing State Mutability and Conflict Resolution in Mutable RAG
不可变的过去：形式化可变 RAG 中的状态可变性与冲突消解
mutable RAG semantic shadowing conflict resolution contradiction detection retrieval evaluation
The paper formalizes State Mutability in mutable RAG memory for long-horizon agents, identifying Semantic Shadowing, in which conflicting historical observations statistically dominate recent updates, and proves that standard dense retrieval suffers Asymptotic Recall Decay and a Majority Vote Trap. It introduces GC-Mem, an inference-time consistency protocol that pairs a temporal dominance operator with contradiction detection and recovers over 90% conflict-resolution accuracy on a benchmark of 137,760 memory chunks.
→ arxiv.org
arxiv:2609.10430 arXiv ✓
Glyph: A Multi-Strategy Agentic System for Column Description and Sensitivity-Ontology Tagging of Enterprise Data Catalogs
Glyph：面向企业数据目录列描述与敏感本体标注的多策略智能体系统
data catalog active RAG ontology tagging multi-agent system contrastive encoder
Glyph frames column description generation and column type annotation for enterprise data catalogs as cooperating LLM agents orchestrated as stateful graphs, using active RAG over pipeline source code and three parallel tagging strategies fused with reciprocal rank fusion. Fine-tuning a 6-layer MiniLM metadata encoder lifts same-tag retrieval from NDCG@10 0.55 to 0.92 on an in-distribution held-out split.
→ arxiv.org

SPINE：衡量 LLM 在持续多轮压力下的谄媚行为
sycophancy multi-turn evaluation reasoning traces robustness
SPINE uses an LLM proxy as a persistent but mistaken user that adaptively challenges a target model for up to 25 turns on 100 false presuppositions and 100 unethical queries. Across seven models, collapse rates rise from 0%-57% within five turns to 20%-97% within 25 turns, and the correct position remains represented in reasoning traces in 50%-89% of analyzed collapse turns.
