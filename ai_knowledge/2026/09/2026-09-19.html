Euston: Training Away Mathematical Sycophancy Without Losing the Mathematics
Euston：在不牺牲数学能力的前提下训练模型摆脱数学谄媚
mathematical verification sycophancy GRPO claim verification
Euston is an 8B mathematical claim-verification model trained to resist proving corrupted theorems, using 3,026 matched true/corrupted statement pairs generated with GraphSynth and GRPO fine-tuning of DeepSeek-R1-8B. On a balanced held-out split, balanced accuracy rises from 29.50% to 63.75% while AIME 2026 accuracy falls by a non-significant 4.17 points, and the authors note confounds including the all-false composition of official evaluation sets.

arxiv:2609.23121 arXiv ✓
MM-ContextFold: Context Folding for Multimodal Agentic Retrieval
MM-ContextFold：面向多模态智能体检索的上下文折叠
context folding multimodal retrieval context management multimodal agents
MM-ContextFold is a training-free framework for multimodal agentic retrieval that keeps a persistent text-only main context and spawns ephemeral branch contexts that load images only when needed, then folds results back as concise text. Across seven benchmarks and five backbone models it improves average accuracy by 6.3 percentage points over ReAct while reducing working context length by 27.5%.

arxiv:2609.22951 arXiv ✓
AgentRouter: Heterogeneous Model Routing for Cost-Optimal Multi-Step Agentic Workflows
AgentRouter：面向成本最优多步智能体工作流的异构模型路由
step-level routing cost optimization agent workflows inference cost
AgentRouter formalizes step-level model routing for agent trajectories and trains a 12M-parameter classifier to map each step to one of four model tiers. It reports 72% cost reduction relative to frontier-only baselines while retaining 97.3% of quality, compared with 31% and 44% cost reductions for per-step RouteLLM and FrugalGPT.

ChemCLIR-Bench: Benchmarking Cross-Lingual Information Retrieval in Multilingual Chemical Patents
ChemCLIR-Bench：多语种化学专利跨语言信息检索基准
cross-lingual retrieval chemical patents embedding evaluation Recall@10
The paper builds a five-language chemical patent retrieval dataset from Google Patents and European Patent Office data and evaluates eight embedding models. It reports a substantial monolingual-versus-cross-lingual gap, with the best model's Recall@10 falling from 0.72 to 0.53, and offers the benchmark as a diagnostic framework for model selection.

Beyond Linear Context: Graph-Guided Evidence Navigation for Long-Novel Reasoning with a Local 9B Language Model
超越线性上下文：面向长篇小说推理的图引导证据导航（本地 9B 模型）
knowledge graph evidence navigation long-context reasoning local LLM
The study tests whether a frozen knowledge graph can help a fixed local qwen3.5:9b reader answer 234 multiple-choice questions over 30 detective novels, with the strongest graph route reaching 53.85% versus 46.15% for a recent-window baseline. None of the fifteen graph-baseline contrasts survives Holm correction, so the authors present the result as exploratory evidence and highlight uneven annotation coverage across graph-building pipelines.

arxiv:2609.22977 arXiv ✓
Beyond Similarity: Coverage-Aware Prompt Selection for Time Series Forecasting with LLMs
超越相似度：面向 LLM 时间序列预测的覆盖感知提示选择
prompt selection retrieval diversity prompt pool time series forecasting
CASP-LLM targets prompt selection bias in prompt-based time series forecasting, where top-K cosine similarity retrieval over a learned prompt pool favors dominant temporal patterns and overlooks rare but informative events. Its coverage-aware regularizer combines usage tracking and saturating gates without learnable parameters, matching or improving similarity-based forecasters on most dataset-horizon settings, with exceptions including Electricity and M4-Monthly.

Measured Joules, Learned Routes: Learning to Route for Energy-Efficient LLM Serving
实测焦耳，学习路由：面向节能 LLM 服务的路由学习
model routing energy efficiency LLM serving accuracy-energy tradeoff
The paper trains a language-model router to assign each query to one of a fixed pool of LLMs profiled offline for correctness, latency, power and GPU energy, using supervised fine-tuning followed by GRPO. Across seven benchmark tasks it reports that learned routing improves the accuracy-energy tradeoff and reveals a sharp accuracy-energy phase transition among routers.
