arxiv:2603.21272 arXiv ✓
The Library Theorem: How External Organization Governs Agentic Reasoning Capacity
图书馆定理：外部组织方式如何决定智能体推理能力
external memory indexing retrieval cost context window agentic reasoning parametric memory
The paper formalizes the transformer context window as an I/O page and proves that tool-augmented agents with indexed external memory achieve exponentially lower retrieval cost than sequential scanning: O(log_b N) versus Omega(N) page reads per query. On abstract content in a controlled lookup benchmark up to 5,000 items, the indexed agent used a median of one page read regardless of store size, while models given sorted pages but no index still lost by 5x.

arxiv:2603.21440 arXiv ✓
KG-Hopper: Empowering Compact Open LLMs with Knowledge Graph Reasoning via Reinforcement Learning
KG-Hopper：通过强化学习让紧凑开源 LLM 具备知识图谱推理能力
knowledge-graph reasoning reinforcement learning compact models multi-hop reasoning
KG-Hopper is a reinforcement learning framework that trains compact open LLMs to perform multi-hop knowledge-graph reasoning within a single inference round. A 7B-parameter model outperforms larger multi-step systems up to 70B on eight KG reasoning benchmarks and is competitive with GPT-3.5-Turbo and GPT-4o-mini.

arxiv:2603.21430 arXiv ✓
DomAgent: Leveraging Knowledge Graphs and Case-Based Reasoning for Domain-Specific Code Generation
DomAgent：结合知识图谱与案例推理的领域代码生成
knowledge-graph reasoning case-based reasoning domain code generation DS-1000
DomAgent is an autonomous coding agent whose DomRetriever module combines top-down knowledge-graph reasoning with bottom-up case-based reasoning to supply domain knowledge. On DS-1000 and real-world truck software tasks it helps small open-source models close much of the gap with large proprietary LLMs.

NVIDIA arxiv:2603.21383 arXiv ✓
PivotRL: High Accuracy Agentic Post-Training at Low Compute Cost
PivotRL：低算力成本的高精度智能体后训练
agentic post-training reinforcement learning compute efficiency SFT trajectories
PivotRL runs local on-policy rollouts on existing SFT trajectories and filters for high-variance intermediate turns, rewarding functionally equivalent actions rather than exact string matches. It reports +4.17% in-domain and +10.04% out-of-domain accuracy over standard SFT, matches end-to-end RL on agentic coding with 4x fewer rollout turns, and is used in NVIDIA's Nemotron-3-Super-120B-A12B.

arxiv:2603.21437 arXiv ✓
Pooling and Semantic Shift: The Fundamental Challenges in Long Text Embedding and Retrieval
池化与语义漂移：长文本嵌入与检索的根本挑战
embedding collapse contextual pooling semantic shift anisotropy
The paper proves that contextual pooling intrinsically causes embedding collapse and identifies semantic shift as the primary predictor of severe embedding concentration. Retrieval experiments show anisotropy is harmful mainly when induced by strong semantic shifts.

arxiv:2603.21362 arXiv ✓
AdaRubric: Task-Adaptive Rubrics for Reliable LLM Agent Evaluation and Reward Learning
AdaRubric：面向可靠 LLM 智能体评估与奖励学习的任务自适应评分标准
agent evaluation rubric generation reward learning preference pairs
AdaRubric generates task-specific evaluation rubrics from task descriptions, scores agent trajectories step by step with confidence-weighted per-dimension judgments and produces dense rewards for preference learning. On WebArena, ToolBench and AgentBench it reaches Pearson r = 0.79 with human correlation, and DPO models trained on its pairs improve task success by 6.8-8.5% over the best baseline.
→ arxiv.org
arxiv:2603.21301 arXiv ✓
Enhancing reasoning accuracy in large language models during inference time
在推理阶段提升大语言模型的推理准确率
self-consistency inference-time compute dual-model agreement reasoning accuracy
The authors compare self-consistency via stochastic decoding, dual-model reasoning agreement and self-reflection under identical Chain-of-Thought prompting and verification settings. Self-consistency with nucleus sampling gives 9-15% absolute accuracy gains over greedy decoding, the dual-model approach adds confirmation for moderate-risk settings, and self-reflection yields only marginal improvements.
→ arxiv.org
arxiv:2603.21438 arXiv ✓
PROMPT2BOX:Improving LLM Weakness Discovery and Specificity Estimation by Uncovering Entailment Structure among Prompts
Prompt2Box：通过提示词蕴含结构改进 LLM 弱点发现与具体性估计
box embeddings prompt specificity weakness discovery
Prompt2Box embeds prompts into a box embedding space that captures both semantic similarity and specificity relations. Experiments show a 45% average error reduction in predicting specificity over a prompt-length baseline and 13.5% more LLM weaknesses identified than vector baselines.
