Memory for Autonomous LLM Agents:Mechanisms, Evaluation, and Emerging Frontiers
面向自主 LLM 智能体的记忆：机制、评估与新兴前沿
agent memory memory taxonomy write-manage-read loop continual consolidation agentic evaluation
This survey formalizes LLM agent memory as a write-manage-read loop coupled with perception and action, and proposes a taxonomy spanning temporal scope, representational substrate, and control policy. It reviews five mechanism families and traces evaluation from static recall benchmarks to multi-session agentic tests, closing with open challenges such as continual consolidation and learned forgetting.

KohakuRAG: A simple RAG framework with hierarchical document indexing
KohakuRAG：基于层次化文档索引的简洁 RAG 框架
hierarchical indexing document structure embedding aggregation query planning ensemble inference
KohakuRAG preserves document structure with a four-level document-section-paragraph-sentence tree and bottom-up embedding aggregation, adds an LLM query planner with cross-query reranking, and stabilizes answers with ensemble inference and abstention-aware voting. It placed first on both the public and private leaderboards of the WattBot 2025 Challenge with a final score of 0.861.

Benchmarking Large Language Models for Quebec Insurance: From Closed-Book to Retrieval-Augmented Generation
魁北克保险领域大模型基准测试：从闭卷到检索增强生成
RAG domain benchmark context distraction insurance QA chain-of-thought
The authors introduce AEPC-QA, an 807-question multiple-choice benchmark drawn from Quebec insurance certification handbooks, and evaluate 51 LLMs. They find chain-of-thought reasoning helps, RAG can lift weak models by more than 35 points but may cause context distraction, and generalist models outperform smaller French fine-tuned ones.

KCoEvo: A Knowledge Graph Augmented Framework for Evolutionary Code Generation
KCoEvo：知识图谱增强的演化代码生成框架
knowledge graph API evolution code generation evolution path retrieval
KCoEvo decomposes API migration into evolution-path retrieval and path-informed code generation, building static and dynamic API graphs to model intra-version structure and cross-version transitions. Trained with synthetic supervision derived from real API diffs, it improves migration accuracy and execution success over standard LLM baselines.

Toward Epistemic Stability: Engineering Consistent Procedures for Industrial LLM Hallucination Reduction
迈向认知稳定性：降低工业 LLM 幻觉的一致流程工程
prompt engineering hallucination reduction output consistency LLM-as-judge
The authors compare five prompt-engineering strategies for reducing output variance in industrial settings, evaluating each over 100 repeated runs with an LLM-as-judge. An enhanced data registry received "Better" verdicts in all 100 trials, while decomposed model-agnostic prompting was initially net negative but improved from 34% to 80% in a revised version.

arxiv:2603.07835 arXiv ✓
DistillGuard: Evaluating Defenses Against LLM Knowledge Distillation
DistillGuard：评估针对 LLM 知识蒸馏的防御措施
knowledge distillation model extraction defense evaluation chain-of-thought
DistillGuard evaluates nine defense configurations against LLM knowledge distillation, using Qwen3-14B as teacher and Qwen2.5-7B-Instruct as student across three benchmarks. In the same-family setting most output-level defenses were surprisingly ineffective, and only chain-of-thought removal substantially impaired mathematical reasoning (31.4% versus 67.8% baseline).
→ arxiv.org
arxiv:2603.07784 arXiv ✓
ProgAgent:A Continual RL Agent with Progress-Aware Rewards
ProgAgent：具备进度感知奖励的持续强化学习智能体
continual learning catastrophic forgetting reward learning agent architecture
ProgAgent is a continual reinforcement learning agent that derives dense rewards from unlabeled expert videos via a learned progress estimator, combined with adversarial reward regularization and a JAX-native training loop. On ContinualBench and Meta-World it reportedly reduces forgetting and learns faster than visual-reward and continual-learning baselines.
