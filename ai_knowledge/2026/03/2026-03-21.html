Graphs RAG at Scale: Beyond Retrieval-Augmented Generation With Labeled Property Graphs and Resource Description Framework for Complex and Unknown Search Spaces
规模化 Graph RAG：用标记属性图与 RDF 应对复杂未知搜索空间
Graph RAG labeled property graphs text-to-Cypher semi-structured data
The paper introduces an end-to-end Graph RAG framework that combines Labeled Property Graphs and RDF, supports dynamic document retrieval without pre-specifying document counts and avoids reranking. It presents a text-to-Cypher method reported at over 90% accuracy and finds Graph RAG outperforms embedding-based RAG on complex, semi-structured tasks.

Errors in AI-Assisted Retrieval of Medical Literature: A Comparative Study
AI 辅助医学文献检索中的错误：一项比较研究
literature retrieval citation accuracy reference validity LLM platforms
The study evaluated 2,000 references retrieved by five LLM platforms for 40 original articles from BMJ, JAMA and NEJM. Platforms completely failed to retrieve correct reference data 47.8% of the time; the average score ratio was 0.29, with Grok highest at 0.57 and Gemini lowest at 0.11, and NEJM articles showed lower accuracy than BMJ.

Alignment Whack-a-Mole : Finetuning Activates Verbatim Recall of Copyrighted Books in Large Language Models
对齐打地鼠：微调激活大语言模型对受版权书籍的逐字记忆
verbatim memorization fine-tuning copyright parametric memory safety alignment
The authors show that fine-tuning models to expand plot summaries into full text causes GPT-4o, Gemini-2.5-Pro and DeepSeek-V3.1 to reproduce up to 85-90% of held-out copyrighted books, with single verbatim spans exceeding 460 words. Fine-tuning on one author's novels also unlocks recall of more than 30 unrelated authors, and three models from different providers memorize the same books in the same regions (r >= 0.90).

arxiv:2603.20730 arXiv ✓
Reasoning Topology Matters: Network-of-Thought for Complex Reasoning Tasks
推理拓扑很重要：面向复杂推理任务的思维网络
reasoning topology network-of-thought graph-structured reasoning multi-hop QA
The paper proposes Network-of-Thought, which models reasoning as a directed graph with typed nodes and edges guided by a heuristic controller policy. Across GSM8K, Game of 24, HotpotQA and ProofWriter, NoT beats Tree-of-Thought on multi-hop reasoning (91.0% vs 88.0% on HotpotQA with LLM-as-judge) while CoT remains effective for sequential tasks.

arxiv:2603.20807 arXiv ✓
BenchBench: Benchmarking Automated Benchmark Generation
BenchBench：评测自动化基准生成能力
benchmark generation LLM judges contamination psychometric diagnostics
BenchBench is a three-stage pipeline and dataset for evaluating automated benchmark generation: extracting domain cards from seed benchmarks, prompting designer LLMs to build quota-controlled suites, and validating items with a multi-model answerer panel. Across nine variants it generated 16.7K items and about 152K graded responses, finding benchmark-design ability only moderately correlates with answer-time strength (Spearman rho ~0.37).
→ arxiv.org

Detection of adversarial intent in Human-AI teams using LLMs
利用大语言模型检测人机团队中的对抗意图
human-AI teams adversarial intent interaction traces prompt injection
Using a dataset of multi-party conversations and decisions from a real human-AI team over a 25-round horizon, the authors formulate malicious behavior detection from interaction traces. They find LLMs can identify malicious behavior in real time without task-specific information, suggesting task-agnostic defenses that simple heuristics do not provide.

regulatory knowledge base retrieval-augmented generation ReAct traceable decision support

DiscoUQ: Structured Disagreement Analysis for Uncertainty Quantification in LLM Agent Ensembles
DiscoUQ：面向 LLM 智能体集成的结构化分歧不确定性量化
uncertainty quantification agent ensembles disagreement features confidence calibration
DiscoUQ derives linguistic and embedding-geometry features from disagreement among agents to produce calibrated confidence estimates for multi-agent LLM systems. Its DiscoUQ-LLM variant reached an average AUROC of 0.802 on four benchmarks with better calibration than the best baseline.

arxiv:2603.20953 arXiv ✓
Before the Tool Call: Deterministic Pre-Action Authorization for Autonomous AI Agents
工具调用之前：面向自主 AI 智能体的确定性事前授权
tool-call authorization policy enforcement audit records agent security
The paper presents the Open Agent Passport, an open specification and reference implementation that intercepts agent tool calls before execution, checks them against a declarative policy and emits a cryptographically signed audit record. In an adversarial testbed, social engineering succeeded 74.6% of the time under a permissive policy but 0% under a restrictive OAP policy.
→ arxiv.org

gUFO: A Gentle Foundational Ontology for Semantic Web Knowledge Graphs
gUFO：面向语义网知识图谱的轻量级基础本体
foundational ontology OWL 2 DL semantic web ontology standardization
gUFO offers a lightweight version of the Unified Foundational Ontology for OWL 2 DL and Semantic Web knowledge graphs, presenting its categories, relations and constraints. The paper describes community adoption, compares it with BFO and DOLCE implementations and notes that UFO is being standardized as ISO/IEC CD 21838-5.
