An Industrial-Scale Insurance LLM Achieving Verifiable Domain Mastery and Hallucination Control without Competence Trade-offs
面向保险行业的工业级 LLM：可验证的领域掌握与幻觉控制
domain LLM hallucination control verifiable data RLVR benchmark
INS-S1 is an insurance-specific LLM family trained with a verifiable data synthesis system and a progressive SFT-RL curriculum mixing verified reasoning and AI feedback, intended to avoid the usual trade-off between domain expertise and general capability. The authors also release INSEva, an insurance benchmark with more than 39k samples, and report state-of-the-art domain results with a 0.6% hallucination rate on HHEM while maintaining general capabilities.

arxiv:2603.14597 arXiv ✓
D-MEM: Dopamine-Gated Agentic Memory via Reward Prediction Error Routing
D-MEM：通过奖励预测误差路由的多巴胺门控智能体记忆
agent memory reward prediction error memory consolidation knowledge graph token efficiency
D-MEM decouples short-term interaction from cognitive restructuring with a fast/slow router driven by reward prediction error: a lightweight critic scores surprise and utility, caching routine inputs in an O(1) buffer and triggering an O(N) memory-evolution pipeline for contradictions or preference shifts. The authors introduce the LoCoMo-Noise benchmark and report over 80% lower token consumption, removal of O(N^2) write-latency, and better multi-hop and adversarial performance.

不蒸馏知识而蒸馏推理：面向可靠 LLM 的框架
planning retrieval decomposition teacher-student distillation tool use SEAL-0
The framework separates planning from factual retrieval and answer synthesis, training a lightweight student planner with teacher-generated structured decompositions and searchable fact requests but no factual answers. On the SEAL-0 benchmark, supervised planning improves both accuracy and latency relative to monolithic reasoning models and prompt-based tool-augmented systems.

Compute Allocation for Reasoning-Intensive Retrieval Agents
面向推理密集型检索智能体的计算分配
retrieval pipeline compute allocation re-ranking query expansion BRIGHT benchmark
Using the BRIGHT benchmark and Gemini 2.5 models, the study varies model capacity, inference-time thinking and re-ranking depth across query expansion and re-ranking. It finds that re-ranking gains substantially from stronger models (+7.5 NDCG@10) and deeper candidate pools (+21% from k=10 to 100), while query expansion shows diminishing returns and inference-time thinking gives minimal improvement.

Dynamic Theory of Mind as a Temporal Memory Problem: Evidence from Large Language Models
动态心智理论作为时间记忆问题：来自大语言模型的证据
theory of mind temporal memory belief tracking recency bias
DToM-Track tests whether LLMs can track beliefs over time in multi-turn conversations and finds a consistent asymmetry: models reliably infer an agent's current belief but struggle to recall prior belief states after updates. The pattern holds across model families and scales and is consistent with recency bias and interference effects.

RenderMem: Rendering as Spatial Memory Retrieval
RenderMem：将渲染作为空间记忆检索
spatial memory embodied agents view synthesis AI2-THOR
RenderMem is a spatial-memory framework for embodied agents that maintains a 3D scene representation and renders query-conditioned views as visual evidence, enabling reasoning about line-of-sight, visibility and occlusion from arbitrary viewpoints. Experiments in AI2-THOR show gains on viewpoint-dependent visibility and occlusion queries over prior memory baselines.

Infinite Problem Generator: Verifiably Scaling Physics Reasoning Data with Agentic Workflows
无限问题生成器：用智能体工作流可验证地扩展物理推理数据
agentic workflow synthetic data verifiable reasoning curriculum generation
The Infinite Problem Generator synthesizes physics problems whose solutions are constructed as executable Python programs under a Formula-as-Code paradigm, enforcing mathematical consistency. The authors release ClassicalMechanicsV1 with 1,335 problems expanded from 165 expert seeds, and report a strong linear correlation between formula count and verification code length that serves as a difficulty metric.

arxiv:2603.14426 arXiv ✓
GenState-AI: State-Aware Dataset for Text-to-Video Retrieval on AI-Generated Videos
GenState-AI：面向 AI 生成视频的文本到视频检索状态感知数据集
text-to-video retrieval state change hard negatives benchmark
GenState-AI is a benchmark of 956 AI-generated videos and 195 verified state-change queries across Toy, Cartoon, Home and Manipulation domains, designed so retrieval cannot be solved from static appearance alone. Qwen3-VL (8B) achieves the best macro-average Recall@1 and triplet consistency, but stronger retrieval does not consistently yield correct hard-negative ordering.

When Scanners Lie: Evaluator Instability in LLM Red-Teaming
当扫描器说谎：LLM 红队测试中的评估器不稳定性
red-teaming evaluator reliability LLM security Garak
The study finds that open-source LLM vulnerability scanners produce attack-success rates that shift with the evaluator, with 22 of 25 Garak attack categories showing instability and reported scores varying by up to 33%. It proposes a two-phase, reliability-aware evaluation framework that raises evaluator accuracy from 72% to 89%.
