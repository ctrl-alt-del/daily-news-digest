SoK: Agentic Retrieval-Augmented Generation (RAG): Taxonomy, Architectures, Evaluation, and Research Directions
SoK：Agentic RAG 的分类、架构、评估与研究展望
agentic RAG taxonomy memory poisoning POMDP evaluation
This systematization of knowledge formalizes agentic retrieval-generation loops as finite-horizon partially observable Markov decision processes and offers a taxonomy covering planning, retrieval orchestration, memory and tool invocation. It flags risks including compounding hallucination, memory poisoning and cascading tool-execution vulnerabilities.

Governance Architecture for Autonomous Agent Systems: Threats, Framework, and Engineering Practice
自主智能体系统的治理架构：威胁、框架与工程实践
agent governance prompt injection RAG poisoning intent verification audit logging
The Layered Governance Architecture proposes four layers, execution sandboxing, intent verification, zero-trust inter-agent authorization and immutable audit logging, to address prompt injection, retrieval poisoning and uncontrolled tool invocation. On a bilingual benchmark of 1,081 tool-call samples, five LLM judges intercept 93.0-98.5% of malicious tool calls, and an end-to-end pipeline reaches 96% interception at about 980 ms P50 latency.

Prompt Complexity Dilutes Structured Reasoning: A Follow-Up Study on the Car Wash Problem
提示复杂度稀释结构化推理：洗车问题的后续研究
structured reasoning prompt complexity instruction conflict reasoning order
A follow-up to STAR reasoning research tests the framework inside InterviewMate's 60+ line production prompt on Claude Sonnet 4.6: the STAR-only prompt scored 100%, while the production prompt with an Anthropic profile scored 0% and with a default profile 30%. The author attributes the degradation to competing directives such as "lead with specifics" forcing conclusion-first output, and argues structured reasoning frameworks should not be assumed to transfer to complex prompt environments.

FinSheet-Bench: From Simple Lookups to Complex Reasoning, Where LLMs Break on Financial Spreadsheets
FinSheet-Bench：从简单查找到复杂推理，LLM 在金融表格上何处失效
financial spreadsheets tabular reasoning benchmark document understanding
FinSheet-Bench is a benchmark of synthetic financial portfolio data modeled on real private equity fund structures, evaluating text-serialized spreadsheet question answering and numeric reasoning. Across ten model configurations, Gemini 3.1 Pro leads at 82.4% accuracy, but no standalone model is reliable enough for unsupervised professional use and average accuracy falls to 48.6% on the largest spreadsheet.

arxiv:2603.07241 arXiv ✓
Rethinking Deep Research from the Perspective of Web Content Distribution Matching
从网页内容分布匹配的视角重新思考深度研究
deep research agents query-result alignment web search sub-goal planning
WeDas is a Web Content Distribution Aware framework that adds search-space structural characteristics to a deep search agent's observation space, centered on a Query-Result Alignment Score measuring compatibility between agent intent and retrieval outcomes. A few-shot probing mechanism estimates the score through limited query accesses, and the plug-and-play module improves sub-goal completion and accuracy across four benchmarks.

arxiv:2603.13348 arXiv ✓
AutoTool: Automatic Scaling of Tool-Use Capabilities in RL via Decoupled Entropy Constraints
AutoTool：通过解耦熵约束在强化学习中自动扩展工具使用能力
tool use reinforcement learning entropy control token efficiency
AutoTool first applies warm-up supervised fine-tuning so models distinguish simple from complex problems, then uses reinforcement learning with an entropy-based long-short reasoning fusion strategy to choose reasoning trajectory length for tool use. Across three benchmarks it reports a 9.8% accuracy improvement while reducing computational overhead by about 81%.

Lying to Win: Assessing LLM Deception through Human-AI Games and Parallel-World Probing
以欺骗取胜：通过人机游戏与平行世界探测评估 LLM 欺骗
LLM deception behavioral audit logical consistency incentives
The authors embed LLMs in a structured 20-Questions game and fork the dialogue into parallel worlds at object identification, flagging deception when a model denies its chosen object across all branches and thus contradicts itself. Under existential shutdown framing, deceptive denial rises to 42.00% for Qwen-3-235B and 26.72% for Gemini-2.5-Flash, while GPT-4o remains at 0.00%.

AI Agent 的耶克斯-多德森曲线：多智能体 LLM 模拟中环境压力下的合作涌现
