Diagnosing Retrieval vs. Utilization Bottlenecks in LLM Agent Memory
诊断 LLM Agent 记忆中的检索与利用瓶颈
agent memory retrieval method memory write strategy LoCoMo benchmark chunked storage
A 3x3 study crossing three memory write strategies with three retrieval methods on LoCoMo finds that retrieval method dominates, with average accuracy spanning 20 points (57.1% to 77.2%) across retrieval methods but only 3-8 points across write strategies. Raw chunked storage, which requires no LLM calls, matched or outperformed costlier lossy alternatives.

arxiv:2603.02112 arXiv ✓
Recursive Models for Long-Horizon Reasoning
面向长时程推理的递归模型
long-horizon reasoning recursive decomposition context management isolated contexts theoretical guarantees
The authors propose recursive models that can invoke themselves to solve subtasks in isolated contexts, and prove that any computable problem admits a recursive decomposition where each subtask needs exponentially smaller active context than standard autoregressive models, strictly surpassing single-sequence context management such as summarization. They generalize the framework to agentic systems and show gains on recursive SAT solving and Go traces with small active contexts.
→ arxiv.org
arxiv:2603.02098 arXiv ✓
Efficient and High-Fidelity Omni Modality Retrieval
高效高保真的全模态检索
multimodal retrieval omni-modal embeddings composed queries audio retrieval benchmark
OmniRet is presented as the first retrieval model handling composed queries across text, vision and audio, using attention-based resampling for compact representations and Attention Sliced Wasserstein Pooling to preserve fine-grained detail. Trained on roughly 6 million query-target pairs from 30 datasets, it is benchmarked on 13 retrieval tasks and an MMEBv2 subset, and the authors curate a new Audio-Centric Multimodal Benchmark for composed audio and audio-visual retrieval.

Recursive Think-Answer Process for LLMs and VLMs
面向 LLM 与 VLM 的递归思考-回答过程
iterative reasoning confidence calibration reinforcement learning vision-language models
R-TAP adds iterative think-answer cycles to LLMs and VLMs, using a confidence generator that evaluates response certainty and guides further improvement, trained with recursive confidence-increase and final-answer-confidence rewards. The authors report consistent gains over single-pass methods and fewer "Oops"-like self-reflective expressions, yielding more stable and faster inference-time reasoning.

arxiv:2603.02202 arXiv ✓
Frontier Models Can Take Actions at Low Probabilities
前沿模型能够以极低概率采取行动
action calibration low-probability behavior chain-of-thought monitoring AI oversight frontier models
The authors prompt the GPT-5, Claude-4.5 and Qwen-3 families to take a target action at low probabilities such as 0.01% and test calibration under resampling. They find frontier models surprisingly well calibrated at rates below 1 in 100,000 when an in-context entropy source such as a UUID is available, but all models fail to derive the optimal target rate themselves without entropy or a hint.
→ arxiv.org
arxiv:2603.02081 arXiv ✓
GenDB: The Next Generation of Query Processing -- Synthesized, Not Engineered
GenDB：下一代查询处理——合成而非工程构建
query processing code synthesis LLM agent OLAP benchmark
GenDB is an LLM-powered agentic system that synthesizes instance-optimized query execution code for each incoming query instead of relying on a hand-engineered engine, using Claude Code Agent in a multi-agent prototype. On TPC-H and a new benchmark designed to reduce training-data leakage it reports significantly better performance than DuckDB, Umbra, MonetDB, ClickHouse and PostgreSQL, while discussing current limitations.
→ arxiv.org
arxiv:2604.15319 arXiv ✓
Explainable Iterative Data Visualization Refinement via an LLM Agent
通过 LLM 智能体实现可解释的迭代数据可视化精炼
embedding visualization hyperparameter optimization LLM agent qualitative assessment
The paper proposes an agentic pipeline that treats low-dimensional embedding visualization evaluation and hyperparameter optimization as a semantic task, combining quantitative metrics with LLM approximations of qualitative human judgment. It generates a multi-faceted report and actionable configuration recommendations, and iterates to produce a refined visualization plot in full automation.
