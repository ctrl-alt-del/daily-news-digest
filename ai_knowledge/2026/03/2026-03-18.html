Retrieval-Augmented LLM Agents: Learning to Learn from Experience
检索增强的 LLM 智能体：学会从经验中学习
experience retrieval episodic memory retrieval-aware fine-tuning generalization to unseen tasks trajectory selection
The authors combine LoRA fine-tuning with experience retrieval, integrating retrieved trajectories directly into the training process so agents learn to use them in context. They report substantially better generalization to unseen tasks, with gains that often persist with imperfect experience and even when agents reuse their own failed attempts without test-time parameter updates.

MemArchitect: A Policy Driven Memory Governance Layer
MemArchitect：策略驱动的记忆治理层
memory governance memory decay conflict resolution privacy policy
MemArchitect is a governance layer that separates memory lifecycle management from model weights and enforces rule-based policies for memory decay, conflict resolution and privacy. The authors report that governed memory outperforms unmanaged memory in agentic settings.

Retrieval-Augmented LLMs for Security Incident Analysis
面向安全事件分析的检索增强大语言模型
retrieval-augmented generation security incident analysis forensic reasoning MITRE ATT&CK ablation study
The authors present a RAG-based system that uses a query library mapped to MITRE ATT&CK techniques to extract indicators from raw logs and retrieve context for forensic questions. Across eight LLM configurations, Claude Sonnet 4 reached 94% and DeepSeek V3 89% average recall on 17 malware scenarios, while locally deployed Llama 3.1:70b reached 81% at zero per-query cost.

Toward Evaluation Frameworks for Multi-Agent Scientific AI Systems
面向多智能体科研 AI 系统的评估框架探索
multi-agent evaluation contamination-resistant benchmarks reasoning vs retrieval scientific discovery ground truth
This paper analyzes the challenges of benchmarking scientific multi-agent systems, including separating reasoning from retrieval, data and model contamination, missing ground truth for novel problems, tool use, and replication against a continuously changing knowledge base. It discusses strategies for contamination-resistant problems, scalable task families and multi-turn evaluation, and reports interviews with quantum-science researchers on how they expect to interact with AI systems.

arxiv:2603.17947 arXiv ✓
Unified Policy Value Decomposition for Rapid Adaptation
面向快速适应的统一策略与价值分解
goal embedding rapid adaptation policy decomposition successor features
The authors introduce a framework in which policy and value functions share a low-dimensional goal embedding that captures task identity, learned through a bilinear actor-critic decomposition built on Successor Features. With bases frozen at test time, a single forward pass estimates the goal coefficients and adapts a Soft Actor-Critic agent to novel locomotion directions without gradient updates.

Auditing Preferences for Brands and Cultures in LLMs
审计大语言模型对品牌与文化的偏好
preference auditing persona-diverse prompting geographic bias choice sets
The paper introduces ChoiceEval, a reproducible framework that generates persona-diverse queries and converts free-form model outputs into comparable top-k choice sets to audit brand and cultural preferences. Applied to Gemini, GPT and DeepSeek across 10 topics and more than 2,000 questions, it finds US-developed models favor American entities while DeepSeek shows more balanced but still detectable geographic preferences.
→ arxiv.org
arxiv:2604.03266 arXiv ✓
Emergent Compositional Communication for Latent World Properties
面向潜在世界属性的涌现组合式通信
emergent communication compositional representations multi-agent learning disentangled protocols
Agents communicating through a Gumbel-Softmax bottleneck with iterated learning develop disentangled protocols for latent physical properties such as elasticity, friction and mass ratio without property labels; with four agents, all 80 seeds converged to near-perfect compositionality (PosDis=0.999, 98.3% holdout). The frozen protocol supports action-conditioned planning at 91.5% and transfers to real camera footage with 85.6% mass-comparison accuracy.
