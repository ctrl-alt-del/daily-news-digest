arxiv:2603.13309 arXiv ✓
Preventing Curriculum Collapse in Self-Evolving Reasoning Systems
防止自演化推理系统中的课程坍塌
self-evolving reasoning curriculum collapse semantic coverage synthetic question generation math reasoning
Prism is a question-centric self-evolution method that defines a persistent diversity signal over an embedding-induced semantic partition of mathematical problems and pairs it with a Zone-of-Proximal-Development gate to keep questions near the edge of solvability. Evaluated on seven math reasoning benchmarks against five self-evolving baselines, it achieves the highest accuracy on six of seven tasks, gaining 3.98 points over R-Zero on AMC and 3.68 on Minerva Math, and is used to build the 100k-question Prism-Math dataset.

arxiv:2603.03194 arXiv ✓
BeyondSWE: Can Current Code Agent Survive Beyond Single-Repo Bug Fixing?
BeyondSWE：当前代码智能体能否突破单仓库缺陷修复？
code agents search-augmented coding agent benchmark cross-repository reasoning
BeyondSWE is a 500-instance benchmark drawn from 246 real-world GitHub repositories covering cross-repository issue resolution, domain-specific issue resolution, dependency-driven migration and document-to-repository generation. The best OpenHands-based agent reaches 46.12 average score while the strongest Codex harness with GPT-5.4 reaches 56.65, and search access helps most models only unevenly, showing that agents still struggle to turn retrieved information into version-compatible code changes.
→ arxiv.org
arxiv:2603.03205 arXiv ✓
Learning When to Act or Refuse: Guarding Agentic Reasoning Models for Safe Multi-Step Tool Use
学会何时行动或拒绝：为安全的多步工具使用守护智能体推理模型
agent safety tool use refusal behavior preference-based RL
MOSAIC is a post-training framework that structures agent inference as a plan, check, then act-or-refuse loop with explicit safety reasoning and refusal treated as first-class actions, trained through preference-based reinforcement learning on pairwise trajectory comparisons. Evaluated zero-shot on Qwen2.5-7B, Qwen3-4B-Thinking and Phi-4, it reduces harmful behavior by up to 50% and raises refusal on injection attacks by more than 20% while preserving or improving benign task performance.
→ arxiv.org

Type-Aware Retrieval-Augmented Generation with Dependency Closure for Solver-Executable Industrial Optimization Modeling
类型感知检索增强生成与依赖闭包：面向求解器可执行的工业优化建模
typed knowledge base dependency closure retrieval-augmented generation industrial optimization
The method parses academic papers and solver code into typed units and encodes their mathematical dependencies in a knowledge graph, then retrieves a minimal dependency-closed context containing only the typed symbols a solver-executable model needs. On battery-production demand response and flexible job shop scheduling it generates executable or compilable models where conventional RAG baselines fail.

GSI Agent：面向绿色雨水基础设施的大语言模型领域知识增强
domain knowledge retrieval-augmented generation domain fine-tuning agent pipeline
GSI Agent combines supervised fine-tuning on a curated instruction dataset, retrieval-augmented generation over municipal documents and an agent pipeline that coordinates retrieval, context integration and structured responses for green stormwater infrastructure tasks. arxiv:2603.03512 arXiv ✓
Baseline Performance of AI Tools in Classifying Cognitive Demand of Mathematical Tasks
AI 工具在数学任务认知需求分类中的基线表现
cognitive demand LLM evaluation prompt engineering education
The study tests eleven AI tools, six general-purpose and five education-specific, on classifying mathematics tasks across four levels of cognitive demand using straightforward prompts. On average the tools were accurate in only 63% of cases, no tool exceeded 83%, and all showed a bias toward middle categories while overweighting surface textual features over underlying cognitive processes.
→ arxiv.org
arxiv:2603.03505 arXiv ✓
PhyPrompt: RL-based Prompt Refinement for Physically Plausible Text-to-Video Generation
PhyPrompt：基于强化学习细化提示，实现物理合理的文本到视频生成
prompt refinement reinforcement learning physics commonsense text-to-video
PhyPrompt is a two-stage reinforcement learning framework that fine-tunes an LLM on a physics-focused chain-of-thought dataset and then applies GRPO with a reward curriculum that shifts from semantic fidelity to physical commonsense. Its 7B model reaches 40.8% joint success on VideoPhy2, an 8.6-point gain, and outperforms GPT-4o and DeepSeek-V3 on the benchmark while transferring zero-shot across several text-to-video architectures.

Tucano 2 Cool: Better Open Source LLMs for Portuguese
Tucano 2 Cool：更好的葡萄牙语开源大模型
open-weight models multilingual LLM pretraining corpus post-training data
