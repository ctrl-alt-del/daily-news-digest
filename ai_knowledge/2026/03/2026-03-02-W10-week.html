Memory for Autonomous LLM Agents:Mechanisms, Evaluation, and Emerging Frontiers
面向自主 LLM 智能体的记忆：机制、评估与新兴前沿
agent memory memory taxonomy write-manage-read loop continual consolidation agentic evaluation
This survey formalizes LLM agent memory as a write-manage-read loop coupled with perception and action, and proposes a taxonomy spanning temporal scope, representational substrate, and control policy. It reviews five mechanism families and traces evaluation from static recall benchmarks to multi-session agentic tests, closing with open challenges such as continual consolidation and learned forgetting.

Diagnosing Retrieval vs. Utilization Bottlenecks in LLM Agent Memory
诊断 LLM Agent 记忆中的检索与利用瓶颈
agent memory retrieval method memory write strategy LoCoMo benchmark chunked storage
A 3x3 study crossing three memory write strategies with three retrieval methods on LoCoMo finds that retrieval method dominates, with average accuracy spanning 20 points (57.1% to 77.2%) across retrieval methods but only 3-8 points across write strategies. Raw chunked storage, which requires no LLM calls, matched or outperformed costlier lossy alternatives.

arxiv:2603.03205 arXiv ✓
Learning When to Act or Refuse: Guarding Agentic Reasoning Models for Safe Multi-Step Tool Use
学会何时行动或拒绝：为安全的多步工具使用守护智能体推理模型
agent safety tool use refusal behavior preference-based RL
MOSAIC is a post-training framework that structures agent inference as a plan, check, then act-or-refuse loop with explicit safety reasoning and refusal treated as first-class actions, trained through preference-based reinforcement learning on pairwise trajectory comparisons. Evaluated zero-shot on Qwen2.5-7B, Qwen3-4B-Thinking and Phi-4, it reduces harmful behavior by up to 50% and raises refusal on injection attacks by more than 20% while preserving or improving benign task performance.
