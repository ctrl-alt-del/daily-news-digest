arxiv:2603.11277 arXiv ✓
COMPASS: The explainable agentic framework for Sovereignty, Sustainability, Compliance, and Ethics
COMPASS：面向主权、可持续性、合规与伦理的可解释智能体框架
multi-agent orchestration RAG grounding AI governance LLM-as-judge
COMPASS is a multi-agent orchestration framework with an orchestrator and four specialized sub-agents for sovereignty, carbon-aware computing, compliance, and ethics, each using RAG to ground evaluations in verified documents. An LLM-as-judge assigns quantitative scores and explainable justifications, and automated evaluation indicates that RAG integration improves semantic coherence and mitigates hallucination risk.
→ arxiv.org
arxiv:2603.11339 arXiv ✓
FinRule-Bench: A Benchmark for Joint Reasoning over Financial Tables and Principles
FinRule-Bench：面向财务报表与会计原则联合推理的基准
financial reasoning benchmark rule verification table reasoning
FinRule-Bench pairs real financial statements with human-curated accounting principles and defines three auditing tasks of increasing difficulty: rule verification, rule identification, and joint rule diagnosis. The authors find that models perform well on isolated rule verification but degrade sharply on rule discrimination and multi-violation diagnosis.
→ arxiv.org
arxiv:2603.14173 arXiv ✓
Hybrid Intent-Aware Personalization with Machine Learning and RAG-Enabled Large Language Models for Financial Services Marketing
面向金融服务营销的混合意图感知个性化与 RAG 大模型
RAG personalization financial services grounded generation
The paper presents a hybrid architecture that combines classical machine learning for segmentation, latent intent modeling, and personalization prediction with retrieval-augmented LLMs for grounded content generation. Experiments on a synthetic, reproducible dataset indicate that temporal and intent features improve personalization accuracy and citation-based retrieval reduces unsupported generation.
