Semantic Invariance in Agentic AI
Agentic AI 中的语义不变性
semantic invariance metamorphic testing agent robustness reasoning stability model scale
The paper proposes a metamorphic testing framework that applies eight semantic-preserving transformations to 19 multi-step reasoning problems across seven models from four architecture families. It finds that model scale does not predict robustness: Qwen3-30B-A3B is the most stable at 79.6% invariant responses, while larger models are more fragile.

StatePlane: A Cognitive State Plane for Long-Horizon AI Systems Under Bounded Context
StatePlane：面向有限上下文长时程 AI 系统的认知状态平面
cognitive state plane memory decay episodic memory bounded context model-agnostic
StatePlane is a model-agnostic cognitive state plane that governs the formation, evolution, retrieval and decay of episodic, semantic and procedural state for AI systems operating under bounded context. It argues that long-horizon intelligence can be achieved without expanding context windows or retraining models.

DRCY: Agentic Hardware Design Reviews
DRCY：智能体化硬件设计评审
multi-agent system datasheet retrieval self-evaluation consensus mechanism hardware design
DRCY is a production multi-agent LLM system that automates first-pass schematic connection review by fetching component datasheets, checking pin-by-pin specifications and posting inline comments. Deployed on AllSpice Hub as a CI/CD action, it uses a five-agent pipeline, agentic datasheet retrieval with self-evaluation and multi-run consensus for safety-critical analyses.

arxiv:2603.13628 arXiv ✓
Locatability-Guided Adaptive Reasoning for Image Geo-Localization with Vision-Language Models
面向视觉语言模型图像地理定位的可定位性引导自适应推理
adaptive reasoning retrieval-augmented generation geo-localization GRPO hallucination reduction
Geo-ADAPT introduces an Optimized Locatability Score that estimates how suitable an image is for deep reasoning, and uses it to build a locatability-stratified dataset of 51K reasoning trajectories. A two-stage GRPO curriculum learns an adaptive reasoning policy that reports state-of-the-art geo-localization results while reducing hallucinations.

arxiv:2603.13154 arXiv ✓
ESG-Bench: Benchmarking Long-Context ESG Reports for Hallucination Mitigation
ESG-Bench：面向幻觉缓解的长上下文 ESG 报告基准
hallucination mitigation long-context QA ESG reports chain-of-thought benchmark dataset
ESG-Bench provides human-annotated QA pairs grounded in real ESG report contexts, with fine-grained labels marking whether model outputs are factually supported or hallucinated. Chain-of-thought prompting and fine-tuning on CoT rationales substantially reduce hallucinations, and the authors report that the gains transfer to QA benchmarks beyond ESG.
→ arxiv.org
DeepSeek arxiv:2603.13651 arXiv ✓
Benchmarking Large Language Models on Reference Extraction and Parsing in the Social Sciences and Humanities
大语言模型在社会科学与人文领域的参考文献抽取与解析基准
reference extraction document parsing benchmark LoRA adaptation
The paper introduces a unified benchmark for reference extraction and parsing on social-science and humanities corpora, comparing GROBID with DeepSeek-V3.1, Mistral-Small-3.2-24B, Gemma-3-27B-it and Qwen3-VL. Extraction largely saturates past a moderate capability threshold, parsing remains the bottleneck, and lightweight LoRA adaptation gives consistent gains.
→ arxiv.org

Design and evaluation of an agentic workflow for crisis-related synthetic tweet datasets
面向危机相关合成推文数据集的 agent 工作流设计与评估
agentic workflow synthetic data compliance checking data generation
The paper presents an agentic workflow that iteratively generates synthetic crisis tweets conditioned on target characteristics, checks them against compliance rules and refines them with structured feedback. A post-earthquake damage-assessment case study indicates the synthetic data can support geolocalization and damage-level prediction.
