AgentWorm: Self-Propagating Attacks Across LLM Agent Ecosystems
AgentWorm：跨 LLM 智能体生态的自我传播攻击
agent security self-propagation skill supply chain multi-agent ecosystem attack success rate
AgentWorm is described as the first self-replicating worm attack against a production-scale agent framework, hijacking a victim's core configuration for persistence, executing a payload on each reboot and propagating to newly encountered peers without further attacker intervention. Across five LLM backends, three infection vectors and three payload types it reports a 63% aggregate attack success rate, and the authors find that critical controls able to break the infection loop are not enabled in any observed deployment.

arxiv:2603.21272 arXiv ✓
The Library Theorem: How External Organization Governs Agentic Reasoning Capacity
图书馆定理：外部组织方式如何决定智能体推理能力
external memory indexing retrieval cost context window agentic reasoning parametric memory
The paper formalizes the transformer context window as an I/O page and proves that tool-augmented agents with indexed external memory achieve exponentially lower retrieval cost than sequential scanning: O(log_b N) versus Omega(N) page reads per query. On abstract content in a controlled lookup benchmark up to 5,000 items, the indexed agent used a median of one page read regardless of store size, while models given sorted pages but no index still lost by 5x.

arxiv:2603.20278 arXiv ✓
OpenResearcher: A Fully Open Pipeline for Long-Horizon Deep Research Trajectory Synthesis
OpenResearcher：面向长时程深度研究轨迹合成的全开放流水线
deep research trajectory synthesis offline search supervised fine-tuning BrowseComp
OpenResearcher is a reproducible pipeline that decouples one-time corpus bootstrapping from multi-turn trajectory synthesis and runs the search-and-browse loop fully offline over a 15M-document corpus using search, open and find primitives. With GPT-OSS-120B as teacher it synthesizes over 97K trajectories, and supervised fine-tuning a 30B-A3B backbone reaches 54.8% on BrowseComp-Plus, a 34-point gain over the base model.

对齐打地鼠：微调激活大语言模型对受版权书籍的逐字记忆
verbatim memorization fine-tuning copyright parametric memory safety alignment
The authors show that fine-tuning models to expand plot summaries into full text causes GPT-4o, Gemini-2.5-Pro and DeepSeek-V3.1 to reproduce up to 85-90% of held-out copyrighted books, with single verbatim spans exceeding 460 words. Fine-tuning on one author's novels also unlocks recall of more than 30 unrelated authors, and three models from different providers memorize the same books in the same regions (r >= 0.90).
