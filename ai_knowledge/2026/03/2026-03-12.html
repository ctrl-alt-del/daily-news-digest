BrainMem: Brain-Inspired Evolving Memory for Embodied Agent Task Planning
BrainMem：面向具身智能体任务规划的类脑演化记忆
agent memory knowledge graph embodied agents task planning training-free
BrainMem is a training-free hierarchical memory system that gives embodied agents working, episodic, and semantic memory, continuously transforming interaction histories into structured knowledge graphs and distilled symbolic guidelines. Across EB-ALFRED, EB-Navigation, EB-Manipulation, and EB-Habitat it improves task success, with the largest gains on long-horizon and spatially complex tasks.

arxiv:2603.12458 arXiv ✓
Shattering the Shortcut: A Topology-Regularized Benchmark for Multi-hop Medical Reasoning in LLMs
ShatterMed-QA：面向 LLM 多跳医学推理的拓扑正则化基准
medical knowledge graph multi-hop reasoning benchmark RAG shortcut learning
The authors introduce ShatterMed-QA, a bilingual benchmark of 10,558 multi-hop clinical questions built on a topology-regularized medical knowledge graph whose k-Shattering algorithm prunes generic hub nodes to sever shortcut paths. Evaluations of 21 LLMs show sharp degradation on these tasks, and restoring masked evidence through RAG triggers near-universal performance recovery.

Long-Context Encoder Models for Polish Language Understanding
面向波兰语理解的长上下文编码器模型
long-context encoder knowledge distillation Polish NLP document understanding
The authors introduce a Polish encoder model that handles sequences up to 8,192 tokens through positional embedding adaptation and full-parameter continual pre-training, plus compressed variants trained by knowledge distillation. It achieves the best average performance among Polish and multilingual models on 25 tasks, with especially large gains on long-context tasks.

arxiv:2603.12396 arXiv ✓
Test-Time Strategies for More Efficient and Accurate Agentic RAG
提升智能体 RAG 效率与准确性的测试时策略
agentic RAG de-duplication contextualization multi-hop QA
The authors modify the Search-R1 agentic RAG pipeline with a contextualization module that better integrates retrieved documents into reasoning and a de-duplication module that replaces previously retrieved documents. The best variant, using GPT-4.1-mini for contextualization, reports a 5.6% increase in exact match and a 10.5% reduction in retrieval turns on HotpotQA and Natural Questions.

When LLM Judge Scores Look Good but Best-of-N Decisions Fail
当 LLM 评审分数看起来不错时，Best-of-N 决策为何失败
LLM-as-judge best-of-N judge calibration pairwise comparison
On a 5,000-prompt best-of-4 benchmark from Chatbot Arena, a judge with moderate global correlation (r = 0.47) captured only 21.0% of the improvement that perfect selection would bring. In a best-of-2 audit, explicit pairwise judging raised recovery from 21.1% to 61.2%.
