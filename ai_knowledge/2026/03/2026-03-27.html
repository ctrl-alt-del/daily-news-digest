Beyond Code Snippets: Benchmarking LLMs on Repository-Level Question Answering
超越代码片段：在仓库级问答上评测 LLM
repository-level QA code comprehension structural graphs memorization vs reasoning
StackRepoQA is described as the first multi-project, repository-level question answering dataset, built from 1,318 real developer questions and accepted answers across 134 open-source Java projects. Evaluating Claude 3.5 Sonnet and GPT-4o under direct and agentic prompting, the authors find structural signals help but accuracy remains limited, and high scores often reflect verbatim reproduction of Stack Overflow answers rather than reasoning.

ASTER -- Agentic Science Toolkit for Exoplanet Research
ASTER：面向系外行星研究的智能体科学工具包
agentic science domain tools workflow planning Bayesian retrieval
ASTER is an orchestration framework that gives LLM agents domain-specific tools for exoplanet research, including NASA Exoplanet Archive queries, TauREx forward spectra and Bayesian retrievals, plus workflow planning and interpretation support. A case study on WASP-39b shows the agent moving between datasets, generating model spectra and performing retrievals.

RASPRef: Retrieval-Augmented Self-Supervised Prompt Refinement for Large Reasoning Models
RASPRef：面向大型推理模型的检索增强自监督提示精炼
prompt refinement retrieval augmentation self-supervised feedback reasoning trajectories
RASPRef treats the prompt itself as the optimization target, retrieving relevant examples and prior reasoning trajectories and using multi-sample consistency, verifier feedback and model critiques to refine it without human annotations. Experiments on GSM8K-style mathematical reasoning show retrieval-guided prompting improves over a static prompting baseline.

The Last Fingerprint: How Markdown Training Shapes LLM Prose
最后的指纹：Markdown 训练如何塑造 LLM 文风
training data influence markdown formatting fine-tuning signature stylistic artifacts
The paper proposes that the em dash is markdown leaking into prose, the smallest surviving unit of the structural orientation LLMs acquire from markdown-heavy training corpora. In a two-condition suppression experiment across twelve models from five providers, asking models to avoid markdown removed headers, bullets and bold but em dashes persisted in most, with rates from 0.0 per 1,000 words for Llama to 9.1 for GPT-4.1 under suppression.
→ arxiv.org

Development of a European Union Time-Indexed Reference Dataset for Assessing the Performance of Signal Detection Methods in Pharmacovigilance using a Large Language Model
构建欧盟时间索引药物警戒参考数据集：基于大语言模型的信号检测评估
reference dataset pharmacovigilance information extraction signal detection
The authors built a time-indexed EU pharmacovigilance reference dataset by processing current and historical SmPCs for all 1,513 centrally authorized products with DeepSeek V3 to identify adverse events and linking them to label-inclusion dates. The database covers 17,763 SmPC versions from 1995-2025 and 125,026 drug-AE associations, with 110,823 associations in the active-product reference set.

Generalizable Foundation Models for Calorimetry via Mixtures-of-Experts and Parameter Efficient Fine Tuning
基于专家混合与参数高效微调的通用量热学基础模型
foundation models catastrophic forgetting mixture of experts parameter-efficient fine-tuning
The work builds a next-token transformer foundation model for calorimetry that combines mixture-of-experts pretraining with parameter-efficient fine-tuning, adding lightweight expert modules for new absorber materials and tuning for new particle types without catastrophic forgetting. It reports that next-token calorimeter models are computationally competitive with standard generative approaches under established LLM optimization procedures.

arxiv:2604.19775 arXiv ✓
From Actions to Understanding: Conformal Interpretability of Temporal Concepts in LLM Agents
从行动到理解：LLM 智能体时序概念的一致性可解释性
conformal prediction agent interpretability reward modeling linear probes
The paper introduces a conformal interpretability framework that combines step-wise reward modeling with conformal prediction to label an LLM agent's internal representations as successful or failing at each step. Linear probes on ScienceWorld and AlfWorld show the temporal concepts are linearly separable, and preliminary results suggest steering along successful directions can improve performance.
