Reason and Verify: A Framework for Faithful Retrieval-Augmented Generation
Reason and Verify：面向忠实检索增强生成的框架
RAG faithfulness verification rationale generation reranking biomedical QA
The framework adds neural query rewriting, BGE cross-encoder reranking, and rationale generation that grounds sub-claims in evidence spans, plus an eight-category taxonomy for assessing rationale faithfulness. With Llama-3-8B-Instruct it reaches 89.1% on BioASQ-Y/N and 73.0% on PubMedQA, competitive with systems using much larger models.

ontology metadata standardization tool-using agent biomedical knowledge

CR-Bench: Evaluating the Real-World Utility of AI Code Review Agents
CR-Bench：评估 AI 代码审查智能体的真实效用
code review agents benchmark false positives reflexion
CR-Bench is a benchmarking dataset paired with CR-Evaluator, a fine-grained pipeline for code review agents, addressing coarse success metrics and costly false positives. A preliminary study of single-shot and Reflexion-based agents finds a low signal-to-noise ratio and a trade-off between issue resolution and spurious findings.

Video-Based Reward Modeling for Computer-Use Agents
面向计算机使用智能体的视频奖励建模
computer-use agents reward modeling video evaluation agent trajectories
The authors introduce ExeVR-53k, a dataset of 53k video-task-reward triplets, and ExeVRM, a reward model that judges computer-use agent trajectories from execution video alone. ExeVRM 8B reaches 84.7% accuracy and 87.7% recall, outperforming GPT-5.2 and Gemini-3 Pro across Ubuntu, macOS, Windows, and Android, according to the authors.

arxiv:2603.18034 arXiv ✓
Semantic Chameleon: Corpus-Dependent Poisoning Attacks and Defenses in RAG Systems
语义变色龙：RAG 系统中依赖语料的投毒攻击与防御
RAG poisoning corpus attack hybrid retrieval defense
The paper studies gradient-guided corpus poisoning attacks on RAG pipelines using paired sleeper and trigger documents optimized with GCG. On a 67,941-document corpus the attacks reached a 38.0% co-retrieval rate under vector-only retrieval, while hybrid BM25-plus-vector retrieval reduced attack success from 38% to 0% in the reported tests, though jointly optimized payloads could still reach 20-44%.
