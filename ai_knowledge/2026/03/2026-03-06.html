从行到推理：面向多模态表格理解与编辑的智能体检索
agentic retrieval multimodal embeddings spreadsheet reasoning tool-calling loop benchmark
BRTR replaces single-pass retrieval with an iterative tool-calling loop for multimodal spreadsheet understanding and structured editing, supported by more than 200 hours of expert human evaluation. Compression Method Matters: Benchmark-Dependent Output Dynamics in LLM Prompt Compression
压缩方法很重要：LLM 提示压缩中随基准而变的输出动态
prompt compression instruction survival output dynamics reproducibility
A controlled replication across 5,400 API calls finds that aggressive prompt compression can sharply increase output length in benchmark-dependent ways: at r=0.3, DeepSeek expanded outputs 56x on MBPP but 5x on HumanEval, while GPT-4o-mini stayed comparatively stable. The authors identify prompt structure rather than provider identity as the primary moderator and introduce an instruction-survival metric and a Compression Robustness Index.

arxiv:2604.22757 arXiv ✓
StratRAG: A Multi-Hop Retrieval Evaluation Dataset for Retrieval-Augmented Generation Systems
StratRAG：面向检索增强生成系统的多跳检索评测数据集
multi-hop retrieval retrieval benchmark hybrid retrieval distractors
StratRAG is an open-source retrieval evaluation dataset derived from HotpotQA's distractor setting, with 2,200 examples across bridge, comparison and yes-no questions, each paired with 15 candidate documents containing exactly 2 gold documents and 13 distractors. Hybrid retrieval performs best overall with Recall@2 of 0.70 and MRR of 0.93, while bridge questions remain harder at Recall@2 of 0.67.

Empowering Locally Deployable Medical Agent via State Enhanced Logical Skills for FHIR-based Clinical Tasks
为本地可部署医疗智能体赋能：面向 FHIR 临床任务的状态增强逻辑技能
skill memory clinical agents two-stage retrieval local deployment
SELSM is a training-free framework that distills simulated clinical trajectories into entity-agnostic operational rules in an abstract skill space, then uses query-anchored two-stage retrieval to fetch logical priors during inference. On MedAgentBench with the Qwen3-30B-A3B backbone it eliminates task chain breakdowns for a 100% completion rate and raises overall success by 22.67 absolute points over memory-augmented baselines.

arxiv:2603.06856 arXiv ✓
Evaluating Multi-Agent LLM Architectures for Rare Disease Diagnosis
评估用于罕见病诊断的多智能体 LLM 架构
multi-agent topology rare disease diagnosis reasoning gap knowledge retrieval
The study compares four agent topologies, Control, Hierarchical, Adversarial and Collaborative, across 302 cases spanning 33 rare disease categories, and introduces a Reasoning Gap metric separating internal knowledge retrieval from final diagnostic accuracy. Hierarchical was best at 50.0%, marginally ahead of Collaborative at 49.8% and Control at 48.5%, while Adversarial fell to 27.3% as valid diagnoses were rejected under artificial doubt.

Evaluating Generalization Mechanisms in Autonomous Cyber Attack Agents
评估自主网络攻击智能体的泛化机制
agent generalization LLM agents behavioral analysis security
The study isolates unseen host and subnet IP reassignment as a minimal shift in the NetSecGame environment, training agents on five IP-range variants and testing on a sixth. Some adaptation methods show partial transfer but degrade significantly, while prompt-driven pretrained LLM agents achieve the highest held-out success at the cost of more inference-time compute, reduced transparency and repetition or invalid-action loops.
