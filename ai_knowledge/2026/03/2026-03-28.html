A Reference Architecture for Agentic Hybrid Retrieval in Dataset Search
面向数据集搜索的智能体混合检索参考架构
agentic hybrid retrieval reciprocal rank fusion query planning metadata augmentation dataset search
The paper treats dataset search as a software-architecture problem and proposes a bounded, auditable architecture that fuses BM25 and dense retrieval with reciprocal rank fusion under an LLM agent that plans queries, judges result sufficiency and reranks candidates. It also has an LLM generate pseudo-queries offline to augment both indexes, and defines a seven-variant evaluation framework comparing a single ReAct agent with a multi-agent design.

arxiv:2603.27335 arXiv ✓
PubMed Reasoner: Dynamic Reasoning-based Retrieval for Evidence-Grounded Biomedical Question Answering
PubMed Reasoner：面向循证生物医学问答的动态推理检索
biomedical QA query refinement evidence grounding agentic retrieval
PubMed Reasoner is a three-stage biomedical QA agent that refines MeSH queries using partial metadata, retrieves articles in batches until evidence is sufficient, and generates answers with explicit citations. With a GPT-4o backbone it reaches 78.32% accuracy on PubMedQA, slightly above human experts, and shows consistent gains on MMLU Clinical Knowledge.

Heterogeneous Debate Engine: Identity-Grounded Cognitive Architecture for Resilient LLM-Based Ethical Tutoring
Heterogeneous Debate Engine：面向稳健伦理辅导的身份锚定认知架构
identity-grounded RAG multi-agent debate theory of mind argument complexity
The Heterogeneous Debate Engine combines identity-grounded RAG for doctrinal fidelity with a heuristic theory of mind for strategic opponent modeling in multi-agent debate. The authors report that contrasting doctrinal initializations, such as deontology versus utilitarianism, raised students' Argument Complexity Scores by an order of magnitude over baselines.

Development and Preliminary Evaluation of a Domain-Specific Large Language Model for Tuberculosis Care in South Africa
南非结核病护理领域专用大模型：开发与初步评估
GraphRAG QLoRA fine-tuning domain-specific LLM retrieval-augmented generation
The study fine-tunes BioMistral-7B with QLoRA on South African TB guidelines, selected literature and medical benchmark data, and adds GraphRAG retrieval. Compared with the base model and a general-purpose LLM, the resulting domain-specific model shows better lexical, semantic and knowledge alignment for TB care.

RoMathExam: A Longitudinal Dataset of Romanian Math Exams (1895-2025) with a Seven-Decade Core (1957-2025)
RoMathExam：罗马尼亚数学考试纵向数据集（1895–2025），含 1957–2025 七十年核心集
math dataset text embeddings difficulty estimation curriculum analytics
RoMathExam contains 10,592 Romanian high-school mathematics problems organized into more than 600 complete exam sets from 1895 to 2025, with a standardized core for 1957-2025. It adds curriculum-aligned topic tags and dense text embeddings for variant detection, deduplication and retrieval, and the authors validate a solution-complexity difficulty proxy across three reasoning models.

贪心就是强默认：把智能体当作迭代优化器
