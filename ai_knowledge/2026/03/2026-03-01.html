SWE-Adept: An LLM-Based Agentic Framework for Deep Codebase Analysis and Structured Issue Resolution
SWE-Adept：面向深度代码库分析与结构化问题解决的 LLM 智能体框架
code localization agent working memory multi-agent framework SWE-bench git checkpoints
SWE-Adept is a two-agent framework in which a localization agent finds issue-relevant code via agent-directed depth-first search over dependencies, and a resolution agent implements fixes with adaptive planning and Git-based tools. A shared working memory stores code-state checkpoints indexed by execution step, enabling branching and reverting; on SWE-Bench Lite and SWE-Bench Pro it improves end-to-end resolve rate by up to 4.3%.

arxiv:2603.01152 arXiv ✓
DeepResearch-9K: A Challenging Benchmark Dataset of Deep-Research Agent
DeepResearch-9K：面向深度研究智能体的高难度基准数据集
deep research agents multi-hop QA search trajectories reinforcement learning benchmark dataset
DeepResearch-9K is a 9,000-question deep-research dataset with three difficulty levels, search trajectories and reasoning chains from Tongyi-DeepResearch-30B-A3B, and verifiable answers, built from open-source multi-hop QA data through a low-cost autonomous pipeline. The authors also release DeepResearch-R1, an open training framework supporting multi-turn web interaction, multiple RL approaches and rule-based or LLM-judge rewards, and report state-of-the-art results for agents trained with it.

arxiv:2603.01241 arXiv ✓
TARSE: Test-Time Adaptation via Retrieval of Skills and Experience for Reasoning Agents
TARSE：面向推理智能体的技能与经验检索测试时自适应
skills retrieval experience memory test-time adaptation clinical reasoning step-aware retrieval
TARSE frames clinical question answering as an agent problem with two retrievable resources: reusable skills such as guidelines and protocols, and verified reasoning trajectories from solved cases indexed by step-level transitions. At test time a step-aware retriever selects items and the model is lightly adapted to align its intermediate reasoning, yielding consistent gains over strong medical RAG and prompting-only baselines.

arxiv:2603.01096 arXiv ✓
Unified Vision-Language Modeling via Concept Space Alignment
通过概念空间对齐实现统一视觉-语言建模
multilingual embeddings vision-language alignment concept space video captioning low-resource languages
V-SONAR extends the text-only SONAR embedding space to vision through a post-hoc alignment pipeline that maps an existing vision encoder into it, achieving competitive text-to-video retrieval. With the OMNISONAR decoder it surpasses state-of-the-art vision-language models on video captioning, and the resulting V-LCM matches them on captioning and QA while outperforming them in 61 of 62 tested languages.

Demystifying Group Relative Policy Optimization: Its Policy Gradient is a U-Statistic
解构组相对策略优化：其策略梯度是一个 U 统计量
policy optimization U-statistics group size scaling theoretical analysis reasoning models
The paper shows that the GRPO policy gradient is a U-statistic, deriving its mean squared error, finite-sample error bound and asymptotic suboptimality gap. It finds GRPO asymptotically equivalent to an oracle policy gradient algorithm and derives a universal scaling law for choosing group size, with experiments supporting the theory.

arxiv:2603.01297 arXiv ✓
I Can't Believe It's Not Robust: Catastrophic Collapse of Safety Classifiers under Embedding Drift
难以置信的不稳健：嵌入漂移下安全分类器的灾难性崩溃
embedding drift safety classifiers adversarial robustness calibration
The authors find that safety classifiers trained on frozen embeddings break under small perturbations of normalized magnitude 0.02, about one degree of angular drift, with ROC-AUC falling from 85% to 50% while mean confidence drops only 14%. They report that 72% of misclassifications occur with high confidence and that instruction-tuned models show 20% worse class separability than base models.

arxiv:2603.01311 arXiv ✓
Catalyst-Agent: Autonomous heterogeneous catalyst screening with an LLM Agent
Catalyst-Agent：用 LLM 智能体自主筛选多相催化剂
materials discovery MCP server closed-loop screening autonomous experimentation
Catalyst-Agent is an MCP-server-based LLM agent that runs closed-loop heterogeneous catalyst screening by querying OPTIMADE materials databases, building slabs, computing adsorption energies with Meta FAIRchem's UMA potential in AdsorbML, evaluating descriptors and modifying near-miss candidates. It converged in 1.40-3.41 trials per successful material and proposed previously unreported CO2RR candidates including Sn3Sc, Sn3Y, Tl3La, Pb3Y and In3Y.

Egocentric Co-Pilot: Web-Native Smart-Glasses Agents for Assistive Egocentric AI
第一视角副驾驶：面向辅助式第一视角 AI 的网络原生智能眼镜智能体
egocentric agents hierarchical context compression temporal chain-of-thought smart glasses long-horizon QA
Egocentric Co-Pilot is a web-native neuro-symbolic framework for smart glasses in which an LLM orchestrates perception, reasoning and web tools, with an egocentric reasoning core combining Temporal Chain-of-Thought and Hierarchical Context Compression for long-horizon first-person video QA. Experiments on Egolife and HD-EPIC show competitive or state-of-the-art results, and a human-in-the-loop study reports higher task completion and satisfaction than leading commercial baselines.

Contextual Invertible World Models: A Neuro-Symbolic Agentic Framework for Colorectal Cancer Drug Response
情境可逆世界模型：面向结直肠癌药物反应的神经符号智能体框架
neuro-symbolic agent inverse reasoning drug response world model
The authors present a Contextual Invertible World Model that couples a quantitative machine-learning emulator with an LLM reasoning layer, using a curated Sanger GDSC subset of 83 samples. Through inverse reasoning and in-silico CRISPR perturbations it identifies mutant KRAS dominance over the APC/Wnt axis in 5-fluorouracil resistance and a PIK3CA paradox where repair increases chemoresistance.
