AgentIR: Reasoning-Aware Retrieval for Deep Research Agents
AgentIR：面向深度研究智能体的推理感知检索
reasoning-aware retrieval embedding model deep research agents BrowseComp-Plus
AgentIR introduces reasoning-aware retrieval, which jointly embeds an agent's reasoning trace alongside its query, and DR-Synth, a method that synthesizes retriever training data for deep research from standard QA datasets. The resulting AgentIR-4B embedding model reaches 68% accuracy on BrowseComp-Plus with the open-weight Tongyi-DeepResearch agent, versus 50% for conventional embedding models twice its size and 37% for BM25.

τ-Knowledge：评测对话智能体对非结构化知识的运用
agent evaluation unstructured knowledge long-horizon interaction policy compliance

arxiv:2603.04549 arXiv ✓
Adaptive Memory Admission Control for LLM Agents
面向 LLM 智能体的自适应记忆准入控制
memory admission long-term memory LoCoMo interpretable control
A-MAC treats long-term memory admission as a structured decision over five interpretable factors: future utility, factual confidence, semantic novelty, temporal recency and content-type prior, combining lightweight rule-based features with one LLM-assisted utility assessment. On LoCoMo it improves F1 to 0.583 while reducing latency by 31% compared with LLM-native memory systems, with content-type prior the most influential factor.

arxiv:2603.04390 arXiv ✓
A Dual-Helix Governance Approach Towards Reliable Agentic Artificial Intelligence for WebGIS Development
面向 WebGIS 开发的可靠智能体 AI 双螺旋治理方法
agent governance persistent knowledge graph context limits output variance
The dual-helix governance framework reframes agentic failures such as context limits, forgetting, stochasticity and instruction failure as structural problems, using Knowledge, Behavior and Skills tracks plus a persistent knowledge graph that externalizes facts and enforces protocols. A governed agent refactored a legacy WebGIS codebase, roughly halved trial-to-trial output variance relative to static prompting, and avoided common infodemic mapping errors; the work is operationalized in the open-source AgentLoom toolkit.
→ arxiv.org

AILS-NTUA at SemEval-2026 Task 12: Graph-Based Retrieval and Reflective Prompting for Abductive Event Reasoning
AILS-NTUA 在 SemEval-2026 任务 12：面向溯因事件推理的图检索与反思式提示
graph-based retrieval abductive reasoning reflective prompt evolution causal reasoning
The winning three-stage system for SemEval-2026 Task 12 combines graph-based retrieval, LLM-driven abductive reasoning with prompts optimized through reflective prompt evolution, and post-hoc consistency enforcement, ranking first with an accuracy of 0.95. Cross-model error analysis over 14 models finds shared inductive biases toward incomplete causal chains, proximate causes and salient causes.

neuro-symbolic agent hallucination detection fact ledger financial reasoning

RANGER: Sparsely-Gated Mixture-of-Experts with Adaptive Retrieval Re-ranking for Pathology Report Generation
RANGER：面向病理报告生成的稀疏门控混合专家与自适应检索重排序
adaptive retrieval retrieval re-ranking mixture-of-experts pathology reports
RANGER adds a sparsely gated mixture-of-experts decoder with noisy top-k routing and load-balancing regularization to pathology report generation, plus an adaptive retrieval re-ranking module that refines retrieved memory before integration. On PathText it reports BLEU-4 of 0.1435, METEOR of 0.1883 and ROUGE-L of 0.3038, improving over existing approaches.

iAgentBench: Benchmarking Sensemaking Capabilities of Information-Seeking Agents on High-Traffic Topics
iAgentBench：评测信息搜寻型智能体在高热度话题上的理解能力
open-domain QA evidence synthesis sensemaking
iAgentBench is a dynamic open-domain QA benchmark built from real-world attention signals and common user intent patterns, with questions that require combining evidence across multiple sources. Across several LLMs, retrieval improved accuracy but did not reliably resolve the questions, leading the authors to argue that evaluation should focus on evidence use rather than access alone.

Dual-Modality Multi-Stage Adversarial Safety Training: Robustifying Multimodal Web Agents Against Cross-Modal Attacks
双模态多阶段对抗安全训练：增强多模态 Web 智能体抵御跨模态攻击
multimodal web agents cross-modal attacks adversarial training GRPO
DMAST models the interaction between a multimodal web agent and an attacker as a two-player general-sum Markov game and co-trains both players through imitation learning, oracle-guided supervised fine-tuning and GRPO self-play. On out-of-distribution tasks it nearly halves the attack success rate from 41.2% to 21.4% while raising task completion from 6.2% to 10.2%.
