面向大语言模型的离策略价值强化学习
off-policy RL sample efficiency value-based RL replay buffer
ReVal is a Bellman-update-based value RL framework for LLMs that combines stepwise internal-consistency signals with trajectory-level outcome verification, enabling replay-buffer training on past trajectories. SpecEyes: Accelerating Agentic Multimodal LLMs via Speculative Perception and Planning
SpecEyes：通过推测式感知与规划加速智能体式多模态 LLM
agentic depth speculative planning tool-call latency visual tool chains
SpecEyes is a speculative acceleration framework for agentic multimodal LLMs that uses a lightweight, tool-free model as a planner to predict execution trajectories and terminate expensive tool chains early. A cognitive gating mechanism based on answer separability regulates self-verification, and experiments on V* Bench, HR-Bench and POPE show 1.1-3.35x speedup while preserving or improving accuracy by up to 6.7%.
→ arxiv.org

ReqFusion: A Multi-Provider Framework for Automated PEGS Analysis Across Software Domains
ReqFusion：跨软件领域的多提供商 PEGS 自动化分析框架
requirements extraction PEGS prompting multi-provider consensus F1 evaluation
ReqFusion is a multi-provider framework that extracts and classifies software requirements from PDF, DOCX and PPTX documents using OpenAI, Anthropic and Groq models, guided by the PEGS structure. PEGS-guided prompting reached an F1 of 0.88 versus 0.71 for generic prompting, and evaluation on five projects with 1,050 requirements reported a 78% reduction in analysis time.

GTO Wizard Benchmark
GTO Wizard Benchmark：无限注德州扑克智能体评测基准
poker benchmark planning under uncertainty variance reduction partial observability
GTO Wizard Benchmark is a public API and standardized evaluation framework for heads-up no-limit Texas Hold'em that pits agents against the superhuman GTO Wizard AI and integrates AIVAT variance reduction. A zero-shot study of models including GPT-5.4, Claude Opus 4.6, Gemini 3.1 Pro and Grok 4 found clear progress but all models remain far below the benchmark baseline.
