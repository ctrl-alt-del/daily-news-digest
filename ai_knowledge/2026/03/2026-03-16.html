LiteSemRAG: Lightweight LLM-Free Semantic-Aware Graph Retrieval for Robust RAG
LiteSemRAG：面向鲁棒 RAG 的轻量级无 LLM 语义感知图检索
graph RAG semantic graph token embeddings polysemy efficiency
LiteSemRAG builds a heterogeneous semantic graph from contextual token-level embeddings and performs two-step semantic-aware retrieval, using dynamic semantic node construction and an isolated semantic recovery mechanism to handle polysemy. On three benchmarks it reports the best MRR@10 and competitive or better Recall@10 versus LLM-based graph RAG, while consuming zero LLM tokens.

arxiv:2603.15994 arXiv ✓
Selective Memory for Artificial Intelligence: Write-Time Gating with Hierarchical Archiving
面向人工智能的选择性记忆：写入时门控与分层归档
write-time gating memory archiving salience scoring versioning distractor robustness
The paper introduces write-time gating that filters incoming knowledge objects by composite salience scores covering source reputation, novelty and reliability, while version chains preserve prior states. In LLM evaluation without oracle quality labels it reports 100% accuracy versus 13% for ungated stores, and holds 100% at 8:1 distractor ratios where read-time filtering with Self-RAG falls to 0%.

arxiv:2603.15727 arXiv ✓
AgentWorm: Self-Propagating Attacks Across LLM Agent Ecosystems
AgentWorm：跨 LLM 智能体生态的自我传播攻击
agent security self-propagation skill supply chain multi-agent ecosystem attack success rate
AgentWorm is described as the first self-replicating worm attack against a production-scale agent framework, hijacking a victim's core configuration for persistence, executing a payload on each reboot and propagating to newly encountered peers without further attacker intervention. Across five LLM backends, three infection vectors and three payload types it reports a 63% aggregate attack success rate, and the authors find that critical controls able to break the infection loop are not enabled in any observed deployment.

arxiv:2604.16351 arXiv ✓
Training for Compositional Sensitivity Reduces Dense Retrieval Generalization
为组合敏感性训练会降低稠密检索的泛化能力
dense retrieval compositional sensitivity hard negatives late interaction verifier
Across four dual-encoder backbones, adding structure-targeted negatives consistently reduces zero-shot NanoBEIR retrieval, with an 8-9% mean nDCG@10 drop on small backbones and up to 40% on medium ones, while only partially improving pooled-space separation. The authors benchmark verifiers over token-token cosine maps and find that a small Transformer over similarity maps reliably separates structural near-misses under end-to-end training.

arxiv:2603.15797 arXiv ✓
OMNIFLOW: A Physics-Grounded Multimodal Agent for Generalized Scientific Reasoning
OMNIFLOW：面向广义科学推理的物理约束多模态智能体
neuro-symbolic physics reasoning chain-of-thought scientific agents zero-shot generalization
OMNIFLOW is a neuro-symbolic architecture that grounds frozen multimodal LLMs in physical laws without domain-specific parameter updates, projecting high-dimensional flow tensors into topological linguistic descriptors. A physics-guided chain-of-thought workflow injects constraints such as mass conservation and performs iterative verification, and it is evaluated on turbulence, Navier-Stokes and global weather forecasting tasks.

成本与延迟降低 100 倍：基于轻量代理模型的 AI 查询近似性能分析
embedding proxy AI queries semantic filtering cost efficiency benchmark

arxiv:2603.15990 arXiv ✓
W2T: LoRA Weights Already Know What They Can Do
W2T：LoRA 权重早已知道自己能做什么
LoRA weight-space embedding adapter retrieval model metadata
W2T maps each LoRA update to a canonical form via QR decomposition and SVD so equivalent factorizations share one representation, then tokenizes the components and encodes them with a Transformer into a weight-space embedding. Across language and vision LoRA collections it reports strong attribute classification, performance prediction and adapter retrieval without running the base model or accessing training data.

AsgardBench -- Evaluating Visually Grounded Interactive Planning Under Minimal Feedback
AsgardBench：在最小反馈下评估视觉有依据的交互式规划
interactive planning visual grounding embodied benchmark state tracking
AsgardBench evaluates visually grounded interactive planning with 108 task instances across 12 task types, restricting agents to images, action history and lightweight success/failure signals. Controlled variations in object state, placement and scene configuration create conditional branches, and leading vision-language models show sharp performance drops without visual input.

RadAnnotate: Large Language Models for Efficient and Reliable Radiology Report Annotation
RadAnnotate：高效可靠标注放射学报告的大模型框架
