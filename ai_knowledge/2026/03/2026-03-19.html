Semantic Tool Discovery for Large Language Models: A Vector-Based Approach to MCP Tool Selection
面向大语言模型的语义工具发现：基于向量的 MCP 工具选择方法
MCP tool selection dense embeddings tool discovery token efficiency retrieval hit rate
The paper presents a semantic tool discovery architecture that indexes MCP tools with dense embeddings and selects only the most relevant 3-5 tools instead of exposing a full catalog of 50-100+. On a benchmark of 140 queries over 121 tools from five MCP servers it reports a 99.6% reduction in tool-related token consumption, a 97.1% hit rate at K=3 and sub-100ms retrieval latency.

DeepSeek arxiv:2603.19182 arXiv ✓
Box Maze: A Process-Control Architecture for Reliable LLM Reasoning
Box Maze：面向可靠 LLM 推理的过程控制架构
process control boundary enforcement hallucination mitigation adversarial prompting memory grounding
The paper proposes Box Maze, a conceptual process-control architecture that splits LLM reasoning into memory grounding, structured inference and boundary enforcement. In simulation-based tests with n=50 adversarial scenarios across DeepSeek-V3, Doubao and Qwen, the authors report boundary failure rates falling from about 40% under an RLHF baseline to below 1%.

arxiv:2603.19225 arXiv ✓
FinTradeBench: A Financial Reasoning Benchmark for LLMs
FinTradeBench：面向大语言模型的金融推理基准
financial reasoning retrieval-augmented evaluation trading signals evidence selection
FinTradeBench is a 1,400-question benchmark covering NASDAQ-100 stocks over a ten-year window, with fundamentals, trading-signal and hybrid questions plus an expert-reviewed Core400 subset. The authors find all models perform worse on trading-focused questions, that computation and evidence selection drive most failures, and that retrieval helps trading-signal reasoning but not fundamental reasoning.
→ arxiv.org
arxiv:2603.20321 arXiv ✓
GIP-RAG: An Evidence-Grounded Retrieval-Augmented Framework for Interpretable Gene Interaction and Pathway Impact Analysis
GIP-RAG：面向可解释基因互作与通路影响分析的可溯源检索增强框架
biomedical knowledge graph retrieval-augmented generation multi-step reasoning pathway analysis
GIP-RAG combines a gene-interaction knowledge graph built from KEGG, WikiPathways, SIGNOR, Pathway Commons and PubChem with an LLM, retrieving query-relevant subgraphs into structured prompts for stepwise reasoning. It also simulates pathway-level perturbation propagation and is reported to produce consistent, evidence-supported mechanistic explanations.
→ arxiv.org

ItinBench: Benchmarking Planning Across Multiple Cognitive Dimensions with Large Language Models
ItinBench：跨多个认知维度评测大语言模型的规划能力
planning benchmark multi-dimensional reasoning itinerary planning
ItinBench combines route optimization with verbal reasoning in trip-itinerary planning and evaluates models including Llama 3.1 8B, Mistral Large, Gemini 1.5 Pro and the GPT family. It finds LLMs struggle to maintain high, consistent performance when handling multiple cognitive dimensions at once.

The Efficiency Attenuation Phenomenon: A Computational Challenge to the Language of Thought Hypothesis
效率衰减现象：对思维语言假说的计算挑战
emergent communication language of thought multi-agent reinforcement learning
The paper tests whether thought requires a language-like format by having artificial agents develop a communication protocol through multi-agent reinforcement learning. Agents using the emergent protocol were 50.5% more efficient than those forced to use a human-like symbolic protocol.
