ClawGym: A Scalable Framework for Building Effective Claw Agents
ClawGym：构建高效 Claw 智能体的可扩展框架
personal agents synthetic data agent training benchmark workspace state
ClawGym is a scalable framework covering the full lifecycle of Claw-style personal agents, with ClawGym-SynData (13.5K filtered tasks synthesized from persona-driven intents and skill-grounded operations), realistic mock workspaces and hybrid verification. The authors train ClawGym-Agents via supervised fine-tuning on black-box rollout trajectories and explore reinforcement learning with sandbox-parallel rollouts, and release ClawGym-Bench, a 200-instance benchmark calibrated by automated filtering and human-LLM review.

Detecting Clinical Discrepancies in Health Coaching Agents: A Dual-Stream Memory and Reconciliation Architecture
双流记忆与对账架构：检测健康教练智能体中的临床差异
agent memory clinical reconciliation FHIR discrepancy detection longitudinal agents
The paper introduces a Dual-Stream Memory Architecture that keeps a patient's evolving narrative separate from the structured FHIR clinical record, with a Reconciliation Engine that classifies discrepancies by type, severity and involved FHIR resources. Across 26 patients and 675 longitudinal coaching sessions, the engine detected 84.4% of designed clinical discrepancies with 86.7% safety-critical recall, and coupling extraction with reconciliation exposed a 13.6% error cascade traced to clinical details lost during memory extraction.

Hypencoder Revisited: Reproducibility and Analysis of Non-Linear Scoring for First-Stage Retrieval
Hypencoder 再审视：首阶段检索中非线性打分的可复现性与分析
neural retrieval non-linear scoring reproducibility query latency adversarial robustness
This reproducibility study confirms that the Hypencoder, which replaces fixed inner-product scoring with a query-specific q-net generated by a hypernetwork, beats a similarly trained bi-encoder in-domain and out-of-domain, and that its efficient search substantially cuts query latency with minimal loss. Hard-task support is partial (wins on DL-Hard and FollowIR but not TREC TOT), a Faiss bi-encoder pipeline remains faster, and the non-linear scoring shows no consistent adversarial-robustness disadvantage.

arxiv:2604.27143 arXiv ✓
Enhancing Linux Privilege Escalation Attack Capabilities of Local LLM Agents
提升本地 LLM 智能体的 Linux 提权攻击能力
local agents tool-use techniques reflection retrieval-augmented generation offensive security
An empirical study distills six failure modes of small local models on Linux privilege escalation and evaluates chain-of-thought prompting, RAG, structured prompting, history compression and reflective analysis as extensions to hackingBuddyGPT. Under a shared harness the techniques raise Llama3.1 8B and Qwen2.5 7B from 8% to 67% with guidance, matching guided GPT-4o, while Llama3.1 70B reaches 83%; ablations attribute the largest contribution to reflection and identify vulnerability discovery, not exploitation, as the main constraint.

AutoSP: Unlocking Long-Context LLM Training Via Compiler-Based Sequence Parallelism
AutoSP：基于编译器序列并行释放长上下文 LLM 训练
long-context training sequence parallelism activation checkpointing compiler optimization
AutoSP is presented as the first automated solution for optimizing LLM training for longer contexts, compiling models and applying automated sequence parallelism plus long-context-aware activation checkpointing. It increases training context by up to 2.7x on NVIDIA hardware and 2.5x on AMD over competitive hand-written baselines at negligible runtime cost.

Length Value Model: Scalable Value Pretraining for Token-Level Length Modeling
长度价值模型：面向 Token 级长度建模的可扩展价值预训练
generation-length control value estimation token budget reasoning efficiency
LenVM estimates remaining generation length at every decoding step by formulating length modeling as value estimation with a constant negative reward per generated token, yielding annotation-free dense supervision. On LIFEBench-token it raises Qwen2.5-7B-Instruct's exact-length score from 30.9 to 64.8 in one pass and to 83.6 with LCG, and near 200 tokens on GSM8K it retains about 63% Pass@1 versus 6% under a hard token budget.
→ arxiv.org
arxiv:2604.27201 arXiv ✓
Path-Lock Expert: Separating Reasoning Mode in Hybrid Thinking via Architecture-Level Separation
Path-Lock Expert：通过架构级分离区分混合思考中的推理模式
hybrid thinking reasoning leakage architecture-level separation mode routing
Path-Lock Expert replaces each decoder layer's single MLP with two semantically locked experts, one for /think and one for /no_think, while sharing attention, embeddings, normalization and the language-model head, and a deterministic control-token router selects one expert path for the whole sequence. On Qwen3-4B it generates 17x fewer reflective tokens (6.01 to 0.35 per answer) and roughly halves output length while raising /no_think accuracy from 35.33% to 44.67% and holding /think performance.
