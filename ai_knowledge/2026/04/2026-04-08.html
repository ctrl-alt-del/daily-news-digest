PRIME: Training Free Proactive Reasoning via Iterative Memory Evolution for User-Centric Agent
PRIME：通过迭代记忆演化实现免训练主动推理
agent memory experience distillation proactive reasoning training-free adaptation
PRIME is a gradient-free framework that distills multi-turn interaction trajectories into human-readable experiences covering successful strategies, failure patterns and user preferences, then retrieves them to guide later behavior. CLEAR: Context Augmentation from Contrastive Learning of Experience via Agentic Reflection
CLEAR：通过智能体反思的对比经验学习进行上下文增强
context augmentation agentic reflection experience learning contrastive learning task completion
CLEAR uses a reflection agent to contrast past execution trajectories and summarize useful context, then trains a context augmentation model on those summaries and refines it with reinforcement learning from task-execution rewards. On AppWorld it raises task completion from 72.62% to 81.15%, and on a WebShop subset it lifts average reward from 0.68 to 0.74, with code released at awslabs/CLEAR.

When Should a Language Model Trust Itself? Same-Model Self-Verification as a Conditional Confidence Signal
语言模型何时应信任自己？同模型自验证作为条件置信信号
self-verification confidence estimation selective prediction prompt sensitivity
The study compares same-model self-verification against likelihood-based baselines LL-AVG and LL-SUM on ARC-Challenge and TruthfulQA-MC across model families, scales and prompt variants, measuring correctness ranking and abstention quality. It finds the signal is task- and model-dependent: helpful for Phi-2 and Qwen models on ARC-Challenge, but unreliable on TruthfulQA-MC, where LL-SUM often remains the stronger practical baseline.

让 LLM 直接推理稠密地理空间嵌入：DFR-Gemma
dense embeddings latent space alignment geospatial reasoning multimodal tokens zero-shot evaluation

arxiv:2604.07468 arXiv ✓
M-ArtAgent: Evidence-Based Multimodal Agent for Implicit Art Influence Discovery
M-ArtAgent：基于证据的多模态智能体，用于隐性艺术影响发现
evidence chains multimodal agent adversarial falsification knowledge attribution WIB-100
M-ArtAgent treats implicit artistic influence discovery as probabilistic adjudication, using a ReAct-style controller across investigation, corroboration, falsification and verdict phases with prompt-isolated critics and art-history-grounded operators. On the WIB-100 benchmark of 100 artists and 2,000 directed pairs it reaches 83.7% positive-class F1, 0.666 MCC and 0.910 ROC-AUC, with gains persisting after explicit influence phrases are masked.

CROP: Token-Efficient Reasoning in Large Language Models via Regularized Prompt Optimization
CROP：通过正则化提示优化实现 LLM 的 Token 高效推理
prompt optimization token efficiency reasoning traces cost reduction
CROP augments automatic prompt optimization with textual feedback on response length, pushing optimized prompts toward concise reasoning rather than long traces. On GSM8K, LogiQA and BIG-Bench Hard it cuts token consumption by 80.6% while maintaining competitive accuracy with only a nominal decline.

arxiv:2604.07650 arXiv ✓
A Statistical Framework for Auditing Behavioral Dependence and Induced Bias in LLM Judges
审计 LLM 评判器行为依赖与诱导偏差的统计框架
LLM-as-judge behavioral dependence ensemble verification statistical auditing
The authors introduce a statistical framework for auditing hidden behavioral entanglement among black-box LLMs that can arise from shared pretraining data, distillation or alignment and can undermine LLM-as-a-judge and ensemble verification. Across 18 models from six families they find significant entanglement associated with judge over-endorsement bias, and show that de-entangled verifier reweighting beats majority voting in accuracy and precision.
→ arxiv.org
arxiv:2604.07659 arXiv ✓
Efficient and Effective Internal Memory Retrieval for LLM-Based Healthcare Prediction
面向 LLM 医疗预测的高效内部记忆检索
internal memory key-based retrieval clinical prediction activation probing healthcare benchmark
Keys to Knowledge replaces external retrieval in LLM-based healthcare prediction with key-based access to clinical information encoded in the model's parameter space, so retrieval adds no inference-time overhead. Activation-guided probe construction and cross-attention reranking improve retrieval quality, and the method reports state-of-the-art results on four healthcare outcome prediction benchmarks.

MiniMax arxiv:2604.07658 arXiv ✓
Optimal Decay Spectra for Linear Recurrences
线性循环模型的最优衰减谱
long-context retrieval linear recurrences decay spectra architecture-agnostic
The paper links the weak long-range memory of linear recurrent models to their decay spectra and introduces PoST, an architecture-agnostic framework that enforces geometrically spaced log-decay rates and adapts the spectrum to the actual dependency range. Tested at 180M–440M scale on Mamba-2, RWKV-7, RetNet, Gated DeltaNet and Gated Linear Attention, PoST reports zero-shot language-modeling improvements and stronger long-context retrieval for Mamba-2.
