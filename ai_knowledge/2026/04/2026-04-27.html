arxiv:2604.24831 arXiv ✓
FGDM: Reasoning Aware Multi-Agentic Framework for Software Bug Detection using Chain of Thought and Tree of Thought Prompting
FGDM：基于思维链与思维树提示的推理感知多智能体软件缺陷检测框架
multi-agent framework bug detection flow graph similar-bug retrieval tree-of-thought
FGDM is a four-agent framework that converts source code into a flow graph, identifies erroneous segments and generates repaired code, using chain-of-thought and tree-of-thought prompts and a FAISS vector index of similar past bugs and fixes. Across 100 programs from projects including Ansible, FastAPI, Keras, Pandas and SpaCy, it reports mean Levenshtein-distance reductions of 24.33 for Python and 8.37 for C, with cosine similarities of 0.951 and 0.974.
→ arxiv.org
arxiv:2604.24842 arXiv ✓
Co-Director: Agentic Generative Video Storytelling
Co-Director：智能体式生成视频叙事
multi-agent framework video storytelling semantic drift bandit search benchmark
Co-Director is a hierarchical multi-agent framework that formulates generative video storytelling as a global optimization problem, using a multi-armed bandit to identify promising creative directions and a local multimodal self-refinement loop to limit identity drift and preserve sequence-level consistency. The authors also introduce GenAD-Bench, a 400-scenario dataset of fictional products for personalized advertising, and report that Co-Director significantly outperforms state-of-the-art baselines.
→ arxiv.org
arxiv:2604.24698 arXiv ✓
The Chameleon's Limit: Investigating Persona Collapse and Homogenization in Large Language Models
变色龙的极限：探究大语言模型中的角色坍缩与同质化
persona collapse population diversity multi-agent simulation persona fine-tuning
The paper formalizes Persona Collapse, where LLM agents given detailed human profiles cluster into a few response classes rather than covering population diversity, and quantifies it with coverage, uniformity and complexity metrics. Across eight LLMs on personality, moral reasoning and self-introduction tasks, collapse was universal but task-dependent, sampling more personas did not mitigate it, and persona-targeted fine-tuning narrowed the population further.
→ arxiv.org
