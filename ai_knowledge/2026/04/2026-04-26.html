DeepSeek-V4: Towards Highly Efficient Million-Token Context Intelligence
DeepSeek-V4：迈向高效的百万 Token 上下文智能
million-token context mixture-of-experts sparse attention KV cache efficiency open-weight models
DeepSeek released a preview of the V4 series, comprising DeepSeek-V4-Pro (1.6T parameters, 49B activated) and DeepSeek-V4-Flash (284B, 13B activated), both with one-million-token context. The models combine Compressed Sparse Attention with Heavily Compressed Attention, Manifold-Constrained Hyper-Connections and the Muon optimizer, and at 1M tokens V4-Pro needs only 27% of V3.2's single-token inference FLOPs and 10% of its KV cache, with checkpoints released on Hugging Face.

ZenBrain: A Neuroscience-Inspired 7-Layer Memory Architecture for Autonomous AI Systems
ZenBrain：面向自主 AI 系统的神经科学启发七层记忆架构
agent memory memory architecture memory decay LongMemEval memory coordination
ZenBrain is a seven-layer, neuroscience-derived memory architecture for LLM agents that unifies fifteen mechanisms under a single MemoryCoordinator. The authors report that with stronger decay over 60 days most mechanisms become individually critical, and that ZenBrain beats Letta, Mem0 and A-Mem on all nine LongMemEval-500 answer-quality comparisons at a fraction of full-context token cost.

Prism-Reranker: Beyond Relevance Scoring -- Jointly Producing Contributions and Evidence for Agentic Retrieval
Prism-Reranker：超越相关性打分，为智能体检索联合生成贡献说明与证据
agentic retrieval reranking evidence extraction context efficiency knowledge distillation
Prism-Reranker is a family of rerankers built on Qwen3.5 at 0.8B, 2B, 4B and 9B parameters that returns a yes/no relevance verdict plus, when relevant, a contribution statement and a self-contained evidence passage so agents need not dump entire documents into context. The models combine distillation from a commercial reranker API with supervised fine-tuning; applying the recipe to Qwen3-Reranker-4B lifts its average BEIR-QA NDCG@10 by 1.54, and weights, training recipe and evaluation suite are released.

arxiv:2604.23801 arXiv ✓
Domain Fine-Tuning vs. Retrieval-Augmented Generation for Medical Multiple-Choice Question Answering: A Controlled Comparison at the 4B-Parameter Scale
领域微调与检索增强生成在医学多选题问答中的对比：4B 参数规模下的受控实验
domain fine-tuning retrieval-augmented generation medical question answering knowledge in weights controlled comparison
A controlled 2x2 study at the 4B-parameter scale compared domain fine-tuning (Gemma 3 4B vs. MedGemma 4B) with RAG over medical passages on the full MedQA-USMLE four-option test split (1,273 questions, 15,276 calls). Domain fine-tuning gained 6.8 percentage points in majority-vote accuracy over the general baseline (53.3% vs. 46.4%), while RAG produced no statistically significant gain in either model, so weight-encoded domain knowledge dominated context-supplied knowledge at this scale.

arxiv:2604.23802 arXiv ✓
EndoGov: A knowledge-governed multi-agent expert system for endometrial cancer risk stratification
EndoGov：面向子宫内膜癌风险分层的知识治理多智能体专家系统
guideline knowledge graph multi-agent system rule governance clinical risk stratification guideline compliance
EndoGov is a two-tier multi-agent expert system for endometrial cancer risk stratification in which pathology, molecular and clinical agents produce schema-constrained evidence and a governance agent applies an executable rule set backed by an evidence-level-weighted Guideline Knowledge Graph. On TCGA-UCEC (n=541) it reached 0.943 accuracy and 0.973 macro AUC with a 0.93% conditional logic-violation rate among trigger-exposed cases, and hard-path compliance stayed invariant when the LLM backend was swapped.

Structural Enforcement of Goal Integrity in AI Agents via Separation-of-Powers Architecture
通过分权架构对 AI 智能体目标完整性进行结构化强制约束
agent governance separation of powers capability tokens goal drift detection
The paper proposes Policy-Execution-Authorization (PEA), a separation-of-powers architecture that decouples intent generation, authorization and execution into isolated layers connected by cryptographically constrained capability tokens. It adds intent verification, intent lineage tracking, goal-drift detection and an output semantic gate, and outlines a formal verification framework arguing that goal integrity holds even under adversarial model compromise.

arxiv:2604.23887 arXiv ✓
Evaluation of Prompt Injection Defenses in Large Language Models
大语言模型中提示注入防御的评估
prompt injection output filtering security boundary defense evaluation
An adaptive attacker tested nine defense configurations across more than 20,000 attacks and broke every defense that relied on the model to protect itself. Only output filtering implemented in separate application code held, with zero leaks across 15,000 attacks, leading the authors to argue that security boundaries must be enforced outside the model.

arxiv:2606.13686 arXiv ✓
Benchmarking Web Agent Safety under E-commerce Deceptive Interfaces
电商欺骗性界面下的 Web 智能体安全基准测试
web agents deceptive interfaces agent safety multimodal agents prompt constraints
WebDecept is a lightweight, configurable plugin framework that injects seven deceptive interface patterns seen on the open web, including targeted advertisements, domain redirection and shopping manipulation, into existing web environments during task execution. Controlled evaluation of several multimodal web agents found them highly susceptible to multiple classes of deception, and prompt-based constraints were often insufficient to prevent the failures.
