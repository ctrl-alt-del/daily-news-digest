Automatic Ontology Construction Using LLMs as an External Layer of Memory, Verification, and Planning for Hybrid Intelligent Systems

ontological memory knowledge graph construction RDF/OWL SHACL validation neuro-symbolic reasoning

Serialisation Strategy Matters: How FHIR Data Format Affects LLM Medication Reconciliation
序列化策略很重要：FHIR 数据格式如何影响 LLM 药物重整
data serialisation structured context clinical knowledge model scale
The study compares four FHIR serialisation strategies across five open-weight models on 200 synthetic patients and 4,000 inference runs. Clinical Narrative beats Raw JSON by up to 19 F1 points for models up to 8B, while Raw JSON is best at 70B; omission is the dominant failure mode, and smaller models plateau at roughly 7-10 concurrent active medications.

Using Machine Mental Imagery for Representing Common Ground in Situated Dialogue
用机器心理意象表示情境对话中的共同基础
common ground visual scaffolding persistent context situated dialogue IndiRef
The paper identifies representational blur, where similar but distinct entities collapse into interchangeable descriptions once common ground must be kept beyond the immediate context window. Its active visual scaffolding framework incrementally turns dialogue state into a persistent visual history, and on the IndiRef benchmark visual scaffolding adds gains over full-dialog reasoning, with a hybrid multimodal setting performing best overall.

Co-Evolving LLM Decision and Skill Bank Agents for Long-Horizon Tasks
面向长时程任务的决策与技能库智能体协同进化
skill bank skill discovery skill retrieval long-horizon tasks game benchmark
COSPLAY co-evolves an LLM decision agent that retrieves skills from a learnable skill bank with an agent-managed pipeline that discovers, refines and updates reusable skills and their contracts from unlabeled rollouts. Across six game environments, an 8B base model improves average reward by over 25.1% against four frontier LLM baselines on single-player benchmarks while remaining competitive on multi-player social-reasoning games.

Cross-Session Threats in AI Agents: Benchmark, Evaluation, and Algorithms
AI 智能体的跨会话威胁：基准、评估与算法
cross-session threats guardrails attack taxonomy bounded memory
The paper argues that AI-agent guardrails judge each message in isolation, letting an adversary spread a single attack across many sessions so that only the aggregate carries the payload. It introduces CSTM-Bench, with 26 executable attack taxonomies and two 54-scenario splits, and reports that a session-bound judge and a full-log correlator each lose roughly half their attack recall on the cross-session split, while a bounded-memory Coreset Memory Reader keeps its recall on both.
→ arxiv.org
arxiv:2604.21134 arXiv ✓
Beyond Pixels: Introspective and Interactive Grounding for Visualization Agents
超越像素：可视化智能体的内省式与交互式锚定
chart understanding visual grounding structured specification iPlotBench
IVG addresses the pixel-only bottleneck in which vision-language models treat interactive charts as static images and lose the structured specification that encodes exact values. Combining spec-grounded introspection with view-grounded interaction, it reaches the highest QA accuracy of 0.81 on the 500-figure iPlotBench, with a 6.7% gain on overlapping geometries.
→ arxiv.org
arxiv:2604.21139 arXiv ✓
Slot Machines: How LLMs Keep Track of Multiple Entities
老虎机：LLM 如何追踪多个实体
entity tracking residual stream probing factual retrieval conflict detection
Using multi-slot probing, the authors separate a token's residual stream into largely orthogonal current-entity and prior-entity slots. The prior-entity slot supports relational inferences such as entity-level induction and conflict detection, but only the current-entity slot is used for explicit factual retrieval; open-weight models perform near chance on syntax that forces two subject-verb-object bindings onto one token, while recent frontier models can parse it.
