From Recall to Forgetting: Benchmarking Long-Term Memory for Personalized Agents
从回忆到遗忘：面向个性化智能体的长期记忆基准
long-term memory memory consolidation forgetting-aware accuracy personalized agents Memora benchmark
Memora is a long-term memory benchmark built from weeks- to months-long user conversations, covering remembering, reasoning and recommending tasks with automated memory-grounding checks and human evaluation. It introduces Forgetting-Aware Memory Accuracy, which penalizes reliance on obsolete memories; evaluations of four LLMs and six memory agents find frequent reuse of invalid memories and only marginal gains from memory agents.

ChipCraftBrain: Validation-First RTL Generation via Multi-Agent Orchestration
ChipCraftBrain：通过多智能体编排实现验证优先的 RTL 生成
multi-agent orchestration knowledge-augmented generation hierarchical decomposition RTL generation VerilogEval
ChipCraftBrain combines adaptive multi-agent orchestration with symbolic-neural reasoning, retrieval over a 321-pattern knowledge base plus 971 open-source reference implementations, and hierarchical specification decomposition for RTL generation. It reports 97.2% mean pass@1 on VerilogEval-Human and 94.7% on a 302-problem CVDP subset, and generates eight lint-passing RISC-V SoC modules validated on FPGA.

NightFeats @ MMU-RAGent NeurIPS 2025: A Context-Optimized Multi-Agent RAG System for the Text-to-Text Track
NightFeats @ MMU-RAGent NeurIPS 2025：面向文本赛道的上下文优化多智能体 RAG 系统
multi-agent RAG contradiction reconciliation citation grounding context engineering competition benchmark
NightFeats is a three-phase multi-agent RAG system for the MMU-RAGent competition at NeurIPS 2025, separating retrieval, curation and composition with explicit intermediate representations and handoff contracts. It adds temporal-semantic reranking, bounded contradiction reconciliation and citation-preserving composition, and won Best Dynamic Evaluation in the text-to-text track while surpassing proprietary baselines on LLM-as-a-Judge and human Likert evaluations.

A-MAR: Agent-based Multimodal Art Retrieval for Fine-Grained Artwork Understanding
A-MAR：面向细粒度艺术作品理解的智能体多模态检索
reasoning-conditioned retrieval multimodal RAG evidence grounding art understanding ArtCoT-QA
A-MAR conditions multimodal artwork retrieval on an explicit structured reasoning plan that specifies the goals and evidence requirements for each step, enabling targeted evidence selection and step-wise grounded explanations. The authors also introduce ArtCoT-QA, a diagnostic benchmark for multi-step art reasoning, and report gains over static retrieval and strong MLLM baselines on SemArt and Artpedia.

AgenticRecTune: Multi-Agent with Self-Evolving Skillhub for Recommendation System Optimization
AgenticRecTune：面向推荐系统优化的自进化技能库多智能体框架
self-evolving skillhub multi-agent system system configuration A/B testing skill extraction
AgenticRecTune is a five-agent framework, with Actor, Critic, Insight, Skill and Online agents, that optimizes system-level configurations across the pre-ranking, ranking and re-ranking stages of large recommendation pipelines. Its self-evolving Skillhub has the Insight and Skill agents summarize historical experiment results, extract underlying task mechanics and update reusable skills.

ECLASS-Augmented Semantic Product Search for Electronic Components
融合 ECLASS 语义的电子元器件语义产品搜索
dense retrieval semantic product search product embeddings ECLASS ontology re-ranking
The paper evaluates LLM-assisted dense retrieval for industrial electronic-component search and integrates hierarchical ECLASS semantics into product representations. Dense retrieval with re-ranking reaches 94.3% Hit_Rate@5 on expert queries versus 31.4% for BM25, and ECLASS metadata yields consistent gains across configurations.

TriEx: A Game-based Tri-View Framework for Explaining Internal Reasoning in Multi-Agent LLMs
TriEx：解释多智能体 LLM 内部推理的博弈三视角框架
multi-agent reasoning explainability belief states imperfect-information games
TriEx is a tri-view explainability framework for LLM agents in partially observable games, aligning first-person self-reasoning, second-person belief states about opponents and third-person oracle audits. Tests in imperfect-information games reveal systematic mismatches between what agents say, what they believe and what they do.

Bootstrapping Post-training Signals for Open-ended Tasks via Rubric-based Self-play on Pre-training Text
借助预训练文本上的评分标准自博弈，为开放式任务引导后训练信号
rubric generation self-play reward hacking post-training
POP is a self-play framework in which one LLM synthesizes evaluation rubrics alongside each input-output pair, grounded in a content-rich pretraining corpus to reduce reward hacking and prevent mode collapse. On Qwen-2.5-7B it improved both the pretrained base model and the instruction-tuned model across tasks from long-form healthcare QA to creative writing and instruction following.

Rethinking Reinforcement Fine-Tuning in LVLM: Convergence, Reward Decomposition, and Generalization
重新思考 LVLM 中的强化微调：收敛性、奖励分解与泛化
reinforcement fine-tuning tool use reward decomposition generalization bounds
The paper introduces a Tool-Augmented Markov Decision Process framework for multimodal agentic decision-making with bounded-depth tool calls and uses it to analyze reinforcement fine-tuning with verifiable rewards. It proves a convergence rate for GRPO under composite rewards, derives a reward decomposition bound and establishes a PAC-Bayes generalization bound that helps explain out-of-distribution transfer from tool-augmented training.
