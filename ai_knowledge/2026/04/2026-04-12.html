Deep-Reporter: Deep Research for Grounded Multimodal Long-Form Generation
Deep-Reporter：面向有据可依的多模态长文生成的深度研究
agentic search multimodal generation long-form synthesis context management benchmark
Deep-Reporter is a unified agentic framework for grounded multimodal long-form generation that combines agentic multimodal search and filtering, checklist-guided incremental synthesis and recurrent context management, trained on 8K curated agentic traces. The authors also introduce M2LongBench, 247 research tasks across nine domains in a stable multimodal sandbox, and find that post-training can narrow the gap on this difficult task.

Advertising to Agents: Measuring Description-Framing Bias in LLM Tool Selection
向智能体做广告：测量 LLM 工具选择中的描述框架偏差
tool selection description framing registry bias agent advertising preregistered study
A preregistered study built pairs of tool listings differing in praise, a verifiable specification or list order and found stacked praise raised a tool's pick rate by about 43 percentage points, matching or beating a verifiable specification, while the first-listed tool was chosen about 72 points more often. A "Sponsored" label dampened the effect and a system-prompt warning moved one model, but the authors describe the results as provisional until blind phrase ratings are complete.

Do LLMs Build Spatial World Models? Evidence from Grid-World Maze Tasks
大语言模型会构建空间世界模型吗？来自网格迷宫任务的证据
spatial reasoning world models chain-of-thought maze benchmark representation dependence
The study evaluates Gemini-2.5-Flash, GPT-5-mini, Claude-Haiku-4.5 and DeepSeek-Chat on grid-world maze tasks, finding chain-of-thought accuracy of 80-86% on small mazes with tokenized adjacency inputs but only 16-34% with visual grid formats. Despite 96-99% semantic coverage in reasoning traces, models fail to use that understanding for consistent spatial computation, suggesting representation-specific rather than format-invariant spatial reasoning.

arxiv:2604.10604 arXiv ✓
NSFL: A Post-Training Neuro-Symbolic Fuzzy Logic Framework for Boolean Operators in Neural Embeddings
NSFL：面向神经嵌入中布尔运算符的后训练神经符号模糊逻辑框架
boolean retrieval fuzzy logic embeddings neuro-symbolic query optimization
NSFL adapts formal t-norms and t-conorms to neural embedding spaces without retraining, anchoring logical operations on zero-order similarity scores while steering representations with neuro-symbolic deltas, and adds spherical query optimization for real-time retrieval. Across six encoder configurations and two modalities it reports mAP gains up to 81%, plus an additive 20% average and up to 47% boost on encoders already fine-tuned for logical reasoning.

arxiv:2604.10800 arXiv ✓
Verify Before You Fix: Agentic Execution Grounding for Trustworthy Cross-Language Code Analysis
先验证再修复：面向可信跨语言代码分析的智能体执行锚定
agentic validation execution grounding code embeddings cross-language analysis vulnerability detection
The framework runs hybrid structural-semantic detection, execution-grounded agentic validation and validation-aware iterative repair under an invariant that no repair occurs without execution-based confirmation of exploitability, using a universal AST plus fused GraphSAGE and Qwen2.5-Coder embeddings. It reports 89.84-92.02% intra-language detection accuracy, 74.43-80.12% zero-shot cross-language F1 and 69.74% end-to-end vulnerability resolution.

arxiv:2604.10825 arXiv ✓
CheeseBench: Evaluating Large Language Models on Rodent Behavioral Neuroscience Paradigms
CheeseBench：在啮齿动物行为神经科学范式中评估大语言模型
agent benchmark cognitive paradigms zero-shot agents prompt effects interface sensitivity
CheeseBench evaluates six open-weight LLMs on nine rodent behavioral neuroscience paradigms rendered as ASCII text, with the best model reaching 52.6% average success versus 32.1% for random agents and 78.9% for approximate rodent baselines. It finds diminishing returns beyond 7B parameters, that longer context history and chain-of-thought prompting hurt, and that performance ranges from 20% to 57% depending on interface parameters alone.

Specialty-Specific Medical Language Model for Immune-Mediated Diseases
面向免疫介导疾病的专科医学语言模型
clinical NER domain embeddings entity extraction expert annotation medical language model
The authors manually annotated 371 case reports with two clinical specialists across twelve entity classes and compared NER strategies for immune-mediated and infectious disease text. A transformer trained on clinical-domain embeddings reached an F1 of 0.89, outperforming baselines and zero-shot systems, while a prompted LLM baseline performed substantially worse on span-consistent entity boundaries.
