APEX-MEM: Agentic Semi-Structured Memory with Temporal Reasoning for Long-Term Conversational AI
APEX-MEM：面向长期对话 AI 的智能体半结构化记忆与时序推理
conversational memory property graph temporal reasoning retrieval agent append-only storage
APEX-MEM structures conversations as temporally grounded events in a domain-agnostic property graph, stores them append-only to preserve temporal evolution, and uses a multi-tool retrieval agent that resolves conflicting or evolving information at query time. It reaches 88.88% accuracy on LOCOMO question answering and 86.2% on LongMemEval, outperforming session-aware state-of-the-art approaches.

Evo-MedAgent: Beyond One-Shot Diagnosis with Agents That Remember, Reflect, and Improve
Evo-MedAgent：以会记忆、反思与改进的智能体超越一次性诊断
agent memory self-evolution medical agents tool reliability ChestAgentBench
Evo-MedAgent equips a frozen medical agent with test-time inter-case learning through three memory stores: retrospective clinical episodes, an adaptive procedural heuristics bank that evolves via reflection, and a tool reliability controller. On ChestAgentBench it raises multiple-choice accuracy from 0.68 to 0.79 on GPT-5-mini and from 0.76 to 0.87 on Gemini-3 Flash with no training, adding only one retrieval pass and one reflection call per case.

Shuffle the Context: RoPE-Perturbed Self-Distillation for Long-Context Adaptation
打乱上下文：面向长上下文适配的 RoPE 扰动自蒸馏
long context positional robustness self-distillation RoPE RULER
The paper shows long-context adaptation remains brittle because accuracy depends on the absolute placement of relevant evidence, and proposes a regularizer that creates alternative views of a training sequence by perturbing RoPE indices and trains for consistent predictions via self-distillation. It reports up to 12.04% improvement on RULER-64K for Llama-3-8B and 2.71% on RULER-256K for Qwen-3-4B after SFT, plus better length extrapolation.

Modular Continual Learning via Zero-Leakage Reconstruction Routing and Autonomous Task Discovery
通过零泄漏重建路由与自主任务发现实现模块化持续学习
continual learning catastrophic forgetting embeddings novelty detection modular architecture
The paper proposes a modular architecture with task-specific experts and a distributed outlier-based gatekeeper, using a simultaneous pipeline where teacher learning, student distillation and router manifold acquisition run in parallel while raw data is present locally and then deleted for GDPR compliance. A tight-bottleneck autoencoder provides an unsupervised novelty signal in 4096-D LLM embedding space and supports autonomous retrieval of returning manifolds for lifelong learning without redundant modules.

ReviewGrounder: Improving Review Substantiveness with Rubric-Guided, Tool-Integrated Agents
ReviewGrounder：以评分量表引导的工具集成智能体提升评审实质性
rubric-guided review multi-agent framework evidence grounding peer review benchmark
The authors introduce REVIEWBENCH, a benchmark that evaluates review text against paper-specific rubrics derived from official guidelines, paper content and human reviews, and propose ReviewGrounder, a rubric-guided multi-agent framework that separates drafting from grounding. Using a Phi-4-14B drafter and GPT-OSS-120B grounding stage, it outperforms baselines with larger backbones including GPT-4.1 and DeepSeek-R1-670B on alignment with human judgments and rubric-based quality across eight dimensions.

arxiv:2605.04083 arXiv ✓
AsymmetryZero: A Framework for Operationalizing Human Expert Preferences as Semantic Evals
AsymmetryZero：将人类专家偏好操作化为语义评估的框架
semantic evals expert preferences evaluation contracts agentic evaluation LLM juries
AsymmetryZero represents each task as a stable evaluation contract that makes explicit what is graded, how each criterion is judged and how decisions aggregate, executable with Inspect for model-only evaluations and the Harbor Framework for agentic evaluations. A study holding contracts fixed found criterion-level frontier-vs-compact jury agreement of 75.9-89.6%, with compact juries costing roughly 4.2-5.6% of frontier cost and 21.7-27.1% of latency while showing more internal dissent.
→ arxiv.org
arxiv:2604.14121 arXiv ✓
Correct Prediction, Wrong Steps? Consensus Reasoning Knowledge Graph for Robust Chain-of-Thought Synthesis
预测正确、步骤错误？面向稳健思维链合成的共识推理知识图谱
chain-of-thought reasoning traces consensus aggregation knowledge graph trace quality
CRAFT aggregates consensus components shared across multiple candidate reasoning traces to synthesize improved chain-of-thought traces, motivated by evidence that high label accuracy does not guarantee correct intermediate reasoning and that giving the model the correct answer does not consistently improve reasoning quality. It improves label-prediction accuracy on logical and mathematical benchmarks and yields higher-quality post-processed traces under fine-grained evaluation.
