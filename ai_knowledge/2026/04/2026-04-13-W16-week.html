CoSearch: Joint Training of Reasoning and Document Ranking via Reinforcement Learning for Agentic Search
CoSearch：面向智能体搜索的推理与文档排序联合强化学习训练
agentic search joint training document ranking GRPO retrieval bottleneck
CoSearch jointly trains a multi-step reasoning agent and a generative document ranker with GRPO, after a preliminary experiment found up to a 26.8% relative F1 gap between oracle and fixed retrieval across seven QA benchmarks. A semantic grouping strategy clusters sub-queries by token similarity to form valid ranker optimization groups, and a composite reward combines ranking quality with trajectory-level outcomes; gains are consistent on seven single- and multi-hop QA benchmarks.

HiveMind: OS-Inspired Scheduling for Concurrent LLM Agent Workloads
HiveMind：面向并发 LLM 智能体负载的 OS 启发式调度
agent scheduling concurrent agents API rate limits resource efficiency
HiveMind is a transparent HTTP proxy that applies five OS-inspired primitives, including admission control, rate-limit tracking, AIMD backpressure and priority queuing, to concurrent LLM agent workloads without changing agent code. Across 5-50 concurrent agents, uncoordinated runs failed at 72-100% rates while HiveMind cut failures to 0-18% and eliminated 48-100% of wasted compute, adding under 3ms of overhead.

arxiv:2604.12147 arXiv ✓
From Plan to Action: How Well Do Agents Follow the Plan?
从计划到行动：智能体在多大程度上遵循计划？
plan compliance coding agents SWE-bench workflow internalization prompting
The first extensive systematic analysis of plan compliance examines 21,120 SWE-agent trajectories across four LLMs on SWE-bench Verified and SWE-bench Pro under eight plan variations, finding that without an explicit plan agents fall back on incomplete or overfit internalized workflows. A standard plan improves issue resolution, periodic reminders reduce violations, and a subpar plan hurts performance more than no plan at all.
→ arxiv.org

APEX-MEM: Agentic Semi-Structured Memory with Temporal Reasoning for Long-Term Conversational AI
APEX-MEM：面向长期对话 AI 的智能体半结构化记忆与时序推理
conversational memory property graph temporal reasoning retrieval agent append-only storage
APEX-MEM structures conversations as temporally grounded events in a domain-agnostic property graph, stores them append-only to preserve temporal evolution, and uses a multi-tool retrieval agent that resolves conflicting or evolving information at query time. 叙事胜过数字：大语言模型中的可识别受害者效应及其在对齐与推理下的放大
