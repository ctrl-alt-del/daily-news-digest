Memanto: Typed Semantic Memory with Information-Theoretic Retrieval for Long-Horizon Agents
Memanto：面向长时程智能体的类型化语义记忆与信息论检索
agent memory typed semantic memory temporal versioning conflict resolution LongMemEval
Memanto is a universal agent memory layer combining a typed semantic schema with thirteen memory categories, automated conflict resolution and temporal versioning, backed by Moorcheh's index-free information-theoretic search. It reports state-of-the-art 89.8% on LongMemEval and 87.1% on LoCoMo with a single retrieval query and no ingestion cost, surpassing evaluated hybrid graph and vector systems.

抛硬币式评审？LLM 作为评审的可靠性与偏差
LLM-as-a-judge judge reliability position bias evaluation methodology
The study runs repeated identical LLM-as-a-Judge evaluations on 29 tasks with 50 pairwise and 50 pointwise trials per question. arxiv:2604.22076 arXiv ✓
PrivUn: Unveiling Latent Ripple Effects and Shallow Forgetting in Privacy Unlearning
PrivUn：揭示隐私遗忘中的潜在涟漪效应与浅层遗忘
machine unlearning forgetting depth privacy attacks evaluation framework
PrivUn evaluates unlearning robustness through direct retrieval, in-context learning recovery and fine-tuning restoration attacks, adding forgetting scores, association metrics and forgetting-depth assessment. It finds that privacy unlearning propagates along latent gradient-based associations and is often shallow, leaving private information distributed across deep model layers; association-aware coreset selection and multi-layer representational constraints are explored as remedies.

Transient Turn Injection: Exposing Stateless Multi-Turn Vulnerabilities in Large Language Models
瞬态轮次注入：暴露大语言模型无状态多轮交互漏洞
multi-turn attack stateless moderation adversarial robustness session context
Transient Turn Injection is a multi-turn attack that distributes adversarial intent across isolated interactions to exploit stateless moderation, using automated attacker agents. Evaluations across models from OpenAI, Anthropic, Google, Meta and open-source alternatives find wide variation in resilience and surface model-specific vulnerabilities, especially in medical and high-stakes domains.

arxiv:2604.22871 arXiv ✓
AutoRISE: Agent-Driven Strategy Evolution for Red-Teaming Large Language Models
AutoRISE：面向大语言模型红队的智能体驱动策略演化
red-teaming strategy search coding agents jailbreak
AutoRISE searches over executable attack programs rather than individual prompts: a coding agent edits an attack strategy while a fixed evaluation harness scores the resulting attacks and returns diagnostics for the next edit. Evaluated on 11 models from five families across seven jailbreak datasets, it improves average attack success by 17.0 points over the strongest baseline on held-out models in a black-box, inference-only setting.

Same Methods, Different Rankings: Trainable Depth as an Evaluation Variable in Continual Learning
相同方法，不同排名：可训练深度作为持续学习中的评估变量
continual learning catastrophic forgetting evaluation protocol fine-tuning regime
The paper treats the fine-tuning regime, defined by the trainable parameter subspace, as an evaluation variable for continual learning. Across five methods, five trainable-depth regimes, five datasets and eleven task orders per dataset, method rankings are not consistently preserved, and deeper adaptation is associated with larger update magnitudes, more forgetting and a stronger relationship between the two.
