AutoPKG: An Automated Framework for Dynamic E-commerce Product-Attribute Knowledge Graph Construction
AutoPKG：面向电商产品属性知识图谱自动构建的动态框架
knowledge graph construction multi-agent extraction product attributes graph consolidation A/B evaluation
AutoPKG is a multi-agent LLM framework that induces product types and attribute keys on demand, extracts values from text and images, and consolidates updates through a centralized decision agent that keeps a canonical product-attribute graph consistent. On a Lazada catalog it reaches 0.953 weighted knowledge efficiency for product types and 0.531 edge-level F1 for multimodal value extraction, and online A/B tests attribute GMV lifts of 3.81% in Badge, 5.32% in Search and 7.89% in Recommendation.

HiveMind: OS-Inspired Scheduling for Concurrent LLM Agent Workloads
HiveMind：面向并发 LLM 智能体负载的 OS 启发式调度
agent scheduling concurrent agents API rate limits resource efficiency
HiveMind is a transparent HTTP proxy that applies five OS-inspired primitives, including admission control, rate-limit tracking, AIMD backpressure and priority queuing, to concurrent LLM agent workloads without changing agent code. Across 5-50 concurrent agents, uncoordinated runs failed at 72-100% rates while HiveMind cut failures to 0-18% and eliminated 48-100% of wasted compute, adding under 3ms of overhead.

arxiv:2606.05182 arXiv ✓
LANTERN: Layered Archival and Temporal Episodic Retrieval Network for Long-Context LLM Conversations
LANTERN：面向长上下文 LLM 对话的分层归档与时序情景检索网络
agent memory context compaction episodic retrieval long conversations memory benchmark
LANTERN is a lightweight memory layer that archives every conversation turn and restores details lost during context compaction through hybrid retrieval, with no LLM calls and under 25ms of added latency per turn. On 94 multi-turn conversations it recovered 78.3% of facts lost to compaction versus 72.4% for a MemGPT-style baseline, and raised answer accuracy for four production LLMs by 8.4 percentage points on average.

The Consensus Trap: Rescuing Multi-Agent LLMs from Adversarial Majorities via Token-Level Collaboration
共识陷阱：以 token 级协作让多智能体 LLM 摆脱对抗性多数
multi-agent collaboration majority voting adversarial agents token-level fusion robustness
The paper shows majority voting in multi-agent LLM systems collapses when corrupted agents form a local majority, because voting only sees final answers and not flawed intermediate reasoning. It proposes token-level round-robin collaboration that interleaves agents' generation in a shared context, and experiments show it keeps accuracy robust beyond the point where majority voting fails.

Abstain-R1: Calibrated Abstention and Post-Refusal Clarification via Verifiable RL
Abstain-R1：通过可验证强化学习实现校准弃答与拒答后澄清
calibrated abstention verifiable rewards clarification unanswerable queries RLVR
The authors propose a clarification-aware RLVR reward that jointly optimizes explicit abstention and semantically aligned post-refusal clarification on unanswerable queries while still rewarding correct answers on answerable ones. A trained 3B model, Abstain-R1, improves on Abstain-Test, Abstain-QA and SelfAware and reaches unanswerable-query behavior competitive with larger systems including DeepSeek-R1.

mEOL: Training-Free Instruction-Guided Multimodal Embedder for Vector Graphics and Image Retrieval
mEOL：面向矢量图形与图像检索的免训练指令引导多模态嵌入器
multimodal embeddings SVG retrieval instruction-guided embeddings training-free retrieval benchmark
mEOL uses a multimodal LLM to map text, raster images and SVG code into an aligned embedding space, steering embeddings with modality-specific instructions and structural SVG cues instead of learned projection heads or contrastive training. A semantic SVG rewriting module exposes geometric and relational cues, and on a repurposed VGBench text-to-SVG retrieval benchmark the training-free embeddings outperform encoder-based and training-based multimodal baselines.

Graph-of-Agents: A Graph-based Framework for Multi-Agent LLM Collaboration
Graph-of-Agents：基于图的多智能体 LLM 协作框架
multi-agent collaboration graph orchestration agent selection model cards
Graph-of-Agents models multi-agent LLM collaboration as a graph, sampling relevant agents from model cards, ordering them by comparing their responses, passing messages in both directions and pooling results. With a pool of six models it outperforms multi-agent baselines while using only three agents, according to the authors.
